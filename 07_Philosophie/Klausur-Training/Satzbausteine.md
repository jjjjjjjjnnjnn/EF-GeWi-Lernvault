# Satzbausteine (Philosophie Klausur, auswendig)

## Text rekonstruieren
- Der Autor vertritt die These, dass …
- Das zentrale Argument lautet: …
- Als Prämisse setzt er voraus, dass …
- Daraus zieht er die Konklusion, dass …

## erörtern / prüfen
- Für diese Position spricht, dass …
- Dagegen lässt sich einwenden, dass …
- Dieser Einwand trifft / trifft nicht, weil …

## beurteilen
- Nach dem Kriterium der (Freiheit / Gerechtigkeit / Menschenwürde) …
- Im Vergleich zum Utilitarismus / zu Kant …
- Abschließend beurteile ich …, weil …
