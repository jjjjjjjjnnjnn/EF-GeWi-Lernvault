# Kontraktualismus: Hobbes, Locke, Rousseau, Rawls (社会契约论四家系统对照)

> **中文理解**：这是 QP IF5 `Zusammenleben in Staat und Gesellschaft` 中「个体利益与社会契约作为国家正当化原则」这一条，也是**全科最高频考点**。[已验证] 四家的共同问题是：**国家的正当性从何而来？** 答案都是"契约"——但**缔约者是谁、让渡多少权力、能否反抗**，四家答案截然不同。现有笔记只零散涉及 Rousseau，本篇补齐 Hobbes/Locke 的系统对照 + Rawls。[已验证]
>
> **Klausur-Relevanz**：核心对照题（`Vertragstheorien vergleichen`，AFB II）。几乎必考"三栏对照表"：**Naturzustand / Machtabgabe / Widerstandsrecht**。**最大的坑**：只背人名不记差异——德国答题要求**逐条比较**。[已验证]

## 2. 知识结构 (Struktur)

### 2.1 Hobbes（霍布斯）—— 自然状态是"一切人对一切人的战争"

- **Naturzustand**：无公共权力时，人人平等（连最弱者也能杀死最强者），资源稀缺 → 恐惧与竞争 → *bellum omnium contra omnes*（一切人对一切人的战争）；人的生活"孤独、贫穷、肮脏、野蛮而短暂"。[已验证，短引标出处：Leviathan, Kap. 13]
- **契约**：理性者出于**自我保全**，相互约定把**全部权力**让渡给一个绝对主权者（Leviathan）。这是**Unterwerfungsvertrag**——一旦交出，主权者不受契约约束。
- **Machtabgabe**：**完全**让渡。
- **Widerstandsrecht**：**没有**——反抗主权者等于回到战争状态。[已验证]
- 一句话：**用绝对主权换安全。**

### 2.2 Locke（洛克）—— 自然状态有自由，但缺裁判

- **Naturzustand**：并非战争，而是"自由、平等"的状态；但**缺少公正的裁判者**，纠纷无法裁决 → 不便与不安全。[已验证]
- **契约**：人们只让渡**执行自然法的权力**，保留**生命、自由、财产**（life, liberty, property）等自然权利。政府是**受信托者**（trustee）。
- **Machtabgabe**：**有限**让渡。
- **Widerstandsrecht**：**有**——若政府违背信托、侵犯自然权利，人民有权反抗甚至推翻。[已验证]
- 一句话：**用有限主权换法治与权利保障。**

### 2.3 Rousseau（卢梭）—— 公意与人民主权

- **Naturzustand**：最初是和平的"高贵的野蛮人"；是**社会与私有制**带来了不平等与腐败。[已验证]
- **契约**：每个人把自然自由交给**共同体**，换来"自己给自己立法"的**公民自由**；主权属于**人民整体**（Volkssouveränität），由**公意**（Gemeinwille）指引。
- **Machtabgabe**：让渡给**共同体/公意**（不是给某个统治者）。
- **Widerstandsrecht**：不在经典意义上（因为主权者就是人民自己）；关键是**法律是否符合公意**。[已验证]
- 一句话：**用自然自由换道德与公民自由。**

### 2.4 Rawls（罗尔斯）—— 假设契约与无知之幕

- **Naturzustand 的现代版 = Urzustand（原初状态）**：不是历史状态，而是**假设的**选择情境。
- **Schleier des Nichtwissens（无知之幕）**：选择者**不知道**自己的天赋、出身、财富、价值观——保证选择**公平**。[已验证]
- **契约内容（两大原则）**：① **Grundfreiheiten**（基本自由，人人平等）；② **Differenzprinzip**——社会与经济不平等只有在**最有利于最不利者**时才正当。[已验证]
- **Machtabgabe**：不是历史让渡，而是**原则的选择**（正义原则的正当化）。
- 一句话：**用公平程序推出正义原则。**

### 2.5 四家系统对照表（考场直接可用）

| 维度 | Hobbes | Locke | Rousseau | Rawls |
|---|---|---|---|---|
| Naturzustand | 战争（一切人 vs 一切人） | 自由但无裁判 | 和平→被社会腐蚀 | 假设的 Urzustand |
| 契约性质 | 服从契约（真实） | 信托（真实） | 共同体契约（真实） | 假设的（hypothetisch） |
| Machtabgabe | 全部 | 有限（保留自然权利） | 给共同体/公意 | 选择正义原则 |
| 主权归属 | 绝对君主 | 受约束的政府 | 人民（Volkssouveränität） | 公民（公平程序） |
| Widerstandsrecht | 无 | 有 | 隐含（对非公意之法） | 通过正义原则评判制度 |
| 核心价值 | 安全 | 自由与财产 | 平等与公民自由 | 公平与正义 |

## 3. 解题方法 (Methoden)

### 3.1 契约论对照法（Vergleich in drei Dimensionen）

**编号步骤**：
1. **确定比较维度**：固定用 **Naturzustand / Machtabgabe / Widerstandsrecht** 三栏（这是最高频考点）。—— *KLP 工具：`vergleichen`*
2. **逐家重构**：每家写"自然状态图景 → 让渡程度 → 反抗权"。**先重构再比较**。—— *KLP 工具：`rekonstruieren`*
3. **横向填充表格**：同一维度上逐家对照，**禁止**分四段各讲一家。—— *KLP 工具：Methodenkompetenz「结构化、概念一致」*
4. **归入更大语境**：指出这是"国家正当化原则"的不同答案（安全/自由/平等/公平）。—— *KLP 工具：`einordnen`（II）*

> **判据 / 决策点**：题干出现 `vergleichen` → 必须**逐维度**对照；只写"Hobbes 说…Locke 说…"两段 = 比较失败。

### 3.2 契约论论证重构模板（以 Hobbes 为例）

- P1 无公共权力时，人人为自保而竞争，陷入战争状态。
- P2 战争状态威胁每个人的自我保全。
- P3 只有把权力交给一个不可反抗的主权者，才能建立秩序。
- K 所以理性者会缔结服从契约，让渡全部权力。

### 3.3 应用到当代（Anwendung / Aufgabenart II C）

- **案例**：某一政策/制度是否正当？三步：① 用契约论问"若在无知之幕后，人们会同意它吗？"（Rawls 视角）；② 问"它是否侵犯了保留的自然权利？"（Locke 视角）；③ 问"它是否符合公共利益而非私意相加？"（Rousseau 视角）。—— *KLP 工具：`anwenden`（II）*

### 5.3 Musterlösung

**Aufgabe 1**
1. **Darstellung/Rekonstruktion**: These nennen + P1…P2…K…（显式写结构）✓ 得分点
2. **Vergleich (dimensioniert)**: Naturzustand / Machtabgabe / Widerstandsrecht – mindestens drei Dimensionen. ✓ 得分点（逐维度）
3. **Beurteilung (kriteriengeleitet)**: Kriterium = *Freiheit / Sicherheit*; Hobbes opfert Freiheit für Sicherheit, Locke begrenzt die Machtabgabe um der Freiheit willen. ✓ 得分点（点名标准）
4. **Eigenes Urteil**: eigene Gewichtung begründen. ✓

**Aufgabe 2**（结构模板）
1. **Problem**: Sichert Macht oder begrenzt Macht die Freiheit? ✓
2. **Pro (Hobbes)**: Ohne starken Souverän herrscht der Krieg aller gegen alle; Sicherheit ist Bedingung jeder Freiheit. ✓
3. **Contra (Locke)**: Ein unbegrenzter Staat bedroht selbst die Freiheit; deshalb begrenzte Machtabgabe und Widerstandsrecht. ✓
4. **Abwägung**: Beide berufen sich auf Freiheit, verstehen sie aber entgegengesetzt. ✓
5. **Stellungnahme**: Kriterium = *Rechtsstaatlichkeit*; ich folge Locke, weil Sicherheit ohne Kontrolle in Willkür kippt. ✓

**Aufgabe 3**（II C 案例法）
1. **Fall erschließen**: Spannung zwischen Ordnung und Meinungsfreiheit. ✓
2. **Drei Perspektiven anwenden**: Hobbes – legitim, solange der Souverän Ordnung sichert; Locke – illegitim, weil ein Naturrecht (Meinungsfreiheit) verletzt wird → Widerstandsrecht; Rousseau – entscheidend ist, ob das Gesetz dem Gemeinwillen entspricht, nicht dem Partikularinteresse der Regierung. ✓ 得分点（三家区分）
3. **Beurteilung**: Kriterium = *Legitimität der Herrschaft*; Locke und Rousseau liefern die schärferen Maßstäbe. ✓

**Aufgabe 4**（Prüfungsauftrag）
1. **Erläuterung**: Urzustand + Schleier des Nichtwissens → faire Wahl. ✓
2. **Prüfung**: Hinter dem Schleier wählt man nach der Maximin-Regel; daraus folgt das Differenzprinzip. ✓ 得分点（论证链）
3. **Einwand**: Kritik (z. B. Nozick) – das Differenzprinzip verletze Selbst Eigentum/ Freiheit; alternative Risikoeinstellungen möglich. ✓
4. **EF-Anschluss**: Die Frage „Wie weit darf der Staat eingreifen?" (EF IF1) wird bei Rawls zur Frage der Verteilungsgerechtigkeit. ✓ 得分点（接口）

| 类型 | 表现 | 对策 |
