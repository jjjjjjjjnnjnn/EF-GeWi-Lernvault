# Utilitarismus vs. Kant (EF-Ethik最小可用版)

> 中文：功利主义看后果（最大幸福），康德看动机/准则（能不能变成普遍法则）。

| | Utilitarismus | Kant/Pflichtethik |
|---|---|---|
| Prüffrage | Bringt es den größten Nutzen für die meisten? | Kann die Maxime allgemeines Gesetz werden? |
| Blick auf | Folgen | Pflicht/Motiv |
| Stärke | Praktisch, abwägbar | Schützt Würde, keine Verrechnung von Menschen |
| Schwäche | Minderheit kann geopfert werden | Starr, wenig Folgenblick |

## Klausur-Sätze
- Aus utilitaristischer Sicht lässt sich … rechtfertigen, weil …
- Aus kantischer Sicht ist … problematisch, weil die Maxime …
- Abschließend beurteile ich … nach dem Kriterium der Menschenwürde.

Q:: Utilitarismus vs Kant区别？
A:: Folgen/Nutzen vs. Pflicht/Maxime (普遍法则检验）。
