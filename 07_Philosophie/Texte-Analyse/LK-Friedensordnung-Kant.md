# LK: Kants Friedensordnung (康德：持久和平秩序)

> **中文理解**：这是 QP IF5 `Zusammenleben in Staat und Gesellschaft` 中 **LK 专属**条目 `Bedingungen einer dauerhaften Friedensordnung in einer globalisierten Welt`，对应 §4 #18（**标 [LK] 专属**，全库为零）。[已验证] 康德在《永久和平论》（1795）中提出：和平**不是自然状态**，而须**被建立（gestiftet）**；其条件是一组**先决条款（Präliminarartikel）**加三条**正式条款（Definitivartikel）**：**共和制 + 自由国家联盟 + 世界公民权**。[据推断]
>
> **Klausur-Relevanz**：评价题（`Kants Friedensschrift auf aktuelle Konflikte beziehen`，AFB III）。几乎必考：① 重构三条正式条款；② 把条款**对应当代制度**（UN / EU / ICC）；③ 评判其**可行性**。**最大的坑**：把康德当成「世界国家」主张者——他**明确反对世界专制国**，主张**国家联盟（Föderation）**。[据推断]
>
> ⚠️ **GK 不考此条**（LK 专属，且与 HK4「参与当下政治讨论」强关联）。[已验证]

## 2. 知识结构 (Struktur)

### 2.1 康德的出发点：和平须被「建立」

- 中文：霍布斯式**自然状态**是战争状态；和平**不是**自然给定，而是须**被创设（gestiftet）**的法律状态。所以「永久和平」是一个**规范目标 + 制度方案**，不是预言。[据推断]
- 康德不主张道德说教，而是给出**可操作的条款**（条款式写作，仿条约体）。[据推断]

> *Klausur-Satz*: „Nach Kant ist der Friedenszustand kein Naturzustand, sondern muss durch Recht und Institutionen allererst gestiftet werden."

### 2.2 三条正式条款（Definitivartikel）—— 必考骨架

**第 1 条 · 共和制**
- 原文：„Die bürgerliche Verfassung in jedem Staate soll republikanisch sein."（Kant, *Zum ewigen Frieden*, 1795, Erster Definitivartikel）
- 要点：共和制 = ① 自由 ② 一切臣民共立法律（平等）③ 代议制。**关键论证**：在共和制下，**承担战争代价的公民**须同意开战 → 会**谨慎**对待战争。[据推断]
- 当代对应：民主和平论、议会保留宣战权。[据推断]

**第 2 条 · 自由国家的联邦制**
- 要点：国际法应建立在**自由国家的联盟（Föderation）**上，而**非**一个**世界国家**。理由：世界国家会因过大而变成**专制**，且无法保障自由。[据推断]
- 当代对应：国际联盟（Völkerbund）→ 联合国（UNO）；区域一体化（EU）。[据推断]
- ⚠️ **易错**：康德**反对**世界国（Weltstaat），主张**国家联盟**。[据推断]

**第 3 条 · 世界公民权**
- 要点：世界公民权**限于普遍友好（Hospitalität）**——即到访他国不被敌视的权利，**不是**普遍的干涉权或移民权。[据推断]
- 当代对应：人权普遍性、国际刑事法院（ICC）、难民保护（争议）。[据推断]

> *Klausur-Satz*: „Die drei Definitivartikel lauten: republikanische Verfassung, Föderalismus freier Staaten und auf Hospitalität eingeschränktes Weltbürgerrecht."

### 2.3 先决条款与「自然保证」（补充论证）

- **先决条款（六条，节选）**：不得秘密保留战争材料；不得以继承/交换/赠与方式取得国家；**常备军（stehende Heere）应逐步废除**；不得武力干涉他国宪法与政府；不得以卑劣手段（如暗杀、投毒）作战。[据推断]
- **自然保证（Naturgarantie）**：自然通过**人的自利机制**（贸易互利、公共舆论）促成和平——「商业精神」不利于战争。这是**功能主义式**的辅助论证，补足纯道德论证。[据推断]
- **秘密条款**：哲学家应被允许**公开讨论**战争与和平的普遍准则（启蒙的公开性原则）。[据推断]

> *Klausur-Satz*: „Die Präliminarartikel sollen den Krieg beenden, die Definitivartikel den Frieden dauerhaft sichern; die Naturgarantie ergänzt dies durch die fördernde Wirkung von Handel und Öffentlichkeit."

### 2.4 当代对接与批评（AFB III 必备）

| 康德条款 | 当代制度 | 可行性问题 |
|---|---|---|
| 共和制 | 民主宪政、议会宣战权 | 非民主国家仍开战；「共和」≠「民主」 |
| 自由国家联邦 | UNO、EU | 安理会否决权使集体安全失灵 |
| 世界公民权（Hospitalität） | 人权公约、ICC、R2P | 干涉 vs 主权；难民权争议 |
| 常备军废除 | 军控条约 | 军备竞赛持续 |

- **主要批评**：
  1. **乌托邦指责**：无强制执行力的联盟难保和平（现实主义，Morgenthau）。[据推断]
  2. **主权两难**：要和平需让渡主权，但让渡又威胁国家自主。[据推断]
  3. **干涉悖论**：康德禁武力干涉，但**人道干预（R2P）**似乎道义上必要。[据推断]
  4. **结构不对称**：联盟内权力不均（常任理事国）破坏平等前提。[据推断]
- **辩护方向**：康德方案是**调节性理念（regulative Idee）**，非一次性实现；国际法、国际法庭的进展正是「渐近实现」。[据推断]

## 3. 解题方法 (Methoden)

### 3.1 条款重构 + 当代对接（LK 核心方法）

**编号步骤**：
1. 区分**先决条款**与**正式条款**。—— *KLP 工具：`rekonstruieren`（[未获取到] 精确 AFB）*
2. 逐条写出**正式条款**的内容与**理由**。—— *KLP 工具：`analysieren`（II）*
3. 把每条**对应当代制度/事件**。—— *KLP 工具：`anwenden`（II）*
4. 评价对应是否成立、条件是否满足。—— *KLP 工具：`beurteilen`（III）*

> **判据 / 决策点**：题干出现「auf aktuelle Konflikte beziehen」→ 必须**条款 → 当代案例 → 可行性**三段式，不许只复述康德。

### 3.2 立场对照法（Kant vs 现实主义）

- 固定维度：**和平如何可能 / 主体 / 手段 / 主权地位 / 可行性**，逐维度横向对照。—— *KLP 工具：`vergleichen`（II）· `einordnen`（II）*

### 3.3 规范与可行性的双轨评判（AFB III）

- 两问：① 该方案在**规范上**是否值得追求？② 在**经验上**是否可实现（或至少可渐近实现）？—— *KLP 工具：`erörtern`（II–III）· `beurteilen`（III）*
- **标准词库**：Frieden / Gerechtigkeit / Souveränität / Menschenwürde / Realisierbarkeit。

**Aufgabe 3** `[原创]`（Aufgabenart II B）
> „Dauerhafter Frieden lässt sich nur durch eine überstaatliche Ordnung mit Durchsetzungsmacht erreichen." Erörtern Sie diese Aussage, indem Sie Kants Föderationsmodell und eine realistische Gegenposition gegenüberstellen, und nehmen Sie abschließend Stellung.

**Aufgabe 4** `[原创]`（Aufgabenart II C · EF-Anschluss）
> Fallbeispiel: Eine Staatengemeinschaft diskutiert, ob sie in einen innerstaatlichen Konflikt militärisch eingreifen soll, um eine Bevölkerung zu schützen. Analysieren Sie den Fall mit Kants Prinzip der Nichteinmischung und dem Weltbürgerrecht und beurteilen Sie, welches Prinzip Vorrang haben sollte. Beziehen Sie das EF-Problem der Grenzen staatlichen Handelns (IF1) ein.

### 5.3 Musterlösung

**Aufgabe 1**
1. **Rekonstruktion**: Drei Definitivartikel mit Inhalt und Begründung je Artikel nennen。✓ 得分点（条款完整）
2. **Vergleich (dimensioniert)**: Träger der Ordnung / Souveränität / Gefahr / Stabilität – Föderation vs. Weltstaat. ✓ 得分点（逐维度）
3. **Beurteilung (kriteriengeleitet)**: Kriterium = *Realisierbarkeit und Freiheitssicherung*; Kant fürchtet den Weltstaat als Despotie. ✓ 得分点（点名标准 + 康德理由）
4. **Eigenes Urteil**: eigene Gewichtung begründen. ✓

**Aufgabe 2**（结构模板）
1. **Erläuterung**: Friede als zu stiftender Rechtszustand, nicht Naturzustand. ✓
2. **Anwendung auf die UNO**: Art. 1 → demokratische Mitglieder/öffentliche Zustimmung; Art. 2 → UNO als Staatenbund, nicht Weltstaat; Art. 3 → Menschenrechte/Hospitalität. ✓ 得分点（条款对应）
3. **Grenzen**: Vetorecht, fehlende Durchsetzung, Nichtmitglieder. ✓ 得分点（可行性）
4. **Beurteilung**: Kriterium = *Realisierbarkeit*; UNO ist Annäherung, nicht Vollendung. ✓

**Aufgabe 3**（II B 结构模板）
1. **Problem**: Braucht dauerhafter Frieden eine überstaatliche Zwangsordnung? ✓
2. **Pro (Weltstaat-nah)**: Ohne Durchsetzungsmacht bleibt Völkerrecht machtlos; Hobbes-Argument im Weltmaßstab. ✓
3. **Contra (Kant)**: Weltstaat → Despotiegefahr; Föderation freier Staaten wahrt Freiheit. ✓ 得分点（康德核心论证）
4. **Abwägung**: Durchsetzung vs. Freiheit; Zwischenformen (Sanktionen, Gerichte). ✓
5. **Stellungnahme**: Kriterium = *Freiheitssicherung + Realisierbarkeit*; ich halte eine gestufte Föderation für tragfähig. ✓

**Aufgabe 4**（II C 案例法）
1. **Fall erschließen**: Spannung zwischen Nichteinmischung und Schutz der Bevölkerung. ✓
2. **Prinzipien anwenden**: Nichteinmischung (Präliminarartikel) vs. Weltbürgerrecht/Hospitalität (begrenzt). ✓ 得分点（两家区分）
3. **EF-Anschluss**: EF IF1 fragt nach den Grenzen staatlichen Handelns; hier wird daraus die Frage nach den Grenzen der Nichteinmischung. ✓ 得分点（接口）
4. **Beurteilung**: Kriterium = *Menschenwürde*; Kant ist restriktiv, R2P erweitert – begründete Abwägung nötig. ✓

## 6. Fehlerquellen（典型错误三行）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把康德的「国家联盟」当成「世界国家」 | 康德**反对** Weltstaat，主张 **Föderation**（防专制） |
| 知识错 | 说「世界公民权 = 普遍干涉权/移民权」 | 世界公民权**限于 Hospitalität**（友好接待） |
