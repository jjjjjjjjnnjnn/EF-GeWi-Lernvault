# Kuhn: Paradigma und Wissenschaftsrevolution (库恩：范式与科学革命)

> **中文理解**：这是 QP IF6 `Geltungsansprüche der Wissenschaften` 中 `Der Anspruch der Naturwissenschaften auf Objektivität` 一条，对应 §4 #20（IF6 在 S8 前**完全空白**）。[已验证] 库恩（Thomas S. Kuhn）在《科学革命的结构》（1962）中提出：科学发展**不是**波普尔式的「永久批判与反驳」，而是「**常规科学 → 异常 → 危机 → 革命 → 新常规科学**」的循环。两个核心概念是**范式（Paradigma）**与**不可通约性（Inkommensurabilität）**。[已验证]
>
> **Klausur-Relevanz**：核心比较 + 评价题（`Popper und Kuhn vergleichen`，AFB II→III）。几乎必考「**Popper vs Kuhn 对照表**」（划界标准 / 科学图景 / 反例作用 / 客观性 / 知识增长）。**最大的坑**：以为库恩否定科学进步（他并未否认进步，只否认「线性逼近真理」式的进步）；不知道「不可通约性」的准确含义。[据推断]

## 1. 核心概念 (Kernbegriffe)

| 术语 (DE) | 中文 | English | 定义 / 要点 | 备注 |
|---|---|---|---|---|
| Paradigma | 范式 | paradigm | 一个科学共同体在特定时期公认的**范例性成就**（理论 + 方法 + 标准 + 范例） | Kuhn 核心概念 [已验证] |
| Normalwissenschaft | 常规科学 | normal science | 在范式内**解谜（Rätsellösen）**，不质疑范式本身 | 与「批判」相对 [已验证] |
| Anomalie | 异常 | anomaly | 与范式预期不符、又暂时无法消除的现象 | 危机的导火索 [已验证] |
| Krise | 危机 | crisis | 异常积累、范式失效、规则松动的过渡期 | 革命前夜 [已验证] |
| Wissenschaftliche Revolution | 科学革命 | scientific revolution | 旧范式被新范式**整体替换** | 非累积过程 [已验证] |
| Paradigmenwechsel | 范式更替 | paradigm shift | 革命的结果：共同体改宗（Bekehrung） | 常含世代更替 [据推断] |
| Inkommensurabilität | 不可通约性 | incommensurability | 新旧范式的问题、标准、术语含义**无法逐项对译** | 最常被考的概念 [已验证] |

| Lehrbuchwissenschaft | 教科书科学 | textbook science | 教科书把历史重写为线性积累，遮蔽了革命 | Kuhn 的历史批判 [据推断] |
| präparadigmatisch | 前范式阶段 | pre-paradigmatic | 学派林立、尚无公认范式的阶段 | 如古希腊力学 [据推断] |

| Forschungsprogramm | 研究纲领 | research programme | Lakatos 对 Kuhn/Popper 的综合（硬核 + 保护带） | 对 Kuhn 的修正 [据推断] |
| Relativismus-Vorwurf | 相对主义指控 | charge of relativism | 若范式不可通约，则无跨范式的真理标准 | 对 Kuhn 的主要批评 [据推断] |

## 2. 知识结构 (Struktur)

### 2.1 库恩的问题起点：科学史 ≠ 科学教科书

- 中文：波普尔问的是「科学**应当**怎样」（规范/逻辑），库恩问的是「科学**实际**怎样运行」（描述/历史）。库恩发现：真实科学史里，科学家**遇到反例时并不立即放弃理论**——否则根本无法做常规研究。这正是对波普尔「立即证伪」图景的经验反驳。[已验证]
- 库恩的名言式表述（德语译）：„allgemein anerkannte wissenschaftliche Leistungen, die für eine gewisse Zeit einer Gemeinschaft von Fachleuten maßgebende Probleme und Lösungen liefern."（Kuhn, *Die Struktur wissenschaftlicher Revolutionen*, 1962/1976）[据推断：译文措辞] —— 定义的是**范式**。

> *Klausur-Satz*: „Kuhn beschreibt Wissenschaft nicht normativ, sondern historisch: Nicht die Logik der Forschung, sondern die tatsächliche Praxis der wissenschaftlichen Gemeinschaft steht im Zentrum."

### 2.2 库恩的科学发展阶段模型

1. **präparadigmatisch**：无公认范式，多学派竞争。[据推断]
2. **Normalwissenschaft**：范式确立 → 科学家**解谜（Rätsellösen）**，成果是「在既有框架内解决问题」，而非推翻框架。[已验证]
3. **Anomalien**：出现范式无法消化的现象；起初被容忍、被推迟。[已验证]
4. **Krise**：异常积累，规则松动，出现替代方案，共同体信心动摇。[已验证]
5. **Revolution / Paradigmenwechsel**：新范式胜出，旧范式被整体替换；常伴随**代际更替**与「改宗」。[据推断]
6. **新的 Normalwissenschaft**：循环重新开始。[已验证]

- **经典案例**：托勒密地心说 → 哥白尼日心说（Kopernikanische Wende）；燃素说 → 氧化说（Phlogiston → Sauerstoff）；牛顿力学 → 相对论/量子力学。[据推断]

> *Klausur-Satz*: „Nach Kuhn verläuft Wissenschaft in Zyklen: normale Wissenschaft löst Rätsel innerhalb eines Paradigmas, bis sich Anomalien zur Krise verdichten und eine Revolution das Paradigma ersetzt."

### 2.3 不可通约性（Inkommensurabilität）

- 中文：新旧范式之间**不是同一问题的两个答案**，而是**问题、标准、术语含义都变了**。所以「哪个范式更真」无法用中立标准裁决——这构成对科学**客观性主张**的最强挑战。[据推断]
- **例子**：在亚里士多德物理学里「运动」意味着「趋向其自然位置」；在牛顿力学里意味着「速度变化」。同一个词，含义不可对译。[据推断]
- **重要限定**：不可通约 ≠ 完全无法交流；库恩说的是**无法逐项翻译**、**无法用双方共认的算法裁决**，而非「互不理解」。[据推断]

> *Klausur-Satz*: „Inkommensurabilität bedeutet nicht, dass Paradigmen unverständlich sind, sondern dass es keinen neutralen Maßstab gibt, mit dem sich beide zugleich beurteilen ließen."

### 2.4 Popper vs Kuhn —— 逐维度对照（最高频考点）

| 维度 | Popper | Kuhn |
|---|---|---|
| 划界标准 | **可证伪性**（logisch-normativ） | 范式内的**常规科学 vs 危机**（historisch-deskriptiv） |
| 科学图景 | 永久的**猜想与反驳**（Falsifikationsversuche） | 常规科学 → 危机 → 革命 |
| 反例的作用 | 立即构成**证伪**，理论应被放弃 | 常被**容忍**，直到积累成危机 |
| 客观性 | 通过**批判**可达（批判理性主义） | 受**范式**制约（不可通约性） |
| 知识增长 | **线性逼近真理**（近似论） | **断裂式**范式更替（非累积） |
| 科学共同体 | 几乎不讨论 | **核心角色**（范式由共同体承载） |
| 方法论性质 | 规范（应当如何） | 描述（实际如何） |

> *Klausur-Satz*: „Während Popper die Wissenschaft als permanenten Falsifikationsversuch deutet, beschreibt Kuhn sie als Abfolge von Paradigmen, in denen Gegenbeispiele lange toleriert werden."

### 2.5 对库恩的批评（AFB III 必备）

1. **相对主义/非理性主义指控**：若范式不可通约，则范式选择最终靠「改宗」而非理由 → 科学变成社会学。[据推断]
2. **Lakatos**：应区分**进步性**与**退化性**研究纲领，仍可用理性标准评价，避免库恩的相对主义。[据推断]
3. **「范式」概念模糊**：Masterman 统计出 Kuhn 书中「范式」有二十余种用法。[据推断]
4. **历史反例**：科学史中常存在**连续性**（旧范式的许多成果被新范式保留），并非全然断裂。[据推断]
5. **对客观性的辩护**：即使无「上帝视角」，跨范式的**局部比较**与**经验约束**仍然存在，客观性可弱化保留。[据推断]

## 3. 解题方法 (Methoden)

### 3.1 阶段模型重构（Rekonstruktion des Phasenmodells）

**编号步骤**：
1. 确定所给案例处于哪一**阶段**（正常 / 异常 / 危机 / 革命）。—— *KLP 工具：`einordnen`（II）*
2. 写出该阶段的**范式内容**（理论 + 方法 + 标准）。—— *KLP 工具：`rekonstruieren`（[未获取到] 精确 AFB）*
3. 指出**异常**如何累积成**危机**（用具体史实）。—— *KLP 工具：`analysieren`（II）*
4. 说明革命后**哪些概念含义改变**（=不可通约性）。—— *KLP 工具：`analysieren`（II）*
5. 评价该模型能否解释案例。—— *KLP 工具：`beurteilen`（III）*

> **判据 / 决策点**：题干出现 `Phasenmodell`/`Paradigmenwechsel` → 必须**按阶段顺序**写，不许只写「库恩说科学会革命」。

### 3.2 立场对照法（Popper vs Kuhn，逐维度）

**编号步骤**：
1. **固定比较维度**（划界标准 / 科学图景 / 反例作用 / 客观性 / 知识增长）。—— *KLP 工具：`vergleichen`（II）*
2. **先各自重构**（Prämisse → Konklusion），再逐维度对照。—— *KLP 工具：`rekonstruieren`*
3. **归入更大框架**：规范 vs 描述；逻辑 vs 历史。—— *KLP 工具：`einordnen`（II）*
4. 评判谁的图景更贴近科学实践。—— *KLP 工具：`beurteilen`（III）*

> **判据 / 决策点**：只写「Popper 说…Kuhn 说…」两段 = 比较失败；必须**同一维度横向对照**。

### 3.3 文本分析法（Aufgabenart I）

- 三步：① 找出作者对「科学如何发展」的**核心论断**；② 重构其**理由链**（史实 → 结论）；③ 指出**隐含假设**（如「史实描述即规范性结论」）。—— *KLP 工具：`analysieren`（II）*

**Aufgabe 3** `[原创]`（Aufgabenart II C）

Analysieren Sie den Fall mit Kuhns Begriffen Paradigma und Inkommensurabilität und beurteilen Sie, welche Deutung überzeugt.

**Aufgabe 4** `[原创]`（Aufgabenart II B · EF-Anschluss）

### 5.3 Musterlösung

**Aufgabe 1**
1. **Rekonstruktion**: 六阶段模型按序写出（präparadigmatisch → Normalwissenschaft → Anomalie → Krise → Revolution → neue Normalwissenschaft）。✓ 得分点（阶段完整）
2. **Vergleich (dimensioniert)**: Umgang mit Gegenbeispielen – Popper: sofortige Falsifikation; Kuhn: Toleranz bis zur Krise. ✓ 得分点（逐维度）
3. **Beurteilung (kriteriengeleitet)**: Kriterium = *Deskriptive Angemessenheit an die Wissenschaftsgeschichte*; Popper normativ, Kuhn deskriptiv. ✓ 得分点（点名标准）
4. **Eigenes Urteil**: Beide Modelle erfassen unterschiedliche Aspekte; Kuhn beschreibt, Popper bewertet. ✓

**Aufgabe 2**（结构模板）
1. **Problem**: Ist der Paradigmenwechsel rational begründbar? ✓
2. **Pro (Kuhn-nah)**: Inkommensurabilität – kein neutraler Maßstab; Wechsel durch Gemeinschaft/Generationen; „Bekehrung". ✓
3. **Contra**: Lakatos – progressive vs. degenerierende Forschungsprogramme; auch Kuhn nennt Gründe (Problemlösungskraft, Einfachheit). ✓
4. **Abwägung**: „Nicht vollständig algorithmisch" ≠ „beliebig"; Wahl ist begründet, aber nicht zwingend. ✓ 得分点（核心区分）
5. **Stellungnahme**: Kriterium = *Begründbarkeit*; ich halte einen schwachen Rationalismus für tragfähig. ✓

**Aufgabe 3**（II C 案例法）
1. **Fall erschließen**: Streit um „Ersetzen vs. Ergänzen". ✓
2. **Begriffe anwenden**: Paradigma = Grundbegriffe + Standards; Inkommensurabilität prüfen: Haben sich Grundbegriffe geändert? ✓ 得分点（关键检验）
3. **Analyse**: Team A argumentiert kuhnianisch (Begriffswandel), Team B popperianisch/kumulativ (Anschluss). ✓
4. **Beurteilung**: Kriterium = *Tiefe des Begriffswandels*; entscheidend ist, ob gemeinsame Maßstäbe fehlen. ✓

**Aufgabe 4**（Prüfungsauftrag）
1. **Erläuterung**: EF IF2 fragt nach der Reichweite der Erkenntnis; Kuhn radikalisiert dies zur Frage, ob es einen paradigmenunabhängigen Maßstab gibt. ✓ 得分点（接口）
2. **Prüfung**: Aus Inkommensurabilität folgt nicht zwingend Relativismus – möglich ist eingeschränkte Vergleichbarkeit (partielle Übersetzung, empirische Zwänge). ✓ 得分点（论证链）
3. **Einwand/Gegenrede**: Ein Relativist könnte einwenden, „eingeschränkt" sei selbst paradigmaabhängig. ✓
4. **Fazit**: Kriterium = *Konsistenz*; Inkommensurabilität stützt Relativismus, erzwingt ihn aber nicht. ✓

## 6. Fehlerquellen（典型错误三行）
