# Menschenbild-Überblick (人是什么)

> 中文：人=自然存在+能反思、能负责的存在。EF常考两种张力：bestimmt (决定/自然) vs. frei (自由/选择)。

## 两种简化模型（考试够用）
1. **Natur-Modell**：人受本能/环境/基因影响 → 行为可解释 (erklären)。
2. **Freiheits-Modell**：人能 Distanz nehmen, entscheiden, verantworten → 行为要理解+评价 (verstehen/beurteilen)。

## Klausur-Sätze
- Der Text vertritt ein Menschenbild, das … betont.
- Dies zeigt sich daran, dass …
- Kritisch lässt sich einwenden, dass …

## Anki (SR写法)
Menschenbild::Vorstellung davon, was den Menschen ausmacht / 人像
