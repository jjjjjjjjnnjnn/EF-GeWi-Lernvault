# Wissenschaftliche Erkenntnistheorie (科学认识论基础)

> **中文理解**：这是 QP IF6 `Geltungsansprüche der Wissenschaften` 中 `Erkenntnistheoretische Grundlagen der Wissenschaften` 与 `Wissenschaftliche Methode` 两条，对应 §4 #21（IF6 在 S8 前**完全空白**）。[已验证] 它追问：科学知识的**基础**是观察还是理论？科学**推理**有哪几种形式（归纳 / 演绎 / 溯因）？以及科学凭什么主张**客观性**？[已验证]
>
> **Klausur-Relevanz**：核心分析 + 比较题（`Erkenntnistheoretische Grundlagen analysieren`，AFB II）。几乎必考：① 归纳问题的结构（Hume）；② 归纳 / 演绎 / 溯因三形式的**适用范围**；③ 客观性的**可辩护版本**（主体间性、可重复性）与**被质疑版本**（价值中立、观察中立）。**最大的坑**：把 EF 的入门版（「知识来自经验还是理性」）直接搬来当 QP 答案——**同名但深度不同**，QP 必须**结合科学实例**。[已验证]

## 1. 核心概念 (Kernbegriffe)

| 术语 (DE) | 中文 | English | 定义 / 要点 | 备注 |
|---|---|---|---|---|
| Erkenntnistheorie | 认识论 | epistemology | 研究知识来源、范围、证成的学科 | 本课理论哲学主线 |

| Abduktion | 溯因/外展 | abduction | 从结果推**最佳解释** | Peirce；可错 [据推断] |
| Hypothetisch-deduktive Methode | 假说-演绎法 | hypothetico-deductive method | 假说 → 演绎预言 → 检验 | 与 Popper 衔接 [已验证] |

## 2. 知识结构 (Struktur)

### 2.1 科学的认识论基础：经验论 vs 唯理论（QP 深度版）

- 中文：EF 只问「知识从哪来」，QP 要求**落到科学实例**：近代科学革命中，**培根**（Bacon）主张「观察 → 归纳 → 普遍规律」（新工具/实验方法），**笛卡尔**主张「清楚分明的理性原理」为知识地基。二者在科学自我理解中形成持续张力。[已验证]
- **康德的综合**：知识 = **经验材料 + 先天形式**（范畴）；「概念无直观则空，直观无概念则盲」——这为「科学既要观察又要理论」提供了经典辩护。[据推断]

> *Klausur-Satz*: „Während der Empirismus die Erfahrung als Quelle wissenschaftlicher Erkenntnis ansieht, behauptet der Rationalismus, dass sichere Erkenntnis auf Vernunftprinzipien beruht; Kant vermittelt beide, indem er Erkenntnis aus Anschauung und Verstandesbegriffen zusammensetzt."

### 2.2 归纳问题（Humes Problem）

- 中文：归纳**没有逻辑必然性**。「太阳过去每天升起」不**逻辑地**推出「明天必然升起」。所以经验论面临一个内在困难：**经验如何证成超出经验范围的普遍命题？** [已验证]
- 这正是 Popper 转向证伪的起点：既然归纳不能**证实**，就让科学靠**反驳**来推进。[已验证]

> *Klausur-Satz*: „Das Induktionsproblem besteht darin, dass sich aus endlich vielen Einzelbeobachtungen kein allgemeiner Satz logisch ableiten lässt."

### 2.3 科学推理的三种形式

| 形式 | 方向 | 结论性质 | 例 |
|---|---|---|---|
| Deduktion | 普遍 → 个别 | **必然**（保真） | 所有人会死；苏格拉底是人；故苏格拉底会死 [据推断] |
| Induktion | 个别 → 普遍 | **或然**（可错） | 观察 N 只白天鹅 → 「所有天鹅是白的」[已验证] |
| Abduktion | 结果 → 最佳解释 | **或然**（可错） | 地板湿 → 最可能的解释是下过雨 [据推断] |

- **要点**：科学**同时**使用三者——假说来自溯因/创造性猜想，预言靠演绎，普遍规律靠归纳支持（但不可证实）。**不存在唯一一套固定流程**。[据推断]

> *Klausur-Satz*: „Wissenschaftliche Forschung verbindet Deduktion, Induktion und Abduktion; keine dieser Formen allein sichert die Wahrheit einer Theorie."

### 2.4 客观性主张：从强到弱

- **强版本（已被广泛质疑）**：
  - **观察中立**：观察是「纯给定」的。→ 反驳：**观察的理论负荷**（Hanson）——看什么、怎么看，已由理论决定。[据推断]
  - **价值中立**：科学完全不涉及价值。→ 反驳：**研究问题的选择、经费、应用**都含价值判断（Weber 本人也只主张「研究的逻辑」中立）。[据推断]
- **弱版本（可辩护）**：
  - **主体间性**：结果可被他人独立复核。[据推断]
  - **可重复性**：实验可被独立重做。[据推断]
  - **公开的批判程序**：结论须经同行审查（peer review）。[据推断]
- **结论**：科学客观性的可靠内核不是「无主体」，而是「**可被多个主体检验**」。[据推断]

> *Klausur-Satz*: „Ein tragfähiger Objektivitätsbegriff stützt sich nicht auf einen neutralen Beobachter, sondern auf Intersubjektivität und Reproduzierbarkeit."

### 2.5 与 EF（IF2）的深度差异（EF-Anschluss 关键）

| 维度 | EF · IF2 | QP · IF6 |
|---|---|---|
| 问题 | 知识从哪来？（入门） | 科学凭什么有效？（系统） |
| 材料 | 概念辨析 | **科学实例**（实验、理论更替） |
| 结论 | 「经验 vs 理性」二分 | 二分被综合（Kant）、被历史化（Kuhn） |
| 风险 | — | ⚠️ 直接搬 EF 内容 = 深度不足，**扣分** |

> *Klausur-Satz*: „Die Einführungsphase fragt nach den Quellen der Erkenntnis, die Qualifikationsphase nach den Geltungsansprüchen der Wissenschaften – gleiche Stichworte, aber unterschiedliche Tiefe."

## 3. 解题方法 (Methoden)

### 3.1 推理形式判定（Rekonstruktion der Schlussform）

**编号步骤**：
1. 写出**前提**与**结论**。—— *KLP 工具：`rekonstruieren`（[未获取到] 精确 AFB）*
2. 判断方向（个别→普遍 / 普遍→个别 / 结果→解释）。—— *KLP 工具：`analysieren`（II）*
3. 标注结论是**必然**还是**或然**。—— *KLP 工具：`erläutern`（I–II）*
4. 指出**可错点**（归纳跳跃 / 隐含假设）。—— *KLP 工具：`beurteilen`（III）*

> **判据 / 决策点**：题干问「该推理是否可靠」→ 先判**形式**，再判**前提真假**；两者不可混淆。

### 3.2 客观性主张的分层检验

**编号步骤**：
1. 明确被检验的是**哪一版**客观性（观察中立 / 价值中立 / 主体间性）。—— *KLP 工具：`analysieren`（II）*
2. 找**反例或反论**（理论负荷 / 价值渗透）。—— *KLP 工具：`überprüfen`（II–III）*
3. 提出**弱化版**并说明其可靠性来源。—— *KLP 工具：`entwickeln`（III）*
4. 依标准评判。—— *KLP 工具：`beurteilen`（III）*

### 3.3 立场对照法（Empirismus vs Rationalismus，QP 版）

- 固定维度：**知识来源 / 代表 / 科学实例 / 优势 / 弱点**，逐维度横向对照；禁止分段各讲一家。—— *KLP 工具：`vergleichen`（II）· `einordnen`（II）*

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`（Aufgabenart I）
> Rekonstruieren Sie die Argumentation des vorliegenden Textes zu den erkenntnistheoretischen Grundlagen der Wissenschaft in Prämissen und Konklusion. Vergleichen Sie die Position anschließend mit einer rationalistischen Auffassung und beurteilen Sie, welche die Praxis der Naturwissenschaften besser erklärt.

**Aufgabe 2** `[NRW-官方公开]`（Aufgabenart II A）
> „Alle Erkenntnis stammt aus der Erfahrung." Erläutern Sie an diesem Text die These des Empirismus, prüfen Sie sie mit dem Induktionsproblem und entwickeln Sie eine begründete eigene Position.

**Aufgabe 3** `[原创]`（Aufgabenart II B）
> „Wissenschaft ist objektiv, weil ihre Ergebnisse unabhängig vom Forscher überprüfbar sind." Erörtern Sie diese Aussage, indem Sie zwischen starker und schwacher Objektivität unterscheiden und die Theoriebeladenheit der Beobachtung einbeziehen.

**Aufgabe 4** `[原创]`（Aufgabenart II C · EF-Anschluss）
> Fallbeispiel: Ein Team veröffentlicht ein Ergebnis, ein zweites Team kann den Versuch nicht reproduzieren; das erste verweist auf abweichende Messbedingungen. Analysieren Sie den Fall mit den Kriterien Intersubjektivität und Reproduzierbarkeit und beurteilen Sie, was daraus für den Objektivitätsanspruch der Wissenschaft folgt. Beziehen Sie das EF-Problem der Erkenntnisquellen (IF2) ein.

### 5.3 Musterlösung

**Aufgabe 1**
1. **Rekonstruktion**: These nennen + P1…P2…K…（显式写结构）。✓ 得分点
2. **Vergleich (dimensioniert)**: Erkenntnisquelle / Vertreter / wissenschaftliches Beispiel / Stärke / Schwäche – mindestens drei Dimensionen。✓ 得分点（逐维度）
3. **Beurteilung (kriteriengeleitet)**: Kriterium = *Erklärungskraft für die wissenschaftliche Praxis*; Empirismus erklärt Beobachtungsbasis, Rationalismus die Theoriebildung. ✓ 得分点（点名标准）
4. **Eigenes Urteil**: Vermittlung (Kant) begründen. ✓

**Aufgabe 2**（结构模板）
1. **Erläuterung**: Empirismus – Erfahrung als einzige Quelle; Beispiel: Messreihen, Experimente. ✓
2. **Prüfung**: Induktionsproblem – endliche Beobachtungen stützen keinen allgemeinen Satz logisch. ✓ 得分点（核心论证）
3. **Gegenposition**: Rationalismus/angeborene Strukturen; bzw. Popper – Falsifikation statt Verifikation. ✓
4. **Entwicklung eigener Position**: Kriterium = *Begründbarkeit*; Erfahrung notwendig, aber nicht hinreichend. ✓
5. **Fazit**: Empirismus als Basis unverzichtbar, als Alleinanspruch unhaltbar. ✓

**Aufgabe 3**（II B 结构模板）
1. **Problem**: Ist Objektivität durch Überprüfbarkeit definierbar? ✓
2. **Starke Version**: Beobachterneutralität – widerlegt durch Theoriebeladenheit der Beobachtung (Hanson). ✓ 得分点
3. **Schwache Version**: Intersubjektivität + Reproduzierbarkeit – tragfähig, aber fallibel (nicht reproduzierbare Befunde). ✓ 得分点（分层）
4. **Abwägung**: Objektivität als *Verfahrenseigenschaft*, nicht als *Beobachtereigenschaft*. ✓
5. **Stellungnahme**: Kriterium = *Prüfbarkeit*; schwache Objektivität ist verteidigbar. ✓

**Aufgabe 4**（II C 案例法）
1. **Fall erschließen**: Nichtreproduzierbarkeit trotz gleicher Theorie. ✓
2. **Kriterien anwenden**: Intersubjektivität verletzt (kein geteiltes Ergebnis); Reproduzierbarkeit fraglich (Bedingungen strittig). ✓ 得分点（两家标准）
3. **Analyse**: Der Streit zeigt, dass Objektivität ein *Verfahren* ist, das scheitern kann. ✓
4. **EF-Anschluss**: EF IF2 – Erkenntnisquellen; hier wird daraus die Frage, wie weit Erfahrung intersubjektiv kontrollierbar ist. ✓ 得分点（接口）
5. **Beurteilung**: Kriterium = *Kontrollierbarkeit*; Reproduzierbarkeit bleibt regulative Idee. ✓

## 6. Fehlerquellen（典型错误三行）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把「归纳」与「演绎」结论性质混同 | 归纳 = **或然**，演绎 = **必然** |
| 知识错 | 说「经验论反对理性」 | 经验论主张知识**源于经验**，非反对理性 |
| 表达错 | 直接搬 EF 入门内容当 QP 答案 | QP 必须**结合科学实例**（实验、理论更替） |
