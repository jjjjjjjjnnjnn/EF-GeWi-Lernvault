# Verantwortung und Anwendungsethik (责任与应用伦理)

> **中文理解**：这是 QP IF4 `Werte und Normen des Handelns` 中 `Verantwortung in ethischen Anwendungskontexten` 一条，属 §4 #13。[已验证] 把伦理原则用到**具体领域**（环境、医疗、技术）时，冲突才真正显现——此时「责任」成为评价段的核心标准词。KLP 要求「把伦理原则应用到应用语境中并彼此划界」。[已验证]
>
> **Klausur-Relevanz**：评价题（`Verantwortung als Kriterium anwenden`，AFB III）+ 案例分析（`Ethische Prinzipien auf Anwendungsfälle anwenden`，II C）。几乎必考「**原则 → 冲突 → 裁决**」三步推演。**最大的坑**：把「责任」当口号用而不定义。[已验证]

## 2. 知识结构 (Struktur)

### 2.1 责任的结构：三个追问

- 中文：说「某人对某事负责」，必须先答三问：① **向谁**负责（Adressat：他人、社会、后代、自然）？② **依据什么**负责（Norm：义务、后果、契约、德性）？③ **后果归谁**（Zurechnung：主体须有自由与认知能力）？[据推断]
- **关键**：责任以**自由**与**预见能力**为前提——不自由者、无法预见后果者，责任随之减弱（连 IF3 的 Willensfreiheit）。

> *Klausur-Satz*: „Verantwortung lässt sich nur bestimmen, wenn geklärt ist, wem gegenüber, nach welchem Maßstab und für welche Folgen jemand verantwortlich ist."

### 2.2 Weber：责任伦理 vs 信念伦理

- **Gesinnungsethik（信念伦理）**：只看**动机与原则**是否纯洁——「我做了我该做的，后果不由我负责」。[据推断，M. Weber, *Politik als Beruf*]
- **Verantwortungsethik（责任伦理）**：对**可预见的后果**负责——「我必须为我行为的后果担责」。[据推断]
- 关键：这不是「对错」之分，而是**两种责任维度**；成熟行动者**兼取两者**（Weber 本人如此主张）。[据推断]

### 2.3 Jonas：技术时代的责任原理

- 中文：Hans Jonas 在《责任原理》中指出：现代技术的**作用范围与时间跨度**空前——核能、基因技术、气候影响可及**未来世代**。传统伦理（只对同时代、近距离的人负责）不够用了。[据推断]
- **新命令**：「**你的行为须使地球上真正的人类生活得以持续**」（Handle so, dass die Wirkungen deiner Handlung verträglich sind mit der Permanenz echten menschlichen Lebens）。[据推断，Jonas, *Das Prinzip Verantwortung*]
- **Heuristik der Furcht**：因未来不可知，应**优先设想最坏后果**（Vorsorgeprinzip 的哲学根据）。[据推断]

### 2.4 应用领域与典型冲突

| 领域 | 核心冲突 | 常用原则 |
|---|---|---|
| 环境伦理 | 经济发展 vs 代际正义 | Nachhaltigkeit / Vorsorge |
| 医疗伦理 | 患者自主 vs 医生行善 | Autonomie / Fürsorge |
| 技术伦理 (AI) | 效率 vs 隐私/自主 | Menschenwürde / Nichtschaden |
| 气候政策 | 当代福利 vs 后代生存 | Generationengerechtigkeit |

## 3. 解题方法 (Methoden)

### 3.1 三步推演法（原则 → 冲突 → 裁决）

**编号步骤**：
1. **提炼案例的特殊性**：谁受影响？涉及哪些价值？（**先看案例，不先套原则**）。—— *KLP 工具：`analysieren`（II）*
2. **应用原则**：分别用 Utilitarismus / Kant / Tugendethik 或 Verantwortungs-/Gesinnungsethik 分析。—— *KLP 工具：`anwenden`（II）*
3. **暴露冲突**：指出哪两个原则在此**对撞**（如效率 vs 人的尊严）。—— *KLP 工具：`erörtern`（II–III）*
4. **依标准裁决 + 表态**：选定标准（Menschenwürde / Gerechtigkeit / Nachhaltigkeit），给出自己的判断。—— *KLP 工具：`beurteilen`（III）· `Stellung nehmen`（III）*

> **判据 / 决策点**：题干出现 `anwenden` → 必须**具体到案例**；只复述原则不看案例 = 应用失败。

### 3.2 责任三问检查表（评价段专用）

1. **Adressat**：我对谁负责？（同时代人 / 后代 / 自然）
2. **Norm**：依据什么？（义务 / 后果 / 契约 / 德性）
3. **Zurechnung**：我有自由与预见能力吗？
- 三问齐备 → 责任成立；任一缺失 → 责任减弱或转移。—— *KLP 工具：`analysieren`（II）*

### 3.3 文本分析法（Aufgabenart I）

- 三步：① 找出作者主张的**责任主体与对象**；② 重构其理由链；③ 检验隐含前提（如「技术进步必然扩大责任」是否成立）。—— *KLP 工具：`rekonstruieren`（[未获取到] 精确 AFB）*

### 5.3 Musterlösung

**Aufgabe 1**
1. **Darstellung/Rekonstruktion**: These nennen + P1…P2…K…（显式写结构）✓ 得分点
2. **Vergleich (dimensioniert)**: Bezugspunkt (Folgen vs. Gesinnung) / Reichweite (Zeit/Adressat) / Handlungsmaßstab – mindestens zwei Dimensionen. ✓ 得分点（逐维度）
3. **Beurteilung (kriteriengeleitet)**: Kriterium = *Reichweite der Folgen*; 责任伦理适合处理长期、技术性后果，信念伦理保护动机纯洁性。✓ 得分点（点名标准）
4. **Eigenes Urteil**: eigene Gewichtung begründen. ✓

**Aufgabe 2**（结构模板）
1. **Problem**: Bestimmt die Gesinnung oder die Verantwortung für Folgen den moralischen Wert? ✓
2. **Pro (Verantwortungsethik)**: In der technischen Moderne wirken Handlungen weit und lang → Folgenverantwortung ist unverzichtbar. ✓
3. **Contra (Gesinnungsethik)**: Wer nur auf Folgen schaut, kann aus Kalkül Unrecht tun; Prinzipientreue schützt vor Beliebigkeit. ✓
4. **Abwägung**: Beide sind keine Gegensätze, sondern komplementäre Dimensionen. ✓
5. **Stellungnahme**: Kriterium = *Zurechenbarkeit*; ich folge Weber: reife Verantwortung verbindet Gesinnung und Folgenabschätzung. ✓

**Aufgabe 3**（II C 案例法）
1. **Fall erschließen**: Spannung zwischen kurzfristiger sozialer und langfristiger ökologischer Verantwortung. ✓
2. **Zwei Perspektiven anwenden**: Utilitarismus – Abwägung der Gesamtnützlichkeit; Jonas – Verantwortung gegenüber künftigen Generationen wiegt schwer, Heuristik der Furcht gebietet Vorsorge. ✓ 得分点（两家区分）
3. **Beurteilung**: Kriterium = *Generationengerechtigkeit*; die Verantwortungsethik liefert den weiteren Zeithorizont. ✓

**Aufgabe 4**（II C 案例法 · EF-Anschluss）
1. **Fall erschließen**: Eingriff in Freiheit vs. Schutz künftiger Lebensgrundlagen. ✓
2. **Verantwortungsbegriff anwenden**: Adressat = künftige Generationen; Norm = Vorsorge; Zurechnung = Staat kann Folgen voraussehen. ✓ 得分点（三问齐备）
3. **Beurteilung**: Kriterium = *Legitimität staatlichen Handelns*; paternalistischer Eingriff braucht starke Rechtfertigung, hier überwiegt der Schutz Dritter/Ferner. ✓
