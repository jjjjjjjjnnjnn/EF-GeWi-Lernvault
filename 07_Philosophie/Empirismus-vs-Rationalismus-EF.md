# Empirismus vs Rationalismus (经验论 vs 唯理论 · EF 入门版)

> **中文理解**：这是 EF 理论哲学入门（IF2 `Erkenntnis und ihre Grenzen`）里"人类认识的原则与范围"这一条的**核心对照**。它问一个看似简单、实则决定一切的问题：**我们的知识从哪里来？** 唯理论（Rationalismus）说来自理性自身（天赋观念、演绎）；经验论（Empirismus）说来自感官经验（白板、归纳）。EF 只需要你**把两派讲清楚并比较**；QP（IF6）才要求你把这套工具用到**科学实例**上。[已验证]
>
> **Klausur-Relevanz**：这是 Aufgabenart I/II 的**高频对照题**（`Empirismus und Rationalismus vergleichen`，AFB II）。注意：KLP 在 EF 与 QP 两处都出现这个名字——**EF 是入门，QP 是深化**，把 EF 的答案直接搬去 QP 会因深度不足失分。[已验证]

## 2. 知识结构 (Struktur)

### 2.1 唯理论（Rationalismus）—— 知识源于理性

**核心主张**：真正可靠的知识必须**像数学一样**，从自明的原则出发经演绎得出；感官会骗人（例如筷子在水中看起来是弯的），所以感官不能作为知识的最终基础。[已验证]

- **Descartes（笛卡尔）**：方法上的普遍怀疑 → 怀疑一切 → 发现"我思故我在"（*cogito, ergo sum*）不可怀疑 → 以此作为确定性的阿基米德点 → 上帝存在与天赋观念保证清楚分明的认识为真。[已验证]
- **Leibniz（莱布尼茨）**：天赋观念"像大理石的纹路"——不是现成观念，而是心灵**先天的倾向与结构**。[据推断，通行的"大理石"比喻]
- **强项**：能解释**数学与逻辑**的必然性（2+2=4 不靠经验）。
- **弱项**：天赋观念如何被证实？不同文化的观念差异如何解释？

> *Klausur-Satz*: „Der Rationalismus erklärt die Herkunft sicherer Erkenntnis aus der Vernunft selbst, weil nur das Denken von den Täuschungen der Sinne unabhängig ist."

### 2.2 经验论（Empirismus）—— 知识源于经验

**核心主张**：心灵最初是一块**白板**（tabula rasa）；一切观念最终都来自经验（感觉 sensation + 内省 reflection）。没有经验就没有内容。[已验证]

- **Locke（洛克）**：反对天赋观念——如果观念是天生的，那么儿童和"未开化民族"也该有，事实不然。[已验证]
- **Berkeley（贝克莱）**：进一步主张"存在即被感知"（*esse est percipi*）。[已验证]
- **Hume（休谟）**：把经验论推到极端——一切观念都是印象（impressions）的复制品；**因果性不是从经验中读出的**，而只是反复观察养成的**心理习惯**（Gewohnheit）；由此产生**归纳问题**（Induktionsproblem）。[已验证]
- **强项**：符合科学的观察-实验精神；不诉诸神秘的"天赋"。
- **弱项**：无法解释数学必然性；推向极端会导致**怀疑论**（连因果律都可疑）。

> *Klausur-Satz*: „Der Empirismus leitet alle Erkenntnis aus der Erfahrung ab, weil der Verstand nach Locke zunächst eine tabula rasa ist."

### 2.3 康德的综合（Synthese）—— 两派的"第三条路"

康德认为两派各有对错：**内容来自经验，形式来自主体**。名言：*„Gedanken ohne Inhalt sind leer, Anschauungen ohne Begriffe sind blind"*（Kritik der reinen Vernunft）。知识 = 经验材料 + 先天形式（空间、时间、因果范畴）。因此存在**先天综合判断**（synthetisch a priori）：既扩展知识，又具必然性。[已验证]

> *Klausur-Satz*: „Nach Kant entsteht Erkenntnis erst durch das Zusammenwirken von sinnlicher Anschauung und Verstandesbegriffen, weshalb weder reiner Rationalismus noch reiner Empirismus genügt."

### 2.4 四栏对照表（考场直接可用）

| 比较维度 | Rationalismus | Empirismus |
|---|---|---|
| 知识来源 | 理性（Vernunft） | 经验（Erfahrung） |
| 代表 | Descartes, Leibniz, Spinoza | Locke, Berkeley, Hume |
| 认识起点 | 天赋观念 / 自明原则 | tabula rasa / 感官印象 |
| 方法模型 | 演绎（像数学） | 归纳（像实验） |
| 优势 | 解释必然性（数学、逻辑） | 符合科学观察精神 |
| 弱点 | 天赋观念难证实 | 推向极端成怀疑论 |

## 3. 解题方法 (Methoden)

### 3.1 立场对照法（Vergleich in vier Schritten）

**编号步骤**：
1. **确定比较维度**（给定或自选）：知识来源 / 代表 / 方法 / 优势弱点。—— *KLP 工具：`vergleichen` 要求"按维度"*
2. **分别重构**两派的核心论证（P→K），**先重构再比较**。—— *KLP 工具：`rekonstruieren`*
3. **逐维度对照**：写"在 X 维度上，A 主张…，而 B 主张…"。**禁止**分两段各讲一派了事。—— *KLP 工具：Methodenkompetenz「结构化、概念一致」*
4. **归入更大语境**（Einordnung）：指出这是近代认识论的根本分裂，并由康德尝试综合。—— *KLP 工具：`einordnen`（AFB II）*

> **判据 / 决策点**：题干出现 `vergleichen` → 必须**逐维度**对照；只写"笛卡尔说…洛克说…"两段 = 比较失败。

### 3.2 论证重构（Rationalismus/Empirismus 各一条）

- **笛卡尔（唯理论）**：P1 凡可怀疑的都不能作为知识基础。P2 感官与一切外部事物都可怀疑。P3 "我在怀疑"这件事本身不可怀疑。K 所以"我思"是第一个确定点，理性是知识的最终基础。
- **洛克（经验论）**：P1 若观念是天赋的，则人人（含儿童）都应具有。P2 事实上儿童并不具有这些观念。K 所以不存在天赋观念，一切观念来自经验。

### 3.3 怀疑论压力测试（Reichweite 检验）

用怀疑论当"压力测试"：如果感官会骗人（笛卡尔的梦论证），还剩什么可靠？如果因果只是习惯（休谟），科学知识的基础还稳吗？—— 这个方法直接服务于 IF2 的**"认识的范围与界限"**这一条。[已验证]

> Stellen Sie die erkenntnistheoretische Position des folgenden Textes dar und rekonstruieren Sie ihren Argumentationsgang. Vergleichen Sie sie anschließend mit der entgegengesetzten Position (Empirismus bzw. Rationalismus) und beurteilen Sie, welche Position die Reichweite menschlicher Erkenntnis besser erklärt. **Aufgabe 3** `[原创]`（Aufgabenart II C）

Analysieren Sie den Streit, ordnen Sie beide Positionen in Rationalismus bzw. Empirismus ein und beurteilen Sie, wer das bessere Argument hat.

**Aufgabe 4** `[NRW-改编]`（Aufgabenart II B · EF-Anschluss）

### 5.3 Musterlösung

**Aufgabe 1**
1. **Darstellung**: Position = Empirismus (oder Rationalismus, je nach Material) + Kernthese in einem Satz. ✓
2. **Rekonstruktion**: P1… P2… K…（显式写 Prämisse/Konklusion）✓ 得分点
3. **Vergleich (dimensioniert)**: Tabelle mit Quelle / Methode / Stärke / Schwäche; mindestens drei Dimensionen. ✓ 得分点（逐维度）
4. **Beurteilung (kriteriengeleitet)**: Kriterium = *Erklärungsreichweite*. Empirismus erklärt Naturwissenschaft gut, Mathematik schlecht; Rationalismus umgekehrt. ✓ 得分点（点名标准）
5. **Eigenes Urteil**: Kant-Synthese als Ausweg nennen; eigene Position begründen. ✓

**Aufgabe 2**（结构模板）
1. **Problem**: Herkunft aller Erkenntnis aus der Erfahrung? ✓
2. **Pro (Empirismus)**: Locke – tabula rasa; ohne Sinneseindruck kein Inhalt. ✓
3. **Contra (Rationalismus)**: mathematische Sätze sind notwendig und allgemein, nicht durch einzelne Beobachtungen erreichbar; Descartes' cogito als erfahrungsunabhängige Gewissheit. ✓
4. **Abwägung**: Die Aussage gilt für empirische Inhalte, nicht für formale Wahrheiten. ✓
5. **Stellungnahme**: Kants Unterscheidung a priori / a posteriori löst die Einseitigkeit. ✓

**Aufgabe 3**（II C 案例法）
1. **Fall erschließen**: Streit um die Herkunft mathematischer Erkenntnis. ✓
2. **Einordnung**: Tom = Empirismus (Zählen als Erfahrung); Lena = Rationalismus (Notwendigkeit der mathematischen Wahrheit). ✓ 得分点（归类）
3. **Analyse**: Toms Zählen erklärt, wie wir den *Satz kennenlernen*, aber nicht, warum er *notwendig* gilt. ✓
4. **Beurteilung**: Kriterium = *Notwendigkeit*. Lena hat im Kern recht, wenn auch das "ohne jede Erfahrung" zu stark ist; Kants synthetisch a priori vermittelt. ✓

## 6. Fehlerquellen（典型错误三行）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 以为"经验论 = 反对理性" | 经验论**不否认理性**，只主张**知识内容源于经验**；理性负责加工 |
| 知识错 | 把 `a priori`（独立于经验）与 `synthetisch a priori` 混为一谈 | a priori 只讲"不靠经验"；synthetisch a priori 还要求"扩展知识" |
| 表达错 | 比较题写成两段独立介绍，不做逐维度对照 | 用"在 X 维度上，A…而 B…"句式，每个维度一段 |
