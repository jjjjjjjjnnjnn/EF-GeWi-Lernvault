# Popper: Falsifikation und Abgrenzung (波普尔：证伪与划界)

> **中文理解**：这是 QP IF6 `Geltungsansprüche der Wissenschaften` 的核心考点，而 IF6 是四个 QP IF 中**唯一笔记完全为零**的一个，约占 Abitur 题材 1/4。[已验证] 波普尔（Karl Popper）回答的是**划界问题（Abgrenzungsproblem）**：什么才算**科学**？他的答案惊人：科学不是"能被证实的"，而是"**能被证伪的**"。[已验证]
>
> **Klausur-Relevanz**：核心论证题（`Popper's Falsifikationskriterium rekonstruieren und beurteilen`，AFB II→III）。几乎必考：① 重构证伪的逻辑结构（modus tollens）；② 用它判断一个命题是否科学；③ 与 Kuhn 比较。**最大的坑**：把"证伪"当成"证明某理论是错的"。**证伪不是证明错误，而是提供一个可以被检验推翻的结构。** [已验证]

## 2. 知识结构 (Struktur)

### 2.1 划界问题：为什么"可证实"不行？

Popper 的问题起点是：**归纳不能证实普遍命题。** 无论观察多少只白天鹅，都不能推出"所有天鹅都是白的"——只要一只黑天鹅就推翻它（Hume 的归纳问题）。所以"科学 = 被证实的知识"这条路走不通。[已验证]

Popper 的转向：**科学的力量不在"能被证实"，而在"能被证伪"。** 一个理论越是**冒险**（排除的可能性越多），它越有科学价值；一个什么都能解释的理论（如占星术、某些精神分析）反而**不科学**。[已验证]

> *Klausur-Satz*: „Nach Popper ist ein Satz genau dann wissenschaftlich, wenn er prinzipiell durch Erfahrung falsifiziert werden kann; nicht die Verifizierbarkeit, sondern die Falsifizierbarkeit ist das Abgrenzungskriterium."

### 2.2 证伪的逻辑结构（modus tollens）

- 中文：证伪是**演绎**的——从理论 T 演绎出预言 P；若观察结果与 P 矛盾，则 T 被证伪。这是**有效的演绎推理**（modus tollens），不同于归纳。[已验证]
- 形式：P1 若 T 为真，则 P 必然发生。P2 观察显示非 P。K 所以 T 为假。
- **关键例子**：爱因斯坦的广义相对论预言"光线在引力场中弯曲"——如果 1919 年日食观测**没有**看到弯曲，理论就被推翻。正是这种**可被推翻的风险**使它成为科学。[已验证]
- **反例**：一个"什么都能解释"的理论（无论发生什么都能自圆其说）**不可证伪**，因此不是科学。

> *Klausur-Satz*: „Das Falsifikationsschema folgt dem Modus tollens: Wenn aus der Theorie T die Prognose P folgt und die Beobachtung non-P ergibt, ist T widerlegt."

### 2.3 假说-演绎法（hypothetisch-deduktive Methode）四步

1. **Problem** → 2. **Hypothese/Vermutung**（大胆猜想）→ 3. **Deduktion** 出可检验的预言 → 4. **Prüfung/Falsifikationsversuch**（严格检验，试图推翻）。
- 通过的假说**不是被"证实"**，而只是**暂时"经受住检验"**（bewährt）——它随时可能被未来的反例推翻。[已验证]
- 因此科学知识是**暂时的、可错的**（fallibel），永远开放于修正。

### 2.4 对 Popper 的批评（AFB III 必备）

1. **Duhem-Quine 问题**：一次观察与预言矛盾时，不一定是**理论**错——也可能是**辅助假设**或测量装置错。理论总是作为整体被检验，无法孤立地证伪。[已验证]
2. **Kuhn 的批评**：实际科学史中，科学家遇到反例时**往往不立即放弃**理论（否则无法做常规科学）；范式更替是**社会-历史过程**，不是单个反例的裁决。[已验证]
3. **Feyerabend 的批评**：科学史上"怎么都行"（anything goes），不存在唯一的方法规则。[据推断]
4. **可证伪性过高**：若按严格标准，许多公认的科学理论（如进化论的部分命题）也难说可证伪；而某些伪科学反而"看似可证伪"。[据推断]

## 3. 解题方法 (Methoden)

### 3.1 证伪结构重构（Rekonstruktion des Falsifikationsschemas）

**编号步骤**：
1. 写出理论 **T** 及其内容。—— *KLP 工具：`rekonstruieren`*
2. 演绎出可观察的**预言 P**。—— *KLP 工具：`analysieren`*
3. 写出**反例陈述**（Basissatz: non-P）。—— *KLP 工具：`analysieren`*
4. 用 **modus tollens** 得出结论：T 被证伪。—— *KLP 工具：`anwenden`*
5. 区分"**逻辑上被证伪**"与"**科学家实际放弃**"（后者涉及辅助假设、范式）。—— *KLP 工具：`beurteilen`（III）*

> **判据 / 决策点**：题目要求"判断某命题是否科学" → 只问一件事：**它原则上能否被经验推翻？** 能 = 科学；不能 = 非科学。

### 3.2 划界标准应用（Anwendung des Abgrenzungskriteriums）

- 提问模板：**"什么样的观察结果会推翻它？"**
  - 若答案是"没有任何观察能推翻它" → 不可证伪 → 非科学。✓
  - 若答案是"某个具体观察" → 可证伪 → 科学（至少形式上是）。✓

### 3.3 立场对照（Popper vs Kuhn）—— 统一维度

| 维度 | Popper | Kuhn |
|---|---|---|
| 划界标准 | 可证伪性 | 范式内的常规科学 vs 危机 |
| 科学图景 | 永久的批判、猜想与反驳 | 常规科学 → 危机 → 革命 |
| 反例的作用 | 立即构成证伪 | 常被容忍，直到积累成危机 |
| 客观性 | 通过批判达成 | 受范式制约（不可通约性） |
| 知识增长 | 线性逼近真理 | 断裂式范式更替 |

> *Klausur-Satz*: „Während Popper die Wissenschaft als permanenten Falsifikationsversuch deutet, beschreibt Kuhn sie als Abfolge von Paradigmen, in denen Gegenbeispiele lange toleriert werden."

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`（Aufgabenart I）
> Stellen Sie das Falsifikationskriterium Poppers dar und rekonstruieren Sie das zugehörige Argumentationsschema in Prämissen und Konklusion. Vergleichen Sie es anschließend mit dem Verifikationsideal und beurteilen Sie, ob die Falsifizierbarkeit ein tragfähiges Abgrenzungskriterium ist.

**Aufgabe 2** `[NRW-官方公开]`（Aufgabenart II B）
> „Eine Theorie, die durch keine mögliche Beobachtung widerlegt werden kann, ist keine wissenschaftliche Theorie." Erörtern Sie diese Aussage am Beispiel einer Naturwissenschaft und einer Pseudowissenschaft.

**Aufgabe 3** `[原创]`（Aufgabenart II C）
> Fallbeispiel: Eine Gruppe behauptet, eine bestimmte „Energie" beeinflusse das Wetter, und erklärt jede Abweichung damit, dass die Energie „eben anders wirke". Ein Physiker wendet ein, die These sei gar nicht überprüfbar. Analysieren Sie den Fall mit Poppers Abgrenzungskriterium und beurteilen Sie, wer im Recht ist.

**Aufgabe 4** `[NRW-改编]`（Aufgabenart I · EF-Anschluss）
> Erläutern Sie, wie Poppers Induktionskritik an das EF-Problem der Erkenntnisquellen (Empirismus) anknüpft, und beurteilen Sie mit dem Duhem-Quine-Einwand, ob sich einzelne Theorien überhaupt eindeutig falsifizieren lassen.

### 5.3 Musterlösung

**Aufgabe 1**
1. **Darstellung**: Falsifizierbarkeit als Abgrenzungskriterium; Verifikation unmöglich wegen Induktionsproblem. ✓
2. **Rekonstruktion (modus tollens)**: P1 若 T，则 P。P2 观察到 non-P。K T 被证伪。✓ 得分点（写对逻辑形式）
3. **Vergleich**: Verifikationsideal (Induktivismus) – 试图用正面实例确证；Popper – 只承认反驳的证明力（Asymmetrie von Verifikation und Falsifikation）。✓
4. **Beurteilung (kriteriengeleitet)**: Kriterium = *Konsistenz / Anwendbarkeit*; 优点：给科学清晰界限；弱点：Duhem-Quine（无法孤立证伪）、伪科学也常"看似可证伪"。✓ 得分点（点名标准 + 批评）
5. **Eigenes Urteil**: Kriterium ist notwendig, aber nicht hinreichend. ✓

**Aufgabe 2**（结构模板）
1. **Problem**: Was unterscheidet Wissenschaft von Pseudowissenschaft? ✓
2. **Pro**: Poppers Kriterium – Falsifizierbarkeit; Beispiel: Relativitätstheorie (riskante Prognose) vs. Astrologie (deutet alles). ✓
3. **Contra**: Duhem-Quine – Theorien werden im Verbund geprüft; "Nichtfalsifizierbarkeit" kann auch an Hilfsannahmen liegen. ✓
4. **Abwägung**: Das Kriterium ist ein starkes, aber nicht alleiniges Werkzeug. ✓
5. **Stellungnahme**: Ich halte es für unverzichtbar, weil es dogmatische Immunisierungsstrategien aufdeckt. ✓

**Aufgabe 3**（II C 案例法）
1. **Fall erschließen**: Eine These, die jede mögliche Beobachtung absorbiert. ✓
2. **Kriterium anwenden**: Frage: „Welche Beobachtung würde sie widerlegen?" Antwort: keine → nicht falsifizierbar → nach Popper nicht wissenschaftlich. ✓ 得分点（关键提问）
3. **Analyse**: Die „Energie"-These ist immun gegen Gegenbeispiele; sie erklärt im Nachhinein alles (ad hoc). ✓
4. **Beurteilung**: Kriterium = *Prüfbarkeit*; der Physiker hat mit Popper recht. ✓

## 6. Fehlerquellen（典型错误三行）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把"证伪（Falsifikation）"当"证明错误" | 证伪 = 提供**可被推翻**的结构；被证伪才叫错误 |
| 知识错 | 说"Popper 认为科学靠归纳积累" | Popper **反对归纳**；科学靠**猜想与反驳** |
| 表达错 | 只写"Popper 说可证伪"，不写 modus tollens 结构 | 必须显式写 P1/P2/K 的演绎形式 |
