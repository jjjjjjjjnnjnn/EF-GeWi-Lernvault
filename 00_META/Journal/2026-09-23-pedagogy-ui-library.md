# 2026-09-23 无痛自然习得教育组件库与 AI 助教全闭环集成（`[App] c6402c1`）

## 背景与教育内核

落实用户提出的“深挖教育方面，以无痛、自然学会为核心，针对不同学科采用不同呈现和学习方式”的战略要求，克服传统学习中的外在认知负荷过载、下笔空白恐惧症与虚假熟练度陷阱：

1. **认知阶梯式渐进释放 (Micro-Scaffolding)**：将德语高分长句、辩证价值判断解构为可直观插拔拼装的模块；
2. **双重编码 (Dual Coding)**：动态旋转天平视觉、高光划词论证树，图文互证；
3. **学科差异化呈现 (Disciplinary Modalities)**：为文科专属设计高频突破口。

## 核心实现

1. **`SatzbauLego.tsx`（句式积木组件）**：
   - 4 大卡槽（出处 + 分析性动词 + 论据手法 + 效果/结论）；
   - 即插即拔磁吸积木库，语法自动规整大写与标点；
   - 预设德语 Sachtextanalyse、SoWi 不平等模型及哲学康德道义论全真题型；
   - 支持考纲标准度校验、一键复制与错题标注。
2. **`BalanceBoard.tsx`（辩证天平组件）**：
   - 原生 SVG 动态天平梁，Neigungswinkel 随 Pro/Contra 权重差值动态平滑倾斜（0.4s cubic-bezier 缓动）；
   - 核心价值准则轴选择（如自由 vs 公平、效率 vs 伦理）；
   - 依据权重差值与准则自动合成标准 3 句式 `Sachurteil / Werturteil`（满足 NRW 考纲算子 beurteilen / bewerten 要求）。
3. **`TextHighlighter.tsx`（荧光标注解构画板）**：
   - 4 色专属高光笔（🟢论点、🟡论据、🔴修辞、🔵关联词）交互划词；
   - 右侧实时聚类生成论证骨架树，并自动合成分析陈述句雏形。
4. **AI 助教工作台全闭环集成 (`Tutor.tsx`)**：
   - 助教顶栏增设「句式积木」、「辩证天平」、「文本解构」一键抽屉；
   - 拼装或裁决成果支持一键 `setInput(...)` 填入聊天输入框，向 AI 助教发起深度推演与追问。
5. **单元测试与构建验证**：
   - 编写 `pedagogy.test.tsx` 8 项全真交互单测；
   - 41 个测试套件，242 项测试 100% 全绿，`npm run build` 耗时 6.23s 零错误。
