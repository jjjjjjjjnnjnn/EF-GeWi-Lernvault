# 2026-10-09 工作日志：知识图谱降噪、抽屉四维关闭与导航消冗

## 1. 任务背景与核心突破

根据实机界面截图与体验诊断（存在功能重复、右侧研习抽屉无法关掉、顶部导航层层套娃挤压视窗、画布节点物理碰撞卡片重叠、背景残影噪声感严重），本轮工作进行了针对性架构精简与交互优化：

1. **彻底解决右侧研习抽屉关闭问题（四维关闭闭环）**：
   - **再次点击同一节点关闭**：`setSelectedNodeId` 升级为优雅的 toggle 状态反选逻辑；
   - **点击画布空白区域关闭**：SVG 背景 `<rect>` 绑定清空选中，且全局画布轻点手势（欧氏位移 < 6px）自动检测并退出选中；
   - **点击右上角小叉关闭**：关闭按钮注入 `e.stopPropagation()` 与 `data-testid="skill-tree-drawer-close"`；
   - **按 ESC 键关闭**：注册全局 `keydown` 监听器，按 `Escape` 键一秒收起研习面板。
2. **删除全局顶栏重复的技能树功能**：
   - 从 `AppHeader.tsx` 中剔除冗余的「技能树 (`Skill-Tree`)」按钮，消除全局层与学科工作区「0. 知识图谱」的功能套娃与心智负担。
3. **消除 80% 画布噪点（锁定节点极大轻量化）**：
   - 对未解锁（`isLocked` 且非聚焦/未悬停/未选中）的静默节点，**彻底隐藏 196px × 58px 的长方形白底卡片与引力桥梁**，仅在星空轨道上渲染极简精致的纯色小星体灰点（Orb）；
   - 用户鼠标滑过（hover）、点击选中或处于因果链聚焦时，完整学术白卡片与因果角标才平滑浮现；
   - 在 DOM 树中保留隐藏文本节点，兼顾无障碍屏幕阅读器与测试断言契约。
4. **根治相邻卡片重叠互压（径向交错与引力半径升级）**：
   - 升级 `engine/skillTree.ts` 中的 `computePlanetaryRadialLayout`；
   - 将同心轨道初始半径从 180 增至 210，轨道步长从 130 增至 160；
   - 对同扇区分桶相邻节点注入径向交错算法（Radial Staggering：`±26px~36px` 错落排列），彻底杜绝同弧线卡片边框切着边框、文字压着文字。
5. **压缩顶部双层工具条高度**：
   - 压缩 `SkillTreeCanvas.tsx` 顶部两层控制条（内边距紧凑化为 `py-1` 与 `py-1.5`，最小高度降至 38px/34px），为画布释放大面积开阔纵深视野。
6. **严密工程验证全绿**：
   - `SkillTreeCanvas.test.tsx`：追加四维关闭机制断言，13 个测试用例全部通过（100% PASS）；
   - 全量测试 `npx vitest run`：74 个测试套件，535 个测试用例全绿通过；
   - 生产打包 `npm run build`：0 错误，0 警告；
   - 规范检查 `python scripts/vault-check.py`：PASS。
