# 2026-09-23晚 用户反馈三连修（`[App] b2e5b4f`，build过，1420在线200）

## 1. 笔记库“Alle(4)只显示1条”——根因找到

- 不是数据丢了，是**顶栏搜索词跨tab常驻过滤**：从命令面板点笔记、Quiz/Tutor点引用、或搜过词，都会 `setQuery(thema)`；切Fach徽章时query还在，列表继续被过滤——Alle(4)+只剩Menschenbild+切徽章全空，对得一丝不差。
- 修：列表上方加**蓝色filter-chip**（`Filter: "xxx" · n Treffer + ×`），一键清除。以后任何残留搜索都看得见、一点就掉。

## 2. 设置中心（功能不再分散）

- 新第8 tab **设置**（齿轮图标，Alt+8，命令面板也有入口）：1语言→2知识库（状态+打开+重进引导）→3 AI引擎（复用AiSettings）→4数据与导出（FSRS/XP/清库reload）→5快捷键（开`?`）→6关于。
- 顶栏瘦身： vault/命令/语言/`?` 四按钮 → **一个设置齿轮**（搜索框保留；快捷键 Strg+K、/、L、? 照旧）。

## 3. 背卡“首卡非Again直接完成”——根因找到

- `partitionQueue` 每次评分后重算 + `gradeCard` 把刚评的卡 due 推到明天 → 队列两头同时缩（idx+1 且长度−1）：4张卡评2次就“完成”，小卡组首卡Good直接结束。Again看着“正常”只是错觉（同样双缩）。
- 修：**会话快照**——进背卡冻结一次队列，走完快照才算完成；Again卡经典重排到队尾（今天内重背）；FSRS落盘与header计数（到期/新卡）保留，计数口径改为快照。
