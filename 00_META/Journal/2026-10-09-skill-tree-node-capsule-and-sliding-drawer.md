# 2026-10-09 工作日志：知识图谱全量考点单行胶囊化与研习抽屉平滑抽拉动画

## 1. 任务背景与核心突破

根据实机界面截图与最新体验反馈（“看不到关联的节点了。我希望的是能看到，但是不乱，能找到重点。原本右侧出现的信息栏挺好的，增加回去。增加抽拉动画：可以从屏幕右侧抽出来，然后用收回代替删除”），本轮迭代重点重构了画布节点的视觉信息层级，并升级了研习抽屉的平滑抽拉动效与常驻把手机制：

1. **“看得见 + 不乱 + 能找重点”三位一体的节点形态重构**：
   - **普通待解锁考点（Locked）**：摒弃彻底隐藏文字的做法，采用极致轻量单行胶囊（高仅 18px，宽 75-130px），显示清晰考点中文标题（字号 9.5px、中灰 `--gray`），无笨重白底卡片、无冗余外框，全星系节点考点名清清楚楚，信息整洁不散乱；
   - **当前可攻坚重点（Available）**：高度增至 22px，采用醒目高对比墨黑外框（`strokeWidth="1.4"`）+ 墨黑指引圆心 + 加粗墨字，在星空背景中一眼锁定当前第一学习攻坚点；
   - **焦点/悬停/选中及因果前后节点（Focal & Causal Chain）**：平滑升起展开 196px × 58px Tufte 学术星盘卡片，上下游关联连线加粗显示墨黑箭头，并显式标注 `← 前置` / `→ 直接解锁` 指示角标，因果脉络清晰明确。
2. **研习抽屉开箱常驻（恢复右侧信息栏）**：
   - 首次进入知识图谱时，初始选中状态默认锚定推荐攻坚考点（`recommendedNextNodeId` 或首节点），确保右侧研习抽屉开箱即有、重点明确，解决此前空白无信息的体验断层。
3. **“用收回代替删除”的 GPU 丝滑抽拉动效**：
   - 抽屉不再直接从 DOM 卸载，而是采用硬件加速的 CSS 抽拉平滑过渡（`transition-transform duration-300 ease-[cubic-bezier(0.16,1,0.3,1)]`）；
   - **展开态**：`translate-x-0 shadow-2xl pointer-events-auto`；
   - **收回态**：`translate-x-full pointer-events-none shadow-none`；
   - 在四维关闭（同一节点反选、空白画布点击、右上角小叉、ESC 快捷键）触发时平滑滑回右边缘；
   - 维持 `displayDrawerNode` 与 `drawerCausalAnalysis` 镜像缓存，确保抽拉收回动画期间内容稳定不白屏、不坍缩。
4. **屏幕右边缘悬浮抽拉拉手（一键呼出）**：
   - 抽屉收回后，在屏幕右边缘精致浮现竖排微型把手 `[ ◀ 研习卡片 ]`（`data-testid="skill-tree-drawer-open-handle"`），随时一键丝滑抽拉唤醒。
5. **门禁与测试全绿回归**：
   - `SkillTreeCanvas.test.tsx`：13 个测试套件全部通过（包含抽拉展开、收回、把手呼出等全链路断言）；
   - `npm run build`：TypeScript 编译零报错，Vite 打包构建通过（12.4s）；
   - `python scripts/vault-check.py`：416 笔记、1942 单词行、360 索引链接、356 微课全绿通过（PASS）。
