# 2026-09-23 全并行工作流 X1–X8（8 路 subagent + 主线程裁决）

## 背景

W1–W7 收口后剩 7 个主题：raw 死字段、bundle 超大、~680 处 raw hex、官方时长边界、云同步白名单、`worker/compute` 处置、测试质量。用户令「尽量多开线程，忽略成本，质量效率优先」。

## 集成冲突与主线程裁决

- **X1 删 `Block.raw` 导致 TS 编译失败**：`src/modules/KlausurSim.test.tsx:24,30` 的 fixture 仍在写该字段，X1 无权修改该文件，X3/X4/X5 均因此无法完成 `npm run build`。主线程直接删除两处陈旧 fixture 属性化解。
- **X3 报告的 Flashcards 灰字缺口为误报**：X7 基于并行时序的旧快照报 `text-[#1C1B17]`，X5 已修为 `text-[var(--gray)]`。**教训：并行 agent 的报告可能基于旧工作树，主线程必须独立复核每条「缺陷」声明再动手。**
- **X7 报告的 Quiz 学术诚信缺口为真**：生成题标签只写「3-stufige Klausuraufgabe」未标自编。主线程改为「Selbst zusammengestellte Übungsaufgabe / 自编三段式练习大题」，与 KlausurSim 口径统一。

## 样式 token 化（~944 → 0）

七路并行清空生产代码硬编码色值：Tutor 170→0、Quiz 299→0、Reise 209→0、Onboarding 62→0、Flashcards 42→0、Settings 39→0、Planner 28→0、Home 21→0、Mindmap 19→0、Library 44→0、MathHtml 6→0、Diagram 3→0。同步把 9/10/11px 小字提到最小字号 token、去掉大圆角、把符号控件全换 16px 手写内联 SVG。**生产 tsx 最终零 `#hex`、零 active shadow、零 italic、零 emoji**（仅 index.css 的 token 定义本身与 diagram.ts 的 SVG 约束串保留颜色）。

顺带修 Quiz 密度：删 14 处黑底填充 + 22 处黑底白字，31 处卡片边框改发丝线+留白。Mindmap/Lernplan/Karteikarten 向契约声明的形态靠拢（墨色实心根、衬线倒计时、单一发丝纸卡）。

## 行为改进（非纯样式）

- **Quiz 计时器合并**：原有两个独立 interval 实现，合并为 `useQuizTimer`（绝对截止时间，不漂移），Space 键在输入中与带修饰键时一律拒绝。
- **Quiz Fehlerlog 去重**：补丁文本原在复制处理器与预览处各构造一次，可漂移；提取为 `src/quizgen.ts` 纯函数，两处共用同一 memo。
- **云同步白名单显式化**：此前「全部持久化键 = 云安全」是错的。新增 `SYNC_STORAGE_ALLOWLIST` 12 键（学习进度与偏好）+ 7 键显式 local-only（AI/端点凭据、同步配置本身、token 计量）逐条附理由；新增持久化键不再自动进云。擦除仍覆盖全部 19 键。
- **bundle 拆分**：`streamClient` 混合静态/动态 import 改为唯一缓存懒加载路径；entry chunk 718.09 kB → 473.91 kB（raw −244 kB / gzip −79 kB）。**诚实结论：初始总传输量未实质下降**，收益在缓存与变更隔离，HF/WebLLM 仍懒加载。
- **`worker/compute` 转真 Worker**：原用 `setTimeout` 假装离线。改为 `new Worker(new URL(...), {type:"module"})`，无 `Worker` 环境走回退。仍零生产调用方——记录为「有基础设施但未接线」。
- **删除 `Block.raw` 死字段**（W7 审计判定行为冗余，X1 用 mutation 验证：恢复旧的「必须 `##`」实现会使真实 VaultNote 抽取测试失败）。新增 `src/engine/examSource.ts` 稳定输入契约，composer 不再伸手进 parser 内部。
- **官方时长表补全**：补入新begin现代语/古 begun 语（210′/240′）、古语续读 300′/240′、Kunst +60′、Musik Gestaltungsaufgabe +60′、自然科学「题内标明的实践附加时间」结构化字段、Sport 笔试 GK 显式 `not-in-written-exam`、口试第四科显式未定。时长表来源集中为常量 `NRW_2026_WORKING_TIME_SOURCE = BASS 13-32 Nr. 3.2 (VVzAPO-GOSt), Fassung 2026/2027`。
