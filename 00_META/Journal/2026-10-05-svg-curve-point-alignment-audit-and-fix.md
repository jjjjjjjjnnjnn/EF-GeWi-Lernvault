# 全量交互实验曲线轨迹与指示圆点几何偏位大面积扫描与精修总结

## 1. 任务背景与核心排查
用户在运行本地客户端访问 `http://localhost:1420/?tab=labor`（生物学科“化学突触传递与神经毒素受体阻断实验室”）时发现并截图反馈：
> “目前存在大量图的点都不在线上，进行大面积扫描修复”

### 根因深度剖析
1. **二次贝塞尔曲线顶点衰减率误解**：
   - SVG 二次贝塞尔曲线 `M x0 y0 Q cx cy x2 y2` 中，参数中点 `t = 0.5` 处的实际曲线极值坐标为：
     $B_y(0.5) = 0.25 y_0 + 0.5 cy + 0.25 y_2$
   - 原代码在突触去极化波形中将控制点设为 `cy = 125 - epsp * 4`，而将指示点 `<circle>` 也硬编码在 `cy = 125 - epsp * 4`。但曲线波峰实际仅到达 $125 - 2 \cdot \text{epsp}$，导致圆点悬浮在曲线上空达一倍高度，脱离曲线轨迹！
2. **全局兜底实验通用画布（Default Canvas）指示点静态高度漂移**：
   - 任何未单独定制渲染的实验均走 default 通用画布，其 `cy` 原硬编码为 `170 - data.graphY * 1.2`，不随自变量滑块 `paramA` 演化，滑块拖动时圆点水平平移但高度固化，完全脱离二次抛物线。
3. **三次贝塞尔曲线再分配点位估值与曲线解耦**：
   - 社科洛伦兹曲线再分配（Bürgergeld）20% 人口标记点此前使用近似线性偏移，未代入三次贝塞尔曲线方程 $B(t) = (1-t)^3 P_0 + 3(1-t)^2 t P_1 + 3(1-t)t^2 P_2 + t^3 P_3$ 计算。
4. **种群波动数学离散与截断不匹配**：
   - 洛特卡-沃尔泰拉捕食者猎物曲线在 `Math.max(10, ...)` 截断与 `Math.round` 离散化上存在微量差值，导致圆点在波谷处微脱离。

## 2. 核心修复清单
1. **化学突触去极化波形（`synapse`）**：
   - 将控制点修正为 `Q 330 ${125 - epsp * 8} 390 125`，确保曲线顶点在 $t=0.5$ 处精确为 $125 - \text{epsp} \cdot 4$，与圆点坐标完全重合，严丝合缝。
2. **全局通用分析画布（`default`）**：
   - 引入精确二次贝塞尔曲线解析函数，动态计算 $(curCx, curCy) = B(paramA / 100)$，圆点实时贴附曲线滑行。
3. **洛伦兹再分配曲线（`sozialstaat`）**：
   - 严格在 $t=0.2$ 处求解三次贝塞尔多项式，使 Bürgergeld 兜底指示圆点与净收入曲线 `nettoPath` 100% 吻合。
4. **捕食者-猎物生态波动（`raeuber-beute`）**：
   - 提取浮点连续值 `rawPrey` 与 `rawPred` 驱动 `curYPrey` 与 `curYPred`，消除舍入与截断偏差。
5. **缓冲溶液滴定曲线（`puffer`）**：
   - 注入定义域范围截断（1..13），使测定探针圆点永远处于酸碱滴定 S 曲线内。
6. **表观遗传与聚合反应细节修正**：
   - 表观遗传 DNA 链改用精确圆弧 `A` 贴合八聚体，乙酰化/甲基化修饰基团精确绑定链条；
   - 自由基反应尾端虚线键与圆点完成闭合连接。
