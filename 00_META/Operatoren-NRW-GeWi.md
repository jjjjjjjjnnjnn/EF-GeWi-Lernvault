# Operatoren-NRW-GeWi 文科Operatoren中德对照

| Operator (Deutsch) | 中文 | 要求 | Beispielsatz |
|---|---|---|---|
| beschreiben | 描述 | 准确复述所见，不解释 | Die Karikatur zeigt … |
| darstellen | 呈现/阐述 | 系统呈现事实、模型 | Das Schaubild stellt … dar. |
| zusammenfassen | 概括 | 压缩要点 | Zusammenfassend lässt sich sagen, dass … |
| analysieren | 分析 | 分层+找关系+用术语 | Im Folgenden wird … analysiert. |
| erklären | 解释 | 原因/机制 | Dies lässt sich dadurch erklären, dass … |
| vergleichen | 比较 | 异同+标准 | Im Vergleich zu … |
| erörtern | 论述 | 正反+权衡 | Diese Position ist kritisch zu erörtern. |
| beurteilen / bewerten | 评判 | 用标准下判断 | Abschließend lässt sich beurteilen, dass … |
| Stellung nehmen | 表态 | 表明立场+论证 | Dazu nehme ich wie folgt Stellung: … |

> Klausur第一步永远是：划出Operatoren → 按动词分配段落。写错动词=整题跑题。
