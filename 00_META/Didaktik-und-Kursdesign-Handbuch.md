## 一、 核心愿景与双轨沉淀架构 (Vision & Dual-Track Architecture)

为了实现“任意一本书、一个考纲、一套知识体系均能被精细化拆解并无痛高效掌握”，系统采用**双轨并进**沉淀架构：

```
                    ┌──────────────────────────────────────────────┐
                    │      知识源泉：教材原典 / 考纲 (KLP NRW)      │
                    └──────────────────────┬───────────────────────┘
                                           │
         ┌─────────────────────────────────┴─────────────────────────────────┐
         ▼                                                                   ▼
┌─────────────────────────────────┐                         ┌─────────────────────────────────┐
│     轨道 A: 交互微课 (Lernreise) │                         │   轨道 B: 备考指南 (Obsidian MOC)│
│     • 面向 App 教学演播厅 / Studio│                         │   • 面向 iPad/PC 离线开箱即用    │
│     • 10–15 min 游戏化心流通关   │                         │   • MOC 导航 / 图片索引 / AB作业 │
│     • 可玩微世界 / 0分排雷诊断    │                         │   • 尺寸公式速查 / 进场勾选清单  │
│     • 15 NP 标答 / FSRS 公理     │                         │   • 考场 18 押题范文 / 术语词典   │
└─────────────────────────────────┘                         └─────────────────────────────────┘
```

- **轨道 A（动态交互心流 · `Lernreise/`）**：在桌面端 App (`TeachingStudio`) 中运行，遵循 Enterprise-v5 规范，通过“认知冲突 ➔ 概念预训练 ➔ 可动沙盒 ➔ 0分排雷 ➔ 15 NP 标答”让学生无痛建立心智模型。
- **轨道 B（静态学术军火库 · `学科/`）**：以标准 Obsidian Vault 形式沉淀（对标 `Biologie` 标杆架构），实现纯离线、零插件依赖、带原件作业纸（AB）与图解索引的终极备考指南。

## 二、 四大教育学与认知科学理论基石 (Pedagogical Foundations)

所有课程与笔记的设计，必须建立在实证教育科学基础之上，杜绝盲目搬运：

### 1. 德国学科教学论与范例教学（Wolfgang Klafki: Kategoriale Didaktik）
- **教学核心**：培养学生的学术成熟度与批判性判断力（*Mündigkeit & Urteilskompetenz*）。教学不是百科全书式罗列，而是抓“以一驭百”的**范例（Das Exemplarische）**。
- **克拉夫基五重问诊（Didaktische Analyse）**：
  1. *Elementare Bedeutung*（基本意义）：现象背后最底层、最普适的科学规律或社会公理是什么？
  2. *Exemplarische Bedeutung*（范例意义）：学会该案例能否自如迁移到整个领域？
  3. *Gegenwartsbedeutung*（现实关涉性）：在学生当下的生活中对应何种真实切身体验？
  4. *Zukunftsbedeutung*（未来关涉性）：在未来的学术深造或全真会考中具有何种长远价值？
  5. *Zugänglichkeit & Anschaulichkeit*（结构可触达性）：通过何种直观载体（教具、天平、沙盒）让抽象概念具身化？
- **北威州（NRW）三级能力阶梯（AFB I–III）**：
  - **AFB I (Reproduktion)**：基础事实复现（*darstellen, nennen*）；
  - **AFB II (Reorganisation / Analyse)**：因果机制建模与分析（*analysieren, erläutern*）；
  - **AFB III (Reflexion & Urteil)**：价值张力权衡与学术评价（*beurteilen, bewerten, Stellung nehmen*）。
  - **铁律**：每节微课必须完成从 AFB I 到 AFB III 的完整认知跃迁。

### 2. 认知负荷理论与多媒体学习科学（Sweller's CLT & Mayer's CTML）
- **预训练原则（Pre-training Principle）**：在进入复杂实验与综合分析前，必须在 Step 2 严格前置掌握 5 个核心专业术语，严禁让学生在推理时现查生词导致工作记忆雪崩。
- **剔除诱人细节效应（Seductive Details Effect / Rey 2012）**：讲无关的“八卦冷知识”会显著损伤学习成效。故事要么直接承载概念因果，要么坚决不写。
- **双重编码（Dual Coding）与冗余效应（Redundancy Principle）**：
  - 视觉与言语通道并行：文字负责逻辑精密性，SVG 动态图表负责空间直觉；
  - 界面信息杜绝多重套娃与同义反复，保持 Edward Tufte 高数据墨水比。

### 3. 理解为先的逆向课程设计（Wiggins & McTighe: Backward Design / UbD）
- **Stage 1 (Desired Results)**：以终为始，先定下本节课的 15 NP 会考标答与终局公理（Kernsatz）；
- **Stage 2 (Assessment Evidence)**：提炼考场最致命的 0 分混淆项（Absturz-Falle）作为实战检验标准；
- **Stage 3 (Learning Plan)**：反向推导所需的认知冲突（Hook）与可玩微世界（Sandbox）脚手架。

### 4. 提取练习与间隔重复（Dunlosky 2013, Roediger & Karpicke, FSRS）
- **测试效应（Testing Effect, d≈1.0）**：合书默写与自解释效果远超划线重读；
- **穿插辨别训练（Interleaved Discrimination）**：混排题型，先选“考哪个理论/模型”，再做解答；
- **FSRS 记忆调度**：将每课提炼的 Kernsatz 打入间隔重复算法，实现终生记忆保鲜。

## 三、 书籍/大纲精细化解构四层流水线 (Book-to-Course Pipeline)

面对厚重教材或考纲，执行以下四层流水线：

```
Level 0: 宏观知识图谱拓扑化 (Macro DAG)
  └── 映射 NRW 考纲 Inhaltsfelder，理顺前置依赖，切分章节模块
        │
Level 1: 章节认知单元原子化 (Meso Chunking)
  └── 10–15 分钟专注微课块；每课锚定 1 个核心矛盾 / 价值冲突
        │
Level 2: 交互微世界与具身载体绑定 (Micro Sandbox Binding)
  └── MINT 理科配参数沙盘；GeWi 文科配价值天平 / 决策树 / 文本解剖台
        │
Level 3: 会考标答与考场公理提纯 (Assessment & Axiom)
  └── 15 NP 德语学术论述范句 + 0分排雷诊断 + 三段论公理 (Kernsatz)
```

## 四、 轨道 A：交互微课设计规范 (Lernreise Enterprise-v5 Spec)

每门微课文件命名为 `Lernreise/[Fach]-[Thema]-L[n].md`，严格执行五步闭环：

### 1. Schritt 1: Entdecken (现象与认知冲突)
- **Leitfrage**: 直击痛点的现实设问；
- **Kognitiver Konflikt**: 呈现两难决策 `[Option A]` 与 `[Option B]`，让学生直觉站队；
- **AUFLÖSUNG (nach der Wahl lesen)**:
  - `Mechanismus A`: 揭示选项 A 的内在逻辑或局限；
  - `Mechanismus B`: 揭示选项 B 的内在逻辑或局限；
  - `Ein-Satz-Kern`: 一句话点破矛盾本质。

### 2. Schritt 2: Verstehen (预训练核心术语与因果链)
- **5 个核心术语 (Termini)**：德文 Fachbegriff + 德文精确定义 + 中文释义；
- **Kausalkette (因果链)**：用 `A ➔ B ➔ C ➔ D` 形式清晰展现逻辑传导。

### 3. Schritt 3: Modellieren (交互微世界探究)
- 挂载具体的交互教具（如 `DilemmaBalanceScale`, `VariableSliderBox`, `LogicBlockBuilder`, `OsmoseSimulator` 等）；
- 给出明确的 **Beobachtungsauftrag（探究任务）**，要求学生通过拨动滑块或调整变量得出规律。

### 4. Schritt 4: Ausprobieren & Absturz-Falle (考场 0 分排雷诊断)
- **题干与引述 (AFB II)**：真实考场情境或学生答卷摘录；
- **诊断提问**：考官为何判 0 分？最致命的概念混淆是？
- **选项设计**：
  - 正确项：精准指出学科级逻辑/概念混淆；
  - 干扰项：高水准混淆项，绝不写搞笑弱智选项，**绝不在选项中提前剧透“满分/解析”**；
- **MUSTERLOESUNG**: 深入阐述评分标准与失分根源。

### 5. Schritt 5: Szenario & Abitur-Transfer (15 NP 会考标答与公理)
- **终局考查 (beurteilen - AFB III)**：考查高难度评价动词；
- **德语高分范句 (Muster-Formulierung)**：包含标准让步句式（*Zwar..., dennoch...*）与专业术语；
- **KERNSATZ (公理)**：三段论公理，直通 FSRS；
- **ERWARTUNGSHORIZONT**: 列出 AFB I–III 采分点分值分布。

## 五、 轨道 B：Obsidian 备考指南与学科笔记规范 (Vault Guide Spec)

参考 `Biologie` 标杆，每个学科建立专属的高清备考指南目录，结构如下：

```
学科目录/ (如 06_Bio/ 或 独立备考专区)
├── 00_Import_Anleitung.md               # 离线部署/iPad/PC 2分钟快速上手指南
├── 00_Übersicht_Index.md                # 总导航 MOC (文件地图 + 图片索引 + 附件 + 速查表)
├── 01_Kapitel1_Thema.md                 # 核心章节精读笔记 (大表 + Callouts + 涌现规律)
├── 02_Kapitel2_Thema.md
├── ...
├── 06_Klausur_Musterantworten_Glossar.md # 18道大题高分押题范文 + Operatoren + 错题排查
├── Anhang_Bilder/                       # 自绘/公版 CC 图解 (一图一考点，注明显式锚点)
└── Anhang_Originale/                    # 真实教材练习纸 (Klett AB PDF) + 考纲动词文件
```

### 必配核心模块清单：
1. **MOC 全景地图（`00_Übersicht_Index.md`）**：
   - **Vault-Karte**：双链索引所有章节文件；
   - **Bilder-Index**：三列表格（图片名、文件路径、`Wofür / 看什么` 考核点）；
   - **Bildnachweis**：所有配图标注 CC0 / CC-BY / 自绘版权说明；
   - **尺寸/公式速查表（Spickzettel）**：常用单位换算、考场高频公式与计算防踩坑提示；
   - **Operatoren 动词实战解法**：如 *erkennen (名+特征)*、*begründen (特征➔规则➔结论)*、*erläutern (材料-步骤-观察-解释)*；
   - **Checkliste（进场勾选清单）**：考前 10 分钟逐项自我核验。
2. **章节精读笔记规范**：
   - 顶部提供关联文件导航与考点（Lernziel）；
   - 核心知识大表（中德对照、定义、实例）；
   - `> [!warning] Verwechslung`：标红高频易混点；
   - `> [!example] Musterantwort`：可直接背诵抄写的德语高分答题模板；
   - `Mermaid` 架构图（金字塔、因果流、演变图谱）；
   - 真实作业单习题与详细解析（Klett-AB Aufgaben mit Lösung）。

## 六、 外部 AI 批量设计标准化 Prompt 模板 (Batch Prompt Spec)

当分发给外部 AI 批量设计课程时，统一使用以下 Prompt 规范：

```markdown
你是一位深谙德国北威州（NRW）高中会考标准（Abitur）与认知科学教学论（Didaktik）的资深学科导师。
请针对以下教材章节/主题，设计一门符合 Enterprise-v5 规范的互动微课与配套 Obsidian 笔记：

【学科与主题】：[输入学科，如 SoWi / Bio / Deutsch] - [输入主题名称]
【核心能力要求】：涵盖 NRW AFB I, II, III 阶梯，重点针对操作动词 [如 erläutern, beurteilen]
【参考教材/知识点】：[输入教材段落、知识点或大纲要求]

【硬性生产铁律】：
1. 严格采用 Enterprise-v5 结构（Schritt 1 到 Schritt 5）；
2. Schritt 1 必须具备尖锐的认知冲突（[Option A] vs [Option B]）与 AUFLÖSUNG（含 Mechanismus A/B 与 Ein-Satz-Kern）；
3. Schritt 2 必须前置锁定 5 个核心专业术语及其精准德文解释，附 Kausalkette；
4. Schritt 3 必须挂载具身互动教具（指定工具类型与观察探究任务）；
5. Schritt 4 必须为真实 0 分答案排雷诊断（严禁选项剧透“满分/解析”字样，选项必须具备深度迷惑性）；
6. Schritt 5 必须给出符合 15 NP 的德语学术评价句（含 Zwar..., dennoch... 让步句式）、KERNSATZ 公理与 ERWARTUNGSHORIZONT 评分矩阵；
7. 文本杜绝同义反复，语言精炼，符合 Tufte 高密度学术规范。
```

## 七、 质量审查与验收量规 (Quality Gate Rubric)

每门课程或笔记落库前，必须通过以下自查清单：

| 审查维度 | 合格标准 (Pass Criteria) | 致命红线 (Fail if present) |
| :--- | :--- | :--- |
| **认知负荷** | 术语前置（5个）、一屏一概念、无冗余文本 | 实验中突现生词、大段纯理论灌输、无关段子 |
| **考纲契合** | 覆盖 AFB I–III，直扣 NRW 官方 Operatoren | 仅停留在名词解释（AFB I）、脱离考纲 |
| **防剧透性** | 选项纯粹为内容辨析，答案与解析收归反馈卡 | 选项文本内包含“满分金句”、“失分症结”等元数据 |
| **德语学术** | 规范使用专业德语 Fachsprache，让步从句严谨 | 纯中文概括、低幼化口语表达、德语语法错误 |
| **门禁合规** | `python scripts/vault-check.py` PASS，格式严密 | Frontmatter 缺失、文件名含变音符号空格 |
