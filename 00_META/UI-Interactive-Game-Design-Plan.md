# 全学科课程交互游戏化设计、五大黄金 UI 范式收敛与外部 AI 任务分配总纲

> 针对用户明确决策：「方案 1 (Brilliant) 与方案 5 (Workbench) 合并」、「方案 2 (Editorial) 入驻课程讲解」、「方案 3 (Duolingo) 适度用于总览」、「方案 7 (Bento)、方案 8 (Chapters)、方案 11 (Socratic) 采纳融合，其余不采纳」。
> 本文档确立**去 AI 浮夸感、回归高级清爽**的前端设计准则，并对全学科 269 门互动课程进行交互游戏化分类映射与外部 AI 执行任务分配。

## 一、 设计哲学升级：如何彻底消除「AI 机械质感」，重归高级清爽？

### 1. 痛点诊断：什么是典型的「AI 塑料感（AI-Slop）」？
- **滥用无意义的高饱和霓虹光晕（Neon Cyan/Magenta Overload）**：全屏泛滥紫蓝色阴影，导致视觉焦点发散。
- **排版节奏单调（Monotonous Cadence）**：无论什么学科，都是千篇一律的卡片套卡片，缺少符合学科认知特征的版面呼吸感。
- **缺乏真实的物理/思维反馈**：界面元素机械排列，用户点击后缺乏弹簧阻尼、微位移、即时参数联动的触感。

### 2. 人性化高分前端设计原则（清爽、克制、高级、丝滑）
- **功能性色彩（Functional Color Discipline）**：
  - 90% 的面积使用克制而优雅的 Neutral 灰阶（Dark 模式采用深岩黑 `#09090b`、炭黑 `#121214`、微边框 `border-white/[0.08]`；Light 模式采用温润纸白 `#fdfdfd`、珍珠灰 `#f4f4f5`）。
  - 仅在**交互把手（Slider Thumb）**、**激活状态（Active Node）**、**物理矢量箭头**、**核心结论高光**处使用 1 种主题焦点色。
- **数学级几何对齐与留白（Consistent Spatial Rhythm）**：
  - 严格统一外间距（`gap-4` / `gap-6`）与卡片圆角（`rounded-2xl`），杜绝参差不齐。
- **纯手工高精内联矢量图（Handcrafted Pure Inline SVG）**：
  - **严格零 Emoji**（严守 AGENTS.md §7 与合约测试规范）。
  - 所有插图均为针对学科真实考点绘制的动态 SVG（真实的激光折射角、分子双脂层微粒、真实的洛伦茨曲线积分阴影、真实的康德四步定言命令石碑刻度）。
- **即时触感微交互（Micro-Interactions）**：
  - 拖动滑块时，图表、文字说明与数据 HUD 同步在 16ms 内无损更新；按钮具备轻微按压弹性（`active:scale-[0.98]`）。

## 三、 十大学科课程交互游戏化设计规划（具体活动玩法）

### 1. 理科阵营（Mathe / Physik / Chemie / Bio）
| 学科 | 典型课题 | 推荐范式 | 具体互动游戏/操作设计 | 采分点闭环 (Klausur-Ertrag) |
| :--- | :--- | :--- | :--- | :--- |
| **Physik** | 简谐振动与单摆 | **G1: Brilliant-Work** | 拖动调节摆长 $l$ 与重力场 $g$，观察回复力分量矢量动态分解，挑战将周期调节至正好 $2.0\text{ s}$。 | 掌握 $T = 2\pi\sqrt{l/g}$ 并在右侧卡片输出标准误差分析句式。 |
| **Physik** | 斜面力学与动摩擦 | **G1: Brilliant-Work** | 动态调整倾角 $\alpha$，观察下滑力 $F_H$ 突破静摩擦极限瞬间滑块启动并绘制 $v-t$ 图。 | 掌握受力分解图规范与临界角判据 $\tan\alpha = \mu$。 |
| **Chemie** | 勒夏特列与工业合成氨 | **G3: Socratic-Lab** | 操作高压活塞加压（100-300 bar）与温度滑块，苏格拉底四步追问为何升温反而导致产率下降。 | 推导平衡常数 $K_c$ 与放热反应关系，生成工业两难论证答题模板。 |
| **Bio** | 植物细胞质壁分离 | **G1: Brilliant-Work** | 滴加高浓度蔗糖溶液，微观观察液泡水分外渗、细胞膜与纤维素细胞壁分离并产生张力。 | 掌握水势方程 $\Psi = \Psi_s + \Psi_p$ 与原质壁分离时间定量计算。 |
| **Mathe** | 导数切线极限逼近 | **G1: Brilliant-Work** | 拖拽割线点使 $\Delta x \to 0$，观察割线斜率 $\frac{\Delta y}{\Delta x}$ 动态演变至瞬时切线斜率 $f'(x)$。 | 强化微积分极限定义，克服「除以零」的认知障碍。 |

## 四、 外部 AI 执行任务分配清单（批量生产排期）

我们采用标准模块化规范，将具体的游戏制作任务分配给外部 AI。每个任务均独立输出至 `src/modules/DesignStudio/` 下对应的模板。

### 第一波：MINT 核心理科互动工坊（优先度：最高）
- **Task WP-1 (Physik)**: 实现 `StudioOpticsBench.tsx`（Snellius 折射 + 光纤全反射探究沙盒，采用 **G1** 范式）。
- **Task WP-2 (Chemie)**: 升级 `StudioSocraticTitration.tsx`（酸碱中和突跃 + 强弱酸对比 + 苏格拉底四步追问，采用 **G3** 范式）。
- **Task WP-3 (Bio)**: 升级 `StudioOsmoseLab.tsx`（植物与动物红细胞双模对照渗透实验，采用 **G1** 范式）。
- **Task WP-4 (Mathe)**: 实现 `StudioBoxOptimizer.tsx`（长方体最大容积极值裁剪 3D 展开图互动，采用 **G1** 范式）。

### 第二波：文科与社科沉浸工作台（优先度：高）
- **Task WP-5 (SoWi)**: 实现 `StudioMarktWelfare.tsx`（供求平衡 + 价格管制 + 消费者剩余图解，采用 **G1** 范式）。
- **Task WP-6 (Philo)**: 升级 `StudioChaptersEthik.tsx`（康德 vs 功利主义全屏章节剧场，采用 **G4** 范式）。
- **Task WP-7 (Deutsch/Englisch)**: 实现 `StudioEditorialReader.tsx`（通用杂志级双栏/长文原典精读流，采用 **G2** 范式）。

### 第三波：全课程通用收官仪表盘
- **Task WP-8 (Global)**: 完善 `StudioBentoDashboard.tsx`（适配全 269 门课程第 8 步的四宫格元认知总结，采用 **G5** 范式）。

## 五、 技术交付标准与验收门禁

外部 AI 交付代码时，必须严格执行以下红线：
1. **纯手工内联 SVG**：严禁引入外部大体积图片，严禁出现任何 Emoji 图标。
2. **TypeScript 严格模式**：所有 Props、状态及事件处理必须具备清晰的 TS Interface，`npx tsc -b` 零报错。
3. **性能预算**：Canvas/SVG 动画必须在 60fps 运行，滑块拖动无卡顿防抖。
4. **沙盒安全**：新增文件仅进入 `src/modules/DesignStudio/`，生产文件 `Reise.tsx` 零污染。
