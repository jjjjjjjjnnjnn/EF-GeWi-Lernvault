# Lernsystem (Feynman + FSRS + Klausur-Drill)

> 方法证据等级见 `Lernmethoden-Evidenz.md`（单真相源）。本页只写动作，不论证。

## 1. 课后15分钟（每天每科）
套 `Templates/Stunden-Nachbereitung-GeWi.md`：合书默写3行 + 开书对照 + 5个德语概念进Anki + 1道题。

## 2. 周末Feynman（每科30分钟）
中文讲一遍 → 德语写3句Klausur-Satz（必须用Operatoren）→ 术语进Glossar。

## 3. Anki-FSRS
- 来源：各科 `Vokabeln-Anki/*.csv`（分号分隔，`scripts/vault-check.py` 校验）。
- Obsidian内也可用 `Q:: A` 直接背（插件 obsidian-spaced-repetition-recall）。
- 文科每天上限：新卡15/复习100，考前再加。
- 考前按 Klausur 倒排**三轮重学**（successive relearning），不用平均用力。

## 4. 考前7天Drill
套 `Templates/Klausur-Drill-GeWi.md`：只刷 `Klausur-Training/` + `Texte-Analyse/` + Fehlerlog。重读笔记不计入复习。

## 5. AI用法
贴课堂笔记/题目 → 回：中德双语讲解 + Anki卡markdown + 同类题。沉淀回对应学科文件夹。
