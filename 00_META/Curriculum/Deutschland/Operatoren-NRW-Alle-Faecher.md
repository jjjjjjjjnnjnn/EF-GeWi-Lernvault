> ⚠️ **本文件最重要的结构性发现**（[已验证]）：NRW 的 Operatoren 表**存在两套并行的编制哲学**——
> - **A 组（文科 5 科：Deutsch / Philosophie / SoWi / Musik / Sport）**：逐条给出 AFB 区间，一张表即可判断题目层级。
> - **B 组（Englisch / Mathematik / Physik / Chemie / Biologie）**：官方明写「Grundsätzlich können sich alle Operatoren auf alle drei Anforderungsbereiche beziehen」，**不按动词分配 AFB**，层级由**任务情境与材料**决定。
>
> 因此：**不能用 A 组的「动词→AFB」直觉去套 B 组**。例如 `beschreiben` 在 Deutsch 是 I–II，在 Mathematik 却可能出现在任何 AFB。

## 1. AFB 三级通则

| AFB | 德文 | 中文 | 认知动作 |
|---|---|---|---|
| **AFB I** | Reproduktion | 复述 | 再现已知：列举、复述、概括、描述 |
| **AFB II** | Reorganisation und Transfer | 重组与迁移 | 把已知知识**重新组织**并应用到**新情境**：分析、解释、比较、关联 |
| **AFB III** | Reflexion und Problemlösung | 反思与问题解决 | 批判性检验、权衡、自主判断、提出解决方案 |

[已验证] —— 以上定义出自 Deutsch Operatoren 表头，为 IQB 各州共用 Abituraufgabenpool 的统一表述。

**Abitur 覆盖要求** [已验证]：

1. Abitur 任务**必须覆盖全部三个 AFB**。
2. **AFB II 为重点**（Reorganisation und Transfer 是高中毕业考试的主战场）。
3. IQB 共用池的 Operatoren **通常被归入多于一个 AFB**（同一动词随任务不同可落在不同层级）——这是 A 组表出现「I–II」「II–III」区间的原因。
4. **未列入本表的动词也可使用**：只要按该动词的标准语义结合任务表述，能判断考生可按题意作答即可。[已验证，各科 PDF 均有此条兜底说明]

| begründen | III | 论证 | 用相应证据、例子或论证链，为分析结论／判断／评估／评价提供专业与事实支撑 |

**B. Sprachmittlung（语言中介）**

| 动词 | AFB | 中文 | 该科含义 |
|---|---|---|---|
| explain | 不限 | 解释 | 使某事清晰，必要时兼顾文化相关差异 |
| outline | 不限 | 概述 | 简明复述要点，必要时澄清文化相关方面 |
| present | 不限 | 介绍／呈现 | 简明复述要点，必要时澄清文化相关方面（用于面向国际受众的正式文本） |
| summarize, sum up | 不限 | 总结 | 同上；必要时补充信息以避免误解 |
| write (+ text type) | 不限 | 写作（+体裁） | 依据德语文本产出英文文本 |

**C. Hörverstehen（听力）**

| 动词 | AFB | 中文 | 该科含义 |
|---|---|---|---|
| complete, fill in | 不限 | 补全／填空 | 按字数限制补全句子或缺失信息 |
| list, name | 不限 | 列举 | 列出所提到的重要方面 |
| match | 不限 | 配对 | 建立对应关系（含干扰项） |
| state | 不限 | 陈述 | 说明说话者支持的观点 |
| tick | 不限 | 勾选 | 勾出正确答案 |

> 💡 Sprachmittlung 栏的 `explain / outline / summarize / write` 与 A 栏同名但**含义更窄**：额外要求「兼顾／澄清文化相关差异」。这是英语科特有的细分。[已验证]

### Musik

> 来源：`mu_operatoren_mitbeispielen_final_1.pdf`（PDF 未标版本年份）。[已验证]

> 3. 可用附加语限定（如「rechnerisch」「grafisch」）。

| **beschreiben / describe** | **10（全部）** | DE I–II；PL I；SW I–II；MU I；SP I–II（主 I）；MA/EN/PH/CH/BI 不限 | 共同内核是「结构化复述」。**数学科明确不需要 Begründung**；文科则多用专业术语且在逻辑关联中复述 |
| **analysieren / analyse / analyze** | 9（除 MA） | DE I–II–III；PL II；SW 主 II；MU II；SP II；EN/PH/CH/BI 不限 | 文科＝按维度拆解文本／材料并呈示（DE 强调「内容—形式—语言」功能关联）；理科＝针对特定问题提炼重要组成部分／性质／关联；**化学额外含实验检验** |
| **begründen / give reasons** | 9（除 EN） | DE III；PL III；SW III；MU III；SP II–III；MA/PH/CH/BI 不限 | 文科＝为判断／结论提供专业与事实支撑；数学＝通过逻辑推理确认论断（必须呈示过程）；理科＝可追溯地呈示理由 |
| **vergleichen / compare** | 9（除 MA） | DE II–III；PL II；SW II–III；**MU III**；SP II–III（主 II）；EN/PH/CH/BI 不限 | 内核一致（共同点／相似点／差异）。**音乐科独为 AFB III**（须建立在两部作品各自考察结果之上） |
| **erläutern / explain** | 9（除 EN） | DE II–III；PL I–II；SW II–III；MU II；SP II；MA/PH/CH/BI 不限 | 与 `erklären` 的分工在全科一致：erläutern＝补充信息／例子使其易懂；erklären＝归因到规则／规律性 |
| **beurteilen** | 9（除 EN） | DE II–III；PL III；SW III；MU III（与 bewerten 合并）；SP III；MA/PH/CH/BI 不限 | **Sachurteil（事实判断，用专业标准）**。数学科特别注明「必须给出理由」 |
| **interpretieren / deuten / interpret** | 8（DE/EN/SW/MU/MA/PH/CH/BI） | DE I–II–III；SW II–III；MU III；EN/MA/PH/CH/BI 不限 | 文科＝整体意义解读；理科＝把结果／描述／假设放回问题情境建立可追溯关联；数学＝建立图形／式子／结果与事实情境的关联 |
| **erklären / explain** | 8（DE/EN/PL/SW/SP/PH/CH/BI） | DE II；PL I–II；SW II；SP II–III（主 II）；EN/PH/CH/BI 不限 | 见上（与 erläutern 的分工） |

### 3.2 极易混淆的四组动词（全科通用判别）

| 组 | 判别要点 | 官方依据 |
|---|---|---|
| **erklären vs erläutern** | erklären＝**归因**（把事态归到规则／规律性／因果）；erläutern＝**加料说明**（补充信息与例子使其易懂）。AFB 上 erläutern 常更高半级 | [已验证] DE / PL / SW / PH / CH / BI 释义一致 |
| **beurteilen vs bewerten** | beurteilen＝**Sachurteil**（专业标准、事实判断）；bewerten＝**Werturteil**（社会价值与规范、含立场）。SW 明写「bewerten = beurteilen + 反思价值尺度」 | [已验证] SW / PL / PH / CH / BI |
| **erörtern vs diskutieren** | erörtern＝文科的「正反权衡后得出判断」；diskutieren＝「论点相互对照并权衡」，理科与 SW 用。两者在 Musik 被**合并为同一条** | [已验证] MU 合并条 + SW / DE |
| **entwerfen vs entwickeln** | entwerfen＝**前瞻性规划草案**（DE/SW/SP 为 AFB III，**MU 例外为 II**）；entwickeln＝**逐步推进／构建**（PL/SW III，MU II，**SP II–III 主 III**，Bio 为设计实验／模型） | [已验证] 各科 AFB 不一致，**这是最易失分点** |

### 3.3 各科独有动词（仅该科出现）

### 3.4 同名动词的科际「陷阱清单」

> 以下动词**看似相同但各科层级不同**，跨科套用会失分。[已验证]

| 动词 | 陷阱 |
|---|---|
| `vergleichen` | Musik = **AFB III**；其余科多为 II 或以 II 为主 |
| `entwickeln` | Philosophie/SoWi = **III**；Musik = **II**；Sport = II–III 主 III |
| `entwerfen` | Deutsch/SoWi/Sport = **III**；Musik = **II** |
| `beschreiben` | Philosophie/Musik = **纯 I**；Deutsch/SoWi/Sport 含 II |
| `darstellen` | Musik 与 `wiedergeben` 合并为 **I**；Deutsch/Philo/SoWi = I–II |
| `analysieren` | Deutsch = **I–II–III 全跨**；Philo/Musik/Sport = **纯 II**；SoWi = 主要 II |
| `untersuchen` | Deutsch = II（与 erschließen 同义）；Musik 与 analysieren **合并**；理科 = 学科方法探究 |
| `prüfen / überprüfen` | Deutsch `prüfen` = III、`überprüfen` = II–III（**两个词不同级**）；SoWi 同；Sport 合并为 III；Bio 合并为不限 |
| `zusammenfassen` | Deutsch = I–II；Philo = I–II；Sport = I–II；Bio = 不限；**Mathe/Physik/Chemie 表中根本没有这条** |
