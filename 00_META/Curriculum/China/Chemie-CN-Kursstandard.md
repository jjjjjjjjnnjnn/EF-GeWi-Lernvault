## 1. 课程结构

| 层次 | 构成 | 学分/课时 | 性质 |
|---|---|---|---|
| **必修** | **不划分模块，共 5 个主题** | **4 学分** | 全体必学 |
| **选择性必修** | **3 个模块** | 每模块 **2 学分**，共 **6 学分** | 升学需求（选考化学者必全修） |
| **选修** | **3 个系列** | 每 9 学时 0.5 学分，**0~4 学分** | 自主选择 |

- 必修不划分模块（`[已验证]` 原文「必修课程不划分模块，共 4 学分」）〔注：前期简报表述一致〕
- 选择性必修 3 模块：**《化学反应原理》《物质结构与性质》《有机化学基础》**，各 2 学分 `[已验证]`
- 选修 3 系列：**《实验化学》《化学与社会》《发展中的化学科学》** `[已验证]`
- 选修学分最小单位 = 0.5 学分（9 学时） `[已验证]`

### 必修 5 主题（官方标题）
1. 化学科学与实验探究
2. 常见的无机物及其应用
3. 物质结构基础与化学反应规律
4. 简单的有机化合物及其应用
5. 化学与社会发展

`[已验证]` 5 个主题名称与前期简报完全一致。

**学考关系** `[已验证]`：
- 全体高中学生**必须修习 4 学分必修课程**。
- 选化学作为**计入高校招生录取总成绩**的学业水平考试科目者 → **须修习选择性必修课程全部 3 个模块，获 6 学分**。
- 其他学生可只修习选择性必修的**部分模块**获相应学分。

## 2. 各模块知识点清单

> 编号为课标原始「内容要求」编号（如 `2.3` = 该主题第 3 条），非本项目自编，便于回查原文。全部 `[已验证]`。

### 2.1 必修课程（5 主题，共 4 学分）

#### 主题1：化学科学与实验探究

| 编号 | 条目 | 课标要点关键词 |
|---|---|---|
| 1.1 | 化学科学的主要特征 | 化学是原子分子水平研究组成/结构/性质/转化/应用的学科；发展历程与趋势；实证与推理、宏观与微观联系；**实验、假说、模型、比较、分类等方法**；**物质的量及其相关物理量**的含义与应用 `[已验证]` |
| 1.2 | 科学探究过程 | 探究核心要素：提出问题与假设 → 设计方案 → 实施实验 → 获取证据 → 分析解释/建构模型 → 形成结论 → 交流评价 `[已验证]` |
| 1.3 | 化学实验 | 物质检验/分离/提纯/溶液配制的基础知识技能；研究物质性质、探究反应规律、分离检验制备的**核心思路与基本方法**；**实验条件控制** `[已验证]` |
| 1.4 | 科学态度与安全意识 | 化学品安全标识；常见废弃物处理；实验室突发事件应对 `[已验证]` |
| 1.5 | 学生必做实验 | 配制一定物质的量浓度的溶液 `[已验证]` |

#### 主题2：常见的无机物及其应用

| 编号 | 条目 | 课标要点关键词 |
|---|---|---|
| 2.1 | 元素与物质 | 物质分类；同类物质相似性；各类物质相互转化；**同种元素不同价态可通过氧化还原反应相互转化**；**胶体（分散系）** `[已验证]` |
| 2.2 | 氧化还原反应 | 化合价变化为判据；**本质 = 电子转移**；常见氧化剂与还原剂 `[已验证]` |
| 2.3 | 电离与离子反应 | 酸碱盐电解质在水溶液或熔融态电离；**离子反应及其发生条件**；常见离子检验 `[已验证]` |
| 2.4 | 金属及其化合物 | **钠、铁**及其重要化合物的主要性质与应用 `[已验证]` |
| 2.5 | 非金属及其化合物 | **氯、氮、硫**及其重要化合物的主要性质；生产应用与生态环境影响 `[已验证]` |
| 2.6 | 物质性质及物质转化的价值 | 金属/非金属化合物多样性；通过化学反应探索性质、实现转化 `[已验证]` |
| 2.7 | 学生必做实验 | ① 铁及其化合物的性质 ② 不同价态含硫物质的转化 ③ 用化学沉淀法去除粗盐中的杂质离子 `[已验证]` |

#### 主题3：物质结构基础与化学反应规律

| 编号 | 条目 | 课标要点关键词 |
|---|---|---|
| 3.1 | 原子结构与元素周期律 | 元素/核素含义；**核外电子排布**；原子结构—元素性质—周期表位置关系；**元素周期表结构**；以第三周期（Na Mg Al Si S Cl）及**碱金属、卤族**为例的同周期/主族递变规律 `[已验证]` |
| 3.2 | 化学键 | **离子键、共价键**的形成；化学键概念；分子空间结构；**化学键断裂与形成 = 物质变化的实质 + 能量变化主因** `[已验证]` |
| 3.3 | 化学反应的限度和快慢 | 可逆反应含义；**化学平衡**（一定条件下可达到）；**平均速率表示方法**；影响速率的因素（实验探究）；**变量控制方法** `[已验证]` |
| 3.4 | 化学反应与能量转化 | 吸热/放热反应；体系能量改变与化学键断裂形成有关；**以原电池为例认识化学能→电能**；**从氧化还原反应角度初步认识原电池工作原理** `[已验证]` |
| 3.5 | 学生必做实验 | ① 同周期、同主族元素性质的递变 ② 化学反应速率的影响因素 ③ 化学能转化成电能 `[已验证]` |

#### 主题4：简单的有机化合物及其应用

| 编号 | 条目 | 课标要点关键词 |
|---|---|---|
| 4.1 | 有机化合物的结构特点 | 分子有空间结构；以**甲烷/乙烯/乙炔/苯**认识碳原子成键特点；以**乙烯/乙醇/乙酸/乙酸乙酯**认识**官能团**；**同分异构现象** `[已验证]` |
| 4.2 | 典型有机化合物的性质 | **乙烯、乙醇、乙酸**的结构/主要性质/应用；**官能团与性质的关系**；**氧化、加成、取代、聚合**反应类型；有机物间可转化 `[已验证]` |
| 4.3 | 有机化学研究的价值 | 合成新物质的价值；**高分子、油脂、糖类、蛋白质**的应用 `[已验证]` |
| 4.4 | 学生必做实验 | ① 搭建球棍模型认识有机化合物分子结构的特点 ② 乙醇、乙酸的主要性质 `[已验证]` |

#### 主题5：化学与社会发展

| 编号 | 条目 | 课标要点关键词 |
|---|---|---|
| 5.1 | 化学促进可持续发展 | **绿色化学**观念；资源全面节约、物能循环利用 `[已验证]` |
| 5.2 | 化学科学在材料科学、人类健康等方面的重要作用 | 金属/无机非金属/高分子材料；**材料组成—性能—应用的联系**；药物合成 `[已验证]` |
| 5.3 | 化学在自然资源和能源综合利用方面的重要价值 | **合成氨、工业制硫酸、石油化工**；海水/金属矿物/煤/石油的开发利用；清洁低碳能源体系 `[已验证]` |
| 5.4 | 化学在环境保护中的作用 | 污染成因/危害/防治；**以酸雨的防治和废水处理为例**；相关国策法规 `[已验证]` |
| 5.5 | 化学应用的安全与规则意识 | 化学品应用/化工生产/环保/食品药品安全的法律法规意识 `[已验证]` |

## 4. 高考（等级性考试）考查要求

- **考查范围**：**必修（4 学分，5 主题）+ 选择性必修全部 3 模块（6 学分）** `[已验证]`（选考化学者须修满选择性必修全部 3 模块）
- **依据水平**：**水平 4** `[已验证]`
- **核心素养（5 项）** `[已验证]`：
  1. **宏观辨识与微观探析** —— 不同层次认识物质多样性；从元素/原子/分子水平认识组成结构性质变化；形成「**结构决定性质**」观念
  2. **变化观念与平衡思想** —— 化学变化需条件、遵循规律、伴能量转化；有**限度、速率，可调控**；多角度动态分析
  3. **证据推理与模型认知** —— 基于证据提出假设并证实/证伪；建立观点—结论—证据的逻辑关系；**建立认知模型并用模型解释现象**
  4. **科学探究与创新意识** —— 发现并提出有探究价值的问题；设计探究方案；敢于质疑、勇于创新
  5. **科学态度与社会责任** —— 安全与严谨求实；**绿色化学**与可持续发展意识；对与化学有关的社会热点作价值判断

## 5. 化学解题方法系统（**重点：德国可借鉴处**）

> ⚠️ **本节性质说明**：**课标本身不规定「解题方法/技法」**——它只规定**内容要求**与**学业要求**。以下方法链是**中国教学传统从课标内容要求中涌现出的解题范式**，用于本项目评估「可迁移性」。
> 标注规则：**方法的存在性**若可追溯到课标条文 → `[已验证]`（并注明来源条目）；**方法本身的体系化归纳** → `[据推断]`。

### 5.1 化学计算的系统方法

| 方法 | 内容 | 标注 |
|---|---|---|
| **以物质的量为中心的换算网络** | `n = m/M = V/Vm = c·V = N/NA`，四路互通；**物质的量是化学定量研究的「中心物理量」** | `[已验证]` 内容要求 1.1（物质的量及其相关物理量）；学业要求主题1 第 5 条（物质的量/摩尔质量/气体摩尔体积/物质的量浓度相互关系进行简单计算）；水平 1-2 |
| **守恒法** | **质量守恒**（水平 2-2「应用质量守恒定律分析物质转化对资源利用的影响」`[已验证]`）；**电荷守恒 / 电子守恒 / 元素守恒** | 质量守恒 `[已验证]`；**电荷守恒、电子守恒为教学归纳** `[据推断]` |
| **差量法** | 利用反应前后质量/体积差求算 | `[据推断]` 课标无明文，属教学技法 |
| **平衡常数/转化率计算** | 书写 K 表达式；EQ K 与 Q 判断方向；转化率计算 | `[已验证]` 模块1 学业要求主题2 第 1 条 |
| **焓变计算（盖斯定律）** | 反应焓变的简单计算；热化学方程式书写 | `[已验证]` 模块1 内容要求 1.2；学业要求主题1 第 2 条 |
| **pH 计算** | 溶液 pH 的简单计算与调控 | `[已验证]` 模块1 学业要求主题3 第 3 条 |
| **滴定计算** | 中和滴定 | `[已验证]` 模块1 必做实验（强酸与强碱的中和滴定） |

> **德国可借鉴点**：中国把「**物质的量（Stoffmenge）**」做成一个**枢纽概念**，所有定量关系绕其旋转；德国 NRW 更倾向按反应式**比例（Stöchiometrie）**直觉处理。**嫁接入口**：德国 Sek I 已有 `Mol` 概念，可在 EF 阶段补一张「**换算网络图**」把 n = m/M、V/Vm、c·V 三线并接，直接提升定量题速度。

### 5.2 离子方程式的书写与判断逻辑

**课标依据链** `[已验证]`：
- 必修 2.3「电离与离子反应」：认识电解质电离；**通过实验事实认识离子反应及其发生的条件**；了解常见离子检验
- 水平 1-1：「**能认识离子反应和氧化还原反应的本质，能结合实例书写离子方程式和氧化还原反应化学方程式**」
- 必修 2.7 学生必做实验：「用化学沉淀法去除粗盐中的杂质离子」

**解题逻辑链（教学归纳）** `[据推断]`：
1. **写**：正确写出化学方程式
2. **拆**：强酸、强碱、可溶性盐 → 拆成离子；**弱电解质、沉淀、气体、氧化物、水 → 不拆**
3. **删**：删去两边不参加反应的离子（旁观离子）
4. **查**：**电荷守恒** + **原子守恒** 双重检验
5. **判**：是否符合**发生条件**（生成沉淀/气体/弱电解质；或氧化还原）

> **德国可借鉴点**：德国 KLP 涉及 `Ionenreaktionen` 但**不系统训练「拆—删—查」四步法**，学生在 `Redoxgleichungen` 配平时缺乏电荷守恒的显式检验习惯。**嫁接入口**：把该四步法作为 EF/Q1 的**配平工具卡**，配合「电荷守恒双查」直接补强德国偏弱的 `Argumentieren` 严谨性。

### 5.3 电化学（原电池/电解池）分析框架

**课标依据** `[已验证]`：
- 必修 3.4：「**以原电池为例认识化学能可以转化为电能，从氧化还原反应的角度初步认识原电池的工作原理**」；学业要求主题3 第 5 条「**辨识简单原电池的构成要素**，分析简单原电池的工作原理」
- 模块1 内容要求 1.3：原电池、常见化学电源、**电解池**工作原理；电解在物质转化与储能中的应用；**金属电化学腐蚀本质与防护措施**
- 模块1 学业要求主题1 第 3、4 条：**能分析、解释原电池和电解池的工作原理，能设计简单的原电池和电解池**；利用电化学原理解释金属腐蚀、选择并设计防腐措施

**课标点明的「电化学体系四要素」** `[已验证]`（模块1 教学提示原文要素列举）：
> **电极反应 · 电极材料 · 离子导体 · 电子导体** —— 课标明确以此四要素建立**对电化学过程的系统分析思路**。

**分析框架（教学归纳）** `[据推断]`：
1. 判**类型**（原电池 = 自发电化学；电解池 = 被迫电化学）
2. 定**两极**（正/负极 或 阴/阳极）
3. 写**半反应**（氧化半反应 / 还原半反应）
4. 查**电子流向**与**离子迁移方向**
5. 算**电量—物质量**关系（法拉第定律）

> **德国可借鉴点**：这是**最有价值的一条**。中国课标明确给出「**电极反应 / 电极材料 / 离子导体 / 电子导体**」四要素系统框架，德国 KLP 的 `Elektrochemie` 更偏现象与储能应用，**缺少一个统一的「分析四要素」抓手**。**嫁接入口**：做成 Q1 的 `Analyseraster`，与德国已有的 `Redoxreihe` 拼接。

### 5.4 有机推断的思路链

**课标依据** `[已验证]`：
- 模块3 主题1 内容要求 1.2：「**同一分子中官能团之间存在相互影响**」「在一定条件下**官能团可以相互转化**」「知道常见官能团的**鉴别方法**」
- 模块3 主题1 内容要求 1.3：「**基团之间的相互影响会导致键的极性发生改变**」
- 模块3 主题2 内容要求 2.3：「**认识有机合成的关键是碳骨架的构建和官能团的转化**，了解**设计有机合成路线的一般方法**」
- 模块3 学业要求主题2 第 4 条：「能综合应用有关知识完成**推断有机化合物、检验官能团、设计有机合成路线**等任务」
- 模块3 教学提示：「**兼顾正向合成和逆向合成任务**，引导学生关注**结构对比、官能团转化和碳骨架构建**」

**思路链（教学归纳）** `[据推断]`：
1. 由**分子式/不饱和度**推骨架
2. 由**特征反应条件**（如 NaOH/醇、浓硫酸加热）反推官能团
3. 由**红外/核磁**谱图定位官能团与环境
4. **逆向合成分析（Retrosynthese）**：从目标物倒推 → 碳骨架构建 + 官能团转化
5. **官能团保护**策略（课标教学提示明示「体会**官能团保护**、绿色设计等思想」`[已验证]`）

> **德国可借鉴点**：德国 Q2 有机部分**极简**（NRW 有机比重远低于中国），而**逆向合成（Retrosynthese）**在德国属于大学内容。中国的「**碳骨架 + 官能团**双轴分析法」把一个复杂推断题降维成两步，可移植为德国的**选修拓展单元**。
