## 2. 各模块知识点清单

> 条目名取自课标「【内容要求】」的**单元—知识点标题级**信息。
> 标注：**[已验证]** = 直接读官方 PDF 全文确认；**[据推断]** = 由条目语义归纳的**解题技法层**结论（本项目核心价值区，见 ★）。
> ★ = **中国解题技法特色**，德国 KLP 对应位置见 `Mapping/Mathe-DE-CN-Mapping.md`。

### 2.1 必修

#### 主题一 预备知识（18 课时）

**单元 1：集合** [已验证]
- 集合的概念与表示：元素与集合的属于关系；自然语言 / 图形语言 / 符号语言三种刻画；全集与空集
- 集合的基本关系：包含与相等；子集的识别
- 集合的基本运算：并集 / 交集 / 补集；`Venn` 图表达

**单元 2：常用逻辑用语** [已验证]
- 必要条件、充分条件、充要条件（分别与**性质定理 / 判定定理 / 数学定义**对应）
- 全称量词与存在量词
- 全称量词命题与存在量词命题的**否定**（量词互换规则）

**单元 3：相等关系与不等关系** [已验证]
- 等式与不等式的性质（**类比法**：共性 vs 差异）
- **基本不等式** `√(ab) ≤ (a+b)/2 (a,b ≥ 0)`；求简单最大值 / 最小值 ★

**单元 4：从函数观点看一元二次方程和一元二次不等式** [已验证]
- 从函数观点看一元二次方程：借助图象判断**实根存在性与个数**；函数零点与方程根的关系
- 从函数观点看一元二次不等式：借助一元二次函数图象求解不等式，解集用集合表示；**「函数—方程—不等式」三位一体**（二次函数图象法） ★

> **教学提示要求** [已验证]：明确要求「避免编制偏题、怪题，避免繁琐的技巧训练」——此为中国课标内的**反刷题**表述，对照时值得注意。

#### 主题二 函数（52 课时）

**单元 1：函数概念与性质** [已验证]
- 函数概念：用**集合语言 + 对应关系**建立完整函数概念；函数三要素；求简单函数定义域；图象法 / 列表法 / 解析法；分段函数
- 函数性质：**单调性**（用符号语言表达）、**最大值 / 最小值**、**奇偶性**（几何意义）、**周期性**（结合三角函数）
- ☆选学：函数的形成与发展（撰写小论文）

**单元 2：幂函数、指数函数、对数函数** [已验证]
- 幂函数：`y=x, y=1/x, y=x², y=√x, y=x³` 的图象与变化规律
- 指数函数：指数幂拓展（整数 → 有理数 → 实数指数幂）、运算性质、单调性与特殊点
- 对数函数：**对数概念与运算性质**、**换底公式**、单调性与特殊点、**对数函数与指数函数互为反函数**
- ☆选学：对数概念形成史（小论文）

**单元 3：三角函数** [已验证]
- 角与弧度：任意角、**弧度制**、弧度与角度互化
- 三角函数概念和性质：**单位圆定义**（正弦 / 余弦 / 正切）、图象、周期性 / 单调性 / 奇偶性 / 最值、**诱导公式**（由单位圆对称性 + 定义推导）
- 同角三角函数基本关系式：`sin²x + cos²x = 1`、`tan x = sin x / cos x`
- 三角恒等变换：**两角差余弦公式**（推导过程）→ 两角和与差公式 → **二倍角公式**；推导积化和差 / 和差化积 / 半角公式（**不要求记忆**） ★
- 三角函数应用：`y = A·sin(ωx+φ)` 的实际意义与参数影响 ★（**A/ω/φ 三参数体系**）
- ※ 课标提示：三角恒等变换公式**亦可由向量数量积推导**两角差余弦公式（**向量 ⇄ 三角**交叉点）

**单元 4：函数应用** [已验证]
- 二分法与求方程近似解：函数零点与方程解的关系、**零点存在定理**、二分法程序框图、借助计算工具求近似解
- 函数与数学模型：选择恰当函数类型刻画变化规律；比较**「对数增长 / 直线上升 / 指数爆炸」**增长速度差异 ★

#### 主题三 几何与代数（42 课时）

**单元 1：平面向量及其应用** [已验证] ★★（**本项目最高价值区之一**）
- 向量概念：实际背景（力 / 速度 / 位移）、几何表示、基本要素、相等向量
- 向量运算：
  - 加、减运算及运算规则与几何意义
  - **数乘运算**及几何意义；**两向量共线**的含义
  - 线性运算性质及其几何意义
  - **数量积**：由物理「功」引入；概念与物理意义；计算 ★
  - **投影**与投影向量的意义 ★
  - **用数量积判断垂直**
- 向量基本定理及坐标表示：
  - **平面向量基本定理**及其意义（**基底分解**——德国 EF 缺口的上游补位） ★★★
  - **正交分解**及坐标表示
  - 坐标表示加 / 减 / 数乘运算
  - 坐标表示数量积；表示两向量夹角
  - 坐标表示**共线条件、垂直条件**
- 向量应用与解三角形：
  - 向量方法解决平面几何问题、力学问题及其他实际问题
  - 由向量运算**探索三角形边长与角度关系**，导出**余弦定理、正弦定理** ★
  - 用余弦定理、正弦定理解决简单实际问题

> **教学提示** [已验证]：对**非正交分解**只要求一般了解、不必展开。

**单元 2：复数** [已验证]
- 复数的概念：由**方程的解**认识复数；代数表示及其几何意义；两复数相等的含义
- 复数的运算：代数形式的**四则运算**；加 / 减运算的几何意义
- ☆选学：**复数的三角表示**（与代数表示的关系；乘 / 除运算的三角表示及几何意义）

**单元 3：立体几何初步** [已验证]
- 基本立体图形：柱 / 锥 / 台 / 球及简单组合体的结构特征；表面积与体积公式；**斜二测法**画直观图
- 基本图形位置关系：
  - **基本事实 1–4**（即公理 1–4）+ 定理「两组边分别平行 ⇒ 两角相等或互补」
  - **性质定理**（由直观感知归纳并**加以证明**）：线面平行 ⇒ 线线平行；面面平行 ⇒ 交线平行；垂直于同一平面的两直线平行；面面垂直 + 交线垂线 ⇒ 线面垂直
  - **判定定理**：线线平行 ⇒ 线面平行；两相交直线平行于同一平面 ⇒ 面面平行；线垂直于面内两相交直线 ⇒ 线面垂直；平面过另一平面的垂线 ⇒ 面面垂直
  - 用已得结论证明空间位置关系的简单命题
- ☆选学：几何学的发展（小论文）

> **教学提示** [已验证]：判定定理在必修阶段**只要求直观感知、操作确认**，**在选择性必修课程中用向量方法论证**——这是 **综合几何法 → 向量法** 的中国式两段衔接设计。

#### 主题四 概率与统计（20 课时）

**单元 1：概率** [已验证]
- 随机事件与概率：**样本点 / 有限样本空间 / 随机事件**；事件的并、交与互斥；**古典概型**及概率计算；概率性质与运算法则；**用频率估计概率**
- 随机事件的独立性：两个事件独立性的含义；利用独立性计算概率

**单元 2：统计** [已验证]
- 获取数据的基本途径及相关概念：统计报表与年鉴、社会调查、试验设计、普查与抽样、互联网；总体 / 样本 / 样本量、数据随机性
  - ※ 教学提示要求介绍**基本计数方法**（树状图、列表）
- 抽样：**简单随机抽样**（抽签法、随机数法）；**分层随机抽样**（各层样本量比例分配、样本均值与方差）；抽样方法的选择
- 统计图表：选择恰当图表做可视化描述
- 用样本估计总体：集中趋势参数（**平均数 / 中位数 / 众数**）；离散程度参数（**标准差 / 方差 / 极差**）；取值规律；**百分位数** ★

#### 主题五 数学建模活动与数学探究活动（6 课时） [已验证]

- 数学建模活动基本过程：发现提出问题 → 分析问题、构建模型 → 确定参数、计算求解 → 检验结果、改进模型 → 解决实际问题
- 数学探究活动：发现问题 → 猜测结论 → 提出思路方案 → 自主探索 / 合作论证
- 必修阶段要求完成 **1 个课题研究**；报告形式：专题作业 / 测量报告 / 算法程序 / 实物 / 研究报告 / 小论文

### 2.2 选择性必修

#### 主题一 函数（30 课时）

**单元 1：数列** [已验证] ★★★（**项目第一优先级嫁接入口**）

- 数列概念：数列的表示方法（列表 / 图象 / **通项公式**）；数列是**一类特殊函数**
- **等差数列**：
  - 概念与**通项公式**的意义
  - **前 n 项和公式**；通项公式与前 n 项和公式的**关系**（`aₙ = Sₙ − Sₙ₋₁`） ★
  - 在情境中发现**等差关系**并解决问题
  - 体会**等差数列 ⇄ 一元一次函数**的关系
- **等比数列**：
  - 概念与**通项公式**的意义
  - **前 n 项和公式**；与通项公式的关系 ★
  - 在情境中发现**等比关系**并解决问题
  - 体会**等比数列 ⇄ 指数函数**的关系
- ☆选学：**数学归纳法**原理；用数学归纳法证明数列中的简单命题 ★
- ★ **技法层归纳** [据推断]（课标只给「探索并掌握」，以下为中国教学实践普遍展开的技法，课标正文未逐条列出）：
  - **递推构造**：由 `aₙ₊₁ = p·aₙ + q` 等递推式构造等差 / 等比数列求通项
  - **错位相减**：`{等差 × 等比}` 型数列求和
  - **裂项相消**：分式型通项拆分为差式后相消求和
  - **分组求和**：可拆为若干等差 / 等比或可求和子列的数列
  - **倒序相加**：与等差数列前 n 项和推导同源
  - ※ **与德国接点**：NRW KLP 点名的跨领域概念 `Iteration` 与 `Kumulation` 正是数列的语言（见 `00-Design.md § S1 结论`）。
- ※ 教学提示要求结合中国古代数学成果（**杨辉三角**、《四元玉鉴》）阅读，撰写小论文。

**单元 2：一元函数导数及其应用** [已验证] ★★★

- 导数概念及其意义：
  - 由**平均变化率 → 瞬时变化率**的过程了解导数概念及其实际背景 ★
  - 体会**极限思想**
  - 由函数图象**直观理解导数的几何意义**（切线斜率）
- 导数运算：
  - 由定义求 `y=c, x, x², x³, 1/x, √x` 的导数
  - **基本初等函数导数公式 + 四则运算法则**；简单**复合函数**（限于形如 `f(ax+b)`）的导数
  - 会使用**导数公式表**
- 导数在研究函数中的应用：
  - **单调性与导数的关系**；利用导数研究单调性；求**不超过三次的多项式函数**的单调区间 ★
  - 在某点取得**极值的必要条件与充分条件**；求极大值 / 极小值；求给定闭区间上不超过三次多项式函数的**最大值 / 最小值** ★
  - 体会**导数 ⇄ 单调性 / 极值 / 最值**的关系
- ☆选学：微积分的创立与发展（牛顿、莱布尼茨、柯西、魏尔斯特拉斯等；研究报告）
- ★ **技法层归纳** [据推断]（课标给出了工具，**未**显式命名以下题型；这是中国高考的核心区分点）：
  - **用导数证明不等式**（将「求极值」升级为「作证明」，德国无此题型，但**不需要新知识点**） ★★★
  - **含参数单调性讨论**（按参数分类讨论导函数零点位置）
  - **恒成立 / 存在性问题转化为最值问题**
  - **零点个数讨论**（结合单调性与极值符号）
  - ※ **与德国接点**：项目判定此为「**性价比最高**」的嫁接项，直接补强德国偏弱的 `Argumentieren`（AFB III）。

#### 主题二 几何与代数（44 课时）

**单元 1：空间向量与立体几何** [已验证]

- 空间直角坐标系：建立必要性；刻画点的位置；由特殊长方体顶点坐标探索**空间两点间距离公式**
- 空间向量及其运算：由平面向量**类比推广**到空间向量（概念 + 运算及法则）
- 向量基本定理及坐标表示：
  - **空间向量基本定理**及其意义；**正交分解**及坐标表示
  - 线性运算及其坐标表示
  - **数量积**及其坐标表示
  - **投影**与投影向量的意义
- 空间向量的应用 ★：
  - 用向量语言描述直线和平面：**直线的方向向量、平面的法向量** ★
  - 用向量语言表述线线 / 线面 / 面面**夹角**及**垂直与平行**关系
  - **用向量方法证明必修内容中的判定定理**（衔接必修主题三）
  - 用向量方法解决**点到直线 / 点到平面 / 平行直线间 / 平行平面间的距离**问题与简单夹角问题，并能描述解题程序 ★

**单元 2：平面解析几何** [已验证] ★★★（**中国深度显著超过德国**）

- **直线与方程**：
  - 确定直线位置的几何要素；**倾斜角与斜率**概念；过两点直线斜率的计算公式
  - 由斜率判定两条直线**平行或垂直**
  - 直线方程的形式：**点斜式、两点式、一般式**
  - 用**解方程组**求两直线交点坐标
  - **两点间距离公式、点到直线距离公式**；两平行直线间距离
- **圆与方程**：
  - 圆的**标准方程与一般方程**
  - 由方程判断**直线与圆、圆与圆的位置关系**
  - 用直线和圆的方程解决简单数学问题与实际问题
- **圆锥曲线与方程** ★★★：
  - 圆锥曲线的实际背景
  - **椭圆**：由情境抽象出定义 → **标准方程 + 简单几何性质**（**掌握**级） ★
  - **抛物线、双曲线**：定义、几何图形、标准方程、简单几何性质（**了解**级） ★
  - 体会**数形结合**思想；椭圆、抛物线的简单应用
  - ★ **技法层归纳** [据推断]：**统一处理框架**——建系 → 设方程 → 联立 → 消元得一元二次方程 → 韦达定理（根与系数关系）→ 弦长公式 / 中点弦 / 定点定值 / 最值范围；这是中国解析几何的标准答题链路，**德国 KLP 无对应深度**。
- ☆选学：平面解析几何的形成与发展（小论文）

#### 主题三 概率与统计（26 课时）

**单元 1：计数原理** [已验证] ★
- 两个基本计数原理：**分类加法计数原理、分步乘法计数原理** ★
- 排列与组合：排列、组合的概念；由计数原理**推导排列数公式、组合数公式** ★
- **二项式定理**：用多项式运算法则和计数原理**证明**；解决二项展开式有关的简单问题 ★

**单元 2：概率** [已验证]
- 随机事件的条件概率：**条件概率**计算；条件概率与独立性的关系；**乘法公式**；**全概率公式** ★；☆选学 **贝叶斯公式**
- 离散型随机变量及其分布列：概念；**分布列及数字特征（均值、方差）**；**伯努利试验**；**二项分布**及其数字特征；**超几何分布**及其均值 ★
- 正态分布：由**误差模型**了解服从正态分布的随机变量；借助**频率直方图**的几何直观了解正态分布特征；正态分布的均值、方差及含义 ★

**单元 3：统计** [已验证]
- 成对数据的统计相关性：**样本相关系数**的统计含义；与**标准化数据向量夹角**的关系（**统计 ⇄ 向量** 交叉点）★
- 一元线性回归模型：模型含义；参数统计意义；**最小二乘原理**；参数的**最小二乘估计**；用统计软件；用模型进行预测 ★
- **2×2 列联表**：统计意义；**独立性检验**及其应用 ★

## 4. 高考（等级性考试）考查要求

- **考查范围**：**必修 + 选择性必修**（8 + 6 = **14 学分**；必修 144 课时 + 选择性必修 108 课时） [已验证]
  - ※ 选修课程**不在高考范围内**，供大学自主招生参考。
- **依据水平**：**水平二** —— 原文：「数学学业质量水平二是高考的要求，也是数学高考的命题依据」 [已验证]
- **核心素养（6 项）** [已验证]：
  1. **数学抽象** —— 从数量 / 图形关系抽象出数学概念及关系；从具体背景抽象出一般规律和结构并用数学语言表征
  2. **逻辑推理** —— 从事实与命题出发依规则推出其他命题；含**归纳、类比**（特殊→一般）与**演绎**（一般→特殊）
  3. **数学建模** —— 对现实问题作数学抽象、用数学语言表达、用数学方法构建模型解决问题
  4. **直观想象** —— 借助几何直观与空间想象感知事物形态与变化
  5. **数学运算** —— 在明确运算对象的基础上依运算法则解决数学问题
  6. **数据分析** —— 针对研究对象获取数据，运用数学方法对数据整理、分析、推断
- **每主题「重点提升」的素养**（课标【学业要求】末句明示） [已验证]：

| 必修 主题二 函数 | 数学抽象、数学建模、数学运算、直观想象、逻辑推理 |
| 必修 主题三 几何与代数 | 直观想象、逻辑推理、数学运算、数学抽象 |
| 必修 主题四 概率与统计 | 数据分析、数学建模、逻辑推理、数学运算 |
| 必修 主题五 建模与探究 | 数学建模、数学抽象、数据分析、数学运算、逻辑推理、直观想象（**全部六项**） |
| 选必 主题一 函数 | 数学抽象、数学运算、直观想象、数学建模、逻辑推理 |
| 选必 主题二 几何与代数 | 直观想象、数学运算、数学建模、逻辑推理、数学抽象 |

## 5. 与德国体系的初步对照线索

> ⚠️ **无官方中德对照文件**。本节只列「可对照维度」，具体映射见 `Mapping/Mathe-DE-CN-Mapping.md`。

| 维度 | 中国 | 德国 NRW |
|---|---|---|
| 结构单位 | **主题 → 单元 → 编号条目**（三级，含课时的硬约束） | **Inhaltsfeld → inhaltliche Schwerpunkte**（无课时约束） |
| 取向 | 内容 / 知识导向，**规定细到知识点**；同时并行一条建模探究主线 | **能力导向（Kompetenzen）**，淡化内容标准 |
| 学段划分 | 必修 / 选择性必修 / 选修（**按学习路径**切） | EF / Q1 / Q2（**按学年**切），GK / LK 分流 |
| 水平数 | **3 级**（水平一 = 毕业，水平二 = 高考，水平三 = 自招） | Zentralabitur + EPA **0–15 点制**；AFB I/II/III |
| 能力维度 | **六大核心素养**（数学抽象 / 逻辑推理 / 数学建模 / 直观想象 / 数学运算 / 数据分析） | **五维**（含 Reflektieren 为 Problemlösen 子维度，见 `00-Design.md § 1.6`） |
| 考试时长 | 高考 120 min（全国卷）/ 部分省市 150 min [据推断] | Abitur **300 min**（LK）/ **255 min**（GK） [已验证，见 `01-Quellen.md § A.4`] |
| 题型取向 | 高度强调**解题技法体系**（数列求和、导数证不等式、解析几何联立消元） | 强调 `Argumentieren`（AFB III）与**判断统计**（Konfidenzintervall） |

**关键差异（本项目核心借鉴对象）** [据推断]：
1. **数列** —— 德国 KLP 全文无此主题；中国有独立大板块（30 课时）。**合法嫁接入口**：`Iteration` 与 `Kumulation`。
2. **用导数证明不等式** —— 德国无此题型，但**不需要新知识点**（EF 已教单调性与极值）。**性价比最高**。
3. **平面向量基本定理（基底分解）** —— 中国在必修阶段完成；德国 EF 无 `Skalarprodukt`，而 Q1 的 G 域几乎全建立其上。

> ⚠️ **反向落差**（`both-de-deeper`）：德国 LK 的**判断统计学**（Konfidenzintervall + Stichprobenumfang 估算）深度超过中国选择性必修（中国此项仅在 A/B 类选修中出现）。德国 `Normalverteilung` 的 `Verteilungsfunktion = Integralfunktion` 解释是中国 S⇄A 交叉的唯一显式对应点。
