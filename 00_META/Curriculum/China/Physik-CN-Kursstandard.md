## 1. 课程结构

| 层次 | 构成 | 学分/课时 | 性质 |
|---|---|---|---|
| **必修** | 必修1、必修2、必修3（3 模块） | **每模块 2 学分，共 6 学分** [已验证] | 全体必学 |
| **选择性必修** | 选择性必修1、选择性必修2、选择性必修3（3 模块） | **每模块 2 学分，共 6 学分** [已验证] | 升学需求；**三模块有递进关系** |
| **选修** | 选修1、选修2、选修3（3 模块，**仅供参考**） | **每模块 2 学分，共 6 学分** [已验证] | 学校自主开设、自主考核；**三模块为并列关系** |

**结构逻辑** [已验证]：
- 必修 = 高中生物理核心素养发展的**共同基础**；选择性必修 = 按升学要求选择；选修 = 自主选择。
- 选择性必修三模块**有递进关系**（注重系统性）；选修三模块**是并列关系**（分别从物理学与社会、技术、近代物理三个方向展开）。
- 学完必修后可先选选择性必修、再选修选修；**选择性必修建议按模块顺序学习**以保证衔接。

**学考关系**（原文依据见 §4）[已验证]：
- **合格性考试**（高中毕业）：学完 **必修 课程**即可参加；**水平 2 为合格**。
- **等级性考试**（**高考**，用于高等院校招生录取）：学完 **必修 + 选择性必修** 两部分即可参加；**水平 4 为依据**。

## 3. 学业质量水平

- **本科水平数：5 级**（⚠️ 物理 **5 级**，与数学 3 级、化学 4 级、生物 4 级不同，**禁止套用**）[已验证]

**水平划分依据** [已验证]*（结构性要点，非原文照录）*：按四要素（物理观念 / 科学思维 / 科学探究 / 科学态度与责任）描述，**按「问题情境的复杂程度、知识技能的结构化程度、思维方式或价值观念的综合程度」由低到高递进**；每一级水平**都同时包含四个方面**。

| 水平 | 对应考试 | 关键词（依四要素综合归纳）[据推断] |
|---|---|---|
| 水平 1 | —（基础起点） | 初步了解概念规律；能说出简单模型；在他人指导下收集数据；有好奇心 |
| 水平 2 | **合格性考试（毕业）** | 了解概念规律，解释**简单自然现象、解决简单实际问题**；能在**熟悉情境**中应用常见模型；能按**已有方案**获取数据 |
| 水平 3 | —（过渡） | 了解概念规律的**相互关系**；能**根据需要选用恰当模型**；能在他人帮助下**制订方案** |
| 水平 4 | **等级性考试（高考）★** | **理解**概念规律及相互关系，**综合应用**解决实际问题；能把实际问题的对象与过程**转换成物理模型**；能对**综合性**问题分析推理；能**制订方案**、选用合适器材；能撰写**完整**实验报告 |
| 水平 5 | 最高（超出高考要求） | 清晰系统理解；能处理**较复杂**实际问题、在**新情境**中推理；解决物理问题**具有新颖性**；能制订**有一定新意**的方案 |

> **水平 4 与水平 2 的实质分界** [据推断]：水平 2 是「**熟悉情境中的单点应用**」，水平 4 是「**真实情境中的建模 + 多规律综合**」。这条分界正是中德对照的关键刻度（德国 AFB II = Reorganisation und Transfer 与之高度同构）。

  - 取向 = 体现**基础性和全面性**；考查对必修基本概念和基本规律的**了解和认识**；围绕生产生活或科技设计问题情境，考查**运用基础知识解决简单实际问题**的能力
- **等级性考试（高考，用于高等院校招生录取）**：
  - 范围 = **必修 + 选择性必修 两部分内容**（⭐ 选修1-3 **不在**高考范围）
  - 依据 = **学业质量水平 4**（原文："学业质量水平 4 是用于高等院校招生录取的学业水平等级性考试的命题依据"）
  - 取向 = 体现**综合性和应用性**；考查对**重要物理概念与规律的理解与运用**；情境与生产生活、科技发展紧密联系；关注**物理学前沿与成果应用**；强调**创新精神和实践能力**；要求试卷有**较好区分度**

### 4.2 试卷与题型结构要求 [已验证]

- 需制订**多维命题细目表**（试卷长度、内容结构、难度结构）。
- **选择题**：鉴别对概念规律及其相互关系的**理解**，提高**覆盖面**与**信度**。
- **非选择题**：呈现**解答过程**，深入反映**分析问题、解决问题的能力**，评价**较高层次**的核心素养。
- **难度设计维度**：素养水平层次 × 情境复杂性/新颖性 × 知识深度/广度。
- **情境要求**：具有**问题性、真实性、探究性或开放性**；尽量创设**类型多样、有一定复杂程度的开放性真实情境**。
- **评分标准**：须基于核心素养**研制等级**，摒弃单纯知识性描述。
- **试题命制三步骤**：① 依素养与学业质量水平定**考核目标** → ② 依内容要求设**任务情境** → ③ 依水平与行为表现定**评分标准**。

### 4.4 ⭐ 物理解题方法层次（课标明示或强推导的技法链）

> 这是**德国可借鉴处**的核心。课标在「教学建议」中**明确点名**了若干方法论（尤其「等效思想」「分析与综合」「模型建构」），其余为从内容要求条目归纳的**高考实际考查技法**。

**A. 受力分析：整体法与隔离法** [据推断，由 1.2.2 + 1.2.3 + 选择性必修1 归纳]
- 课标**明示的基础**：「共点力的平衡条件」（必修1.2.2）与「用牛顿运动定律解决问题」（必修1.2.3）。
- 课标**明示的方法论**：在「力的合成与分解」「运动的合成与分解」教学中，要让学生经历「**把一个整体事物分解为几个要素研究**」与「**把几个要素结合成整体进行综合认识**」的思维过程，并体会「**等效**」的物理思想 [已验证，教学建议原文要点]。
- **层次链**（高考实操）[据推断]：
  1. 单物体受力分析（重力→弹力→摩擦力→其他力；**按性质分类不按效果**）
  2. **隔离法**：系统内各物体**加速度不同**时必须隔离，逐体列牛顿第二定律
  3. **整体法**：系统内各物体**加速度相同**时优先整体，只解外力
  4. **整体 + 隔离混合**：整体求系统外力 → 隔离求内力（常见于连接体、叠放体、斜面-滑块）
  5. **等效法**：把多个力等效为合力（合成/分解），把「非共点」等效为共点（三力汇交）
- **德国对照位**：德国 KLP Physik 的 Kraft 概念在 EF 引入，但**很少系统训练「整体/隔离」的判据（加速度是否相同）**。这是 `CN-only` 倾向的方法论。→ 建议做成《整体法与隔离法决策卡》。

**B. 动能定理 vs 动量定理的选择策略** [据推断，由必修2.1.2 + 选必1.1.1 归纳]
- 课标明示的两条定理均已完备覆盖：**动能定理**（必修2.1.2，且课标明示「**可由牛顿第二定律推导出**」）与**动量定理**（选必1.1.1，明示「通过**理论推导和实验**理解」，并要求体会「动量定理与牛顿第二定律的**一致性**」）[已验证]。
- **选择策略层次链** [据推断]：
  1. **看已知量与未知量**：涉及**位移/路程** → 优先动能定理；涉及**时间** → 优先动量定理
  2. **看力的性质**：**变力做功**问题 → 动能定理（动能定理对变力、曲线运动也成立，是最大优势）；**变力冲量**问题 → 动量定理（如流体碰撞、平均力）
  3. **看过程特征**：**碰撞/爆炸/反冲**（极短时间、内力远大于外力）→ 动量守恒；**摩擦生热/多过程能量转化** → 能量守恒/动能定理
  4. **组合解**：**动量守恒 + 能量守恒**联立解一维碰撞（弹性/非弹性）；**动量定理 + 动能定理**分列解同一过程
  5. **矢量性提醒**：动量定理是**矢量式**（须定正方向），动能定理是**标量式**（无方向）——**这是选择策略的第一判据**
- **德国对照位**：德国 KLP Physik 有 `Impuls` 与 `Energiesatz`，但**中德共同点较高**（`both-equal` 或 `both-cn-deeper`）；中国的优势在**「选择策略」被显式训练**（因高考题量大、需快速定位），德国偏向概念理解。→ 建议做成《Impuls vs. Energie 决策树》。

**C. 带电粒子在电磁场中的轨迹分析（尤其偏转）** [据推断，由必修3.1.5 + 选必2.1.3 归纳]
- 课标明示的**两条并列路径**：
  - **电场偏转**（必修3.1.5）：「能分析**带电粒子在电场中的运动**情况」→ 实操为**类平抛**（`E` 沿电场方向加速 + 垂直方向匀速），轨迹是**抛物线** [据推断]
  - **磁场偏转**（选必2.1.3）：「能用**洛伦兹力**分析带电粒子在**匀强磁场**中的**圆周运动**」「了解带电粒子在匀强磁场中的**偏转**及其应用」，并点名 **质谱仪** 与 **回旋加速器** [已验证]
- **轨迹分析层次链** [据推断]：
  1. **判据分流**：力与速度同向 → 直线加速；力⊥速度 → 圆周运动；力与速度成角 → 螺旋线（可选）
  2. **电场中**：`qE = ma` → 类平抛分解（沿场：匀加速；垂直场：匀速）→ **偏转角 tanθ = v⊥/v∥**
  3. **磁场中**：`qvB = mv²/r` → **半径 r = mv/(qB)**、**周期 T = 2πm/(qB)（与速度无关！）** ← 回旋加速器的原理根基
  4. **几何法核心**：**定圆心**（两处洛伦兹力方向的垂线交点）→ **找半径**（几何/三角函数）→ **算圆心角**（= 偏转角）→ **t = (θ/2π)·T**
  5. **临界问题**：速度方向连续变化 → 用**旋转圆/放缩圆/平移圆**三种几何模型（高考高频）[据推断]
  6. **复合场**：电场+磁场+重力并存 → 分类讨论（平衡/匀速直线/匀速圆周）
- **德国对照位**：⭐ **这是中德差异最大处**。德国 KLP Physik 对带电粒子在磁场中的运动**只做定性/半定量处理**（`F = qvB` 的引入与方向判定），**极少系统训练「定圆心-找半径-算圆心角」的几何化解题链**，也不涉及质谱仪/回旋加速器的定量计算。→ **`CN-only` 高价值模块**，适合做《Lorentzkraft 轨迹几何法》专题卡。

**D. 电路的等效变换与动态分析** [据推断，由必修3.2.3 + 3.2.4 归纳]
- 课标明示的基础：**串并联电路电阻特点**（3.2.3）、**闭合电路欧姆定律**（3.2.4，并要求"体会**图像法**在研究物理问题中的作用"——即 **U-I 图像求 E 与 r**）、**电功、电功率及焦耳定律**（3.2.5）[已验证]
- **技法层次链** [据推断]：
  1. **等效变换**：串联/并联化简；**等效电源**（把 `(E,r)` 与一个电阻打包成新 `(E',r')`）；电表内阻的处理与"电表改装"
  2. **动态分析（滑动变阻器/B 变化引发电学量联动）**：
     - **程序法**：局部 R 变化 → 总 R 变化 → 总 I 变化（闭合欧姆定律）→ 路端电压变化 → 局部电压/电流变化（**"串反并同"口诀**）
     - **极限法/特殊值法**：把变阻器推向 0 与 ∞ 两端快速定位
     - **图像法**：U-I 图像中**斜率 = -r**，纵截距 = E
  3. **功率分析的"三值"区分**：电源总功率 / 电源输出功率（高效点 R = r）/ 内耗功率
- **德国对照位**：德国 KLP Physik 的 EF 电路内容偏**定性 + 简单定量**（Ohmsches Gesetz、Reihen-/Parallelschaltung），**对动态电路分析、等效电源、U-I 图像求 r 的系统训练远少于中国**。→ 倾向 `CN-only` / `both-cn-deeper`，适合做《Dynamische Schaltungsanalyse》技法卡。

## 5. 与德国体系的初步对照线索

> ⚠️ **无官方中德对照文件**。本节只列「可对照维度」，具体映射见 `Mapping/`。

| 维度 | 中国（物理） | 德国 NRW（Physik KLP 2022/23） |
|---|---|---|
| **结构单位** | 模块（必修1-3 / 选必1-3 / 选修1-3）× 主题 × 编号条目 | **Inhaltsfelder + inhaltliche Schwerpunkte**，分 EF / Q1 / Q2 |

| **能力清单** | 4 项核心素养（物理观念 / 科学思维 / 科学探究 / 科学态度与责任） | 各科 Kompetenzbereiche（Sach-/Methoden-/Urteilskompetenz 类）+ **Erkenntnisgewinnung / Kommunikation / Bewertung** |

| **数学化深度** | 高：矢量运算、图像法、几何法（轨迹）、微元/极限方法**明示** | 中等：EF 阶段偏概念与定性 |

| **STSE / 社会责任** | **显式独立素养**（科学态度与责任，含 STSE） | 有 `Bewertung`，但 STSE 不构成独立素养维度 |
| **高考（等级考）范围** | **必修 + 选择性必修**（选修1-3 不考） | Abitur 覆盖 Q1/Q2 的 IF（外加 EF 基础） |

**结构关键差异（供 Mapping 用）** [已验证/据推断]：
1. 中国物理的**知识总量显著更大**（9 模块 vs 德国 EF+Q1+Q2 的有限 IF），且**必做实验被逐条规定**（21 个）——德国无此机制。
2. 中国在**「解题方法」层有隐性但极强的要求**（见 §4.4 四条技法链），高考题量驱动；德国以 AB II（Reorganisation und Transfer）为重心，但**不训练固定技法套路**。→ **这是最有价值的嫁接点**。
3. 中国的「**核心素养 4 项**」是可迁移的能力框架，与德国能力取向**兼容**，可作为中德对话的公共语言（对比：数学 6 项 / 化学 5 项 / 生物 4 项）。
