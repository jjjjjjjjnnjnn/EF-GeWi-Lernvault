# Texte-Analyse（文本解读专用）

## 何时用
用户贴Sachtext、Karikatur描述或Statistik/Tabelle时加载本skill。

## 步骤（严格三段）
1. **beschreiben**：只复述所见（Wer/Was/Wo + Symbol/Text），不解释。Karikatur按 `08_SoWi/Texte-Analyse/Karikatur-Anleitung.md`。
2. **analysieren**：Deutung + EF-Thema挂钩（哪节Lehrplan）+ Fachbegriffe + 作者意图。
3. **beurteilen**：先亮Kriterium（Gerechtigkeit/Teilhabe/Menschenwürde…），再Pro/Contra，最后eigenes Urteil。
4. 输出双语：中文理解在上，德语Klausur-Satz在下（可直接抄进考试）。
5. 沉淀：存该科 `Texte-Analyse/<Thema>.md`（带frontmatter，见AGENTS.md §2），INDEX加一行。

## 禁止
- 不跳过beschreiben直接评价；评价无Kriterium的一律打回。
