# Mathe Q1/Q2 Terminologie (数学 Q1/Q2 术语对照表 DE-CN-EN)

> **中文理解**：这是一张**术语卡性质的元笔记**，不是知识讲解，而是**查词表**。它汇总 Q1/Q2 的 **G 域（解析几何与线性代数）**与 **S 域（随机与统计）**术语——这两块正是现有笔记最薄弱、且德国 KLP 有大量**专名**（如 `Normalenform`、`Prognoseintervall`）的地方 [据推断]。
> 数学答卷按 `Darstellungsleistung`（表达分）评分：**术语用错或用中文式直译，即使算对也会扣分** [已验证]。因此本表的使用方式是**默写**，不是通读。
> 术语全部取自 NRW KLP 的 Schwerpunkte 命名（标 [已验证]）与本项目对中德对照的归纳（标 [据推断]）；EN 列仅供国际教材对照，非德国考试用语。
>
> **Klausur-Relevanz**：G 与 S 域的**专名**是免工具题（Aufgabenart I）与术语解释题的稳定得分点；`Normalenform`、`Verteilungsfunktion` 等 KLP 专名必须**原样写出** [已验证]。

## 7. 术语自测（3 题 + 答案）

**Aufgabe 1** `[原创]`
> Nennen Sie die deutsche Bezeichnung für: ① 法向式 ② 异面 ③ 置信区间 ④ 拐点.

**Aufgabe 2** `[原创]`
> Entscheiden Sie, welche Paare verwechselt werden können, und erklären Sie kurz den Unterschied: (a) `Varianz` / `Standardabweichung`; (b) `Prognoseintervall` / `Konfidenzintervall`; (c) `Normalenform` / `Koordinatenform`.

**Aufgabe 3** `[原创]`
> Ein Schüler schreibt: „Das Integral der Dichtefunktion ist die Wahrscheinlichkeit." Beurteilen Sie die Aussage und formulieren Sie sie fachlich korrekt.

### Musterlösung

**Aufgabe 1**
1. ① `Normalenform` ✓ 得分点：LK 专名
2. ② `windschief` ✓
3. ③ `Konfidenzintervall` ✓
4. ④ `Wendepunkt` ✓ 得分点：四条全对

**Aufgabe 2**
1. **(a)** `Varianz` ist das mittlere Abweichungsquadrat, `Standardabweichung` ist deren Wurzel und hat dieselbe Einheit wie die Daten. ✓ 得分点：指出开方与单位
2. **(b)** `Prognoseintervall`: bekanntes $p$ ⇒ Bereich für eine **künftige** Stichprobe; `Konfidenzintervall`: unbekanntes $p$ ⇒ Schätzung aus der Stichprobe. ✓ 得分点：区分"已知 $p$ / 未知 $p$"
3. **(c)** `Normalenform` ist eine **eigene Darstellungsform** $(x-p)\cdot n=0$ (LK); `Koordinatenform` ist $ax+by+cz=d$. ✓ 得分点：指出 LK 专名

**Aufgabe 3**
1. **Kritik**: Die Aussage ist **ungenau** — nicht das Integral der Dichtefunktion "ist" eine Wahrscheinlichkeit, sondern das Integral über ein Intervall **gibt** die Wahrscheinlichkeit an. ✓ 得分点：指出表述不精确
2. **Korrekte Formulierung**: $P(a\le X\le b)=\int_a^b\varphi(t)\,dt=\Phi(b)-\Phi(a)$; die Verteilungsfunktion $\Phi(x)=\int_{-\infty}^{x}\varphi(t)dt$ ist eine **Integralfunktion**. ✓ 得分点：写出公式 + 点出 Integralfunktion
3. **Ergänzung**: Bei stetigen Zufallsgrößen gilt $P(X=x)=0$; Wahrscheinlichkeiten entsprechen **Flächeninhalten** unter $\varphi$. ✓ 得分点：`beurteilen` 必须给理由
