# QP-Materialien: Karikatur und Gestaltungsaufgabe (宏观题材素材库 + QP 教材地图) `[跨 IF]`

> **中文理解**：EF 阶段的 Karikatur 与 Gestaltungsaufgabe 训练**素材是微观 / 中观的**（政党、参与、消费），而 QP 的题材全部换成 **IF4–IF7 的宏观议题**（经济政策、欧盟、不平等、全球结构）。本篇把**方法层保持不变、素材层整体替换**——这是 EF→QP 四个台阶中的第 ④ 阶。[据推断，SoWi-Oberstufe §5.5 台阶 4]
>
> **Klausur-Relevanz**：Karikatur 是跨 IF 通用材料，Gestaltungsaufgabe 是 Abitur 明列的题型取向之一（`gestalten` 为 SoWi 官方 III 级动词）。两者都**不靠背知识取胜，靠方法稳定性取胜**。[已验证，Operatoren §SoWi `gestalten` = III]

### 2.2 Karikatur 宏观题材：象征词典（**考场速查**）

| 象征 | 常见所指 | 对应 IF |
|---|---|---|
| 天平 / 跷跷板 | 分配不公、目标量冲突 | IF4 · IF6 |
| 破船 / 救生圈 / 水泵 | 危机应对与团结赤字 | IF5 |
| 共同的钱袋 / 钱包 | 共同债务、转移支付 | IF5 LK · IF4 LK |
| 无牙的看门狗 | 执行力缺口、软法 | IF7 |
| 大小不等的椅子 | 决策权不对称 | IF7 · IF5 |
| 生锈的机器 / 搬走的工厂 | 区位劣势、去工业化 | IF7 |
| 沉重的账单 / 沙漏 | 代际负担、财政可持续性 | IF6 |
| 温度计 / 融化的冰块 | 气候治理缺口 | IF7 · IF4 LK-B |

> ⚠️ **表达错高发点**：把「象征」写成「作者认为」。正确写法是「Das Symbol X steht für …，dies deutet auf … hin」。

### 2.3 Gestaltungsaufgabe：六种产品形态与评分要点

| 产品形态 | 典型题干 | 评分要点（三件套） |
|---|---|---|
| **Rede / Redemanuskript** | 在会议上发表演讲 | 立场明确 + 论证有据 + 受众适配 |
| **Offener Brief** | 致部长的公开信 | 诉求具体 + 论据数据化 + 文体规范 |
| **Strategiepapier / Maßnahmenkatalog** | 制定一揽子措施 | 问题 → 工具 → 目标量后果 → 代价 |
| **Beratungspapier / Memo** | 为决策者写咨询要点 | 结构化 + 方案对比 + 推荐理由 |
| **Karikatur / Plakat** | 设计一幅批判性漫画或海报 | 象征选择 + 文字标语 + 概念挂钩 |
| **Szenario / Zukunftsskizze** | 描绘两种未来情景 | 条件差异清晰 + 后果链完整 |

> *Klausur-Satz*: `Eine Gestaltungsaufgabe verlangt nicht nur eine Position, sondern ein adressatengerechtes Produkt — bewertet werden Inhalt, Struktur und Form zugleich.` [据推断]

### 2.5 Abitur「3 题选 1」的选题策略

1. **先扫 Operator，不先读材料**：看三题的动词分布，优先选 AFB III 有把握的那题。
2. **再看 IF 归属**：Abitur 2027 聚焦 IF4+IF6 → 这两 IF 的题通常与材料贴合度最高。
3. **再看材料类型**：Karikatur + 数据 + 文本的组合题信息量最大，但也最耗时；240 min（GK）要留够写作时间。
4. **最后看 Gestaltungsaufgabe**：若出现设计任务，**必须先锁定 Adressat 与 Textsorte**，再动笔。

> ⚠️ **时间红线**：选题时间计入总时长，且**一旦选定不得中断** [已验证，SoWi-Oberstufe §4]。

## 3. 解题方法 (Methoden)

### 3.1 Karikatur 三步法（宏观题材版，**全科通用**）

**编号步骤**：
1. **beschreiben（AFB I–II）**：Wer / Was / Wo + 图像元素 + 文字标语 + 象征物。
   ——*KLP 工具：beschreiben（I–II）*
2. **analysieren（AFB II）**：① Deutung（象征指向什么）② Kontext（哪一 IF、哪一争议）③ Intention（作者批判什么）。
   ——*KLP 工具：analysieren（überw. II）+ interpretieren（II–III）*
3. **beurteilen（AFB III）**：明示 Kriterium → Pro / Contra → 带条件 Urteil。
   ——*KLP 工具：beurteilen（III）*

> **判据 / 决策点**：题干只写 `beschreiben und analysieren` → 停在第 2 步；出现 `beurteilen` / `Stellung nehmen` → 必须走第 3 步并写出 Kriterium。

### 3.2 Gestaltungsaufgabe 五步法（`gestalten`，AFB III）

1. **定任务**：产品是什么（Rede / Brief / Strategie / Karikatur / Szenario）？——*KLP 工具：gestalten 定义「产品导向」* [已验证]
2. **定受众**：写给谁（部长 / 公众 / 同学 / 企业）？语域随之变化。——*KLP 工具：Adressatenbezug*
3. **定立场**：一句话表态 + 两条核心论据（可从材料与知识库取）。
4. **定结构**：按产品体裁搭骨架（演讲 = 开场 → 论证 → 呼吁；备忘录 = 问题 → 方案 → 建议）。
5. **回检**：是否至少挂了 **2 个 Fachbegriffe**？是否回应了材料？是否写了代价？

> ⚠️ **常见失分**：只写立场不写产品形态 → 不符合 `gestalten` 的定义；或产品里出现「我认为」而缺少文体化的表达。

### 3.3 材料分析三步（QP 版，30/40/30）

1. **darstellen**（约 30%，AFB I–II）：Materialart / Autor / Kernaussage / 材料间关系。
2. **analysieren**（约 40%，AFB II）：归入 IF + 模型 + 立场；指出材料之间的**一致或冲突**。
3. **erörtern / bewerten / gestalten**（约 30%，AFB III）：按 Kriterium 权衡 → 判断或产品。

### 3.4 多材料组合的阅读顺序

先读最短的（漫画文字 / 数据标题）建坐标 → 再读立场文本标出两个核心论断 → 最后读数据，只找能支持或反驳前两步的数字。写作时**材料引用带编号**（M1/M2/M3），这是可见得分点。[据推断]

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | Karikaturanalyse（跨 IF）· Gestaltungsaufgabe（产品导向）· 多材料组合题 |
| Operator | `beschreiben`（I–II）· `analysieren`（überw. II）· `interpretieren`（II–III）· `beurteilen`（III）· `gestalten`（III）· `entwickeln`（III） |
| AFB | I（图像描述）→ II（象征解读与归类）→ **III（评价 / 产品构建）** |
| 建议分值 / 时长 | Abitur SoWi GK 240 min / LK 300 min（3 题选 1，含选题时间，不得中断）[已验证，SoWi-Oberstufe §4] |

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> Beschreiben Sie die Karikatur und analysieren Sie, auf welchen Sachverhalt des Inhaltsfeldes sie sich bezieht. (AFB I–II)

**Aufgabe 2** `[原创]`
> Eine Karikatur zeigt eine Waage, auf deren einer Seite ein Container, auf der anderen ein überquellender Korb mit Grundnahrungsmitteln liegt. Interpretieren Sie die Karikatur und ordnen Sie sie einem Inhaltsfeld zu. (AFB II)

**Aufgabe 3** `[NRW-改编]`
> Beurteilen Sie die Aussage der Karikatur anhand eines selbst gewählten Kriteriums aus dem Bereich der Verteilungs- oder Legitimationsfragen. (AFB III)

**Aufgabe 4** `[原创]`
> Entwerfen Sie auf Grundlage der Materialien eine Rede für eine Podiumsdiskussion zur Frage, ob eine stärkere europäische Integration wirtschaftlich vorteilhaft ist. (AFB III)

**Aufgabe 5** `[NRW-改编]`
> Entwickeln Sie ein Strategiepapier mit drei Maßnahmen zur Bewältigung eines demografisch bedingten Finanzierungsproblems der sozialen Sicherung und begründen Sie die Auswahl Ihrer Maßnahmen. (AFB III)

### 5.3 Musterlösung

**Aufgabe 1**（beschreiben + analysieren）
1. **Beschreibung**：Ort, Figuren, Gegenstände, Text,象征物 ✓ 得分点（AFB I）
2. **Deutung**：象征指向的争议（分配 / 合法性 / 执行缺口）✓ 得分点（AFB II）
3. **Zuordnung**：Inhaltsfeld benennen + 材料与 IF 条目的对应关系 ✓ 得分点（AFB II）
4. **Fazit**：`Die Karikatur greift mit dem Symbol X ein Kernproblem des Inhaltsfeldes Y auf.` ✓

**Aufgabe 2**（interpretieren + einordnen）
1. **Bildbefund**：Waage, Container vs. gefüllter Korb ✓ 得分点（AFB I–II）
2. **Deutung**：Ungleichgewicht zwischen Handelsgewinnen und Grundversorgung bzw. zwischen Exportinteressen und Verteilungsfragen ✓ 得分点（AFB II）
3. **Einordnung**：IF7（ internationale Wirtschaftsbeziehungen）或 IF6（分配）✓ 得分点（AFB II）
4. **Intention**：Kritik an einer Priorisierung, nicht an der Globalisierung als solcher ✓

**Aufgabe 3**（beurteilen，AFB III）
1. **Kriterium 明示**：Verteilung（公平）或 Legitimation（合法性）✓ 得分点
2. **Pro-Argument**：Karikatur trifft einen realen Mechanismus（如 Regulierungswettbewerb）✓ 得分点
3. **Contra-Argument**：Überzeichnung, Ausblendung der Konsumentengewinne ✓ 得分点
4. **Synthese**：`Unter der Bedingung, dass die Karikatur als Zuspitzung eines realen Verteilungsproblems gelesen wird, ist ihre Aussage tragfähig; als Pauschalurteil über Handel überzeichnet sie.` ✓

**Aufgabe 4**（entwerfen，Rede）
1. **Adressat & Textsorte**：Podiumsdiskussion, Redemanuskript ✓ 得分点
2. **Position**：klare These mit zwei Argumenten（Binnenmarkt, Währungsunion）✓ 得分点
3. **Gegenargument einbeziehen**：Souveränitäts- und Legitimationskosten ✓ 得分点
4. **Rhetorische Form**：Ansprache, Überleitung, Appell ✓ 得分点
5. **Fachbegriffe**：mindestens zwei（Binnenmarkt, Supranationalität, asymmetrischer Schock）✓

**Aufgabe 5**（entwickeln，Strategiepapier）
1. **Problem**：demografische Belastung der Sozialfinanzierung ✓ 得分点
2. **Maßnahmen**：z. B. Erwerbsbeteiligung erhöhen / Zuwanderungspolitik / Beitrags- und Leistungsanpassung ✓ 得分点
3. **Begründung je Maßnahme**：Wirkung auf Finanzierbarkeit und Verteilung ✓ 得分点
4. **Zielkonflikte**：Akzeptanz, Generationengerechtigkeit, Arbeitsmarktfolgen ✓ 得分点
5. **Format**：klare Struktur（Problem → Maßnahmen → Begründung → Zielkonflikte）✓

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把 Gestaltungsaufgabe 当成普通评价题写（只表态不产出产品）；选题时忽略 Adressat | 动笔前先写「产品形态 + 受众」两行 |
| 知识错 | Karikatur 只描述不挂概念（停在 AFB I）；产品里一个 Fachbegriff 都没有 | 每篇 Karikatur 必挂 1 个概念；每个产品必挂 2 个术语 |
| 表达错 | 写「Der Autor meint…」代替「Das Symbol X steht für…」；材料引用不带编号 | 固定句式 + 材料编号 M1/M2/M3 |
