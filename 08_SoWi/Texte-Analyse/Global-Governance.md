# Global Governance (全球治理) `[LK]`

> **中文理解**：`Global Governance` 的核心是**「没有世界政府，却要有世界秩序」**——治理（governance）不等于政府（government）。KLP IF7 的 LK 专属条目考的不是「有哪些国际组织」，而是**多主体、多层级、无强制力的治理网络如何产生规则，以及它为什么总被指责「合法性赤字」**。[已验证，SoWi-Oberstufe §2 IF7 LK 增量]
>
> **Klausur-Relevanz**：Abitur 2027 聚焦 IF4+IF6，IF7 退居次级；但 Global Governance 是 IF7 里**唯一自带理论坐标**的条目（Government vs. Governance），因此也是 `erörtern` / `problematisieren` 最容易升到 AFB III 的落点。[据推断]

## 2. 知识结构 (Struktur)

### 2.1 Government vs. Governance（**核心对照表，必背**）

| 维度 | Government | Governance |
|---|---|---|
| **主体** | 国家（单一） | 国家 + IO + NGO + 企业 + 网络（多元） |
| **强制力** | 有（法律与暴力垄断） | 无（靠互惠、声誉、互赖） |
| **边界** | 领土排他 | 跨边界、功能导向 |
| **约束形式** | hard law 为主 | soft law、自愿承诺、同行审议 |
| **合法性来源** | 选举与宪法 | 绩效、参与、专业权威（混合） |
| **典型缺陷** | 对外无管辖权 | 合法性赤字、执行乏力 |

> ⚠️ **概念性错误**：把 Global Governance 说成「世界政府」或「世界国家」——**恰恰相反，它是在没有世界政府的前提下运作的**。[据推断]

> *Klausur-Satz*: `Global Governance bezeichnet die Gesamtheit der Regelungsstrukturen jenseits des Nationalstaats, die ohne eine Weltregierung auskommen und deshalb auf Koordination, Reziprozität und institutionelle Selbstbindung angewiesen sind.` [据推断]

### 2.2 主体矩阵（Akteur × Rolle × 合法性来源 × 缺陷）

| 主体 | 角色 | 合法性来源 | 典型缺陷 |
|---|---|---|---|
| **Staaten** | 规则制定者与执行者 | 民主选举 / 宪法 | 大国否决、搭便车 |
| **Internationale Organisationen** | 秘书处、监督、争端解决 | 成员国授权 | 官僚化、授权有限 |
| **NGOs** | 倡议、监督、议题设定 | 会员基础、道义权威 | 代表性不明、问责弱 |
| **Transnationale Unternehmen** | 投资、标准扩散、游说 | 市场绩效 | 私人权威无民主基础 |
| **Epistemische Gemeinschaften** | 知识供给、问题界定 | 专业权威 | 民主问责缺口 |
| **Transnationale Netzwerke** | 监管合作（如监管者网络） | 专业互认 | 透明度低 |

> *Klausur-Satz*: `Charakteristisch für Global Governance ist die Pluralität der Akteure: Neben Staaten und internationalen Organisationen wirken NGOs, Unternehmen und Expertennetzwerke an der Regelbildung mit.` [据推断]

### 2.3 规范的三级约束力

1. **Hard Law**：条约与有约束力的决议（违反可被制裁）。
2. **Soft Law**：宣言、准则、自愿标准（靠声誉与互惠生效）。
3. **Informelle Verständigung**：峰会承诺、同行审议（灵活但易失效）。

> *Klausur-Satz*: `Die Wirksamkeit globaler Governance hängt entscheidend davon ab, welche Bindungsqualität die jeweiligen Normen aufweisen — zwischen völkerrechtlich bindendem Hard Law und unverbindlichem Soft Law liegen erhebliche Durchsetzungsunterschiede.` [据推断]

### 2.4 治理缺口的三个典型领域（**抽象化表述，考场上配材料**）

| 领域 | 治理结构现状 | 缺口所在 |
|---|---|---|
| **Klima / Umwelt** | 框架公约 + 国家自主贡献 | 承诺与执行之间的落差、无制裁 |
| **Handel / Finanzen** | 规则密集（WTO、IWF、G20） | 规则与劳工/环境标准的衔接 |
| **Gesundheit / Gesundheitssicherheit** | 协调机制 + 国家自主 | 公共品供给与融资不足 |

> ⚠️ 这三格是**分析模板**，具体案例由材料提供；不要凭记忆填具体事件。

### 2.5 合法性赤字的两条线（**评价主战场**）

- **Input-Legitimität（输入）**：谁参与决策？是否可问责？→ 赤字：技术官僚化、代表性缺口。
- **Output-Legitimität（输出）**：治理是否有效解决问题？→ 赤字：承诺不执行、搭便车。
- **关键判断**：两者**不能互相替代**——「有效」不能自动补足「不民主」，反之亦然。

> *Klausur-Satz*: `Das Legitimationsdefizit globaler Governance lässt sich präzise in eine Input- und eine Output-Dimension zerlegen: fehlende Rückbindung der Entscheider einerseits, unzureichende Problemlösung andererseits.` [据推断]

### 2.6 改革选项（**`entwickeln` 的弹药库**）

| 方案 | 思路 | 主要反对理由 |
|---|---|---|
| **UN-Reform** | 扩大代表性、改善决策效率 | 大国利益难以触动 |
| **Regionalisierung** | 区域组织承担更多治理功能 | 区域间协调问题、排他性 |
| **Multi-Stakeholder** | 公私主体共同定规则 | 代表性不明、私人利益俘获 |
| **Verrechtlichung** | 从 soft law 走向 hard law | 主权成本高、批准难 |
| **Transparenz / Accountability** | 强化问责与信息公开 | 效果有限、成本增加 |

## 3. 解题方法 (Methoden)

### 3.1 Governance 定位三步法（`analysieren`，AFB II）

**编号步骤**：
1. **认主体**：材料里是谁在行动（国家 / IO / NGO / 企业 / 网络）？——*KLP 工具：benennen（I–II）*
2. **定规范层级**：涉及的是 hard law、soft law 还是非正式承诺？——*KLP 工具：analysieren（überw. II）*
3. **判合法性来源**：这个安排的正当性来自参与（input）还是绩效（output）？——*KLP 工具：problematisieren（III）*

> **判据 / 决策点**：题干出现「Legitimität」→ 必须走 2.5 的两条线，不许只写一句「不民主」。

### 3.2 对照法：Government vs. Governance（`vergleichen`，AFB II–III）

1. **明写维度**：主体 / 强制力 / 规范形式 / 合法性来源 / 缺陷——*KLP 工具：vergleichen 要求「按维度」* [已验证，Operatoren §SoWi]
2. **逐维度对齐**，两侧各一句。
3. **提 Gemeinsamkeit**：两者都是**调控方式**，都要解决集体行动问题。
4. **提 Unterschied**：强制力与合法性来源的根本差异。
5. **收一句 Gewichtung**：治理在**有效性**上更灵活，在**合法性**上更脆弱。[据推断]

### 3.3 材料分析三步（SoWi 通用 30/40/30）

1. **darstellen**（约 30%，AFB I–II）：Materialart / Autor / Kernaussage。——*KLP 工具：darstellen（I–II）*
2. **analysieren**（约 40%，AFB II）：材料归入某主体 + 某规范层级 + 某合法性维度。——*KLP 工具：analysieren + einordnen（überw. II）*
3. **erörtern / bewerten**（约 30%，AFB III）：按 input / output 两条线权衡 → 带条件判断。——*KLP 工具：erörtern（III）/ bewerten（III）*

### 3.4 Karikatur 三步（治理题材版）

1. **beschreiben**：Wer/Was/Wo + Symbol（圆桌但座位不等、没有主席的会议、纸做的墙、无牙的看门狗）+ Text。——*KLP 工具：beschreiben（I–II）*
2. **analysieren**：Deutung（象征无强制力的规则 / 代表性失衡 / 执行缺口）+ Kontext（Global Governance）+ Intention。——*KLP 工具：analysieren + interpretieren（II–III）*
3. **beurteilen**：明示 Kriterium（Input-Legitimität / Output-Legitimität / Effektivität）→ Pro/Contra → Urteil。——*KLP 工具：beurteilen（III）*

> 中文自查：若漫画画「一条没有牙齿的看门狗守着一扇大门」，问的就是**执行力缺口**。

### 3.5 AFB III 四步骨架（`erörtern` / `problematisieren`）

1. **These**：点立场 + 依据（治理缺口论证 / 合法性赤字论证）
2. **Antithese**：给对立面**最强**反驳（例如：无治理时问题更严重）
3. **Kriterien**：明示尺度（**Input-Legitimität / Output-Legitimität / Effektivität / Souveränität**），逐条衡量
4. **Synthese**：带条件的判断

## 4. 🇨🇳 CN-Methode

**不适用（该科无中国对照技法）。** 理由：Global Governance 的理论核心是**无世界政府条件下的规则生产与合法性赤字**，其分析对象是多主体、多层级的跨国治理网络；中国高中课程没有对应的「治理 vs. 政府」概念框架，直接类比会混淆概念层级并造成答题规范错配。合规性：✅（不引用任何 CN 材料）。

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | Materialanalyse（Sachtext / Statistik / Karikatur）+ Erörterung；LK 可含 Gestaltungsaufgabe |
| Operator | `darstellen`（I–II）· `analysieren`（überw. II）· `vergleichen`（II–III）· `erörtern`（III）· `problematisieren`（III）· `bewerten`（III）· `entwickeln`（III） |
| AFB | I（概念复述）→ II（主体与规范层级归类）→ **III（合法性赤字权衡 / 改革方案构建）** |
| 建议分值 / 时长 | Abitur SoWi LK 300 min（3 题选 1，含选题时间）[已验证，SoWi-Oberstufe §4] |

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> Definieren Sie den Begriff Global Governance und erläutern Sie, worin er sich von einer Weltregierung unterscheidet. (AFB I–II)

**Aufgabe 2** `[原创]`
> Analysieren Sie den folgenden Beschluss eines internationalen Gremiums im Hinblick darauf, welche Akteure beteiligt sind, welche Bindungsqualität die Vereinbarung hat und worin ein Legitimationsproblem liegen könnte. (AFB II)

**Aufgabe 3** `[NRW-改编]`
> Vergleichen Sie die Entscheidungs- und Legitimationsstrukturen einer internationalen Organisation mit denen eines transnationalen Netzwerks hinsichtlich Rückbindung und Durchsetzungsfähigkeit. (AFB II–III)

**Aufgabe 4** `[原创]`
> Eine Karikatur zeigt einen runden Verhandlungstisch mit ungleich großen Stühlen, während im Hintergrund ein zahnloser Hund vor einer Tür Wache steht. Analysieren Sie die Karikatur und beurteilen Sie die dargestellte Problematik anhand eines selbst gewählten Kriteriums. (AFB II–III)

**Aufgabe 5** `[NRW-改编]`
> Erörtern Sie, ob das Legitimationsdefizit globaler Governance durch eine stärkere Verrechtlichung (Hard Law) verringert werden kann. Beziehen Sie mindestens zwei Kriterien ein. (AFB III)

### 5.3 Musterlösung

**Aufgabe 1**（darstellen + erläutern）
1. **Definition**：Gesamtheit der Regelungsstrukturen jenseits des Nationalstaats ✓ 得分点（AFB I）
2. **Abgrenzung**：keine zentrale Zwangsgewalt, keine Territorialhoheit ✓ 得分点（AFB I–II）
3. **Mechanismen**：Reziprozität, Reputation, institutionelle Selbstbindung ✓ 得分点（AFB II）
4. **Fazit**：`Global Governance ist gerade nicht die Vorstufe einer Weltregierung, sondern deren funktionales Äquivalent unter Bedingungen fortbestehender staatlicher Souveränität.` ✓

**Aufgabe 2**（Fallanalyse）
1. **Sachverhalt**：Gremium, Anlass, Kerninhalt ✓ 得分点（AFB I）
2. **Akteure**：Staaten, IO, ggf. NGOs und Unternehmen ✓ 得分点（AFB II）
3. **Bindungsqualität**：hard law / soft law / informelle Selbstverpflichtung einordnen ✓ 得分点（AFB II）
4. **Legitimationsproblem**：Input-Dimension（fehlende Rückbindung）und Output-Dimension（Durchsetzung）✓ 得分点
5. **Fazit**：`Der Beschluss illustriert die Governance-Lücke: breites Mandat, schwache Bindung, begrenzte Rückbindung.` ✓

**Aufgabe 3**（vergleichen，维度对齐）
1. **Dimensionen 明写**：Rückbindung / Durchsetzungsfähigkeit ✓ 得分点（AFB II）
2. **Internationale Organisation**：formelle Mitgliedschaft, klare Zuständigkeit, ggf. Sanktionsmechanismen → höhere Bindung, langsamere Entscheidung ✓
3. **Transnationales Netzwerk**：flexibel, fachlich, konsensbasiert → hohe Anpassungsfähigkeit, geringe Rückbindung und Transparenz ✓ 得分点
4. **Gemeinsamkeit**：beide ohne weltstaatliche Zwangsgewalt ✓
5. **Gewichtung**：ein Satz zum Trade-off zwischen Effektivität und Legitimation ✓

**Aufgabe 4**（Karikatur，AFB II–III）
1. **beschreiben**：runder Tisch, ungleich große Stühle, zahnloser Hund, Tür ✓
2. **analysieren**：Deutung = asymmetrische Einflussmacht trotz formaler Gleichheit + Durchsetzungsschwäche; Kontext = Global Governance; Intention = Kritik an Scheinpartizipation und fehlender Sanktionskraft ✓ 得分点
3. **beurteilen**：Kriterium = Input-Legitimität oder Effektivität → Pro（Verhandlungsrahmen statt Anarchie）/ Contra（Machtasymmetrie und Unverbindlichkeit）→ Urteil ✓ 得分点

**Aufgabe 5**（erörtern，AFB III 骨架）
1. **These**：`Verrechtlichung kann das Legitimationsdefizit verringern, weil bindende Regeln Erwartungssicherheit und einklagbare Verantwortung schaffen.` ✓ 得分点
2. **Antithese**：`Dagegen spricht, dass Hard Law die Zustimmung souveräner Staaten voraussetzt und deshalb entweder verwässert oder gar nicht zustande kommt.` ✓ 得分点
3. **Kriterien**：**Output-Legitimität**（Wirksamkeit）、**Input-Legitimität**（Rückbindung）、**Souveränität**（Kosten der Bindung）、**Effektivität**（Durchsetzung）✓ 得分点
4. **Synthese**：`Unter der Bedingung, dass Verrechtlichung mit stärkerer parlamentarischer Beteiligung und transparenten Verfahren verbunden wird, überwiegen die Vorteile; reine Verrechtlichung ohne Rückbindung verschiebt das Defizit lediglich von der Durchsetzung zur Legitimation.` ✓（**带条件的判断**为满分标志）

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把 Global Governance 写成「世界政府」；把软法与硬法混用 | 先写 2.1 对照表再答题；规范三级单独列 |
| 知识错 | 只写主体清单，不写规范层级与合法性来源 | 主体 × 规范 × 合法性三列表合书默写 |
| 表达错 | 合法性评价只写「不民主」一句，不分 input / output | 强制「两条线各一段 + 明示 Kriterium」 |
