# Karikatur-Anleitung (SoWi Klausur)

1. **beschreiben** (5句内)：Wer/Was/Wo + Symbol + Text. 不解释。
   - Die Karikatur zeigt … / Im Vordergrund … / Die Sprechblase sagt …
2. **analysieren**：Deutung (Was bedeutet das Symbol?) + Kontext (Welches EF-Thema? Ungleichheit/Partizipation/Markt?) + Intention des Karikaturisten.
3. **beurteilen**：Kriterium nennen (z.B. Gerechtigkeit, Teilhabe) → Pro/Contra → eigenes Urteil mit Begründung.
