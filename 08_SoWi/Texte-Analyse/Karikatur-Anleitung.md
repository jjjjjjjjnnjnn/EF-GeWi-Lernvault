# Karikatur-Anleitung (SoWi Klausur)

1. **beschreiben** (5句内)：Wer/Was/Wo + Symbol + Text. 不解释。
   - Die Karikatur zeigt … / Im Vordergrund … / Die Sprechblase sagt …
2. **analysieren**：Deutung (Was bedeutet das Symbol?) + Kontext (Welches EF-Thema? Ungleichheit/Partizipation/Markt?) + Intention des Karikaturisten.
3. **beurteilen**：Kriterium nennen (z.B. Gerechtigkeit, Teilhabe) → Pro/Contra → eigenes Urteil mit Begründung.

> 中文自查：我能用3句话讲清“画了什么→讽刺什么→我同不同意”吗？

## Beispiel: Fraktion vs. Gewissen (Leitfrage „Gewissen oder Partei?", eigene Beschreibung)

> 中文：这是 4.3 freies Mandat 的标准配图，只记要素不复制原图。

- **beschreiben 要素（用自己的话）**：讲台后一名议员正要发言，气球里的话只说到一半（大致是"议员只服从良心……"，引的是 Art.38 方向）；一只标着 FRAKTION 的巨手从画面右上按住他的头，把他压回讲台。记住三件套：Rednerpult（讲台=议会发言场）、Riesenhand FRAKTION（大手=党团压力）、abgebrochene Sprechblase（被打断的气球=良心没说完）。
- **analysieren（按上面 2 走）**：Deutung=巨手象征 Fraktionsdisziplin 对 freies Mandat 的压制；Kontext=Kap.4.3 良心 vs 党纪，配 Impfpflicht-Zeitstrahl 作业（S.154–158 立场演变）说明"常规议题有党纪、良心议题放开"；Intention=漫画家讽刺"纸面自由委任、实际党团说了算"。
- **beurteilen（按上面 3 走）**：Kriterium=Repräsentation + Gewissensfreiheit；Pro 党纪（稳定执政）/ Contra（掏空 Art.38）；Urteil-Baustein（2 句，直接背）:
  - `Die Karikatur überzeichnet, aber sie trifft den Kern: Fraktionsdisziplin schränkt das freie Mandat faktisch ein.`
  - `Bei Gewissensfragen (Sterbehilfe, Impfpflicht) ist der Verzicht auf Fraktionszwang geboten — sonst wird Art. 38 GG zur Dekoration.`
- **Zweitbeleg M23（转述）**：Merkel 2017 把"Ehe für alle"放开为 Gewissensentscheidung（CDU/CSU 可自由投票）——Klausur 里这是"党纪有例外"的标准例，与漫画主例正好一正一反。
