# Globalisierungskritik und Institutionen der ökonomischen Globalisierung (全球化批判与塑造全球化经济维度的机构) `[B 方向]`

> **中文理解**：这篇把 KLP IF7 中 **Abschnitt B 的两个专属条目**合在一处：`Institutionen zur Gestaltung der ökonomischen Dimension der Globalisierung`（WTO / IMF / Weltbank / G20 等）与 `Globalisierungskritik`（对全球化的系统性质疑）。两者是一体两面——**先看清「谁在管」，才能问「规则公平吗」**。[已验证，SoWi-Oberstufe §2 IF7 B 方向]
>
> **Klausur-Relevanz**：全球化批判**不是情绪化的反全球化**，而是两条主线：**分配**（谁得利、谁承担代价）与**合法性**（谁定的规则、谁被排除）。`erörtern` / `widerlegen` 这两个 AFB III 动词在这里的落点最密。[据推断]

## 2. 知识结构 (Struktur)

### 2.1 机构矩阵（**核心表，必背**）

| 机构 | Mandat | 主要手段 | 决策结构 | 典型争议 |
|---|---|---|---|---|
| **IMF** | 国际收支稳定、宏观监督 | 贷款、条件性、监督报告 | 加权投票（份额制） | 条件性过强、紧缩代价 |
| **Weltbank** | 长期发展、减贫 | 项目贷款、技术援助 | 加权投票 | 项目条件、债务可持续性 |
| **WTO** | 贸易规则与争端解决 | 谈判回合、争端裁决、最惠国待遇 | 共识原则（一国一票） | 回合停滞、裁决执行难 |
| **G20** | 主要经济体政策协调 | 峰会承诺、同行审议 | 非正式、自我设定 | 无条约基础、代表性 |
| **ILO** | 劳工标准 | 公约与建议（多为软法） | 三方结构（政府/雇主/工会） | 执行力弱 |
| **UNCTAD** | 贸易与发展 | 研究、政策建议 | 联合国大会体系 | 影响力相对有限 |

> ⚠️ **辨别错**：把 **IMF 与 Weltbank 职能互换**——记住「**IWF 管短期的收支，Weltbank 管长期的发展**」。[据推断]

> *Klausur-Satz*: `Die ökonomische Dimension der Globalisierung wird von einem institutionellen Geflecht gesteuert, dessen Mandate sich teils überschneiden und dessen Entscheidungsstrukturen unterschiedlich legitimiert sind.` [据推断]

### 2.2 WTO 的三重功能与三重争议

- **功能**：① 规则设定（最惠国待遇、国民待遇）② 谈判论坛（回合制）③ **争端解决**（准司法裁决）。
- **争议**：① 谈判回合长期停滞（发展议题僵局）② 裁决执行依赖成员自愿 ③ 贸易规则与劳工 / 环境标准的**衔接缺口**。

> *Klausur-Satz*: `Die WTO ist zugleich Regelwerk, Verhandlungsforum und Streitschlichtungsinstanz — ihre Schwäche liegt weniger in den Regeln als in der Durchsetzung und in der Reichweite ihres Mandats.` [据推断]

### 2.3 全球化批判的四条主线

| 主线 | 核心命题 | 代表论证 | 需注意的边界 |
|---|---|---|---|
| **Verteilung（分配）** | 全球收益分配极不均，输家集中 | 行业 / 地区失业、工资压力 | 不能只讲输家不讲消费端降价收益 |
| **Legitimation（合法性）** | 规则由少数强经济体主导 | 加权投票、技术官僚决策 | 「退出」不是可行选项 |
| **Ökologie（生态）** | 贸易与投资放大资源消耗与排放 | 碳泄漏、运输排放 | 贸易也能扩散绿色技术 |
| **Kultur / Souveränität（文化与主权）** | 标准同质化、政策空间被压缩 | 规制竞争、投资保护条款 | 需与保护主义区分 |

### 2.4 批判 vs. 反批判（**成对写才拿 Vielfalt 分**）

| 批判论点 | 反批判（Gegenargument） |
|---|---|
| 结构调整计划加剧社会代价 | 无融资时危机更深、调整只是被推迟 |
| Race to the bottom 压低标准 | 实证上标准总体趋同而非竞相下降 [据推断] |
| 机构缺乏民主合法性 | 相比无规则状态，规则提供可预期性与争端渠道 |
| 贸易扩大不平等 | 贸易降低消费品价格，对低收入家庭实际购买力有正效应 |
| 增长不可持续 | 去增长在发展中国家缺乏政治可行性 |

> *Klausur-Satz*: `Die Globalisierungskritik ist dann überzeugend, wenn sie konkrete Mechanismen benennt — etwa Konditionalität oder Regulierungswettbewerb — statt Globalisierung pauschal abzulehnen.` [据推断]

### 2.5 与一体化 / 全球治理的接口（**升 AFB III 的关键**）

- **Governance ohne Government**：这些机构没有世界政府式的强制力 → 只能靠**互惠、声誉、争端机制**起作用。
- **Mehrebenen-Struktur**：国家层面（政策空间）↔ 区域层面（EU 等）↔ 全球层面（WTO/IMF）。
- **缺口**：气候、税收、数字平台等领域的规则供给明显落后于经济一体化速度 → 这是批判最有力的落点。[据推断]

> *Klausur-Satz*: `Globalisierungskritik lässt sich präzise formulieren als Diagnose einer Governance-Lücke: Die ökonomische Integration ist weiter fortgeschritten als die Regelungs- und Legitimationsstrukturen.` [据推断]

## 3. 解题方法 (Methoden)

### 3.1 机构定位三步法（`analysieren`，AFB II）

**编号步骤**：
1. **认机构**：材料点名的是哪一个（或哪几个）机构？——*KLP 工具：benennen（I–II）*
2. **配 mandate 与手段**：它在这件事上**能做什么**（贷款 / 裁决 / 协调 / 研究）？——*KLP 工具：analysieren（überw. II）*
3. **判决策结构与争议**：加权投票还是共识？谁被排除？——*KLP 工具：problematisieren（III）*

> **判据 / 决策点**：题干出现「Rolle von …」→ 只走 1–2 步；出现「Bewertung der Legitimität」→ 直接进 2.5 接口。

### 3.2 批判—反批判对照法（`erörtern` / `widerlegen`，AFB II–III）

1. **摘出批判命题**：材料给的是四条主线中的哪一条？——*KLP 工具：herausarbeiten（II）*
2. **补最强反论点**：不是敷衍一句，而是写出**对方最强的版本**。——*KLP 工具：widerlegen 要求「举出论据」* [已验证，Operatoren §SoWi]
3. **明示 Kriterium**：Effizienz / Verteilung / Legitimation / Nachhaltigkeit。——*KLP 工具：beurteilen（III）*
4. **带条件结论**：„Unter der Bedingung X überwiegt A"。——*KLP 工具：erörtern（III）*

### 3.3 材料分析三步（SoWi 通用 30/40/30）

1. **darstellen**（约 30%，AFB I–II）：Materialart / Autor / Kernaussage。——*KLP 工具：darstellen（I–II）*
2. **analysieren**（约 40%，AFB II）：材料归入某机构 + 某批判主线 + 某立场。——*KLP 工具：analysieren + einordnen（überw. II）*
3. **erörtern / problematisieren**（约 30%，AFB III）：按 Kriterium 权衡 → 带条件判断。——*KLP 工具：erörtern（III）/ problematisieren（III）*

### 3.4 Karikatur 三步（全球化题材版）

1. **beschreiben**：Wer/Was/Wo + Symbol（集装箱、天平、会议长桌、不同的碗、投票砝码）+ Text。——*KLP 工具：beschreiben（I–II）*
2. **analysieren**：Deutung（象征分配不均 / 决策权失衡 / 标准竞争）+ Kontext（机构与批判主线）+ Intention。——*KLP 工具：analysieren + interpretieren（II–III）*
3. **beurteilen**：明示 Kriterium → Pro/Contra → Urteil。——*KLP 工具：beurteilen（III）*

> 中文自查：若漫画画「一杆天平，一端是集装箱，另一端是空碗」，问的是**分配的公平性**。

### 3.5 AFB III 四步骨架（`erörtern` / `diskutieren` / `widerlegen`）

1. **These**：点立场 + 依据（机制论证：race to the bottom / Governance-Lücke）
2. **Antithese**：给对立面**最强**反驳
3. **Kriterien**：明示尺度（**Effizienz / Verteilung / Legitimation / Nachhaltigkeit**），逐条衡量
4. **Synthese**：带条件的判断

## 4. 🇨🇳 CN-Methode

**不适用（该科无中国对照技法）。** 理由：该条目讨论的是**国际机构 mandate 与决策结构**（加权投票 / 共识原则 / 争端裁决）以及由此产生的合法性争议，中国高中课程无对应的国际组织制度分析框架；且涉及贸易与劳工标准的政策语境差异，直接类比会造成答题规范与价值尺度错配。合规性：✅（不引用任何 CN 材料）。

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | Materialanalyse（Sachtext / Statistik / Karikatur）+ Erörterung；可含 Gestaltungsaufgabe |
| Operator | `darstellen`（I–II）· `analysieren`（überw. II）· `vergleichen`（II–III）· `erörtern`（III）· `widerlegen`（II–III）· `problematisieren`（III） |
| AFB | I（机构 / 概念复述）→ II（mandate 归类 / 机制指认）→ **III（批判与反批判权衡）** |
| 建议分值 / 时长 | Abitur SoWi GK 240 min / LK 300 min（3 题选 1，含选题时间）[已验证，SoWi-Oberstufe §4] |

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> Stellen Sie die Mandate von IWF und Weltbank dar und erläutern Sie, worin sie sich unterscheiden. (AFB I–II)

**Aufgabe 2** `[原创]`
> Analysieren Sie den folgenden Beschluss eines internationalen Wirtschaftsgremiums im Hinblick darauf, welches Mandat beansprucht wird, wie Entscheidungen zustande kommen und welche Kritik daran ansetzen könnte. (AFB II)

**Aufgabe 3** `[NRW-改编]`
> Vergleichen Sie die Entscheidungsstrukturen von WTO und G20 hinsichtlich ihrer Legitimationsgrundlage und ihrer Durchsetzungsfähigkeit. (AFB II–III)

**Aufgabe 4** `[原创]`
> Eine Karikatur zeigt eine Waage, auf deren einer Seite ein Container, auf der anderen eine leere Schale liegt; daneben stehen Vertreter unterschiedlich großer Staaten. Analysieren Sie die Karikatur und beurteilen Sie die dargestellte Spannung anhand eines selbst gewählten Kriteriums. (AFB II–III)

**Aufgabe 5** `[NRW-改编]`
> Erörtern Sie die These, dass die Kritik an den Institutionen der ökonomischen Globalisierung berechtigt ist. Gehen Sie auf mindestens zwei Kritikpunkte und je ein Gegenargument ein. (AFB III)

### 5.3 Musterlösung

**Aufgabe 1**（darstellen + erläutern）
1. **IWF-Mandat**：kurzfristige Zahlungsbilanzhilfe, makroökonomische Überwachung ✓ 得分点（AFB I）
2. **Weltbank-Mandat**：langfristige Entwicklungsfinanzierung, Armutsreduktion ✓ 得分点（AFB I）
3. **Unterschied**：Zeithorizont（kurz vs. lang）und Zielsetzung（Stabilisierung vs. Strukturwandel）✓ 得分点（AFB II）
4. **Fazit**：`Beide Institutionen stammen aus dem Bretton-Woods-System, unterscheiden sich aber grundlegend in Zeithorizont und Zielsetzung.` ✓

**Aufgabe 2**（Fallanalyse）
1. **Sachverhalt**：Gremium, Anlass, beanspruchtes Mandat ✓ 得分点（AFB I）
2. **Entscheidungsstruktur**：z. B. gewichtete Stimmrechte oder Konsensprinzip ✓ 得分点（AFB II）
3. **Kritikansatz**：Legitimationsdefizit / Repräsentationslücke / Durchsetzungsschwäche ✓ 得分点（AFB II）
4. **Fazit**：`Der Beschluss macht die Governance-Lücke sichtbar: Das Mandat reicht weiter als die demokratische Rückbindung.` ✓

**Aufgabe 3**（vergleichen，维度对齐）
1. **Dimensionen 明写**：Legitimationsgrundlage / Durchsetzungsfähigkeit ✓ 得分点（AFB II）
2. **WTO**：formelle Mitgliedschaft, Konsensprinzip, quasi-judiziale Streitschlichtung → hohe Regelbindung ✓
3. **G20**：informelles Forum, Selbstverpflichtung, keine Sanktionen → hohe Flexibilität, geringe Bindung ✓ 得分点
4. **Gemeinsamkeit**：beide ohne weltstaatliche Zwangsgewalt ✓
5. **Gewichtung**：ein Satz zum Trade-off zwischen Bindungswirkung und Legitimation ✓

**Aufgabe 4**（Karikatur，AFB II–III）
1. **beschreiben**：Waage, Container vs. leere Schale, unterschiedlich große Staaten ✓
2. **analysieren**：Deutung = ungleiche Verteilung der Globalisierungsgewinne und asymmetrische Entscheidungsmacht; Kontext = Institutionen der ökonomischen Globalisierung; Intention = Kritik an Verteilungs- und Legitimationsdefiziten ✓ 得分点
3. **beurteilen**：Kriterium = Verteilung oder Legitimation → Pro（Handelsgewinne insgesamt）/ Contra（Gewinne konzentrieren sich）→ Urteil ✓ 得分点

**Aufgabe 5**（erörtern，AFB III 骨架）
1. **These**：`Die Kritik ist berechtigt, weil Konditionalität und Regulierungswettbewerb nachweisbare Verteilungswirkungen haben und die Entscheidungsstrukturen nicht direkt demokratisch rückgebunden sind.` ✓ 得分点
2. **Antithese**：`Dagegen spricht, dass ohne diese Institutionen Koordination gänzlich fehlte und dass Handelsgewinne die Konsumentenpreise senken.` ✓ 得分点
3. **Kriterien**：**Verteilung**（Gewinner/Verlierer）、**Legitimation**（Rückbindung）、**Effizienz**（Koordinationsgewinn）、**Nachhaltigkeit**（Standardniveau）✓ 得分点
4. **Synthese**：`Unter der Bedingung institutioneller Reformen — etwa transparenterer Entscheidungsverfahren und verbindlicher Sozial- und Umweltstandards — überwiegt der Nutzen der Koordination; ohne sie verstärkt sich die Legitimationslücke.` ✓（**带条件的判断**为满分标志）

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把 IMF 与 Weltbank 职能互换；把 WTO 的「共识原则」写成「加权投票」 | 记口诀「IWF 短期收支 / Weltbank 长期发展」；决策结构单独列一列 |
| 知识错 | 把全球化批判写成情绪化反对全球化，讲不出机制（Konditionalität / race to the bottom） | 四条主线 × 每条一个机制名词，合书默写 |
| 表达错 | 只写批判不写反批判，或反批判写成敷衍一句 | 强制「一条批判配一条最强反论点」 |
