# EU: Integrationsgeschichte und Integrationsmodelle (欧盟：一体化历史与模型)

> **中文理解**：一体化不是一条平滑直线，而是**危机驱动的步进**——每一步（Montanunion → EWG → Binnenmarkt → Maastricht → Lissabon）都对应一次**功能扩张**与一次**主权让渡**。背后的争论是「**欧洲该由谁驱动**」：国家主导（Intergouvernementalismus）、超国家机构主导（Supranationalismus）、还是走向联邦（Föderalismus）？KLP IF5 把 `Historische Entwicklung` 与 `Europäische Integrationsmodelle` 并列，正是要你把**史实**与**理论坐标**扣在一起——评价任何 EU 争议前，先选坐标。
>
> **Klausur-Relevanz**：Abitur 2027 聚焦 IF4+IF6，IF5 退居次级；但一体化模型是 QP 台阶 3「理论工具显性化」的典型落点，`vergleichen` + `erörtern` 组合在 LK 中概率不低。[据推断]

## 1. 核心概念 (Kernbegriffe)

| 术语 (DE) | 中文 | English | 定义 / 要点 | 备注 |

## 2. 知识结构 (Struktur)

### 2.1 时间轴（六个节点 + 每步新增职能）

| 年份 | 事件 | 新增职能 | 性质 |
|---|---|---|---|
| 1951 | Montanunion (EGKS) | 煤钢共管 | 经济部门一体化 [据推断] |
| 1957 | Römische Verträge | 建立 EWG 共同市场 | 经济一体化 [据推断] |
| 1986 | Einheitliche Europäische Akte | 内部市场计划 | 市场深化 [据推断] |
| 1992/93 | Vertrag von Maastricht | 建立 EU + 货币联盟 | 政治一体化 [据推断] |
| 2004 | Osterweiterung | 大规模扩大 | 地理扩张 [据推断] |
| 2007/09 | Vertrag von Lissabon | 机构改革、强化议会 | 制度深化 [据推断] |

> *Klausur-Satz*: `Die europäische Integration verlief schrittweise: Von der Montanunion über die EWG und den Binnenmarkt bis hin zu Maastricht und Lissabon wurde jeweils eine neue Funktion ergänzt.`

> ⚠️ **只背年份不背「每步新增了什么职能」→ 无法用于分析题**。

### 2.2 三个 Integrationsmodelle 对照（**本篇核心，必背**）

| 维度 | Intergouvernementalismus | Supranationalismus | Föderalismus |
|---|---|---|---|
| **一体化动力** | 成员国（国家利益） | 超国家机构 | 联邦式共同体 |
| **主权归属** | 保留在成员国 | 部分让渡给超国家机构 | 共享/分层主权 |
| **决策方式** | 一致同意为主 | 多数表决 | 联邦层级分工 |
| **典型机构** | Europäischer Rat / Rat der EU | Kommission / EuGH / EZB | 议会 + 联邦结构 |
| **民主合法性** | 经由成员国政府 | 经由超国家机构 | 经由公民 + 层级 |
| **适用现象** | 外交、安全、财政 | 竞争、货币、法律 | 内部市场、区域政策 |
| **典型批评** | 效率低、易僵局 | 民主赤字 | 主权丧失、认同不足 |

> *Klausur-Satz*: `Während der Intergouvernementalismus die Mitgliedstaaten als Motor der Integration sieht, betont der Supranationalismus die Rolle überstaatlicher Institutionen, und der Föderalismus zielt auf eine bundesstaatliche Ordnung.`

### 2.3 扩大 vs. 深化（Erweiterung vs. Vertiefung）

- **Erweiterung**：加国家（2004 东扩）。
- **Vertiefung**：加一体化深度（Maastricht、Lissabon）。
- 张力：国家越多，深化越难（一致同意门槛）。

> *Klausur-Satz*: `Erweiterung und Vertiefung stehen in einem Spannungsverhältnis, weil mehr Mitglieder eine tiefere Integration erschweren.`

### 2.4 危机驱动的步进（接《EU-Krisenbewaeltigung》）

- 每次危机（金融危机、主权债务、难民、Brexit、疫情）都是一次**跃迁或撕裂**。
- 评价争议前必须**先选模型坐标**，否则 AFB III 无理论支撑。

> *Klausur-Satz*: `Die Integration war stets krisengetrieben: Jede Krise führte entweder zu einem Integrationssprung oder zu einer neuen Zerreißprobe.`

## 3. 解题方法 (Methoden)

### 3.1 模型对照答题法（`vergleichen`，AFB II–III）

**编号步骤**：
1. **明写 Vergleichskriterien**（动力 / 主权 / 决策 / 合法性）——*KLP 工具：vergleichen 要求「按维度」* [已验证]
2. **维度对齐并列**（不是逐个讲完）
3. **Gemeinsamkeiten**：都承认一体化是持续过程
4. **Unterschiede**：动力与主权归属
5. **Gewichtung**：哪个模型更适合材料现象

> **判据 / 决策点**：题干给「Gipfeltreffen / nationale Interessen」→ 倾向 Intergouvernementalismus；给「Kommission / EuGH-Urteil」→ 倾向 Supranationalismus。

### 3.2 时间轴答题法（`darstellen` / `einordnen`，AFB I–II）

1. **节点定位**：材料事件处于哪个阶段？——*KLP 工具：einordnen（überw. II）*
2. **职能说明**：该节点新增了什么？——*KLP 工具：erläutern（II–III）*
3. **因果连接**：前一危机/需求如何导致此步？——*KLP 工具：erklären（II）*

### 3.3 材料分析三步（SoWi 通用 30/40/30）

1. **darstellen**（约 30%，AFB I–II）：Materialart / Autor / Kernaussage。*KLP 工具：darstellen（I–II）*
2. **analysieren**（约 40%，AFB II）：把材料立场归入某一模型并给证据。*KLP 工具：analysieren + einordnen（überw. II）*
3. **erörtern / Stellung nehmen**（约 30%，AFB III）：按 Kriterien 权衡 → eigenes Urteil（**含价值尺度反思**）。*KLP 工具：erörtern（III）/ Stellung nehmen（III）*

### 3.4 Karikatur 三步（宏观题材版）

1. **beschreiben**：Wer/Was/Wo + Symbol + Text（如「欧洲列车」「拼图」「过桥」）——*KLP 工具：beschreiben（I–II）*
2. **analysieren**：Deutung（象征一体化/解体）+ Kontext（哪一模型之争）+ Intention——*KLP 工具：analysieren + interpretieren（II–III）*
3. **beurteilen**：Kriterium（Legitimation / Handlungsfähigkeit）→ Pro/Contra → Urteil——*KLP 工具：beurteilen（III）*

> 中文自查：漫画常把一体化画成「往同一方向跑的列车/划船」——先认出它批评的是**速度**还是**方向**。

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | Materialanalyse（Sachtext / Karikatur）+ Erörterung |
| Operator | `darstellen`（I–II）· `einordnen`（überw. II）· `vergleichen`（II–III）· `erörtern`（III） |
| AFB | I（史实/立场复述）→ II（模型归类）→ **III（权衡判断）** |
| 建议分值 / 时长 | GK 240 min / LK 300 min（3 题选 1，含选题时间）[已验证] |

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> Stellen Sie die historische Entwicklung der EU von der Montanunion bis zum Vertrag von Lissabon dar und nennen Sie jeweils die neu hinzugekommene Funktion. (AFB I–II)

**Aufgabe 2** `[原创]`
> Vergleichen Sie den Intergouvernementalismus und den Supranationalismus hinsichtlich der Träger der Integration und der Souveränität. (AFB II–III)

**Aufgabe 3** `[NRW-改编]`
> Analysieren Sie den vorliegenden Sachtext im Hinblick darauf, welches Integrationsmodell der Autor vertritt. (AFB II)

**Aufgabe 4** `[原创]`
> Erörtern Sie, ob die europäische Integration eher durch Mitgliedstaaten oder durch supranationale Institutionen vorangetrieben werden sollte. (AFB III)

### 5.3 Musterlösung

**Aufgabe 1**（时间轴）
1. **节点**：Montanunion (1951) → EWG (1957) → Binnenmarkt (1986) → Maastricht (1992/93) → Lissabon (2007/09) ✓ 得分点（AFB I）
2. **职能**：煤钢共管 → 共同市场 → 市场深化 → 政治联盟+货币 → 机构改革 ✓ 得分点（AFB II）
3. **Fazit**：`Jeder Schritt ergänzte eine neue Funktion.` ✓

**Aufgabe 2**（模型对照）
1. **Kriterien 明写**：Träger / Souveränität ✓ 得分点（AFB II）
2. **Intergouvernementalismus**：Mitgliedstaaten, Souveränität bleibt ✓
3. **Supranationalismus**：überstaatliche Institutionen, partielle Souveränitätsabgabe ✓
4. **Gemeinsamkeit**：beide beschreiben die EU als Mehrebenensystem ✓ 得分点
5. **Gewichtung**：ein Satz zur Erklärungskraft ✓

**Aufgabe 3**（模型归类）
1. **darstellen**：Autor + Kernaussage ✓
2. **Textsignale**：betont er nationale Regierungen / Gipfel? → intergouvernemental; betont er Kommission/EuGH? → supranational ✓ 得分点（AFB II）
3. **Fazit**：`Der Autor argumentiert supranationalistisch, weil er die Integration überwiegend auf die Kommission und den EuGH zurückführt.` ✓

**Aufgabe 4**（erörtern，AFB III 骨架）
1. **These**：`Supranationale Institutionen treiben die Integration effizienter voran, weil sie Einzelinteressen bündeln.` ✓ 得分点
2. **Antithese**：`Dagegen spricht das Demokratiedefizit; Mitgliedstaaten sichern die Legitimation über Wahlen.` ✓ 得分点
3. **Kriterien**：Legitimation / Handlungsfähigkeit / Effizienz ✓ 得分点
4. **Synthese**：`Unter der Bedingung wirksamer parlamentarischer Kontrolle überwiegen supranationale Impulse; ohne ausreichende Legitimation bleiben die Mitgliedstaaten der wichtigere Träger.` ✓（**带条件的判断**为满分标志）

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把 Intergouvernementalismus 与 Supranationalismus 的动力写反 | 记「国家驱动 vs. 机构驱动」二问卡 |
| 知识错 | 只背年份，讲不出每步新增的职能 | 时间轴每节点强制配一句「+ 什么职能」 |
| 表达错 | 评价 EU 争议时不给模型坐标，直接表态 | AFB III 段先写 „Aus der Perspektive des … lässt sich sagen, dass …" |
