# Ungleichheitsmodelle und Theorien (社会不平等模型与理论：阶级 / 阶层 /  milieu)

> **中文理解**：IF6 考的**不是现象**（那在 EF 层），而是**理论模型**——用哪把尺子给社会分层？**Klasse（阶级）**看生产关系与财产（Marx 二元 / Weber 多元）；**Schicht（阶层）**看连续刻度（收入/教育/声望加权）；**Milieu（生活圈）**不看高低、看「活法」（价值与生活方式聚类）。三套模型的**分层依据、层数、冲突来源、解释力、盲区**各不相同，选错模型 = 模型误配 = AFB III 失分。
>
> **Klausur-Relevanz**：`Modelle und Theorien gesellschaftlicher Ungleichheit` 是 IF6 三条共有条目中**唯一带理论纵深**的，是 Abitur 2027 聚焦域的 AFB III 主战场之一。[据推断]

|---|---|---|---|---|

## 2. 知识结构 (Struktur)

### 2.1 三模型总览（一句话人像）

- **Klassenmodell**：社会按**生产关系**分成**利益对立的集团**——Marx 是二元（资本家/无产者），Weber 是多元（财产+市场机会+声望）。
- **Schichtenmodell**：社会是**连续的高低梯度**——收入、教育、声望加权成「层」，适合解释渐进流动。
- **Milieu-Modell**：社会按**价值与生活方式**横向聚成「圈子」——不看高低，看活法，解释消费、政治取向、文化品味。

> *Klausur-Satz*: `Während Klassenmodelle auf Produktionsverhältnissen und Schichtmodelle auf kontinuierlichen Merkmalen beruhen, ordnen Milieumodelle die Gesellschaft nach Werten und Lebensstilen.`

### 2.2 三模型对照表（**本篇核心，必背**）

| 维度 | Klassenmodell | Schichtenmodell | Milieu-Modell |
|---|---|---|---|
| **分层依据** | 生产关系 / 财产（Marx）；+ Marktchancen（Weber） | 收入 / 教育 / 声望（加权） | 价值 / 生活方式 / 品味 |
| **层数结构** | 二元对立（Marx）或多元（Weber） | 连续梯度（Ober-/Mittel-/Unterschicht） | 横向聚类（无高低） |
| **冲突来源** | 阶级利益对立（Ausbeutung） | 资源差距，非必然对立 | 价值/文化差异，非必然对立 |
| **代表人物** | K. Marx · M. Weber | 常见于社会学分层研究 | SINUS / Bourdieu 传统 [据推断] |
| **解释力** | 结构性断裂、阶级冲突 | 渐进流动、收入分布 | 消费、政治取向、文化差异 |
| **盲区** | 忽视中间层与流动 | 难解释结构性断裂 | 掩盖纵向不平等 |
| **典型 Abitur 落点** | „Ist die Gesellschaft noch Klassengesellschaft?" | 流动数据题 | 政治参与/消费材料题 |

> *Klausur-Satz*: `Das Schichtenmodell erklärt graduelle Mobilität besser, während das Klassenmodell strukturelle Brüche und Interessensgegensätze stärker betont.`

### 2.3 Marx vs. Weber（阶级模型内部辨析，高频考点）

| 维度 | Marx | Weber |
|---|---|---|
| 分层核心 | 生产关系（是否占有生产资料） | 财产 + Marktchancen + 声望 + 权力 |
| 层数 | 二元（Bourgeoisie / Proletariat） | 多元（Klassen + Stände） |
| 冲突逻辑 | 必然的阶级对抗 | 机会差异，非必然对抗 |
| 盲区 | 忽视中产阶级 | 结构张力较弱 |

> *Klausur-Satz*: `Weber erweitert das marxsche Klassenmodell um Marktchancen, soziales Ansehen und Macht.`

### 2.4 模型与「社会变迁」的接口

- 个体化、去传统化 → 旧阶级/阶层模型是否还适用？
- 现象层（EF《Soziale-Ungleichheit》）只描述维度；QP 层要**反问模型适用边界**。

> *Klausur-Satz*: `Angesichts von Individualisierung und Prekarisierung ist zu prüfen, ob die klassischen Ungleichheitsmodelle die heutige Gesellschaft noch angemessen erfassen.`

## 3. 解题方法 (Methoden)

### 3.1 模型对照答题法（`vergleichen`，AFB II–III）

**编号步骤**：
1. **明写 Vergleichskriterien**（分层依据 / 层数 / 冲突 / 解释力）——*KLP 工具：vergleichen 要求「按维度」* [已验证]
2. **维度对齐并列**（不是逐个讲完）
3. **Gemeinsamkeiten**：都承认不平等是结构性的
4. **Unterschiede**：依据、层数、解释力
5. **Gewichtung**：哪个模型更适合材料现象

### 3.2 模型选择法（`prüfen` / `problematisieren`，AFB III）

1. **现象诊断**：材料是**断裂型**（阶级冲突）还是**渐变型**（收入分布）？
2. **模型匹配**：断裂 → Klasse；渐变 → Schicht；价值/消费 → Milieu
3. **盲区指认**：所选模型解释不了什么？
4. **判断**：`Das Phänomen lässt sich besser mit … erklären, weil …, allerdings bleibt … unberücksichtigt.`

> **判据 / 决策点**：题干若给「Mobilitätsdaten」→ 倾向 Schicht；若给「Klassenbewusstsein / Konflikt」→ 倾向 Klasse；若给「Werte / Konsum」→ 倾向 Milieu。

### 3.3 材料分析三步（通用 30/40/30）

1. **darstellen**（30%，I–II）：Materialart / Autor / Kernaussage
2. **analysieren**（40%，II）：把材料现象归入某一模型并给证据
3. **beurteilen / erörtern**（30%，III）：按 Kriterien 权衡模型适用性

### 3.4 Karikatur 三步（宏观题材）

1. **beschreiben**：画面里的「层」或「圈」如何呈现？（阶梯、金字塔、圈子）
2. **analysieren**：Deutung（象征哪种分层观）+ Kontext（哪个模型）+ Intention
3. **beurteilen**：Kriterium（Chancengleichheit）→ Pro/Contra → Urteil

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | Materialanalyse + Erörterung |
| Operator | `vergleichen`（II–III）· `prüfen`（III）· `erörtern`（III） |
| AFB | I → II → **III** |
| 建议分值 / 时长 | GK 240 min / LK 300 min（3 题选 1）[已验证] |

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> Vergleichen Sie das Klassenmodell und das Schichtenmodell hinsichtlich ihres Verständnisses sozialer Ungleichheit. (AFB II–III)

**Aufgabe 2** `[原创]`
> Analysieren Sie den vorliegenden Sachtext (zur Individualisierung) im Hinblick darauf, welches Ungleichheitsmodell der Autor verwendet. (AFB II)

**Aufgabe 3** `[NRW-改编]`
> Erörtern Sie, ob das Klassenmodell geeignet ist, die heutige Gesellschaft zu beschreiben. (AFB III)

**Aufgabe 4** `[原创]`
> Prüfen Sie, welches Modell die folgende Statistik (Einkommensverteilung) besser erklärt, und problematisieren Sie dessen Grenzen. (AFB III)

### 5.3 Musterlösung

**Aufgabe 1**
1. **Kriterien**：分层依据 / 层数 / 冲突 ✓（AFB II）
2. **Klasse**：Produktionsverhältnisse，二元或多元，利益对立 ✓
3. **Schicht**：收入/教育/声望，连续梯度，无必然对立 ✓
4. **Gemeinsamkeit**：均为结构性解释，非个人归因 ✓ 得分点
5. **Gewichtung**：一句说明各自解释力边界 ✓

**Aufgabe 2**（材料归类）
1. **darstellen**：Autor + Kernaussage ✓
2. **Textsignale**：betont der Autor Werte/Lebensstile? → Milieu; Klassenkonflikt? → Klasse; Einkommensschichten? → Schicht ✓ 得分点
3. **Fazit**：`Der Autor argumentiert milieu-theoretisch, weil er die Gesellschaft nach Wertorientierungen ordnet.` ✓

**Aufgabe 3**（erörtern，AFB III）
1. **These**：`Das Klassenmodell erklärt strukturelle Ungleichheit und Interessensgegensätze bis heute.` ✓
2. **Antithese**：`Individualisierung, wachsende Mittelschicht und Milieus sprechen gegen eine reine Klassengesellschaft.` ✓ 得分点
3. **Kriterien**：Erklärungskraft / Aktualität / Differenziertheit ✓
4. **Synthese**：`Das Klassenmodell bleibt für strukturelle Brüche relevant, reicht aber allein nicht aus — es muss durch Schicht- und Milieumodelle ergänzt werden.` ✓ 得分点

**Aufgabe 4**
1. **现象诊断**：Einkommensverteilung = 连续梯度 → Schicht ✓
2. **模型匹配**：Schicht 解释渐进分布 ✓
3. **盲区**：掩盖结构性断裂与 Exklusion ✓ 得分点
4. **结论**：`Das Schichtenmodell erklärt die Verteilung gut, blendet aber strukturelle Ausgrenzung aus.` ✓

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把 Klasse 与 Schicht 混为一谈，或把 Milieu 当阶层别名 | 记「断裂→Klasse / 渐变→Schicht / 横向→Milieu」三卡 |
| 知识错 | 把 Marx 与 Weber 都写成「有钱没钱」 | 强制写「Marx=生产关系，Weber=+Marktchancen/声望」 |
| 表达错 | 只描述现象不反问模型适用边界 | 每篇结尾加一句 „Der blinde Fleck des Modells ist…" |
