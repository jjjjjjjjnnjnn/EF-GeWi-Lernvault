# Wirtschaftspolitik: Legitimation und Zielgrößen (经济政策：正当性与目标量 / Magisches Viereck)

> **中文理解**：国家凭什么插手经济？两条理由链——**市场失灵（Marktversagen）**与**稳定责任**；反方向还有一条**国家失灵（Staatsversagen）**。插手之后追什么？四角目标：**增长、就业、物价稳定、外贸平衡**（Magisches Viereck）。四角互相打架（Zielkonflikt），所以任何经济政策题的第一步都是——「这题动了哪个角、牺牲了哪个角」。
>
> **Klausur-Relevanz**：KLP IF4 的两条共有条目 `Legitimation staatlichen Handelns` + `Zielgrößen der gesamtwirtschaftlichen Entwicklung` 天然构成 **理论对照 + 目标冲突** 结构，是 AFB III 的高频出题口。[据推断]

## 2. 知识结构 (Struktur)

### 2.1 Legitimation：国家干预的三条理由链 + 一条反链

**三条支持理由**：
1. **Marktversagen**：外部性、公共品、信息不对称 → 市场结果非最优
2. **Stabilitätsverantwortung**：景气波动、大规模失业 → 国家负责稳定
3. **Verteilungsgerechtigkeit**：结果不公 → 国家再分配

**一条反链（erörtern 必备）**：
4. **Staatsversagen**：信息不足、时滞、寻租、官僚成本 → 干预未必更好

> *Klausur-Satz*: `Staatliches Handeln in der Wirtschaftspolitik lässt sich mit Marktversagen, der Stabilitätsverantwortung und dem Ziel der Verteilungsgerechtigkeit begründen; dem steht jedoch die Möglichkeit des Staatsversagens gegenüber.`

### 2.2 Magisches Viereck（四角魔方）

**四角（Zielgrößen der gesamtwirtschaftlichen Entwicklung）**：

| 角 | Zielgröße | 中文 | 典型指标 |
|---|---|---|---|
| 1 | stetiges und angemessenes Wirtschaftswachstum | 持续适度增长 | BIP-Wachstum |
| 2 | hoher Beschäftigungsstand | 高就业 | Arbeitslosenquote |
| 3 | Preisniveaustabilität | 物价稳定 | Inflationsrate |
| 4 | außenwirtschaftliches Gleichgewicht | 外贸平衡 | Leistungsbilanz |

> *Klausur-Satz*: `Das Magische Viereck umfasst Wirtschaftswachstum, hohen Beschäftigungsstand, Preisniveaustabilität und außenwirtschaftliches Gleichgewicht.`

**为什么叫「magisch」**：因为**同时**达成四角几乎不可能——它们之间存在系统性冲突。

### 2.3 六组目标冲突（必背，答题的「角」）

| # | 冲突对 | 机制（一句话） |
|---|---|---|
| 1 | Beschäftigung ↔ Preisstabilität | 扩张政策拉动就业，也推高通胀（Phillips 关系） |
| 2 | Wachstum ↔ Preisstabilität | 需求过旺推高物价 |
| 3 | Wachstum ↔ außenwirtschaftl. Gleichgewicht | 内需旺盛拉动进口，贸易顺差收窄 |
| 4 | Beschäftigung ↔ außenwirtschaftl. Gleichgewicht | 高就业推高内需与进口 |
| 5 | Wachstum ↔ Umwelt/Nachhaltigkeit | 增长常伴资源消耗与排放（→ 质量型增长） |
| 6 | Vollbeschäftigung ↔ Verteilungsziele | 充分就业政策可能加剧通胀型再分配 |

> *Klausur-Satz*: `Zwischen den Zielen des Magischen Vierecks bestehen Zielkonflikte, etwa zwischen Vollbeschäftigung und Preisstabilität.`

### 2.4 合法性（Legitimation）与目标量的接口

- 国家追四角 = 履行 **Stabilitätsverantwortung** → 其正当性来自「市场自己做不到」
- 但**每动一个角都要交代代价** → 这正是 AFB III 的评价入口

> *Klausur-Satz*: `Jede wirtschaftspolitische Maßnahme muss begründen, welches Ziel sie verfolgt und welches andere Ziel sie dafür zurückstellt.`

## 3. 解题方法 (Methoden)

### 3.1 目标量分析三步（`analysieren`，AFB II）

**编号步骤**：
1. **识别政策**：材料/题干给了什么措施（减税？加息？补贴？）——*KLP 工具：analysieren（überw. II）*
2. **定位「角」**：它**直接**服务哪个 Zielgröße？——*KLP 工具：einordnen（überw. II）*
3. **推出代价**：按 2.3 的六组冲突，它**牺牲**哪个 Zielgröße？——*KLP 工具：erklären（II，归因到机制）*

> **判据 / 决策点**：题干问「Auswirkungen」→ 必须**正反两面**都写（服务谁 / 牺牲谁）；只写一面即缺 Vielfalt der Gesichtspunkte。

### 3.2 合法性论证法（`erörtern`，AFB III）

1. **Marktversagen 指认**：材料中的问题属于哪类失灵？
2. **干预必要性**：为什么市场自己解决不了？
3. **Staatsversagen 反驳**：干预的时滞/成本/副作用？
4. **Kriterien 权衡**：Effizienz / Gerechtigkeit / Finanzierbarkeit
5. **Synthese**：带条件判断

### 3.3 材料分析三步（通用 30/40/30）

1. **darstellen**（30%，I–II）：Materialart / Autor / Kernaussage + 三句复述
2. **analysieren**（40%，II）：论点归因到 Marktversagen 或 Staatsversagen
3. **beurteilen / erörtern**（30%，III）：Kriterien → Urteil

### 3.4 Karikatur 三步（宏观题材）

1. **beschreiben**：谁是国家？什么象征干预？（大手、医生、消防员…）
2. **analysieren**：Deutung + Kontext（哪一角目标）+ Intention
3. **beurteilen**：Kriterium → Pro/Contra → Urteil

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | Materialanalyse + Erörterung |
| Operator | `darstellen`（I–II）· `analysieren`（überw. II）· `erörtern`（III） |
| AFB | I → II → **III** |
| 建议分值 / 时长 | GK 240 min / LK 300 min（3 题选 1）[已验证] |

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> Stellen Sie die Zielgrößen des Magischen Vierecks dar und erläutern Sie zwei Zielkonflikte. (AFB I–II)

**Aufgabe 2** `[原创]`
> Analysieren Sie, welche Zielgrößen die folgende Maßnahme (Anhebung des Leitzinses) verfolgt und welche sie beeinträchtigt. (AFB II)

**Aufgabe 3** `[NRW-改编]`
> Erörtern Sie, ob der Staat in einer Rezession in die Wirtschaft eingreifen sollte. Gehen Sie auf Marktversagen und Staatsversagen ein. (AFB III)

**Aufgabe 4** `[原创]`
> Begründen Sie, warum die gleichzeitige Erreichung aller vier Ziele des Magischen Vierecks kaum möglich ist. (AFB III)

### 5.3 Musterlösung

**Aufgabe 1**
1. **四角列举**：Wachstum / Beschäftigung / Preisstabilität / außenwirtschaftl. Gleichgewicht ✓（AFB I）
2. **冲突一**：Beschäftigung ↔ Preisstabilität（扩张→通胀）✓
3. **冲突二**：Wachstum ↔ außenwirtschaftl. Gleichgewicht（内需→进口）✓
4. **机制句**：每个冲突给一句因果（„weil…"）✓ 得分点

**Aufgabe 2**（Leitzins 上调）
1. **政策**：EZB/央行加息 → Geldpolitik ✓
2. **服务**：Preisstabilität（抑制通胀）✓
3. **牺牲**：Wachstum + Beschäftigung（融资成本↑→投资↓）✓ 得分点（两面）
4. **机制**：`weil höhere Zinsen Investitionen verteuern` ✓

**Aufgabe 3**（erörtern，AFB III）
1. **Pro**：Marktversagen（外部性/公共品）+ 稳定责任 → 干预正当 ✓
2. **Contra**：Staatsversagen（时滞、Crowding-out、债务）✓
3. **Kriterien**：Effizienz / Finanzierbarkeit / Zeitnähe ✓
4. **Synthese**：`Bei konjunktureller Arbeitslosigkeit überwiegt die Interventionsnotwendigkeit; bei strukturellen Ursachen droht Staatsversagen.` ✓ 得分点

**Aufgabe 4**
1. 冲突本质：四角互相牵制（给出至少两组）✓
2. 例证：低失业常伴通胀压力；高增长常伴进口上升 ✓
3. 结论：`Deshalb spricht man vom „magischen" Viereck — die gleichzeitige Optimierung ist theoretisch kaum erreichbar.` ✓

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把「市场失灵」与「国家失灵」写反，或只写一面 | 每次干预题强制写 Marktversagen + Staatsversagen 两句 |
| 知识错 | 把四角记成并列清单，讲不出冲突 | 背六组冲突表，每组一句机制 |
| 表达错 | 只写「该管/不该管」不给 Kriterien | 先写评价尺度，再表态 |
