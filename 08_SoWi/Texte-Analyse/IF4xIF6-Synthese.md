# IF4 × IF6 Synthese (经济政策 × 社会不平等：四个交叉点综合笔记)

> **中文理解**：Abitur 2027 聚焦 IF4 + IF6，出题人最爱的不是「纯 IF4」或「纯 IF6」，而是**两者的交叉**。有四个天然连体点：① 社会国家财政（IF6 的对象 = IF4 的手段）；② 失业（既是 IF6 的不平等成因，又是 IF4 的目标量）；③ 分配政策 / 工资政策（两 IF 工具重叠）；④ 经济与生态（IF4-LK-B `Ökonomie und Ökologie` ↔ IF6 的社会代价分配）。综合题的本质是：**用一套工具同时谈效率与公平**。
>
> **Klausur-Relevanz**：这是应对综合题的「总装车间」——把 IF4 的构想/目标量与 IF6 的模型/社会国家争议拼成一条完整论证链。[据推断]

## 2. 知识结构 (Struktur)

### 2.1 四个交叉点总览（**本篇核心，必背**）

| # | 交叉点 | IF4 侧 | IF6 侧 | 综合张力 |
|---|---|---|---|---|
| ① | **Sozialstaat 财政** | 税收/分配工具、财政可持续性 | 社会国家原则与工具 | 保障 vs. 可负担 |
| ② | **Arbeitslosigkeit** | 目标量（Beschäftigung） | 不平等成因、Prekarisierung | 治失业 vs. 治贫困 |
| ③ | **Verteilungs-/Lohnpolitik** | 收入政策工具（Mindestlohn） | 分配正义、Chancengleichheit | 干预工资 vs. Tarifautonomie |
| ④ | **Ökonomie und Ökologie** | 碳价/规制/补贴（IF4-LK-B） | 社会代价分配 | 环保效率 vs. 分配后果 |

> *Klausur-Satz*: `Die beiden Inhaltsfelder sind über vier Punkte verknüpft: Sozialstaatsfinanzierung, Arbeitslosigkeit, Verteilungs- und Lohnpolitik sowie das Verhältnis von Ökonomie und Ökologie.`

### 2.2 交叉点 ①：社会国家财政

- IF6 要保障 → IF4 要付钱（税/缴费）
- 张力：保障水平 ↔ 缴费率 ↔ 区位竞争力
- 综合判断轴：Finanzierbarkeit + Generationengerechtigkeit + Effizienz

> *Klausur-Satz*: `Sozialstaatliche Leistungen sind nur finanzierbar, wenn die wirtschaftspolitischen Rahmenbedingungen stimmen — beide Felder bedingen einander.`

### 2.3 交叉点 ②：失业

- IF4：失业是四角之一，可用 nachfrage- 或 angebotsorientiert 工具治
- IF6：失业是贫困与 Exklusion 的主因
- 综合张力：**治失业 ≠ 治贫困**（有工作也可能 Prekarität）

> *Klausur-Satz*: `Arbeitslosigkeit ist zugleich eine Zielgröße der Wirtschaftspolitik und eine zentrale Ursache sozialer Ungleichheit.`

### 2.4 交叉点 ③：分配政策 / 工资政策

- 工具：Mindestlohn / Lohnzurückhaltung / Qualifizierung
- 张力：Mindestlohn 保护低收入 vs. 干预 Tarifautonomie、可能减少低技能岗位
- 综合判断轴：Gerechtigkeit + Beschäftigung + Preisstabilität

> *Klausur-Satz*: `Der Mindestlohn verbindet Verteilungsziele mit beschäftigungspolitischen Risiken und verknüpft damit IF4 und IF6.`

### 2.5 交叉点 ④：经济与生态（IF4-LK-B）

- 工具：CO₂-Preis（市场）/ Ordnungsrecht（规制）/ Subvention（补贴）
- 张力：效率（谁最会减，谁先减）↔ 分配（成本落在谁身上）
- 综合判断轴：Effizienz + soziale Ausgleichsverträglichkeit

> *Klausur-Satz*: `Eine CO₂-Bepreisung ist effizient, wirft aber die Frage auf, wer die Kosten trägt — eine Verteilungsfrage im Sinne von IF6.`

### 2.6 综合题论证骨架（**把两 IF 串成一条链**）

```
Problem (IF6: Ungleichheit / Prekarität)
   ↓
Ursache verorten (IF4: Konjunktur? Struktur? Lohnpolitik?)
   ↓
Instrument wählen (IF4: Konzeption + Zielgröße)
   ↓
Verteilungswirkung prüfen (IF6: Wer profitiert, wer verliert?)
   ↓
Kriteriengeleitetes Urteil (Effizienz + Gerechtigkeit + Finanzierbarkeit)
```

> *Klausur-Satz*: `Eine überzeugende Argumentation verknüpft wirtschaftspolitische Instrumente mit ihren sozialen Verteilungswirkungen.`

## 3. 解题方法 (Methoden)

### 3.1 综合题三步法（`analysieren` → `erörtern` → `entwickeln`）

**编号步骤**：
1. **双 IF 定位**：这题的现象属于 IF6 的哪个模型/争议？属于 IF4 的哪个目标量/构想？——*KLP 工具：analysieren + einordnen（überw. II）*
2. **工具—后果链**：选 IF4 工具 → 推 IF6 分配后果——*KLP 工具：erklären（II）*
3. **方案构建**：给出**兼顾两侧**的建议——*KLP 工具：entwickeln（III）*

> **判据 / 决策点**：题干若同时出现「Ungleichheit」+「Wirtschaftspolitik」→ 必走双 IF；只走一侧 = 视角多样性失分。

### 3.2 目标冲突 × 分配后果双检验（AFB III）

1. **目标量检验**：措施服务哪个角、牺牲哪个角？（IF4）
2. **分配检验**：成本/收益落在哪个群体？（IF6）
3. **双检验结论**：`Die Maßnahme ist effizient, aber verteilungspolitisch problematisch — daher ist ein Ausgleich nötig.`

### 3.3 材料分析三步（通用 30/40/30）

1. **darstellen**（30%，I–II）：Materialart / Autor / Kernaussage
2. **analysieren**（40%，II）：双 IF 归类
3. **beurteilen / erörtern**（30%，III）：Kriterien → Urteil

### 3.4 Karikatur 三步（宏观题材）

1. **beschreiben**：画面里谁在付、谁在得？（税、工资、碳价）
2. **analysieren**：Deutung + Kontext（哪个交叉点）+ Intention
3. **beurteilen**：Kriterium（Gerechtigkeit）→ Pro/Contra → Urteil

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | 综合分析型（Materialanalyse + Erörterung + ggf. Gestaltungsaufgabe） |
| Operator | `analysieren`（überw. II）· `erörtern`（III）· `entwickeln`（III） |
| AFB | I → II → **III** |
| 建议分值 / 时长 | GK 240 min / LK 300 min（3 题选 1）[已验证] |

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> Analysieren Sie, inwiefern die Einführung eines höheren Mindestlohns sowohl wirtschaftspolitische als auch sozialpolitische Wirkungen hat. (AFB II)

**Aufgabe 2** `[原创]`
> Erörtern Sie, ob eine CO₂-Bepreisung ein geeignetes Instrument ist, um ökologische und soziale Ziele miteinander zu verbinden. (AFB III)

**Aufgabe 3** `[NRW-改编]`
> Entwickeln Sie ein Konzept, wie der Sozialstaat angesichts des demografischen Wandels finanziert werden kann, ohne die Generationengerechtigkeit zu verletzen. (AFB III)

**Aufgabe 4** `[原创]`
> Beurteilen Sie die These: „Arbeitslosigkeit lässt sich wirtschaftspolitisch lösen, soziale Ungleichheit ist dagegen ein rein gesellschaftliches Problem." (AFB III)

### 5.3 Musterlösung

**Aufgabe 1**（Mindestlohn 双 IF）
1. **IF4 侧**：Zielgröße Beschäftigung + Preisstabilität; Risiko: höhere Lohnkosten → weniger Einstellungen ✓ 得分点
2. **IF6 侧**：Verteilungsgerechtigkeit; Schutz vor Armut trotz Arbeit ✓ 得分点
3. **Kriterien**：Gerechtigkeit vs. Beschäftigung ✓
4. **Fazit**：`Der Mindestlohn verbindet beide Inhaltsfelder, weil er Verteilungswirkungen und Beschäftigungswirkungen zugleich entfaltet.` ✓

**Aufgabe 2**（CO₂-Preis，erörtern）
1. **These**：CO₂-Preis ist effizient (Marktlösung, Internalierung) ✓
2. **Antithese**：soziale Härte für Geringverdiener / ländliche Regionen ✓ 得分点
3. **Kriterien**：Effizienz + Verteilungsverträglichkeit ✓
4. **Synthese**：`Der CO₂-Preis ist ökologisch wirksam, braucht aber einen sozialen Ausgleich (z. B. Klimageld).` ✓ 得分点

**Aufgabe 3**（entwickeln，AFB III）
1. **Problem**：demografischer Wandel → Finanzierungslücke ✓
2. **Maßnahmen**：Erwerbsbeteiligung↑ + Kapitaldeckung ergänzen + Zuwanderung ✓
3. **双检验**：Finanzierbarkeit（缴费率） + Generationengerechtigkeit（代际负担）✓ 得分点
4. **Konzept 呈现**：`Ein Dreiklang aus höherer Erwerbsbeteiligung, ergänzender Kapitaldeckung und gezielter Zuwanderung.` ✓

**Aufgabe 4**（beurteilen）
1. **These 前半**：Arbeitslosigkeit ist wirtschaftspolitisch beeinflussbar ✓
2. **These 后半 反驳**：Ungleichheit hat auch ökonomische Ursachen (Lohn, Steuer, Bildung) ✓ 得分点
3. **Kriterien**：Trennbarkeit der Felder ✓
4. **Urteil**：`Die These trennt zwei Felder, die faktisch verflochten sind — Ungleichheit ist auch wirtschaftspolitisch mitverursacht.` ✓

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 综合题只答一个 IF | 题干出现两领域词 → 强制双 IF 各一段 |
