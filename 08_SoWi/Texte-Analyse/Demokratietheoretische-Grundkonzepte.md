# Demokratietheoretische Grundkonzepte (民主理论基础概念：自由式 / 共和式 / 程序式)

> **中文理解**：民主不只是「投票」——理论上有三套坐标：**自由式（liberal）**说民主的目的是**保护个人自由、限制权力**；**共和式（republikanisch）**说民主是**共同体自我治理**，公民要积极参与、追求公共善（Gemeinwohl）；**程序式 / 多元（prozedural，Robert Dahl）**说民主是一套**可测量的程序**（自由选举 + 竞争 + 参与权），并用 Polyarchie 标准去衡量。这三套坐标决定你**用什么标准**评价参与、政党、选举或民主危机——选错坐标 = 用错尺子。
>
> **Klausur-Relevanz**：这是 KLP IF2 的条目 `Demokratietheoretische Grundkonzepte`，EF 层为 `darstellen` / `analysieren` 的加分项，也是 `beurteilen` 段的**理论坐标**。⚠️ 本条目属 **A 方向 EF**；B 方向 EF 无此条目。[已验证]

## 2. 知识结构 (Struktur)

### 2.1 三坐标总览（一句话人像）

- **自由式**：民主是**工具**——目的是保护个人自由与权利，国家越小越好，参与主要是**投票**。
- **共和式**：民主是**生活方式**——公民应**积极参与**、协商、追求 Gemeinwohl。
- **程序式（Dahl）**：民主是**一套程序**——自由选举、竞争、参与权、言论自由，可用**程度**衡量（Polyarchie）。

> *Klausur-Satz*: `Liberale Demokratietheorien betonen den Schutz individueller Freiheit, republikanische Theorien die aktive Selbstregierung der Bürger, und prozedurale Ansätze wie der von Dahl definieren Demokratie über messbare Verfahren.`

### 2.2 三坐标对照表（**本篇核心，必背**）

| 维度 | Liberale Theorie | Republikanische Theorie | Prozedurale Theorie (Dahl) |
|---|---|---|---|
| **民主是什么** | 保护自由的工具 | 共同体自我治理 | 可测量的程序集合 |
| **国家角色** | 尽量少干预（Nachtwächter） | 公民共同塑造的共同体 | 提供竞争与参与的制度框架 |
| **参与角色** | 投票、监督（instrumental） | 积极参与、协商（intrinsisch） | 选举竞争 + 参与权（messbar） |
| **评价标准** | 自由 / 权利保护 / 权力限制 | Teilhabe / Gemeinwohl / Deliberation | Wettbewerb / Beteiligung / Polyarchie |
| **理论传统** | Locke / Mill / Pluralismus | Rousseau / Arendt / Habermas | R. Dahl（Polyarchie）[据推断] |
| **盲区** | 参与冷淡、政治冷漠被容忍 | 高参与要求可能不现实 | 只问程序，不问结果是否公正 |

> *Klausur-Satz*: `Während die liberale Theorie die Freiheit des Einzelnen in den Mittelpunkt stellt, fragt die republikanische Theorie nach dem Gemeinwohl, und die prozedurale Theorie nach der Qualität demokratischer Verfahren.`

### 2.3 三坐标与「民主的威胁」（接口）

- 自由式看威胁：权力滥用、权利被侵蚀
- 共和式看威胁：公民冷漠、公共讨论萎缩
- 程序式看威胁：选举竞争被破坏、参与权受限

> *Klausur-Satz*: `Je nach demokratietheoretischem Ansatz werden unterschiedliche Gefährdungen der Demokratie sichtbar.`

### 2.4 与宪法基础的接口

- 基本法同时含三种元素：Grundrechte（自由式）、Art. 20 人民主权（共和式）、Wahlverfahren（程序式）
- 参见 EF 篇《Grundgesetz-Verfassungsprinzipien》与《Wehrhafte-Demokratie》

> *Klausur-Satz*: `Das Grundgesetz verbindet liberale, republikanische und prozedurale Elemente miteinander.`

## 3. 解题方法 (Methoden)

### 3.1 三坐标对照答题法（`vergleichen`，AFB II–III）

**编号步骤**：
1. **明写 Vergleichskriterien**（民主是什么 / 参与角色 / 评价标准）——*KLP 工具：vergleichen 要求「按维度」* [已验证]
2. **维度对齐并列**（三列并排）
3. **Gemeinsamkeiten**：三者都承认 Volkssouveränität + Mehrheitsprinzip + Minderheitenschutz
4. **Unterschiede**：目的（自由 vs. 共同体 vs. 程序）
5. **Gewichtung**：哪套坐标适合评价材料中的现象

### 3.2 评价坐标选择法（`beurteilen`，AFB III）

1. **识别现象**：材料谈的是权利保护？参与冷淡？还是选举程序？
2. **选坐标**：权利 → 自由式；参与/公共讨论 → 共和式；选举/竞争 → 程序式
3. **按该坐标的标准评价**（**不可混用尺子**）
4. **判断**：`Legt man die republikanische Theorie zugrunde, ist die sinkende Wahlbeteiligung ein Problem — aus liberaler Sicht ist sie weniger gravierend.`

> **判据 / 决策点**：题干给「Wahlbeteiligung」→ 可自由式（选择自由）或共和式（参与义务）解读；给「Grundrechte」→ 自由式；给「Polyarchie」→ 程序式。

### 3.3 材料分析三步（通用 30/40/30）

1. **darstellen**（30%，I–II）：Materialart / Autor / Kernaussage
2. **analysieren**（40%，II）：材料论点归入哪一坐标
3. **beurteilen**（30%，III）：按该坐标的 Kriterium 权衡

### 3.4 Karikatur 三步（EF 高频材料）

1. **beschreiben**：谁/什么/哪里 + 象征 + 文字（只描述）
2. **analysieren**：Deutung + Kontext（哪一民主理论视角）+ Intention
3. **beurteilen**：Kriterium（Teilhabe / Freiheit）→ Pro/Contra → Urteil

> 中文自查：漫画里的「选民/公民」是被动投票，还是被期待积极发声？这决定用哪套坐标。

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | Materialanalyse（Sachtext / Karikatur）+ Beurteilung |
| Operator | `darstellen`（I–II）· `vergleichen`（II–III）· `einordnen`（überw. II）· `beurteilen`（III） |
| AFB | I → II → III |
| 建议分值 / 时长 | EF 平时 Klausur 90 min（gesellschaftswissenschaftliches Fach）[已验证] |

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> Stellen Sie die liberale, die republikanische und die prozedurale Demokratietheorie dar. (AFB I–II)

**Aufgabe 2** `[原创]`
> Ordnen Sie die folgende Aussage („Demokratie bedeutet vor allem, dass Bürger sich aktiv am Gemeinwohl orientieren.") einer demokratietheoretischen Position zu und begründen Sie Ihre Zuordnung. (AFB II)

**Aufgabe 3** `[NRW-改编]`
> Beurteilen Sie die sinkende Wahlbeteiligung aus der Perspektive zweier Demokratietheorien. (AFB III)

**Aufgabe 4** `[原创]`
> Vergleichen Sie das liberale und das republikanische Verständnis von Partizipation. (AFB II–III)

### 5.3 Musterlösung

**Aufgabe 1**
1. **自由式**：Schutz individueller Freiheit, begrenzter Staat, Wahl als zentrale Partizipation ✓（AFB I）
2. **共和式**：Selbstregierung, aktive Teilhabe, Gemeinwohl ✓
3. **程序式**：messbare Verfahren, Wettbewerb, Polyarchie (Dahl) ✓ 得分点

**Aufgabe 2**（归类）
1. **关键词识别**：„aktiv am Gemeinwohl orientieren" → Teilhabe + Gemeinwohl ✓ 得分点
2. **归类**：republikanische Demokratietheorie ✓
3. **Begründung**：`weil sie aktive Teilnahme und die Orientierung am Gemeinwohl betont` ✓

**Aufgabe 3**（beurteilen，AFB III）
1. **自由式视角**：sinkende Wahlbeteiligung ist tolerierbar — Bürger dürfen frei entscheiden, nicht zu wählen ✓ 得分点
2. **共和式视角**：Wahlbeteiligung ist Ausdruck mangelnder Teilhabe → Problem für die Selbstregierung ✓ 得分点
3. **Kriterien 明确区分**：Freiheit vs. Teilhabe ✓
4. **Urteil**：`Die Bewertung hängt vom zugrunde gelegten Demokratieverständnis ab.` ✓ 得分点

**Aufgabe 4**
1. **Kriterien**：Verständnis von Partizipation / Ziel ✓
2. **自由式**：Partizipation instrumental（投票监督）✓
3. **共和式**：Partizipation intrinsisch（参与本身即价值）✓
4. **Gemeinsamkeit + Gewichtung**：beide erkennen Beteiligung an, gewichten sie aber unterschiedlich ✓

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 三坐标混用（用自由式标准批共和式现象） | 先选坐标，再选标准，一步一验 |
| 知识错 | 把「程序式」与「共和式」都写成「要参与」 | 记：程序式问**程序质量**，共和式问**公共善** |
| 表达错 | 只写「民主好/不好」不给坐标 | 每句评价前写 „Aus Sicht der …-Theorie…" |
