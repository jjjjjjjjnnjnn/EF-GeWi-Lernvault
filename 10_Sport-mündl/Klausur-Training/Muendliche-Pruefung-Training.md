# Mündliche Prüfung im Fach Sport: Redemittel, Operatoren und Drei-Schichten-Struktur (体育口试话术库)

> **中文理解**：体育口试不是「背课文」，而是**用考官能听懂的德语专业话术，把动作/训练/健康问题讲成有理论依据的论证**。结构固定：**Teil 1** = 你独立连贯陈述准备好的内容（zusammenhängender Vortrag）；**Teil 2** = 考试对话（Prüfungsgespräch），讨论更大范围的专业与跨学科关联。时长通常 **20–30 分钟**，考生**无选题权**。本笔记是**跨 IF 的方法层**笔记：给你分 IF 的术语库 + Operator↔AFB 对应 + 三层正交矩阵，让任何一个 IF 的题都能套同一套话术骨架。
>
> **Klausur-Relevanz**：本项目用户走**口试方向**——这篇是「怎么把已学知识说出来」的落地工具，直接决定口试的流利度与专业度得分。

## 2. 知识结构 (Struktur)

### 2.1 口试两部分结构（答题节奏）

中文理解：Teil 1 要把准备好的内容**讲成一个整体**（有开头-展开-结论），Teil 2 要能**接得住追问**。

> *Klausur-Satz*: `In Teil 1 präsentiere ich zusammenhängend, in Teil 2 diskutiere ich im Prüfungsgespräch übergeordnete Zusammenhänge.`

| 部分 | 形式 | 时间 | 你要做什么 |
|---|---|---|---|
| **Teil 1** | zusammenhängender Vortrag | 约 10–15 min | 结构化陈述：定义 → 展开 → 结论 |
| **Teil 2** | Prüfungsgespräch | 约 10–15 min | 接追问、建关联、依准则表态 |

> 时长 20–30 min、考生无选题权、题目须覆盖全部三 AFB：[已验证]（KLP/BASS）。

### 2.2 Operator ↔ AFB 对应（Sport 官方 25 动词）

中文理解：**第一步永远先划出题目里的 Operator**——动词决定 AFB 层级，层级决定你答「描述」还是「评判」。Sport 是少数**逐条给 AFB 区间**的科目（A 组），可直接查表。

> *Klausur-Satz*: `Der Operator gibt an, auf welcher Anforderungsstufe ich antworten muss.`

| Operator | AFB | 中文 | 答题动作（话术起点） |
|---|---|---|---|
| `angeben / nennen` | I | 列举 | 直接罗列，不解释 |
| `beschreiben` | I–II（主 I） | 描述 | 用术语复述结构/过程 |
| `skizzieren` | I–II | 勾勒/图示 | 图/表简要呈现 |
| `darstellen` | I–II | 呈示 | 结构化复述关联 |
| `einordnen / zuordnen` | I–II | 归类 | 放入给定关联 |
| `zusammenfassen` | I–II | 概括 | 压缩复述 |
| `analysieren` | **II** | 分析 | 按维度拆解并呈现 |
| `erlaeutern` | **II** | 阐释 | 加信息/例子说明 |
| `herausarbeiten` | **II** | 提炼 | 从材料识别事态 |
| `erklaeren` | II–III（主 II） | 解释 | 归因到规律/因果 |
| `anwenden / uebertragen` | II–III（主 II） | 应用/迁移 | 迁移到新问题 |
| `auswerten` | II–III（主 II） | 评估数据 | 汇总数据得总体论断 |
| `in Beziehung setzen` | II–III（主 II） | 建立关联 | 按视角建立关联 |
| `vergleichen / gegenueberstellen` | II–III（主 II） | 比较 | 找共同点/差异 |
| `begruenden` | II–III | 论证 | 归因/建立因果 |
| `entwickeln` | II–III（主 III） | 发展/构建 | 逐步推进构想 |
| `eroertern` | **III** | 论述 | 正反权衡后下判断 |
| `auseinandersetzen mit…` | **III** | 辨析 | 依标准形成判断 |
| `beurteilen` | **III** | 评判（Sachurteil） | 依专业标准判断 |
| `bewerten` | **III** | 评价（Werturteil） | 依价值规范表态 |
| `entwerfen` | **III** | 设计 | 规划性勾勒概念 |
| `problematisieren` | **III** | 问题化 | 提炼矛盾、追问 |
| `pruefen / ueberpruefen` | **III** | 检验 | 评判论断/论证 |
| `Stellung nehmen` | **III** | 表态 | 见 beurteilen/bewerten |
| `Stellung nehmen aus der Sicht von …` | **III** | 从某视角表态/反驳 | 体育科独有 |

> ⚠️ **Sport 是唯一单列「从某立场视角表态/反驳」的科目** [已验证]——常考「从某训练学/伦理立场反驳」。

### 2.3 分 IF 专用术语库（口试即时调用）

中文理解：每个 IF 有一套「听到题就能立刻说出口」的核心术语——先抛术语，再解释，最后给例子。

> *Klausur-Satz*: `Ich verwende die Fachbegriffe des jeweiligen Inhaltsfeldes und erkläre sie im Kontext.`

| IF | 核心术语（DE） | 中文 |
|---|---|---|
| **a** Bewegungsstruktur | Grob-/Fein-/stabilisierte Feinkoordination · Phasenanalyse · Bewegungsvorstellung · biomechanische Grundlagen | 学习阶段 · 相位分析 · 动作表象 · 生物力学 |
| **b** Bewegungsgestaltung | Gestaltungskriterien (Raum, Zeit, Dynamik, formaler Aufbau) · Indikatoren · Improvisation/Variation | 编排四准则 · 指标 · 即兴与变奏 |
| **c** Wagnis/Verantwortung | Handlungssteuerung · Emotionen · Angst · Risikowahrnehmung · Motivation | 行动调控 · 情绪 · 恐惧 · 风险感知 · 动机 |
| **d** Leistung | Belastungsgroessen · Trainingsprinzipien · Superkompensation · Ausdauermethoden | 负荷四参数 · 训练原则 · 超量恢复 · 耐力方法 |
| **e** Kooperation/Konkurrenz | Regeln/Normen · Fairness · Aggression · Spielgelegenheiten | 规则规范 · 公平 · 攻击性 · 比赛机会 |
| **f** Gesundheit | Nutzen/Risiken · Praevention · Fitness · Aufwaermen | 益处风险 · 预防 · 体能 · 热身 |

### 2.4 三层正交结构矩阵（本学科核心机制）

中文理解：KLP 不写「学铅球」，而写「在**某 BF/SB** 中，就**某 IF** 的某重点，展现**某能力域**」。口试答题时，你要能**自觉地把自己的答案定位到这三层**——这是「专家型」与「学生型」作答的分水岭。

> *Klausur-Satz*: `Kompetenzen werden immer in einem Bewegungsfeld, bezogen auf ein Inhaltsfeld, in einem Kompetenzbereich gezeigt.`

**过程层（4 能力域）** [已验证]：

| # | Kompetenzbereich | 中文 |
|---|---|---|
| 1 | Bewegungs- und Wahrnehmungskompetenz | 运动与感知能力（**中心与起点**） |
| 2 | Sachkompetenz | 事实能力 |
| 3 | Methodenkompetenz | 方法能力 |
| 4 | Urteilskompetenz | 判断能力 |

> ⚠️ **不存在「psycho-physische Handlungskompetenz」这个能力域**——上游曾给错，不得沿用。它是**总目标**的描述用词，不是第 5 个能力域。[已验证]

**对象层 1（6 IF）**：a Bewegungsstruktur · b Bewegungsgestaltung · c Wagnis/Verantwortung · d Leistung · e Kooperation/Konkurrenz · f Gesundheit

**对象层 2（8 BF/SB）** [已验证]：BF/SB1 感知身体（**仅 GK**）· BF/SB3 田径 · BF/SB4 游泳 · BF/SB5 器械体操 · BF/SB6 体操/舞蹈 · BF/SB7 球类 · BF/SB8 轮滑/划船/冬季 · BF/SB9 格斗（**BF/SB2 在 Oberstufe 被排除**）

**口试中的三层定位句模板**：
> `Diese Kompetenz zeige ich im Bewegungsfeld Leichtathletik (BF/SB3), bezogen auf das Inhaltsfeld Leistung (IF d), im Bereich der Sachkompetenz: Ich erkläre die Belastungsgrößen theoriegeleitet.`

### 2.5 「6 选 2」的备考含义（⚠️ 不是「只教 2 个」）

中文理解：GK 的「6 选 2」= **2 个 IF 全教 + 4 个 IF 只教第一重点**（KLP 粗体那条），**不是只教 2 个**；LK 无「6 选 2」，6 个 IF 全重点通吃。

> *Klausur-Satz*: `Im Grundkurs werden zwei Inhaltsfelder umfassend, die übrigen vier zumindest in ihrem ersten Schwerpunkt behandelt.`

> ⏳ **待确认**：本校选定的 2 个 Akzentuierungs-IF 是哪两个？（决定备考重心）——但**其余 4 个 IF 的第一重点仍是考点**，不可弃。

## 3. 解题方法 (Methoden)

### 3.1 口试三步作答法（Operator → 结构 → 术语）

**编号步骤**：
1. **划 Operator**，定 AFB（§2.2）—— *KLP 工具：Operatorenübersicht*
2. **定结构**：按 IF 选骨架（如 IF d 用「四参数 → 分析 → 评判」）—— *KLP 工具：IF 知识结构*
3. **抛术语 + 举例 + 因果句**（theoriegeleitet）—— *KLP 工具：Fachsprache + begründen*
4. **Teil 2 接追问**：先复述问题 → 给判断 → 给依据 → 给例子 —— *KLP 工具：Stellung nehmen / beurteilen*

> **判据 / 决策点**：Operator 是 `beurteilen` → 必须给**专业标准**；是 `bewerten` → 必须给**价值规范**。混淆 = 整题跑偏。

### 3.2 通用话术骨架（背下来直接套）

| 功能 | 德语句式 |
|---|---|
| 开场定位 | `Ich gliedere meine Antwort in drei Schritte: …` |
| 描述 | `Ich beschreibe …, und zwar in folgender Struktur: …` |
| 分析 | `Ich analysiere … unter dem Aspekt …; dabei fällt auf, dass …` |
| 解释/归因 | `Das erklärt sich dadurch, dass …, weil …` |
| 比较 | `Im Vergleich dazu gilt bei …, dass …; der entscheidende Unterschied ist …` |
| 评判（Sachurteil） | `Nach dem Kriterium … beurteile ich …, weil …` |
| 评价（Werturteil） | `Unter dem Wert … bewerte ich … als …, da …` |
| 论述 | `Einerseits …, andererseits …; abwägend komme ich zu dem Schluss, dass …` |
| 表态 | `Ich nehme Stellung: …, und zwar aus folgendem Grund: …` |
| 从某视角反驳 | `Aus der Sicht von … würde man einwenden, dass …` |
| 收尾 | `Zusammenfassend lässt sich sagen, dass …` |

### 3.3 追问应对三招

1. **听不懂**：`Könnten Sie die Frage bitte präzisieren?`（争取时间 + 显专业）
2. **没准备**：回到「定义 → 例子 → 判断」三件套，用已知推未知
3. **被反驳**：先承认合理处，再用准则反驳 —— `Das ist ein berechtigter Einwand; aus der Sicht von … überwiegt jedoch …, weil …`

- **合规性**：✅；⚠️ 中文「先总后分」逻辑可迁移，但不可直译中文套话。

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | 口试（Mündliche Abiturprüfung / mündliche Prüfung）；含 Teil 1 陈述 + Teil 2 对话 |
| Operator | 全 25 个，随题变化；`beurteilen/bewerten/eroertern` 决定 AFB III |
| AFB | 须覆盖 I+II+III，**AFB II 为重点** [已验证] |
| 建议分值 / 时长 | 20–30 min，无选题权 [已验证] |

> **三条轨道如何考**：
> - **笔试（仅 LK）**：300 min，2 题选 1，题型依 KLP Kap. 3 的 Überprüfungsformen。[已验证]
> - **口试（mündliche Prüfung）**：本笔记主战场，Teil 1 + Teil 2。
> - **实践部分（Praktische Prüfung）**：第 4 Fach 轨道 = **2 部分**（第 1 部分耐力测试或竞争性成绩二选一；第 2 部分为专项成绩检测）；第 2 Fach 轨道 = **3 部分**（含独立耐力部分）。均跨 ≥2 个 BF/SB。[已验证]

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> (Teil 1, 5 min) Beschreiben und erläutern Sie die vier Belastungsgrößen und ordnen Sie Ihr Beispiel einem Bewegungsfeld zu.
> （模拟 IF d 口试题；要求同时命中 Operator、术语、三层定位）

**Aufgabe 2** `[原创]`
> (Teil 2, Prüfungsgespräch) Ein Prüfer sagt: „Training nach dem Superkompensationsmodell ist doch reine Theorie.“ Nehmen Sie Stellung.
> （模拟 AFB III 表态 + 从某视角反驳）

**Aufgabe 3** `[NRW-改编]`
> (Teil 1 + 2) Analysieren Sie den Absprung beim Weitsprung (IF a) und beurteilen Sie, welche Lernphase der beschriebene Sportler erreicht hat.
> （跨 IF a 的分析 + 评判，考 Operator 切换）

### 5.3 Musterlösung

**Aufgabe 1**
1. 开场结构句：`Ich gliedere in Definition, Zusammenwirken und Beispiel.` ✓ 得分点（结构意识）
2. 四参数点名 + 定义（Intensität/Umfang/Dauer/Dichte）✓ 得分点（Fachsprache）
3. 说明耦合：强度↑则量↓ ✓ 得分点
4. 举例并**归 BF/SB**：`im Bewegungsfeld Leichtathletik (BF/SB3)` ✓ 得分点（三层定位，加分）
5. 归 IF：`bezogen auf das Inhaltsfeld Leistung (IF d)` ✓ 加分点
6. 收尾句 ✓ 得分点

**Aufgabe 2**（AFB III）
1. 承认合理处：模型确是**简化**，真实曲线因人因负荷而异 ✓ 得分点
2. 反驳：但模型有**实践预测力**——解释「为何不能天天高强度」并指导训练间隔 ✓ 得分点（关键）
3. 给例：Übertraining（过早）vs Stagnation（过晚）✓ 得分点
4. 用 `Stellung nehmen` 句式表态，判断用专业标准（beurteilen）✓ 加分点
5. 若被追问跨学科：连到生物（内稳态、适应生理）✓ 加分点（Teil 2 要求跨学科）

**Aufgabe 3**
1. 分析：按相位分 Anlauf/Absprung/Flug/Landung，抓 Hauptphase（Absprung）✓ 得分点
2. 生物力学依据：起跳角、KSP 抛物线 ✓ 得分点
3. 判阶段：依观察（是否自动化、是否受干扰）定 Grob/Fein/stabilisiert ✓ 得分点（关键）
4. 给依据，不只给结论 ✓ 得分点
5. 依准则评判（beurteilen，非「我觉得」）✓ 加分点

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | `beurteilen`（专业标准）与 `bewerten`（价值规范）混用；`beschreiben` 答成 `beurteilen` | 先划 Operator，再决定「描述 vs 评判」 |
| 知识错 | 术语不说德语，或把 Lernphasen 与 Bewegungsphasen 混用 | 每个 IF 背 4–6 个核心术语；区分两套「相位」 |
| 表达错 | Teil 1 没有结构（想到哪说到哪）；Teil 2 只答「是/不是」 | 用 §3.2 骨架；每次回答给「判断 + 依据 + 例子」 |
