# Phasenmodelle und Beobachtungsbogen (分相约定对照 + 观察记录表)

> **中文理解**：这是**跨 IF 的方法层笔记**——「把动作切相」是 Bewegungsanalyse 的通用工具（Methodenkompetenz），服务 IF a/b/d，不属单一 IF。核心要解决一个**高频失分点**：德语里「Phase（相）」有**三套互不相同的含义**，混用即失分——
> ① **三相通用约定**（Vorbereitungsphase / Hauptphase / Endphase）＝**方法层**的万能切法；
> ② **项目专属分相**（如跳远四相：Anlauf / Absprung / Flug / Landung）＝**具体动作**的精细切法；
> ③ **Lernphasen 学习阶段**（Grob- / Fein- / stabilisierte Feinkoordination）＝**学习者**的阶段，不是动作的阶段。
> 现有笔记只给了四相例子，缺 ①②③ 的**对照说明**与可复用的 **Beobachtungsbogen（观察记录表）**——本笔记补齐。考试里它出现在：笔试（仅 LK）的 **Analyseaufgabe**（Bewegungsanalyse 属此）；口试 Teil 1 的「分相描述」与 Teil 2 的追问；实践部分的**观察与自我分析**。
>
> **Klausur-Relevanz**：⚠️ 分相是所有 Bewegungsanalyse 题的**第一刀**。切错约定 → 后续的相位目标、生物力学依据、错误纠正**全部连锁出错**。

## 2. 知识结构 (Struktur)

### 2.1 ⚠️ 三套「Phase」概念必须先分清（本笔记第一要务）

中文理解：同一个词 `Phase`，在三处指**完全不同的东西**。答题前先问：「我要切的是**动作**，还是描述**学习者的水平**？」——这是防混用的唯一判据。

> *Klausur-Satz*: `Ich unterscheide Bewegungsphasen, sportartspezifische Phasen und Lernphasen; sie liegen auf verschiedenen Ebenen und dürfen nicht vermischt werden.`

| # | 概念 | 切的是谁 | 数量/命名 | 典型考点 |
|---|---|---|---|---|
| ① | **三相通用约定**（Phasenstruktur） | **动作**（方法层） | 3：Vorbereitung / Haupt / End | 通用分析骨架 |
| ② | **项目专属分相** | **动作**（项目层） | 视项目：4 相等 | 跳远、铅球、跳高 |
| ③ | **Lernphasen** | **学习者** | 3：Grob / Fein / stabilisiert | 判断水平、给教学对策 |

> ⚠️ **最高频失分**：把 ③ 的 `Grob-/Feinkoordination` 说成「动作的第 1/2 相」。**动作相位是空间-时间结构，学习阶段是能力发展水平**——两者不可互换。

### 2.2 三相通用约定（方法层的万能切法）

中文理解：任何动作都能先按「准备 → 主相 → 结束」切三刀。这是**不依赖项目**的通用骨架，适合**第一次接触的动作**或**快速分析**。

> *Klausur-Satz*: `Nach der allgemeinen Phasenstruktur gliedert sich jede Bewegung in eine Vorbereitungs-, eine Haupt- und eine Endphase.`

| 相位 | 目标 | 观察什么（Beobachtungsschwerpunkt） |
|---|---|---|
| **Vorbereitungsphase** | 蓄势：加速/蓄力/对准 | 速度、身体姿态、重心路径 |
| **Hauptphase** | 出成绩：把势能/动能转为结果 | 关键角度、发力顺序、时机 |
| **Endphase** | 收束：缓冲/稳定/过渡 | 落地缓冲、平衡、无多余动作 |

> ⚠️ **主相永远是重点**：分析题 80% 的分在 Hauptphase。三相约定的价值就是**帮你快速定位主相**。

### 2.3 项目专属分相（四相为例）—— 与三相如何映射

中文理解：项目分相只是**把三相细化**，不是另一套体系。跳远四相里：Anlauf ≈ Vorbereitung；**Absprung = Hauptphase**；Flug + Landung ≈ Endphase。**看清映射，就不会「两套体系打架」**。

> *Klausur-Satz*: `Die sportartspezifische Gliederung des Weitsprungs in Anlauf, Absprung, Flug und Landung lässt sich der allgemeinen Drei-Phasen-Struktur zuordnen: Der Absprung entspricht der Hauptphase.`

| 跳远四相 | 映射到三相 | 相位目标 | 生物力学要点 [据推断] |
|---|---|---|---|
| Anlauf | Vorbereitungsphase | 匀加速、踏准板 | 水平速度最大化 |
| **Absprung** | **Hauptphase** | 速度转为远度 | 起跳角、水平/垂直速度分解 |
| Flug | Endphase（前段） | 保平衡、备落地 | 重心抛物线已定，只能优化姿态 |
| Landung | Endphase（后段） | 前伸、缓冲 | 屈膝缓冲、避免后坐 |

> ⚠️ **判据 / 决策点**：题目**点名了项目**（如「Weitsprung」）→ 用**项目专属分相**（更具体、得分更高）；题目**未点名**或要求通用分析 → 用**三相约定**。**两者不冲突，可先三相定位主相，再用项目相细化。**

### 2.4 其他项目的分相速查（迁移示例）

中文理解：换项目只需换相位名称，**「准备-主相-结束」的骨架不变**（Hochsprung：Anlauf–Absprung–Flug–Landung，主相＝Absprung；Kugelstoßen：Angehen–Angleiten–Stoß–Ausgleich，主相＝Stoß）。分相命名为 [据推断]（项目惯例），答题**以题目给定或教师约定为准**。

> *Klausur-Satz*: `Bei jedem Bewegungsfeld bleibt die Grundstruktur gleich, nur die Phasennamen ändern sich.`

### 2.5 Beobachtungsbogen（观察记录表）—— 工具本体

中文理解：分相之后要**逐相观察**。Beobachtungsbogen 把「相 → 观察重点 → 指标 → 观察结果 → 错误 → 纠正」串成一张表——它同时是**分析题答题框架**和**实践课的观察工具**。

> *Klausur-Satz*: `Der Beobachtungsbogen ordnet jeder Phase Beobachtungsschwerpunkte und Indikatoren zu und macht das Urteil nachvollziehbar.`

**① 空白模板**（可直接抄用）：

| Phase | Beobachtungsschwerpunkt | Indikator | Beobachtung (✓/✗/Skala) | Fehlerbild | Korrektur |
|---|---|---|---|---|---|
| Vorbereitung |  |  |  |  |  |
| Hauptphase |  |  |  |  |  |
| Endphase |  |  |  |  |  |

**② 填写示例（Weitsprung，四相版）** [原创示例]：

| Phase | Beobachtungsschwerpunkt | Indikator | Beobachtung | Fehlerbild | Korrektur |
|---|---|---|---|---|---|
| Anlauf | 节奏与加速 | 步频稳定、最后三步不减速 | ✓ | 临板前减速 | 标记步点、短程助跑 |
| Absprung | 快速与蹬伸 | 快速触板、全伸展、摆动腿前摆 | ✗ | 屈膝「刹」板 | 节奏跑 + 起跳板练习 |
| Flug | 平衡与姿态 | 步式保持、不过早收腿 | ✓ | 空中乱摆 | 落地前伸专项 |
| Landung | 前伸与缓冲 | 双脚前伸、屈膝、不后坐 | ✓ | 手后撑、后坐 | 沙坑落地练习 |

> ⚠️ **填表的纪律**：`Beobachtung` 列**只写观察到的**（beschreiben），**判断**（beurteilen）留给 `Fehlerbild` 与 `Korrektur` 列。观察与判断混在一格 = 分析题失分。

## 3. 解题方法 (Methoden)

### 3.1 Bewegungsanalyse「五步刀法」（分相 → 观察 → 依据 → 纠错 → 评判）

**编号步骤**：
1. **定约定**：题目点名项目 → 用项目分相；否则用三相 —— *KLP 工具：Methodenkompetenz*
2. **切相 + 定主相**：切好后标出 Hauptphase —— *KLP 工具：Phasenstruktur*
3. **逐相观察**：按 Beobachtungsbogen 填观察重点与指标（只写观察） —— *KLP 工具：Indikator / Beobachtung*
4. **给生物力学依据**：主相至少两条力学解释 —— *KLP 工具：theoriegeleitet begründen*
5. **纠错 + 评判**：由 Fehlerbild 推 Korrektur；依准则评判（非「我觉得」） —— *KLP 工具：Urteilskompetenz*

> **判据 / 决策点**：Operator 是 `beschreiben` → 只到第 3 步（描述观察）；是 `analysieren` → 到第 4 步（给依据）；是 `beurteilen` → 到第 5 步（依准则判断）。**停在正确的步数，多写不算错，但答非所问会失分。**

### 3.2 口试「分相开场」万能句

| 场景 | 起手句 |
|---|---|
| 描述动作 | `Die Bewegung gliedert sich in …; entscheidend ist …, weil …` |
| 切换约定 | `Ich wähle die sportartspezifische Gliederung, weil die Aufgabe den Weitsprung nennt.` |
| 分清学习阶段 | `Davon zu unterscheiden sind die Lernphasen: Der Sportler zeigt … Grobkoordination.` |
| 依表评判 | `Nach dem Indikator … beurteile ich die Ausführung als …, weil …` |

### 5.3 Musterlösung

**Aufgabe 1**
1. **切相 + 命名**：Anlauf – Absprung – Flug – Landung ✓ 得分点（Fachsprache）
2. **定主相**：Absprung = Hauptphase ✓ 得分点（关键）
3. **依据 1**：起跳角决定重心抛物线 → 远度在起跳瞬间基本确定 ✓ 得分点
4. **依据 2**：水平速度在此转为「水平+垂直」合成 → 转换效率决定远度 ✓ 得分点（theoriegeleitet）
5. **说明其余相为从属**：Anlauf 提供初速、Flug 只能优化姿态、Landung 只影响落地 ✓ 加分点

**Aufgabe 2**
1. 三相切法：Vorbereitung – Haupt – End ✓ 得分点
2. 项目分相（以跳远为例）：四相 ✓ 得分点
3. **建立映射**：Anlauf↔Vorbereitung；Absprung↔Haupt；Flug+Landung↔End ✓ 得分点（关键，`in Beziehung setzen`）
4. 说明**为何两套不冲突**：项目分相是三相约定的细化 ✓ 加分点
5. 一句总结：`Beide Gliederungen beschreiben dieselbe Bewegung auf unterschiedlichem Detaillierungsgrad.` ✓ 加分点

**Aufgabe 3**（AFB II→III）
1. 给出 Beobachtungsbogen（相 × 指标 × 观察 × 错误 × 纠正）✓ 得分点
2. 指标具体可观察（如「最后三步不减速」「快速触板」）✓ 得分点
3. 判定错误：`Geschwindigkeitsverlust durch Stemmen`（临板减速）✓ 得分点（关键）
4. 给**依据**：重心下降 → 抛物线缩短 → 远度损失 ✓ 得分点
5. 给纠正：标记步点 + 短程助跑 ✓ 得分点
6. 依**准则**评判（`beurteilen`，非主观）✓ 加分点

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把 `Lernphasen`（Grob-/Feinkoordination）当成动作相位；项目分相与三相混用不映射 | 先问「切动作还是描述学习者」，用 §2.1 表判断 |
| 知识错 | 主相定错（如把 Anlauf 当 Hauptphase）；只说「角度合适」不给速度分解 | 记住「主相＝决定成绩那一相」；每相配 1–2 条力学依据 |
| 表达错 | Beobachtung 列写成主观判断（「他跳得不好」）；相位名用中文直译 | 观察列只写观察；相位名用德语约定 |
