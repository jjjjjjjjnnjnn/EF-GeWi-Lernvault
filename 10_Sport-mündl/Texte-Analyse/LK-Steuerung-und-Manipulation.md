# [LK] Steuerung und Manipulation (运动中的操控与操纵)

> **中文理解**：现代竞技体育不只是运动员之间的较量——**赞助商、转播方、协会、政治、博彩**都在从外部影响比赛。KLP 在 IF e 的 **LK 段**专列 `Formen der Steuerung und Manipulation im Sport` 为 LK 独有条目——**GK 不考**。它涵盖两个层面：**Steuerung（正当/中性的调控**，如协会设规则、赞助商影响赛程）与 **Manipulation（不正当的操纵**，如兴奋剂、假球、收买裁判）。考试里它出现在：笔试（仅 LK）的 **Erörterungsaufgabe**（论述「商业化的利与弊」）；口试 Teil 2 的追问（「转播时间改动比赛，你怎么看？」）；以及实践部分——你训练动机与比赛环境所受的外部影响。核心能力是：**识别操控形式 → 分析利益方 → 依价值准则评判**。
>
> **Klausur-Relevanz**：⚠️ **LK 专属**。GK 学生不考此条；LK 学生这是 IF e 的第二条加宽条目，且是 `problematisieren` / `bewerten` / `Stellung nehmen`（AFB III）的典型载体。常见失分：把「Steuerung」与「Manipulation」混为一谈——前者未必不道德，后者必然破坏公平。

## 2. 知识结构 (Struktur)

### 2.1 关键区分：Steuerung ≠ Manipulation

中文理解：**这是本条目的核心判断点**。调控可以是正当的（协会设安全规则），操纵必然是破坏性的（改结果）。答题若不分，AFB III 直接失分。

> *Klausur-Satz*: `Steuerung meint die legitime Einflussnahme auf den Sport, Manipulation dagegen die illegitime, auf Täuschung angelegte Einflussnahme.`

| 维度 | Steuerung（调控） | Manipulation（操纵） |
|---|---|---|
| **正当性** | 公开、合规、可接受 | 隐秘、违规、被谴责 |
| **目的** | 组织、保障、发展运动 | 获取不正当利益 |
| **例子** | 协会定规则、赞助改赛程、转播定开赛时间 | 兴奋剂、假球、收买裁判 |
| **对公平** | 不破坏（或权衡后接受） | 直接破坏 |
| **边界** | 可争议但透明 | 明确不可接受 |

> ⚠️ 边界存在**灰色地带**：赞助影响赛程是 Steuerung 还是 Manipulation？——取决于是否损害比赛的**诚信（Integrität）**。[据推断]

### 2.2 操控的四大形式

中文理解：考试常要求「列举并分类操控形式」。四条必须能背出并各配一例。

> *Klausur-Satz*: `Zu den Formen der Manipulation zählen Doping, Spielmanipulation, die Beeinflussung von Schiedsrichtern sowie wirtschaftlicher Druck auf Athleten.`

| 形式 | 机制 | 例子 | 破坏什么 |
|---|---|---|---|
| **Doping** | 用违禁手段提升生理能力 | 血液兴奋剂、类固醇 | Leistungsprinzip + 健康 |
| **Spielmanipulation** | 事先约定结果 | 假球、让分 | 比赛诚信 |
| **Beeinflussung von Schiedsrichtern** | 贿赂/施压裁判 | 收买裁判 | 规则中立性 |
| **wirtschaftlicher Druck** | 赞助/协会施压 | 逼运动员参赛/改项目 | 自主决定 |

> ⚠️ 兴奋剂在 KLP 中同时挂在 **IF f**（`unphysiologische Maßnahmen`，LK 独有）——本笔记从**竞技伦理**角度处理，IF f 从**健康风险**角度处理，二者互补。[据推断]

### 2.3 利益相关方矩阵（分析工具）

中文理解：分析任何操控案例，先问「谁受益、谁受损」。这是 `analysieren` 与 `herausarbeiten` 的操作化。

> *Klausur-Satz*: `Manipulation lässt sich nur verstehen, wenn man die Interessen der beteiligten Gruppen analysiert.`

| 利益方 | 利益 | 对操控的态度 |
|---|---|---|
| 运动员 | 成绩、收入、职业 | 既是受害者，也可能是实施者 |
| 协会/联盟 | 运动发展、声誉 | 名义上反对，实际可能纵容 |
| 赞助商 | 曝光、形象 | 间接施压（要求明星出场） |
| 媒体/转播方 | 收视、广告 | 影响赛程与规则（如改时间） |
| 博彩业 | 赔率利润 | 假球的主要推手 |
| 观众 | 精彩、公平的比赛 | 被操纵时是最终受害者 |
| 国家/政治 | 形象、软实力 | 可能施压追求奖牌 |

### 2.4 商业化：双刃剑

中文理解：**不能一边倒骂商业化**。论述题的高分点是承认两面性并给判据。

> *Klausur-Satz*: `Die Kommerzialisierung des Sports ist ambivalent: Sie sichert Finanzierung und Reichweite, birgt aber die Gefahr, dass wirtschaftliche Interessen die sportliche Fairness verdrängen.`

| 正面 | 负面 |
|---|---|
| 提供资金、职业化 | 赛程过密、伤病 |
| 提升设施与训练水平 | 比赛时间被商业左右 |
| 扩大参与与传播 | 弱者项目被边缘化 |
| 提高运动员收入 | 博彩与假球风险上升 |

## 3. 解题方法 (Methoden)

### 3.1 Manipulationsanalyse（操控案例分析：四步）

**编号步骤**：
1. **描述事实**：发生了什么（谁、何时、如何）—— *KLP 工具：beschreiben / herausarbeiten*
2. **判类型**：属哪种操控形式？是 Steuerung 还是 Manipulation？—— *KLP 工具：einordnen*
3. **析利益方**：谁受益、谁受损、谁纵容？—— *KLP 工具：analysieren / in Beziehung setzen*
4. **依准则评判**：破坏了哪条准则（Leistungsprinzip / Integrität / Fairness）？—— *KLP 工具：kriteriengeleitet bewerten*

> **判据 / 决策点**：若案例是「赞助商要求改开赛时间」，先判它**是否损害诚信**——不损害则属可争议的 Steuerung，损害则越界为 Manipulation。

### 3.2 Erörterung（论述：操控是否应被容忍）

**编号步骤**：
1. **界定问题**：该行为是 Steuerung 还是 Manipulation？争议点在哪 —— *KLP 工具：problematisieren*
2. **列正反论据**：各至少两条，均挂具体判据 —— *KLP 工具：erörtern*
3. **权衡**：说明哪方更强、依据是什么 —— *KLP 工具：prüfen*
4. **明确表态**：给出判断与前提 —— *KLP 工具：bewerten / Stellung nehmen*

> **判据 / 决策点**：`bewerten` 要求「按明示的规范与价值」主张立场——须**明说用的是哪条价值**（如公平、诚信、运动员健康）。

### 3.3 口试即答框架（评判类四句）

1. `Zunächst ist zu klären, ob es sich um legitime Steuerung oder um Manipulation handelt.`
2. `Betroffen sind verschiedene Interessengruppen, insbesondere …`
3. `Verletzt wird dabei vor allem das Leistungsprinzip / die Integrität des Wettkampfs, weil …`
4. `Ich bewerte dies als …, da … (unter der Bedingung, dass …)`

> Erläutern Sie den Unterschied zwischen Steuerung und Manipulation im Sport und ordnen Sie je ein Beispiel zu.

**Aufgabe 2** `[NRW-改编]`

**Aufgabe 4** `[原创]`
> Bewerten Sie die folgende Aussage: *„Doping ist Betrug am Gegner und am Publikum, nicht nur ein Gesundheitsrisiko."* Gehen Sie auf mindestens zwei betroffene Werte ein.

### 5.3 Musterlösung

**Aufgabe 1**（AFB I → II）
1. 定义 Steuerung：**公开、合规**地影响运动条件 ✓ 得分点
2. 定义 Manipulation：**隐秘、违规**地影响结果 ✓ 得分点（关键：须点出「不正当」）
3. 各举一例（如：协会定安全规则 = Steuerung；收买裁判 = Manipulation）✓ 得分点（关键：例子须匹配）
4. 指出边界存在**灰色地带**（如赞助改赛程需看是否损害诚信）✓ 加分点
5. 语言：用 `legitim / illegitim / Integrität` 术语 ✓ 加分点

**Aufgabe 2**（AFB II）
1. **描述事实**：赞助商施压让伤员出场 ✓ 得分点
2. **判类型**：属 `wirtschaftlicher Druck`（操控形式之一）✓ 得分点
3. **利益方分析**：赞助商（要曝光）· 运动员（健康受损）· 俱乐部（要资金）· 观众（要看真实竞技）✓ 得分点（关键：至少三方）
4. **受害价值**：运动员健康、自主决定、比赛的正当性 ✓ 得分点（关键：须点出价值）
5. **依准则评判**：此举把商业利益置于运动员健康之上，损害诚信 ✓ 得分点
6. 语言：用 `betroffen sind … / verletzt wird …` 句式 ✓ 加分点

**Aufgabe 3**（AFB III）
1. **界定问题**：商业化既提供资源又带来操控风险 ✓ 得分点（`problematisieren`）
2. **正方论据**（商业化利公平）：资金提升训练与设施，扩大参与；职业化提高竞技水平 ✓ 得分点
3. **反方论据**（商业化害公平）：赛程被商业左右；假球与博彩风险；弱者项目被边缘化 ✓ 得分点
4. **权衡**：指出关键不在商业化本身，而在**是否有保障诚信的制度** ✓ 得分点（关键：须作权衡）
5. **明确表态**：如「商业化不必然损害公平，但缺乏监管时会」✓ 得分点（关键：`Stellung nehmen`）
6. 区分 `beurteilen`（依专业标准）与 `bewerten`（依价值规范）各一次 ✓ 加分点

**Aufgabe 4**（AFB III）
1. **表态**：同意（并说明理由），先界定 doping 的本质 ✓ 得分点
2. **受害价值 1 · Leistungsprinzip**：成绩不再由能力决定 → 对对手不公平 ✓ 得分点
3. **受害价值 2 · Integrität/诚信**：观众被欺骗，比赛真实性受损 ✓ 得分点（关键：题目要求「两个价值」）
4. 补充：健康风险是**对运动员自身**的伤害，属另一维度（IF f）✓ 得分点
5. 结论：doping 同时破坏三重价值（公平、诚信、健康），故不只是健康问题 ✓ 加分点
6. 语言：术语准确、论证有 `weil / da` 支撑 ✓ 加分点

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把 Steuerung（正当调控）与 Manipulation（不正当操纵）混为一谈 | 记判据：是否**隐秘 + 损害诚信**？是→Manipulation |
| 知识错 | 只说 doping，不知其他操控形式（假球/收买裁判/经济施压） | 背 §2.2 四大形式各配一例 |
| 表达错 | `bewerten` 时不说依据哪条价值 | 每句评判写明判据：Leistungsprinzip / Integrität / Fairness / Gesundheit |
