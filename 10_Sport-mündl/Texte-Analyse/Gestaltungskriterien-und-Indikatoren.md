# Gestaltungskriterien und Indikatoren (编排四准则与可观察指标)

> **中文理解**：编排一个动作组合（Tanz、体操成套、运动艺术表演）不能只说「好看」，必须落到**四个可分析的准则**：空间（Raum）、时间（Zeit）、动态（Dynamik）、形式结构（formaler Aufbau）。每个准则还要配**可观察指标（Indikatoren）**，否则无法评判——这是 KLP 里 IF b 的 Sachkompetenz 明文要求（`Ausführungs- und Gestaltungskriterien (Raum, Zeit, Dynamik, formaler Aufbau)`）。它在 KLP 里属 **IF b — Bewegungsgestaltung** 的**第一重点** `Gestaltungskriterien`。考试形态：笔试（LK）的 **Analyse-/Darstellungsaufgabe**；口试 Teil 1 的「用四准则拆一段编排」；实践部分要求你能按准则**自己编排**一段动作。
>
> **Klausur-Relevanz**：IF b 原为完全空白，四准则+指标是唯一入口。口试最常见考法：给一段编排（或让你即兴编一段），要求**逐准则 + 逐指标**分析或评判。只说「动作很优美」= 零分。

## 2. 知识结构 (Struktur)

### 2.1 四大准则总表（骨架）

中文理解：这是 IF b 的骨架。任何编排分析题，第一句就应点名这四个德语词。

> *Klausur-Satz*: `Bewegungsgestaltung lässt sich anhand der vier Kriterien Raum, Zeit, Dynamik und formaler Aufbau analysieren.`

| 准则 | 中文 | 管什么 | 一句话 |
|---|---|---|---|
| **Raum** | 空间 | 在哪里、往哪动 | 队形、路径、方向、层面 |
| **Zeit** | 时间 | 什么时候、多快动 | 速度、节奏、时长、停顿 |
| **Dynamik** | 动态 | 用多大力、多流畅 | 张力、强弱、流畅-顿挫 |
| **formaler Aufbau** | 形式结构 | 整体怎么组织 | 开端-高潮-收束、重复、对比 |

### 2.2 每个准则的 Indikatoren（可观察指标）—— 本笔记的核心

中文理解：**准则不可直接评判，必须借指标**。例如「空间好不好」无法评，但「队形是否变化、方向是否多样」可以观察。这是 KLP 明示的 `Indikatoren` 要求。

> *Klausur-Satz*: `Jedes Gestaltungskriterium muss durch beobachtbare Indikatoren konkretisiert werden, um eine kriteriengeleitete Beurteilung zu ermöglichen.`

**Indikatoren-Übersicht（四准则 × 可观察指标）**

| Kriterium | 指标 | 中文 | 观察什么 |
|---|---|---|---|
| **Raum** | Formation | 队形 | 行/列/圈/扇形/块状及其变化 |
| | Raumweg | 路径 | 直线/曲线/弧线、路径是否多样 |
| | Raumrichtung | 方向 | 前/后/侧/斜向、方向变换 |
| | Raumebene | 层面 | 低/中/高（贴地—站立—腾空） |
| **Zeit** | Tempo | 速度 | 快/慢及其变化 |
| | Rhythmus | 节奏 | 规律性节拍与重音分布 |
| | Akzent | 重音 | 强拍/突停/顿点 |
| | Zeitveränderung | 时间变化 | 加速/减速/静止（Zeitlupe） |
| **Dynamik** | Spannung | 张力 | 紧绷/放松（Anspannung–Entspannung） |
| | Kraftaufwand | 用力 | 强弱力度及其对比 |
| | Bewegungsfluss | 流动 | 连贯流畅 vs. 顿挫停顿 |
| | Amplitude | 幅度 | 动作幅度的大小变化 |
| **formaler Aufbau** | Gliederung | 段落划分 | 开端/主体/收束是否清晰 |
| | Wiederholung | 重复 | 母题是否再现 |
| | Kontrast | 对比 | 快-慢、强-弱、聚-散的对立 |
| | Steigerung | 递进 | 强度/复杂度是否层层推进 |
| | Spannungsbogen | 张力弧 | 是否有高潮点与收束 |

### 2.3 Gestaltungs- vs. Ausführungskriterien（LK 关键区分）

中文理解：KLP 在 IF b 的 LK 段把二者并列写（`Ausführungs- und Gestaltungskriterien`）——**执行准则**评「动作做得好不好」，**编排准则**评「动作排得好不好」。两者都要评，但不可混。

> *Klausur-Satz*: `Ausführungskriterien bewerten die Qualität der Bewegungsausführung, Gestaltungskriterien dagegen die Komposition der Bewegung.`

| 类别 | 评什么 | 例 |
|---|---|---|
| **Ausführungskriterien** | 动作质量 | 精确性、身体张力、姿态、平衡、表现力 |
| **Gestaltungskriterien** | 编排结构 | Raum / Zeit / Dynamik / formaler Aufbau |

### 2.4 评判必须 kriteriengeleitet

中文理解：KLP 的 Urteilskompetenz 明写「**依准则**独立判断」。评判编排时，每一句判断都要挂到一个准则+指标上。

> *Klausur-Satz*: `Eine Beurteilung der Gestaltung muss kriteriengeleitet erfolgen, das heißt anhand der vier Kriterien und ihrer Indikatoren.`

> ⚠️ 只说「我觉得这段很好看」违反 kriteriengeleitet 要求，属 AFB III 失分点。

## 3. 解题方法 (Methoden)

### 3.1 Gestaltungsanalyse（编排分析：四准则 × 指标）

**编号步骤**：
1. **先客观描述**编排过程（不评价）—— *KLP 工具：Bewegungsbeschreibung*
2. **逐准则拆**：Raum / Zeit / Dynamik / formaler Aufbau 各写一段 —— *KLP 工具：Gestaltungskriterien*
3. **每准则挂指标**：用 §2.2 的指标说「观察到什么」—— *KLP 工具：Indikatoren*
4. **连到效果**：该准则处理得好/差带来什么观感 —— *KLP 工具：in Beziehung setzen*
5. **依准则评判**：给出有依据的判断 —— *KLP 工具：kriteriengeleitet beurteilen*

> **判据 / 决策点**：若分析里出现「很优美」「很震撼」而无准则支撑 → 必须改写成「空间层面：多次队形变换（Formation）增强了动态感」。

### 3.2 Gestaltung entwerfen（编排设计：从准则到成品）

1. **定主题/母题**：要表达什么（如「对抗与和解」）—— *KLP 工具：Bewegungsmotiv*
2. **定形式结构**：开端—高潮—收束 —— *KLP 工具：formaler Aufbau*
3. **填空间**：队形与路径设计 —— *KLP 工具：Raum*
4. **填时间**：节奏与速度变化 —— *KLP 工具：Zeit*
5. **填动态**：张力与力度对比 —— *KLP 工具：Dynamik*
6. **自检**：每个准则是否至少用到一个指标 —— *KLP 工具：kriteriengeleitet*

> **判据 / 决策点**：好的编排通常在**四个准则上都做变化**；只变空间不变时间/动态 → 单调。

### 3.3 口试即答框架（分析类四句）

1. `Im Hinblick auf den Raum fällt auf, dass …`（空间+指标）
2. `Zeitlich zeigt sich …, was sich an … erkennen lässt.`（时间+指标）
3. `In der Dynamik …`（动态+指标）
4. `Der formale Aufbau ist geprägt von …`（形式结构+指标）

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | **Darstellungsaufgabe**（陈述四准则）· **Analyseaufgabe**（分析给定编排）· **Gestaltungsaufgabe**（设计编排，属演示/展示类题型） |
| Operator | `erlaeutern` / `darstellen`（I–II）· `analysieren`（II）· `entwerfen`（III）· `beurteilen` / `bewerten`（III） |
| AFB | I 列举四准则 → II 分析编排 → III 设计并依准则评判 |
| 建议分值 / 时长 | 属 LK 300 min 笔试 IF b 大题；口试 4–6 min 陈述 + 追问 |

> **三条轨道如何考它**：
> - **笔试（仅 LK）**：材料绑定（编排描述/示意图），要求按四准则+指标分析并评判。
> - **口试（mündliche Prüfung）**：Teil 1 连贯陈述「用四准则拆一段编排」；Teil 2 追问「若让你改，你会改哪个准则」。
> - **实践部分（Praktische Prüfung）**：BF/SB6 的展示/演示直接考编排——考官可问「你的编排在空间与形式结构上怎么设计的？」。

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> Erläutern Sie die vier Gestaltungskriterien und ordnen Sie jedem Kriterium mindestens zwei beobachtbare Indikatoren zu.

**Aufgabe 2** `[原创]`
> Analysieren Sie folgende Bewegungsfolge hinsichtlich Raum, Zeit, Dynamik und formalem Aufbau:
> *„Eine Gruppe von sechs Schülerinnen beginnt in einer Reihe, löst sich dann in zwei Kreise auf, führt zunächst langsame, dann schnelle Drehungen aus und endet in einer stehenden, symmetrischen Formation."*

**Aufgabe 3** `[原创]`
> Entwerfen Sie eine etwa 30-sekündige Bewegungsfolge (BF/SB6) und erläutern Sie, wie Sie die vier Gestaltungskriterien bewusst eingesetzt haben.

**Aufgabe 4** `[原创]`
> Beurteilen Sie kriteriengeleitet die Gestaltung einer von Ihnen gewählten Bewegungsfolge. Gehen Sie dabei auf mindestens drei Kriterien ein und nennen Sie je einen Indikator.

### 5.3 Musterlösung

**Aufgabe 1**（AFB I → II）
1. 四准则点名 + 一句话定义：Raum / Zeit / Dynamik / formaler Aufbau ✓ 得分点（4×0.5）
2. 每准则配 ≥2 个指标（如 Raum→Formation, Raumweg；Zeit→Tempo, Rhythmus）✓ 得分点（关键）
3. 点明「准则须借指标才可评判」✓ 得分点
4. 区分 Gestaltungs- vs. Ausführungskriterien ✓ 加分点

**Aufgabe 2**（AFB II）
1. **Raum**：Reihe → zwei Kreise（Formation 变化）+ 位置移动（Raumweg）✓ 得分点
2. **Zeit**：zuerst langsam, dann schnell（Tempo/Zeitveränderung）✓ 得分点
3. **Dynamik**：由慢到快伴随张力/力度变化（Spannung/Kraftaufwand）✓ 得分点
4. **formaler Aufbau**：开端（Reihe）→ 发展（Kreise, 加速）→ 收束（对称站位）形成 Spannungsbogen ✓ 得分点（关键：须点出结构）
5. 结论：编排在四准则上均有变化 → 结构完整、不单调 ✓ 加分点

**Aufgabe 3**（AFB III）
1. 定母题（如「收缩—扩张」）✓ 得分点
2. **Raum**：设计队形与路径变化（如 Kreis → Gasse）✓ 得分点
3. **Zeit**：设计快慢对比与重音 ✓ 得分点
4. **Dynamik**：设计张力强弱对比 ✓ 得分点
5. **formaler Aufbau**：开端—高潮—收束，含重复或对比 ✓ 得分点（关键）
6. 逐条 begründen：说明每个设计对应哪个指标、为何有效 ✓ 得分点（AFB III 要求 kriteriengeleitet）
7. 反思：说明该编排对表演者协调/节奏能力的要求 ✓ 加分点

**Aufgabe 4**（AFB III）
1. 表态：给出**有依据的总判断**（如「结构清晰但动态对比不足」）✓ 得分点（关键：立场明确）
2. 至少三个准则各一段，且每段**点名指标** ✓ 得分点（3×0.5）
3. 用 `weil / da` 把判断挂到指标上 ✓ 得分点（kriteriengeleitet）
4. 给改进建议（改哪个准则、用哪个指标）✓ 加分点
5. 语言：全程用四准则德语术语 ✓ 加分点

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把 **Gestaltungskriterien**（编排准则）与 **Ausführungskriterien**（执行准则）混用 | 记：编排=「排得好不好」，执行=「做得好不好」 |
| 知识错 | 只背四准则名称，配不出 Indikatoren | 每准则至少背 2 个指标（见 §2.2） |
| 表达错 | 评判时写「很优美/很震撼」而不挂准则+指标 | 每句判断必须写成「准则：指标：观察→判断」 |
