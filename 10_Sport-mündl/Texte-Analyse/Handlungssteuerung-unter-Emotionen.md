# Handlungssteuerung unter Emotionen (情绪影响下的行动调控)

> **中文理解**：为什么同样的动作，比赛时做得出、练习时也做得出，但一紧张就崩？因为**行动不是纯技术的，它被心理状态调控**。KLP 的 IF c 第一重点 `Handlungssteuerung unter verschiedenen psychischen Einflüssen` 就是研究：情绪（Emotionen）、激活水平（Aktivierung）、恐惧（Angst）、压力（Stress）如何影响**感知—决策—执行**整条链。核心模型是**倒 U 型（Yerkes-Dodson）**：激活水平太低（提不起劲）或太高（僵掉）都差，中间有最优区。考试形态：口试 Teil 1 连贯陈述一个情绪影响运动表现的情境链；笔试（LK）的 **Analyse-/Erörterungsaufgabe**；实践部分则要求你在真实压力情境（如高空项目、比赛）中**调控自己并事后反思**。
>
> **Klausur-Relevanz**：IF c 原为**完全空白**，本笔记是该 IF 第一重点的唯一入口。口试高频：「描述一次你因紧张失误的经历，并用理论解释」。⚠️ **LK 要求 `theoriegeleitet erläutern`**（须挂理论模型），EF/GK 只要求 `beschreiben`/`erläutern`。

## 2. 知识结构 (Struktur)

### 2.1 情绪如何影响行动：一条因果链

中文理解：情绪不是「感觉」，它会**改生理、改注意、改决策**，最后改结果。口试答题就用这条链串。

> *Klausur-Satz*: `Emotionen wirken auf die Handlungssteuerung, indem sie über physiologische Aktivierung, Aufmerksamkeitslenkung und Entscheidungsverhalten die Bewegungsausführung beeinflussen.`

`情境（z. B. 点球）→ 认知评价 → 情绪（Angst）→ 生理激活↑ + 注意变窄 → 决策/动作变形 → 结果`

### 2.2 Yerkes-Dodson 倒 U 曲线（**本 IF 的核心模型**）

中文理解：横轴激活水平，纵轴表现。太松（观众席上发呆）与太紧（手抖）都差，**中间有峰值**。而且**任务越复杂，最优激活水平越低**（精细动作比粗大动作更怕「过紧」）。

> *Klausur-Satz*: `Nach dem Yerkes-Dodson-Gesetz verläuft der Zusammenhang zwischen Aktivierung und Leistung umgekehrt U-förmig; das optimale Aktivierungsniveau liegt bei komplexen Aufgaben niedriger als bei einfachen.`

| 激活水平 | 状态 | 表现 |
|---|---|---|
| 过低 | 无聊、注意力涣散、提不起劲 | 差（Aufwärmen 不足） |
| **最优** | 适度紧张、专注、有活力 | **最好** |
| 过高 | 僵硬、手抖、注意过窄、思维狭窄 | 差（「僵掉」） |

> ⚠️ **最优激活因人、因任务而异** [据推断]：同一个人，跳远（粗大、快）的最优激活高于射击（精细）的。答题时**必须说明任务类型**。

### 2.3 焦虑的双成分（LK 理论化加分点）

中文理解：焦虑不是一个东西，它分「想」和「身体」两半——认知性（担心）与躯体性（心跳）。两半对表现的影响**机制不同**：认知性焦虑在高激活时**急剧损害**精细任务；躯体性焦虑在低激活时反而**促进**（唤醒效应）。

> *Klausur-Satz*: `Man unterscheidet kognitive (Besorgnis) und somatische (körperliche Erregung) Angstkomponenten, die sich unterschiedlich auf die Leistung auswirken.`

| 成分 | 表现 | 对表现 |
|---|---|---|
| Kognitiv（担忧） | 「千万别失误」「大家都在看」 | 高激活时**明显损害**精细任务 |
| Somatisch（生理） | 心跳快、出汗、肌肉紧 | 适度时**促进**；过度时损害 |

### 2.4 Aktivationsregulation：上调与下调

中文理解：既然最优在中间，那就要**会调**——太松要「点着」，太紧要「压下去」。

> *Klausur-Satz*: `Zur Aktivationsregulation werden je nach Ausgangsniveau aktivierende oder beruhigende Techniken eingesetzt.`

| 方向 | 何时用 | 技术 |
|---|---|---|
| **下调（beruhigend）** | 过度激活、焦虑、僵硬 | 呼吸调节（慢腹式呼吸）、渐进性肌肉放松（PMR）、正念、仪式化动作、自言自语（Selbstinstruktion） |
| **上调（aktivierend）** | 激活不足、无精打采 | 音乐、喊叫、爆发性热身、目标唤醒（Aufgabenorientierung） |

### 2.5 认知评价：威胁 vs 挑战（Lazarus 类模型）

中文理解：同一个情境（决赛），有人评成「威胁」（我会输、会丢脸），有人评成「挑战」（我能证明自己）。评价不同 → 情绪不同 → 激活与表现不同。

> *Klausur-Satz*: `Dieselbe Situation kann als Bedrohung oder als Herausforderung bewertet werden; die Bewertung entscheidet über Emotion und Handlungssteuerung.`

| 评价 | 情绪 | 后果 |
|---|---|---|
| **Bedrohung（威胁）** | 焦虑、回避 | 激活过高、注意收窄、动作保守 |
| **Herausforderung（挑战）** | 兴奋、投入 | 激活适中、注意开阔、敢于冒险 |

> **教学含义**：调控不只是「深呼吸」，还包括**重评（Reappraisal）**——把「威胁」改成「挑战」。

> ⚠️ 情绪调控长期失败会**掉动机**——这是通向 IF c 第二重点《Motivation-im-Sport》的接口。[据推断]

## 3. 解题方法 (Methoden)

### 3.1 Emotionsanalyse（情绪分析：情境 → 链 → 调控）

**编号步骤**：
1. **描述情境**：什么时候、什么项目、什么压力源 —— *KLP 工具：Situationsbeschreibung*
2. **识别情绪**：是 Angst？Ärger？Freude？—— *KLP 工具：Emotionsbegriff*
3. **定激活水平**：偏低/最优/偏高（用倒 U 定位）—— *KLP 工具：Yerkes-Dodson*
4. **拆成分**：认知性 vs 躯体性 —— *KLP 工具：Angstkomponenten*
5. **追后果**：生理 + 注意 + 决策 + 动作 —— *KLP 工具：Handlungskette*
6. **给调控**：上调还是下调？用什么技术？—— *KLP 工具：Aktivationsregulation*
7. **判效果**：该调控是否合理（kriteriengeleitet）—— *KLP 工具：beurteilen*

> **判据 / 决策点**：若情境里「激活明显偏高」（手抖、僵）→ 选**下调**技术；若「偏低」（懒散）→ 选**上调**。方向错＝调控无效。

### 3.2 Handlungssteuerung theoriegeleitet erläutern（LK 必做：挂理论）

**编号步骤**：
1. **点名理论模型**（Yerkes-Dodson / 双成分 / Appraisal）—— *KLP 工具：Theoriebezug*
2. **把观察挂到模型变量上**（「他的手抖＝躯体性高激活」）—— *KLP 工具：Zuordnung*
3. **用 weil/da 做因果**（`weil die Aktivierung über das Optimum hinausgeht, verengt sich die Aufmerksamkeit`）—— *KLP 工具：begründen*
4. **推调控方案并论证** —— *KLP 工具：Ableitung*
5. **反思边界**：该理论在哪失效（个体差异）—— *KLP 工具：problematisieren*

> **判据 / 决策点**：⚠️ LK 若只描述现象不挂模型 → 直接失分（KLP 明写 `theoriegeleitet erläutern`）。GK 描述清楚即可，但挂模型是加分。

### 3.3 Risikowahrnehmung beurteilen（风险感知评判，AFB III）

1. **分客观风险与主观感知** —— *KLP 工具：objektives vs subjektives Risiko*
2. **判断偏差方向**：高估（过度谨慎）还是低估（盲目冒险）—— *KLP 工具：Fehleinschätzung*
3. **分析原因**：经验、情绪、同伴压力、熟悉度 —— *KLP 工具：Einflussfaktoren*
4. **推教育措施**：如何把感知校准到客观 —— *KLP 工具：Ableitung*
5. **依准则评判**：该措施是否兼顾安全与「冒险教育」目标 —— *KLP 工具：kriteriengeleitet beurteilen*

> ⚠️ 「冒险」≠「不计后果」——IF c 的目标是**负责任的冒险**（Wagnis mit Verantwortung）。[据推断]

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | **Analyseaufgabe**（分析情绪影响链）· **Erörterungsaufgabe**（权衡调控策略）· **Darstellungsaufgabe**（陈述模型） |
| Operator | `beschreiben` / `darstellen`（I–II）· `erklaeren` / `erlaeutern` / `analysieren` / `in Beziehung setzen`（II）· `beurteilen` / `bewerten`（III） |
| AFB | I 描述情绪与激活 → II 分析因果链并挂模型 → III 设计/评判调控方案 |
| 建议分值 / 时长 | 属 LK 300 min 笔试 IF c 大题；口试 4–6 min 陈述 + 追问 |

> **三条轨道如何考它**：
> - **笔试（仅 LK）**：给一段比赛情境材料，要求 `theoriegeleitet` 分析情绪对行动的影响并评判调控措施。
> - **口试（mündliche Prüfung）**：Teil 1 连贯陈述「一次我因情绪影响表现的经历 + 理论解释」；Teil 2 追问「你的调控方向对不对、依据是什么」。
> - **实践部分（Praktische Prüfung）**：BF/SB8/BF/SB9 的风险/对抗情境直接考压力下的执行——考官可要求你**当场调节激活**（如深呼吸/仪式）并说明依据。

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`

**Aufgabe 2** `[原创]`
> Analysieren Sie folgendes Wettkampfsituation hinsichtlich Aktivierungsniveau, Angstkomponenten und Handlungsfolgen:

**Aufgabe 3** `[原创]`
> Entwickeln Sie für die Turnerin aus Aufgabe 2 ein Regulationskonzept und begründen Sie, warum Sie aktivierende bzw. beruhigende Techniken wählen.

**Aufgabe 4** `[原创]`
> Beurteilen Sie kriteriengeleitet, inwiefern eine «risikoreiche» Sportart (BF/SB8) im Sportunterricht mit dem Prinzip «Wagnis mit Verantwortung» vereinbar ist.

### 5.3 Musterlösung

**Aufgabe 1**（AFB I → II）
1. 情绪通过**生理激活 + 注意 + 决策**影响行动 ✓ 得分点
2. 倒 U 模型点名 + 曲线形态（过低/最优/过高）✓ 得分点（关键）
3. 补「任务越复杂，最优激活越低」✓ 得分点
4. 举一具体情境（如点球/器械体操）✓ 加分点

**Aufgabe 2**（AFB II）
1. **情境与激活**：首次比赛 → 激活**偏高**（Heartklopfen、feuchte Hände）✓ 得分点
2. **认知成分**：`Alle schauen zu, ich falle …` = kognitive Angst（担忧、灾难化）✓ 得分点
3. **躯体成分**：Heartklopfen、feuchte Hände = somatische Angst ✓ 得分点（关键：双成分都点）
4. **后果链**：高激活 → 注意收窄 + 肌肉僵硬 → 平衡/精细动作受损 ✓ 得分点
5. **评价**：将情境评为「威胁」（Bedrohung）而非「挑战」✓ 加分点
6. 结论句：激活超出最优区，精细任务（平衡木）受损尤甚 ✓ 得分点

**Aufgabe 3**（AFB III）
1. 先**判方向**：激活偏高 → 需**下调（beruhigend）**✓ 得分点（关键）
2. 选技术并说明机制：慢腹式呼吸（降交感激活）、PMR、Selbstinstruktion（改注意）✓ 得分点
3. **重评（Reappraisal）**：把「威胁」改为「挑战」✓ 得分点（AFB III 高分层）
4. 逐条 begründen（`weil …` 挂到模型）✓ 得分点（LK 要求 theoriegeleitet）
5. 反思：说明个体差异——同一技术对不同人效果不同 ✓ 加分点

**Aufgabe 4**（AFB III）
1. 表态明确（如「可兼容，前提是风险管理到位」）✓ 得分点（关键：立场明确）
2. 区分**客观风险 vs 主观感知**，指出偏差风险 ✓ 得分点
3. 依准则评判：安全（Sicherheit）vs 教育价值（Wagniserfahrung）的权衡 ✓ 得分点
4. 给条件：渐进、护具、明确规则、反思环节 ✓ 得分点
5. 用 `weil/da` 挂到 IF c 目标（Wagnis **mit** Verantwortung）✓ 加分点

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把 State Anxiety（状态）与 Trait Anxiety（特质）混同；把「认知性」与「躯体性」焦虑混用 | 记：状态=此刻波动、特质=稳定倾向；认知=想、躯体=身体 |
| 知识错 | 以为激活「越高越好」，或调控方向选反（该下调却做激活热身） | 牢记倒 U：先判方向再选技术；复杂任务最优激活更低 |
| 表达错 | LK 只描述现象不挂理论模型 | 每段必点名模型（Yerkes-Dodson / 双成分 / Appraisal）+ weil 因果 |
