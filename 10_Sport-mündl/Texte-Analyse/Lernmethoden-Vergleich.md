# Lernmethoden: analytisch-synthetisch vs. Ganzheit (分解-合成法 vs 整体法)

> **中文理解**：教一个动作有两条根本不同的路——**整体法**（Ganzheitsmethode）从头到尾整体教；**分解-合成法**（analytisch-synthetische Methode）先把动作拆成部分分别练，再合起来。选哪条不由喜好决定，而由**动作复杂度、危险性、学习者水平、可用时间**共同决定。它在 KLP 里属 **IF a — Bewegungsstruktur und Bewegungslernen** 的第一重点 `Prinzipien und Konzepte des motorischen Lernens`（EF 与 GK/LK 共通）。考试形态：笔试（LK）的 **Erörterungsaufgabe**（比较+论证+评判）；口试 Teil 1 的「选哪条路、为什么」；实践部分你须能说明自己教练给你拆动作的理由。
>
> **Klausur-Relevanz**：这是 IF a 最高频的「比较+论证」考点。口试最典型问法：给一个具体动作，让你选方法并论证。答「整体法更好」而不看条件是本课第一失分陷阱。

## 1. 核心概念 (Kernbegriffe)

| 术语 (DE) | 中文 | English | 定义 | 备注 |
|---|---|---|---|---|
| Lernmethode | 学习方法 | learning method | 教会一个动作所采用的教学路径 | 本笔记核心 |
| Ganzheitsmethode | 整体法 | whole method | 从第一次练习起就完整地做整个动作 | 保留动作整体性 |
| analytisch-synthetische Methode | 分解-合成法 | analytic-synthetic method | 先拆成部分（Analyse）分别练，再合成整体（Synthese） | 降低难度 |
| ganzheitlich-analytische Methode | 整体-分析法（交替法） | whole-part-whole method | 先整体尝试 → 拆练难点 → 再整体 | 折中方案 |
| Zergliederung | 分解 | decomposition | 把动作切成部分 | 分解的负面风险见 §2.3 |
| Synthese | 合成 | synthesis | 把部分重新连成整体 | 分解法的关键难点 |
| methodische Übungsreihe | 方法练习序列 | methodological exercise series | 由易到难的成套练习步骤 | 分解法的实践形态 |
| Bewegungselement | 动作要素 | movement element | 动作中相对独立的最小单元 | 可按要素拆 |
| Bewegungsphase | 动作相位 | movement phase | 动作在时间上的段落（准备/主/结束） | 可按相位拆 |
| Bewegungsrhythmus | 动作节奏 | movement rhythm | 动作的时间-力度结构 | 分解易破坏它 |
| Erleichterung | 简化 | simplification | 降低难度（降速、减重、加辅助） | 整体法常用辅具 |
| Erschwernis | 加难 | complication | 提高难度（提速、加障碍、变条件） | 巩固阶段用 |
| Lernstand / Vorkenntnisse | 学习水平 / 前知识 | prior knowledge | 学习者当前所处能力状态 | 选方法的核心判据 |

## 2. 知识结构 (Struktur)

### 2.1 三条教学路径总表（骨架）

中文理解：不是「两条」而是「三条」——整体、分解-合成、以及先整体后局部的折中路线。答题时能点出第三条是加分项。

> *Klausur-Satz*: `Grundsätzlich lassen sich die Ganzheitsmethode, die analytisch-synthetische Methode und die ganzheitlich-analytische Methode unterscheiden.`

| 方法 | 做法 | 适用条件 | 优点 | 缺点 |
|---|---|---|---|---|
| **Ganzheitsmethode** | 从一开始就完整地做 | 简单、节奏性强、不可分的动作（跑、跳、投的初级形式） | 保留动作整体节奏与协调结构 | 复杂动作难以掌握、易形成错误定式 |
| **analytisch-synthetische Methode** | 拆部分 → 分别练 → 合成 | 复杂、可自然分解、有难度层次的动作（体操、游泳技术） | 降低单次难度、便于针对性纠错 | 合成难、易丢失整体节奏 |
| **ganzheitlich-analytische Methode** | 先整体尝试 → 拆练关键难点 → 再整体 | 多数中等复杂动作（折中） | 兼顾整体性与针对性 | 需要更长的教学时间 |

> ⚠️ 第三条路（Wechselmethode）常被考生忽略，而它恰是实操中最常用的。[据推断，训练学共识]

### 2.2 选择判据（五问）

中文理解：选方法＝回答五个问题。任何一个答「是」，都倾向不同选择。

> *Klausur-Satz*: `Die Wahl der Methode richtet sich nach der Komplexität der Bewegung, dem Gefährdungspotenzial, dem Lernstand, der verfügbaren Zeit und der Motivationslage.`

| # | 判据 | 倾向 |
|---|---|---|
| 1 | **Komplexität**（动作多复杂？） | 越复杂 → 越倾向分解 |
| 2 | **Gefährdungspotenzial**（危险吗？） | 有危险（如器械体操）→ 先分解+保护 |
| 3 | **Lernstand / Vorkenntnisse**（学得怎样？） | 初学者+复杂动作 → 分解；有基础 → 整体 |
| 4 | **Zeit**（有多少时间？） | 时间紧且动作简单 → 整体 |
| 5 | **Motivationslage**（想不想学？） | 整体法更易给「成功体验」，利于动机 |

### 2.3 分解的两种切法与最大风险

中文理解：分解不是随便切——可以**按相位切**（准备/主/结束）或**按动作要素切**（上肢/下肢/躯干）。切法决定合成难度。

> *Klausur-Satz*: `Die Zergliederung kann nach Bewegungsphasen oder nach Bewegungselementen erfolgen; je stärker zergliedert wird, desto schwieriger ist die anschließende Synthese.`

> ⚠️ **最大风险**：分解过细会破坏 `Bewegungsrhythmus`（动作节奏）与各部分的**时间耦合**，导致「各部分都会、连起来就不会」。[据推断]

### 2.4 易混辨析：三组「切法」

| 概念 | 切什么 | 工具 |
|---|---|---|
| **Lernmethode**（本笔记） | 教学**路径** | 整体 / 分解-合成 |
| **Lernphasen**（见《Motorisches Lernen》） | 学习**过程**阶段 | Grob / Fein / stabilisiert |
| **Bewegungsphasen**（见《Sport-Bewegungsanalyse》） | 动作**本身**的结构 | Vorbereitung / Hauptphase / Endphase |

> *Klausur-Satz*: `Lernmethoden beschreiben den Weg des Lehrens, Lernphasen den Zustand des Lernenden, Bewegungsphasen die Struktur der Bewegung selbst.`

## 3. 解题方法 (Methoden)

### 3.1 Methodenwahl begründen（选方法并论证）

**编号步骤**：
1. **描述目标动作**：说清它由哪些部分/相位构成 —— *KLP 工具：Bewegungsbeschreibung*
2. **判复杂度与危险性**：能否自然分解？有受伤风险吗？ —— *KLP 工具：Komplexitäts-/Gefährdungsanalyse*
3. **判学习者水平**：初学者 / 有基础？ —— *KLP 工具：Lernstand*
4. **选方法并给理由**：用 §2.2 五判据逐条对应 —— *KLP 工具：begründen*
5. **给具体练习步骤**：写成 methodische Übungsreihe —— *KLP 工具：Methodenkompetenz*
6. **点出风险与对策**：如分解后如何保证节奏（用整体-分析法收尾）—— *KLP 工具：theoriegeleitet*

> **判据 / 决策点**：口试若问「为什么不用另一条路」——必须给出**反例条件**（如「若学习者是初学者且动作含高危相位，整体法会带来受伤风险」）。

### 3.2 methodische Übungsreihe 设计（练习序列四步）

1. **定终点**：完整动作是什么 —— *KLP 工具：Zielbewegung*
2. **定切法**：按相位还是按要素拆 —— *KLP 工具：Zergliederung*
3. **排序**：由易到难、由部分到整体（每步只加一个新难点）—— *KLP 工具：methodische Reihe*
4. **留合成位**：最后 1–2 步专门做「连起来」—— *KLP 工具：Synthese*

> **判据 / 决策点**：若序列里没有明确的「合成步骤」，即违反分解法逻辑，必扣分。

### 3.3 口试即答框架（比较类三句）

1. `Die Ganzheitsmethode eignet sich besonders für …`（适用面）
2. `Die analytisch-synthetische Methode bietet sich an, wenn …`（适用面）
3. `Für das konkrete Beispiel wähle ich …, weil …`（落到例子 + 论证）

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | **Erörterungsaufgabe**（比较 + 论证 + 评判）；也可是 **Darstellungsaufgabe**（列举两类方法） |
| Operator | `erlaeutern` / `vergleichen`（II）· `begruenden`（II–III）· `beurteilen` / `Stellung nehmen`（III）· `entwerfen`（III） |
| AFB | I 描述方法 → II 比较与迁移到具体动作 → III 评判与设计 |
| 建议分值 / 时长 | 属 LK 300 min 笔试中 IF a 大题；口试 4–6 min 陈述 + 追问 |

> **三条轨道如何考它**：
> - **笔试（仅 LK）**：材料绑定（KLP 明示 `Klausuren generell materialgebunden`），给一段教学情境或动作描述，要求比较两法并论证选择。
> - **口试（mündliche Prüfung）**：Teil 1 连贯陈述「选哪条路、为什么」；Teil 2 追问「若学习者换成初学者会怎样」（迁移）。
> - **实践部分（Praktische Prüfung）**：你的运动表现本身即受教学路径影响——考官可问「你当初是怎么学这个动作的？为什么教练这样安排？」。

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> Vergleichen Sie die Ganzheitsmethode und die analytisch-synthetische Methode und erläutern Sie die Kriterien, nach denen die Wahl der Methode erfolgt.

**Aufgabe 2** `[原创]`
> Begründen Sie, ob Sie den Speerwurf (BF/SB3) für eine Anfängergruppe eher ganzheitlich oder analytisch-synthetisch einführen würden. Gehen Sie auf mindestens drei Entscheidungskriterien ein.

**Aufgabe 3** `[原创]`
> „Die Ganzheitsmethode ist die bessere Methode." – Nehmen Sie zu dieser Aussage Stellung und belegen Sie Ihre Position an Beispielen.

**Aufgabe 4** `[原创]`
> Entwerfen Sie eine methodische Übungsreihe (mindestens vier Schritte) zur Einführung des Kraulschwimmens (BF/SB4) und begründen Sie die Reihenfolge.

### 5.3 Musterlösung

**Aufgabe 1**（AFB I → II）
1. 点名两法并给定义：Ganzheit（整体做）vs. analytisch-synthetisch（拆-练-合）✓ 得分点（2×0.5）
2. 点出第三条 **ganzheitlich-analytisch** 折中路 ✓ 加分点
3. 给出选择判据：Komplexität / Gefährdung / Lernstand / Zeit / Motivation ✓ 得分点（关键，每条 0.5）
4. 举一个动作例子说明判据如何落地 ✓ 得分点
5. 指出分解法的核心风险（Bewegungsrhythmus 丢失）✓ 加分点

**Aufgabe 2**（AFB II → III）
1. **描述 Speerwurf 结构**：Anlauf → 交叉步 → 最后用力（Wurfauslage）→ 出手（含节奏性强的 whip 动作）✓ 得分点
2. **Komplexität**：多相位、强节奏 → 有分解理由 ✓ 得分点
3. **Gefährdungspotenzial**：出手器械有一定风险，但低于器械体操 → 可部分分解 ✓ 得分点
4. **Lernstand**：初学者 → 宜先用 Erleichterung（轻器械、短助跑）+ 部分分解，而非全分解 ✓ 得分点（关键：不能一路分解到底）
5. **结论**：推荐 **ganzheitlich-analytisch**（先整体体验节奏 → 拆练「交叉步+最后用力」→ 再整体）✓ 得分点（AFB III 需给判断）
6. **begründen**：整体节奏是投掷核心，纯分解会破坏它 ✓ 加分点

**Aufgabe 3**（AFB III）
1. 表态：**该说法不成立（无条件比较无意义）** ✓ 得分点（关键：立场明确）
2. 论证整体法优势：保留节奏与整体性、给成功体验、适合简单动作 ✓ 得分点
3. 论证整体法局限：复杂动作难掌握、易形成错误定式 ✓ 得分点
4. 反例：器械体操/游泳技术若只用整体法 → 难度过高、危险 ✓ 得分点
5. 结论：方法优劣**取决于判据**（kriteriengeleitet），不是绝对优劣 ✓ 加分点（Urteilskompetenz）
6. 语言：使用 `weil / da / deshalb` 论证链 ✓ 加分点

**Aufgabe 4**（AFB III）
1. 定终点：完整 Kraul（含 Beinschlag、Armzug、Atmung、Koordination）✓ 得分点
2. 切法：按**动作要素**拆（腿 / 臂 / 呼吸）+ 最后合成 ✓ 得分点
3. 四步序列（由易到难）：① Beinschlag mit Brett → ② Armzug isoliert → ③ Atmung im Rhythmus → ④ Koordination von Arm/Bein/Atmung ✓ 得分点
4. **留合成步**：最后一步专门练「连起来」✓ 得分点（关键，见 §3.2）
5. **逐条 begründen**：每步只加一个新难点，降低信息负荷 ✓ 得分点
6. 风险对策：合成时若节奏断裂 → 用整体-分析法回炉 ✓ 加分点

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把 **Lernmethode**（教学路径）与 **Lernphase**（学习阶段）混用 | 记：Methode 是「怎么教」，Phase 是「学到哪」 |
| 知识错 | 断言「整体法更好」或「分解法更好」而不看条件 | 一律**依判据**作答，给反例条件 |
| 表达错 | 只写 `Ganzheitsmethode ist besser` 不给 weil 从句 | 每个结论配 `weil / da / deshalb` 论证链 |
