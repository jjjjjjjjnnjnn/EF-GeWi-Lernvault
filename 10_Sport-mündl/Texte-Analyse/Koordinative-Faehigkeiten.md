# Koordinative Fähigkeiten und sportliche Leistungsfähigkeit (协调能力及其对成绩的影响)

> **中文理解**：协调能力（koordinative Fähigkeiten）是「把动作做得准、稳、顺、快」的能力族，它不同于「力气大、耐力好」这类体能（konditionelle Fähigkeiten）。学科通常列七项：连接、区分、平衡、定向、反应、节奏、转换。它们**决定技术质量**，进而影响成绩，并在受伤预防中起关键作用。它在 KLP 里属 **IF a — Bewegungsstruktur und Bewegungslernen** 的 GK/LK 增量重点 `Einfluss der koordinativen Fähigkeiten auf die sportliche Leistungsfähigkeit`。考试形态：笔试（LK）的 **Analyseaufgabe**；口试 Teil 1 的「点名能力 + 说明作用」；实践部分你须能说出自己哪个协调环节弱、如何练。
>
> **Klausur-Relevanz**：它是 IF a 与 IF d（训练学）的接口——协调能力既是「技术的基础」，也是「协调训练的靶子」。口试最常见失分：只罗列七个名词而不联系具体运动。

## 1. 核心概念 (Kernbegriffe)

| 术语 (DE) | 中文 | English | 定义 | 备注 |
|---|---|---|---|---|
| koordinative Fähigkeiten | 协调能力 | coordinative abilities | 控制与调节动作过程的、相对稳定的能力族 | 本笔记核心 |

| Gleichgewichtsfähigkeit | 平衡能力 | balance ability | 维持或恢复身体平衡 | 静态+动态 |
| Orientierungsfähigkeit | 定向能力 | orientation ability | 在空间与时间中确定并改变身体位置 | 空间感 |
| Reaktionsfähigkeit | 反应能力 | reaction ability | 对信号快速、恰当反应的能力 | 连《Informationsverarbeitung》 |
| Rhythmisierungsfähigkeit | 节奏能力 | rhythm ability | 把握并实现给定或自创的节奏 | 与 IF b 时间准则相通 |

| Technik | 技术 | technique | 完成动作的（相对最优的）方式 | 协调能力的外显结果 |
| variable Übungsbedingungen | 变化练习条件 | variable practice conditions | 通过改变条件提高协调要求 | 协调训练核心手段 |
| sensible Phase | 敏感期 | sensitive phase | 协调能力发展最快、最易塑的年龄段 | 通常童年至青春期 |

## 2. 知识结构 (Struktur)

### 2.1 定位：协调能力在哪

中文理解：它站在**感知（输入）与技术（输出）之间**——把感官信息转成精准的动作。它不属于「力气」那一家族。

> *Klausur-Satz*: `Koordinative Fähigkeiten liegen zwischen Wahrnehmung und Technik und bestimmen die Qualität der Bewegungsausführung.`

### 2.2 七项协调能力总表（骨架）

中文理解：这是本笔记的核心清单，也是答题模板。每项都要能配一个**具体运动例子**。

> *Klausur-Satz*: `Zu den koordinativen Fähigkeiten zählen u. a. Kopplungs-, Differenzierungs-, Gleichgewichts-, Orientierungs-, Reaktions-, Rhythmisierungs- und Umstellungsfähigkeit.`

| 能力 | 中文 | 说明 | 运动例 |
|---|---|---|---|
| **Kopplungsfähigkeit** | 连接能力 | 把多个子动作/肢体在时空上串成一个整体 | 游泳手臂+打腿+呼吸的配合 |
| **Differenzierungsfähigkeit** | 区分能力 | 精细调控用力大小与时机 | 传球力度、器械的「手感」 |
| **Gleichgewichtsfähigkeit** | 平衡能力 | 维持/恢复平衡（静态与动态） | 倒立、单腿落地、轮滑 |
| **Orientierungsfähigkeit** | 定向能力 | 在时空里确定并改变身体位置 | 球场上判断站位、跳转 |
| **Reaktionsfähigkeit** | 反应能力 | 对信号快速恰当反应 | 起跑、扑救、接发球 |
| **Rhythmisierungsfähigkeit** | 节奏能力 | 把握并实现节奏 | 助跑节奏、体操成套 |
| **Umstellungsfähigkeit** | 转换能力 | 情境突变时迅速调整动作 | 对手变线后的应变 |

> ⚠️ 学科文献对「几项」有分歧（常见 5 项或 7 项版本），上表为**常见七项表述**。[据推断，训练学共识，非 KLP 原文]

### 2.3 协调能力如何影响成绩（三条机制）

中文理解：不是「协调好=成绩好」这种空话，而是三条可解释的路径。

> *Klausur-Satz*: `Koordinative Fähigkeiten wirken auf die sportliche Leistungsfähigkeit über eine präzisere Bewegungsausführung, eine schnellere Anpassung an Situationen und ein geringeres Verletzungsrisiko.`

| 机制 | 说明 | 后果 |
|---|---|---|
| ① 提高动作精确性 | 用力与时机更准 → 技术更经济 | 成绩提升、能耗下降 |
| ② 加快情境适应 | 比赛变化时能迅速调整 | 战术执行更稳 |
| ③ 降低受伤风险 | 落地/失衡时能及时纠正 | 减少伤病 |

### 2.4 易混辨析：koordinativ vs. konditionell

中文理解：**体能**（力气、耐力、速度）管「发动机有多大」；**协调**管「怎么把力用对地方」。两者共同决定成绩，但训练手段不同。

> *Klausur-Satz*: `Konditionelle Fähigkeiten bestimmen die energetische Basis, koordinative Fähigkeiten die Steuerung und Qualität der Bewegung.`

| 维度 | konditionell | koordinativ |
|---|---|---|
| 本质 | 能量/代谢 | 控制/调节 |
| 例 | 力量、耐力、速度 | 平衡、节奏、定向 |
| 训练 | 负荷参数调（见 IF d） | 变化条件、多样性 |

### 2.5 协调训练的要点（实践落地）

中文理解：协调训练与体能训练**方法相反**——不靠「练到累」，而靠「练得变」。

> *Klausur-Satz*: `Koordinatives Training sollte vielseitig, unter variablen Bedingungen und in ermüdungsfreiem Zustand durchgeführt werden.`

| 要点 | 说明 |
|---|---|
| 多样性（Vielseitigkeit） | 不重复单一动作，广谱刺激 |
| 变化条件（variable Bedingungen） | 改场地/器材/速度/规则，提高协调要求 |
| 未疲劳时练 | 协调对疲劳敏感 → 放在训练课前段 |
| 敏感期利用 | 童年至青春期是协调发展黄金期 |

## 3. 解题方法 (Methoden)

### 3.1 Koordinative Anforderungen analysieren（分析动作的协调要求）

**编号步骤**：
1. **描述动作/情境** —— *KLP 工具：Bewegungsbeschreibung*
2. **逐项对照七能力**：该动作主要要求哪几项 —— *KLP 工具：koordinative Fähigkeiten*
3. **排序主次**：哪一项最关键（写「主/辅」）—— *KLP 工具：Schwerpunktbestimmung*
4. **说明为何关键**：连到成绩/技术 —— *KLP 工具：begründen*
5. **推训练手段**：针对主项设计变化条件练习 —— *KLP 工具：Methodenkompetenz*

> **判据 / 决策点**：若动作「难在稳住」→ 主项是 Gleichgewicht；「难在配合」→ Kopplung；「难在应变」→ Umstellung。

### 3.2 Koordinationstraining entwerfen（协调训练设计）

1. **定主项**（由 §3.1 得出）—— *KLP 工具：koordinative Fähigkeit*
2. **选基础动作** —— *KLP 工具：Übungsauswahl*
3. **加变化条件**（每次只改一个变量）—— *KLP 工具：variable Übungsbedingungen*
4. **控疲劳**（放课前段、组间充分休息）—— *KLP 工具：Belastungssteuerung*
5. **说明为什么这样练** —— *KLP 工具：theoriegeleitet begründen*

> **判据 / 决策点**：若方案「只重复同一动作到累」→ 这是体能训练而非协调训练，必扣分。

### 3.3 口试即答框架（作用类三句）

1. `Die Bewegung stellt vor allem Anforderungen an die …`（点名能力）
2. `Diese Fähigkeit ist entscheidend, weil …`（说明机制）
3. `Trainieren würde ich sie, indem ich … variiere.`（给手段）

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | **Analyseaufgabe**（分析动作的协调要求）；也可是 **Darstellungsaufgabe**（列举七能力） |
| Operator | `erlaeutern` / `analysieren`（II）· `einordnen`（I–II）· `anwenden`（II–III）· `beurteilen`（III） |
| AFB | I 列举能力 → II 分析具体动作 → III 评判训练方案/成绩影响 |
| 建议分值 / 时长 | 属 LK 300 min 笔试 IF a 大题；口试 3–5 min 陈述 + 追问 |

> **三条轨道如何考它**：
> - **笔试（仅 LK）**：材料绑定（动作描述/数据），要求分析协调要求并评判其对成绩的影响。
> - **口试（mündliche Prüfung）**：Teil 1 连贯陈述「某动作主要考哪几项协调能力」；Teil 2 追问「怎么练」「为什么放课前段」。
> - **实践部分（Praktische Prüfung）**：器械体操/球类/格斗的表现直接体现协调水平——考官可问「你哪个协调环节最弱？证据是什么？」。

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> Nennen Sie fünf koordinative Fähigkeiten und erläutern Sie jeweils deren Bedeutung für die sportliche Leistungsfähigkeit.

**Aufgabe 2** `[原创]`
> Analysieren Sie, welche koordinativen Fähigkeiten beim Dribbling im Fußball (BF/SB7) besonders gefordert sind. Bestimmen Sie die wichtigste Fähigkeit und begründen Sie Ihre Wahl.

**Aufgabe 3** `[原创]`
> Begründen Sie, warum koordinatives Training zu Beginn einer Trainingseinheit durchgeführt werden sollte, und entwerfen Sie für eine Übung zur Gleichgewichtsfähigkeit zwei Varianten mit veränderten Bedingungen.

**Aufgabe 4** `[原创]`
> Beurteilen Sie folgende Aussage: „Wer konditionell stark ist, ist auch koordinativ stark." – Nehmen Sie begründet Stellung.

### 5.3 Musterlösung

**Aufgabe 1**（AFB I → II）
1. 五项点名 + 一句话定义（如 Kopplung / Differenzierung / Gleichgewicht / Orientierung / Reaktion）✓ 得分点（5×0.5）
2. 每项连到一个**具体运动例子** ✓ 得分点（关键：不连例子不得分）
3. 说明作用机制（精确性 / 适应性 / 受伤预防）✓ 得分点
4. 点名德语术语（Fachsprache）✓ 加分点

**Aufgabe 2**（AFB II）
1. 逐项对照：Kopplung（运球+观察+身体假动作）· Differenzierung（触球力度）· Gleichgewicht（对抗中重心）· Orientierung（判断空间与对手）· Umstellung（对手逼抢时变向）✓ 得分点（须列 ≥4 项）
2. **定主项**：通常为 **Orientierungsfähigkeit** 或 **Differenzierungsfähigkeit** ✓ 得分点（关键：必须给唯一主项）
3. 论证主项为何最关键（例：控球质量取决于触球力度的精细调节）✓ 得分点
4. 训练手段：加变化条件（缩小场地、增加防守人、限时）✓ 加分点

**Aufgabe 3**（AFB II → III）
1. 论证课前段：协调对疲劳高度敏感，疲劳时动作质量下降 → 放前段 ✓ 得分点（关键）
2. 变化条件原则：每次只改一个变量 ✓ 得分点
3. 变式 A：闭眼单腿站立（去掉视觉输入 → 更依赖 vestibular/kinästhetisch）✓ 得分点
4. 变式 B：单腿站立于软垫/加抛接球（增加干扰 → 提高协调要求）✓ 得分点
5. 说明每个变式的生理/协调依据 ✓ 加分点（theoriegeleitet）

**Aufgabe 4**（AFB III）
1. 表态：**该说法不成立**（二者是不同能力族）✓ 得分点（关键：立场明确）
2. 论证：konditionell 管能量基础，koordinativ 管动作控制，可分离 ✓ 得分点
3. 反例：力量很强但平衡/节奏差的运动员（如部分举重初学者）✓ 得分点
4. 承认联系：体能水平会影响协调的**发挥**（疲劳时协调下降）✓ 得分点（辩证）
5. 结论：二者**相互依存但不能等同**，须分别训练 ✓ 加分点（Urteilskompetenz）

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把 koordinativ 与 konditionell 混同，或把「技术」当「协调能力」 | 记：协调=控制，体能=能量，技术=结果 |
| 知识错 | 只罗列七项名称，不联系具体运动 | 每项必须配一个运动例子 |
| 表达错 | 只说「他协调性不好」不点具体能力项 | 必须点名（如 Gleichgewichtsfähigkeit）+ 给证据 |
