# Regeln und Spielgelegenheiten (规则与游戏机会的营造)

> **中文理解**：规则不是比赛的「外包装」，而是比赛的**构成条件**——没有规则就没有「足球」这件事。KLP 在 IF e 里把 `Gestaltung von Spiel- und Sportgelegenheiten` 列为**第一重点**（EF 与 GK/LK 共通），其下第一条就是 `Regeln und Normen`。考试里它出现在：笔试（仅 LK）的 **Darstellungs-/Analyseaufgabe**（给一个规则改动或一份 Spielform，要求分析它对战术与参与度的影响）；口试 Teil 1 的「描述并解释一个比赛形式」；以及**实践部分**——考官会问「你这个练习/比赛形式为什么这样设计规则？」。核心能力是：**看到规则 → 说出它的功能 → 推演改动后的后果**。
>
> **Klausur-Relevanz**：IF e 在本项目中原为完全空白，而这条是 EF 与 GK/LK 共同的**第一重点**——即使 GK 没把 IF e 选作 Akzentuierung，它**仍然必考**（KLP 粗体第一重点）。口试最常见的失分是「只复述规则条文，不说功能与效果」。

## 1. 核心概念 (Kernbegriffe)

| 术语 (DE) | 中文 | English | 定义 | 备注 |
|---|---|---|---|---|
| Regel | 规则 | rule | 规定比赛如何进行；分**构成性**与**调节性** | 本笔记核心 [据推断] |
| konstitutive Regel | 构成性规则 | constitutive rule | 若不存在则该运动**不成立**（如足球禁手球、越位） | 定义「这是什么运动」 |
| regulative Regel | 调节性规则 | regulative rule | 规范行为方式（如犯规、警告、换人） | 不改变运动本质 |
| Norm | 规范 | norm | 未写入条文但被期待的行为标准（Fairplay） | 与 IF e 第二重点相连 |
| Spielgelegenheit | 比赛/游戏机会 | game opportunity | 被设计出来、可供参与的比赛情境 | 第一重点关键词 |
| Spielform | 比赛形式 | game form | 具体组织形态（人数/场地/规则变体） | 设计对象 |
| Regelvariation | 规则变奏 | rule variation | 有意改动某条规则以达成教学/参与目标 | 最常考的操作 |
| Spielidee | 比赛理念 | game idea | 一项运动的核心玩法逻辑（如「把球投进对方篮筐」） | 改规则不得违背它 |
| Zielschussspiel | 攻门/投篮类比赛 | goal-shooting game | 以进球/得分目标的球类（足球、篮球、手球） | 球类分类之一 |
| Rückschlagspiel | 隔网对抗类 | net/wall game | 隔网来回（排球、羽毛球、乒乓球） | 球类分类之一 |
| Teilnahme / Partizipation | 参与度 | participation | 每个学生的实际触球/投入程度 | 评判游戏机会的核心指标 |
| Spielfähigkeit | 比赛能力 | game-playing ability | 在比赛情境中综合运用技战术的能力 | 教学的目标量 |
| Differenzierung | 差异化 | differentiation | 按水平调整规则/场地/人数 | 组织游戏机会的手段 |
| Regelverstoß | 违规 | rule violation | 违反规则的行为（含战术性违规） | 见《Fairness-und-Aggression》 |

> **术语卡候选**：konstitutive Regel · regulative Regel · Spielform · Regelvariation · Spielidee · Spielfähigkeit · Partizipation

## 2. 知识结构 (Struktur)

### 2.1 规则的两类功能：构成 vs. 调节

中文理解：规则不只是「禁止什么」。**构成性规则**决定了运动的本质——删掉它，这项运动就不再是它；**调节性规则**只管行为秩序——改它，运动还是这项运动。考试中常要求判断「这条规则属于哪一类」。

> *Klausur-Satz*: `Man unterscheidet konstitutive Regeln, die das Wesen des Spiels festlegen, von regulativen Regeln, die das Verhalten der Beteiligten ordnen.`

| 类别 | 作用 | 例子 | 改动的后果 |
|---|---|---|---|
| **konstitutiv** | 定义运动的玩法逻辑 | 足球禁手球；越位；网高 | 改动 → 玩法本质变化（可能变成另一种运动） |
| **regulativ** | 规范行为与秩序 | 犯规、黄牌、换人名额、暂停 | 改动 → 行为方式变化，运动本质不变 |

> ⚠️ 边界并非绝对：越位在历史上是**为限制「站桩进球」而引入**的调节性规则，但今天已被视为足球构成的一部分。[据推断]

### 2.2 规则 → 战术 → 参与度：三段推演链（**本笔记的方法核心**）

中文理解：这是 KLP 要求的能力——改一条规则，不只是改条文，而是**连带改变战术选择与参与结构**。这是 `in Beziehung setzen` 的典型应用。

> *Klausur-Satz*: `Eine Regeländerung verändert nicht nur den formalen Ablauf, sondern auch die taktischen Handlungsoptionen und die Beteiligung aller Spielerinnen und Spieler.`

**推演链**：`Regeländerung → 战术选项变化 → 参与度变化 → 教学效果变化`

| 规则改动 | 战术后果 | 参与度后果 |
|---|---|---|
| 缩小场地 | 空间压力增大，传球更快 | 触球次数上升 |
| 减少每队人数（如 7v7 → 3v3） | 个人对抗增多，决策更频繁 | 每人触球时间显著增加 |
| 强制「每人最多触球 3 次」 | 迫使快速传递、跑位 | 抑制个人盘带，均衡参与 |
| 设「全队得分须由不同人完成」 | 迫使配合 | 抑制「独狼」，鼓励合作 |
| 引入「每次得分后双方全体轮换位置」 | 战术需临时重组 | 全员均等参与各位置 |

> ⚠️ 上表为**通用推演模型**（[据推断]，基于球类教学共识），考试作答须结合题目给定的具体情境，不可套用。

### 2.3 Spielgelegenheiten 的设计三原则

中文理解：设计「游戏机会」不是随便分组开赛，而是要有意识地让**不同水平的人都能参与并进步**。KLP 的第一重点是 `Gestaltung von Spiel- und Sportgelegenheiten`，其落点就是这三条。

> *Klausur-Satz*: `Spiel- und Sportgelegenheiten sollen so gestaltet werden, dass alle Beteiligten unabhängig vom Leistungsniveau angemessen beteiligt sind.`

1. **Zielgruppenorientierung（面向对象）**：按年龄/水平/人数调整规则与场地。
2. **Differenzierung（差异化）**：同一次课内可用不同规则版本（如 A 组 5v5、B 组 3v3）。
3. **Partizipation sichern（保障参与）**：通过规则设计（触球限制、轮换）防止少数人垄断球权。

### 2.4 规则是合作与竞争的调节器

中文理解：IF e 的标题是「合作与竞争」——规则正是**平衡这两者**的装置。竞争性太强 → 弱者退出；合作性太强 → 失去张力。规则改动就是调这个平衡。

> *Klausur-Satz*: `Regeln regulieren das Verhältnis von Kooperation und Konkurrenz, indem sie bestimmen, wie stark Wettkampf und Zusammenarbeit betont werden.`

| 倾向 | 规则手段 | 风险 |
|---|---|---|
| 强化竞争 | 计分、排名、缩短比赛时间 | 弱者参与度下降 |
| 强化合作 | 团队得分、轮换、触球限制 | 竞技张力减弱 |
| 平衡 | 混合计分（个人+团队） | 设计复杂度上升 |

## 3. 解题方法 (Methoden)

### 3.1 Regelanalyse（规则分析：功能—类别—效果）

**编号步骤**：
1. **命名规则**：写出题目给的/你要分析的规则原文 —— *KLP 工具：benennen / angeben*
2. **判类别**：konstitutiv 还是 regulativ？ —— *KLP 工具：einordnen*
3. **说功能**：它解决了什么问题？（防止何种行为/创造何种可能）—— *KLP 工具：erläutern*
4. **推效果**：改动后战术与参与度如何变化？ —— *KLP 工具：in Beziehung setzen*
5. **依准则评判**：这个改动对「参与度/公平性/竞技性」是好是坏？ —— *KLP 工具：kriteriengeleitet beurteilen*

> **判据 / 决策点**：若题目问「为什么这条规则存在」，必须回答**功能**（它阻止了什么、创造了什么），而不是复述条文。

### 3.2 Spielform entwerfen（比赛形式设计：目标—规则—检验）

**编号步骤**：
1. **定目标**：这次比赛要练什么/保障谁的参与？（如「让技术弱者多触球」）—— *KLP 工具：Zielsetzung*
2. **选基础形式**：从哪项运动的 Spielidee 出发？ —— *KLP 工具：Spielidee*
3. **改规则**：改哪 1–2 条达成目标？说明为什么是这几条 —— *KLP 工具：Regelvariation*
4. **定场地与人数**：配套调整 —— *KLP 工具：Differenzierung*
5. **预判效果**：预测战术与参与度变化 —— *KLP 工具：in Beziehung setzen*
6. **检验**：该形式是否仍保有原运动的 Spielidee？（别改到「不是足球了」）—— *KLP 工具：begründen*

> **判据 / 决策点**：好的规则改动通常**只改 1–2 条**且**指向明确目标**；一次改五条 → 无法归因，考试失分。

### 3.3 口试即答框架（分析类四句）

1. `Die Regel „…" ist zunächst zu benennen und einzuordnen: Sie ist konstitutiv/regulativ, weil …`
2. `Ihre Funktion besteht darin, dass …`
3. `Eine Veränderung dieser Regel hätte zur Folge, dass die taktischen Optionen … und die Beteiligung …`
4. `Kriteriengeleitet beurteilt erscheint die Veränderung sinnvoll/nicht sinnvoll, weil …`

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | **Darstellungsaufgabe**（呈示规则及其功能）· **Analyseaufgabe**（分析给定规则/比赛形式）· **Erörterungsaufgabe**（论述规则改动的利弊） |
| Operator | `beschreiben` / `einordnen`（I–II）· `analysieren` / `in Beziehung setzen`（II）· `entwerfen` / `beurteilen` / `begruenden`（III） |
| AFB | I 复述规则 → II 分析规则功能与效果 → III 设计并依准则评判 |
| 建议分值 / 时长 | 属 LK 300 min 笔试 IF e 大题；口试 4–6 min 陈述 + 追问 |

> **三条轨道如何考它**：
> - **笔试（仅 LK）**：材料绑定（规则条文/比赛描述/示意图），要求分析规则功能、推演改动后果并评判。
> - **口试（mündliche Prüfung）**：Teil 1 连贯陈述「描述并解释一个比赛形式」；Teil 2 追问「如果参与者水平差距很大，你会怎么改规则？」。
> - **实践部分（Praktische Prüfung）**：BF/SB7 的实践考核中，考官可问「你刚才这个练习形式为什么这样设规则？」——须现场说明设计意图。

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> Beschreiben Sie die Regeln des Sportspiels, das Sie im Kurs praktizieren, und ordnen Sie je eine Regel als konstitutiv bzw. regulativ ein. Begründen Sie Ihre Einordnung.

**Aufgabe 2** `[NRW-改编]`
> Analysieren Sie die folgende Regelvariation hinsichtlich ihrer Wirkung auf Taktik und Beteiligung:
> *„Im Basketball wird auf einem verkleinerten Feld 3-gegen-3 gespielt; jede Spielerin darf den Ball höchstens dreimal berühren, bevor sie abspielen muss."*

**Aufgabe 3** `[原创]`
> Entwerfen Sie für eine Kursgruppe mit sehr unterschiedlichem Leistungsniveau eine Spielform (BF/SB7), die die Beteiligung aller sichert. Erläutern Sie Ihre Regeländerungen und begründen Sie, warum die Spielidee erhalten bleibt.

**Aufgabe 4** `[原创]`
> Beurteilen Sie kriteriengeleitet, ob eine Regeländerung, die das Teamergebnis stärker gewichtet als den Einzelerfolg, für den Schulsport sinnvoll ist. Nehmen Sie Stellung.

### 5.3 Musterlösung

**Aufgabe 1**（AFB I → II）
1. 复述所选运动的 2–3 条规则（术语正确、用自己话）✓ 得分点（关键：须是**规则条文**而非战术描述）
2. 归类：如「禁手球」= konstitutiv（去掉则不成足球）✓ 得分点
3. 归类：如「黄牌/警告」= regulativ（规范行为，不改本质）✓ 得分点
4. 论证：说明「为何这样归」——构成性规则若删除，Spielidee 崩解 ✓ 得分点（关键：判据明确）
5. 语言：全程用 `konstitutiv / regulativ / Spielidee` 术语 ✓ 加分点

**Aufgabe 2**（AFB II）
1. **命名改动**：场地缩小 + 人数 3v3 + 触球上限 3 次 ✓ 得分点
2. **战术后果**：空间压力↑ → 传球更快、无球跑位增多；触球限制 → 抑制个人盘带、迫使快速决策 ✓ 得分点（关键：须写「战术」层）
3. **参与度后果**：3v3 使每人触球次数显著上升；触球上限使球权分散 ✓ 得分点（关键：须写「参与」层）
4. **关联教学效果**：该形式适合练「快速决策与配合」而非「个人技术」✓ 得分点
5. 结论：改动同时服务战术训练与参与保障，指向明确 ✓ 加分点
6. 语言：用 `in Beziehung setzen` 的句式（`… hat zur Folge, dass …`）✓ 加分点

**Aufgabe 3**（AFB III）
1. 定目标：保障弱者参与 + 维持竞技张力 ✓ 得分点
2. 选基础形式与 Spielidee：如手球/足球的 Zielschussspiel 逻辑 ✓ 得分点
3. 设计 1–2 条规则改动（如「每队得分须由 ≥3 人完成」「每 3 分钟全员轮换」）✓ 得分点（关键：改动须**少而准**）
4. 配套差异化（场地、人数、球的大小）✓ 得分点
5. 预判效果：触球分布更均、弱者参与度上升 ✓ 得分点
6. **论证 Spielidee 未变**：仍是「把球送进对方球门」，只是参与条件变了 ✓ 得分点（关键：AFB III 要求 `begründen`）
7. 反思：承认该形式可能降低竞技强度，需与训练目标权衡 ✓ 加分点

**Aufgabe 4**（AFB III）
1. 明确**立场**（支持/反对/有条件支持）✓ 得分点（关键：`Stellung nehmen` 要求明确表态）
2. 支持方论证：团队得分提升合作与参与，符合学校体育的**教育使命**（视角 E）✓ 得分点
3. 反对方论证：过度弱化个人成功可能削弱竞技动机与成绩导向 ✓ 得分点
4. **依准则判断**：用「参与度」「公平性」「竞技性」三准则逐一权衡 ✓ 得分点（关键：`kriteriengeleitet`）
5. 结论：给出**有条件**判断（如「在混合水平班级中支持，在竞赛队中不适用」）✓ 加分点
6. 语言：用 `beurteilen`（依专业标准）与 `bewerten`（依价值规范）各一次，区分二者 ✓ 加分点

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把 konstitutive 与 regulative Regel 混淆，或把战术描述当规则 | 记判据：删掉它这项运动还成立吗？成立=regulativ |
| 知识错 | 只说「规则限制行为」，说不出规则**创造**比赛可能性 | 每条规则回答两问：阻止什么 + 创造什么 |
| 表达错 | 设计比赛形式时一次改 5 条规则，无法归因 | 每次只改 1–2 条，且明确指向一个目标 |
