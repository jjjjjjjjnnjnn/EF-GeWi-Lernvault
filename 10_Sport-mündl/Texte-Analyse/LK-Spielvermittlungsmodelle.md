# [LK] Spielvermittlungsmodelle (球类教学模型)

> **中文理解**：教一个球类项目，是**先练技术再打比赛**，还是**先打简化比赛再补技术**？这是体育教学法的根本分歧。KLP 在 IF e 的 **LK 段**专列 `Spielvermittlungsmodelle` 为 LK 独有条目——**GK 不考**。考试里它出现在：笔试（仅 LK）的 **Vergleichs-/Analyseaufgabe**（比较两种教学模型并评价其适用情境）；口试 Teil 2 的追问（「你会怎么教一个初学者打排球？」）；以及实践部分——你实际带一个练习时用的方法，正属于某个模型。核心能力是：**说出模型的原理 → 比较优劣 → 依教学情境选择并论证**。
>
> **Klausur-Relevanz**：⚠️ **LK 专属**。GK 学生不考此条；LK 学生这是 IF e 的**加宽条目**，且是 `vergleichen`（AFB II–III）的典型载体。常见失分：只背模型名称，说不出「什么情境下用哪个」。

## 2. 知识结构 (Struktur)

### 2.1 两大路径的根本分歧

中文理解：分歧不在「要不要教技术」，而在**顺序**与**起点**。传统路径把比赛当**终点**（先学会，再打）；战术路径把比赛当**起点**（先打，再学）。

> *Klausur-Satz*: `Technikorientierte Modelle beginnen mit der isolierten Technikschulung und führen erst später zum Spiel, taktikorientierte Modelle dagegen setzen von Anfang an beim vereinfachten Spiel an.`

| 维度 | Technikorientierung（技术优先） | Taktikorientierung（战术优先） |
|---|---|---|
| **起点** | 分解技术练习（Übungsreihe） | 简化比赛（Spielreihe） |
| **顺序** | Technik → Taktik → Spiel | Spiel → Taktik → Technik |
| **学习对象** | 动作定型 | 比赛决策 |
| **典型工具** | 技术练习、重复 | 简化比赛、问题导向提问 |
| **优势** | 技术规范、错误少 | 动机高、决策快、迁移好 |
| **劣势** | 动机低、迁移差、比赛无能 | 技术粗糙、需教师高调控 |

> ⚠️ **不存在「绝对更好」的模型**——选择取决于**学段、水平、目标、项目特性**。这是 LK 评判题的核心判据。[据推断]

### 2.2 TGfU 的六阶段（战术优先的代表模型）

中文理解：TGfU（Teaching Games for Understanding，Bunker & Thorpe）是英语区最著名的战术优先模型。它把一节课组织成**从比赛到比赛**的循环。

> *Klausur-Satz*: `Das TGfU-Modell organisiert den Unterricht in sechs Schritten, die vom Spiel über die taktische Problemstellung zur technischen Vertiefung und zurück zum Spiel führen.`

| 阶段 | 内容 | 中文 |
|---|---|---|
| 1. Game | 简化比赛 | 先打一场简化比赛 |
| 2. Game Appreciation | 理解比赛规则/目的 | 明白这运动怎么玩 |
| 3. Tactical Awareness | 识别战术问题 | 问「为什么打不进？」 |
| 4. Making Appropriate Decisions | 做决策 | 该传还是该射？ |
| 5. Skill Execution | 技术执行 | 按需练所需技术 |
| 6. Performance | 回到比赛 | 检验改进 |

> ⚠️ 上表为 TGfU 的**六步结构**（[据推断]，据该模型公开的通行表述），本项目**未获取到**德语官方 KLP 对 TGfU 的原文定义——KLP 只列条目名 `Spielvermittlungsmodelle`。[未获取到]

### 2.3 球类分类（模型的基础）

中文理解：不同**结构类型**的球类，教学难点不同，模型选择也不同。

> *Klausur-Satz*: `Sportspiele lassen sich nach ihrer Grundstruktur in Zielschuss-, Rückschlag-, Schlag- und Zielspiele klassifizieren.`

| 类型 | 德语 | 例子 | 教学难点 |
|---|---|---|---|
| 攻门类 | Zielschussspiele | 足球、篮球、手球 | 空间争夺与决策 |
| 隔网类 | Rückschlagspiele | 排球、羽毛球、乒乓 | 球路控制与站位 |
| 击打跑分类 | Schlag-/Feldspiele | 棒球、板球 | 时机与配合 |
| 目标类 | Zielspiele | 高尔夫、冰壶 | 精准度 |

> ⚠️ 分类名称与数量为**学科通行划分**（[据推断]）；KLP 未逐条列出。[未获取到]

### 2.4 模型选择的三判据

中文理解：LK 的 `beurteilen` 要求**依标准**选模型。三条判据必须能背出并应用。

> *Klausur-Satz*: `Die Wahl des Vermittlungsmodells sollte sich an Lernziel, Lernvoraussetzungen und Zielgruppe orientieren.`

1. **Lernziel（学习目标）**：要练技术精度 → 偏技术；要练比赛决策 → 偏战术。
2. **Lernvoraussetzungen（学习前提）**：初学者 → 战术模型保动机；进阶者 → 技术模型提精度。
3. **Zielgruppe（对象）**：学校班级（异质、重参与）→ 战术优先；竞赛队（同质、重成绩）→ 技术优先。

## 3. 解题方法 (Methoden)

### 3.1 Modellvergleich（模型比较：三栏法）

**编号步骤**：
1. **点名两模型 + 一句话定义** —— *KLP 工具：benennen / erläutern*
2. **定比较视角**（起点/顺序/目标/工具/效果）—— *KLP 工具：vergleichen（按给定或自选视角）*
3. **逐视角列共同点与差异** —— *KLP 工具：gegenüberstellen*
4. **配教学情境**：各举一个适用场景 —— *KLP 工具：anwenden*
5. **依判据评判**：说明在给定情境下哪个更合适 —— *KLP 工具：kriteriengeleitet beurteilen*

> **判据 / 决策点**：`vergleichen` 在 Sport 是 **II–III, vorw. II**——必须**同时**给出共同点与差异，只写差异会失分。

### 3.2 Vermittlungssequenz entwerfen（设计教学序列）

**编号步骤**：
1. **定目标与对象**：谁、学什么、到什么程度 —— *KLP 工具：Zielsetzung*
2. **选模型**：技术优先 or 战术优先？给理由 —— *KLP 工具：begründen*
3. **设计起点**：Übungsreihe 的第一练 or Spielreihe 的第一场 —— *KLP 工具：Spielform / Übungsform*
4. **设计进阶**：逐步增加复杂度（人数/规则/空间）—— *KLP 工具：entwickeln*
5. **设检验点**：何时回到比赛检验迁移 —— *KLP 工具：Transfer*
6. **反思**：该序列对异质班级是否可行 —— *KLP 工具：beurteilen*

> **判据 / 决策点**：好的序列在**每一阶段都保留比赛元素**（即使技术优先模型，也不能整节课不打比赛）。

### 3.3 口试即答框架（比较类四句）

1. `Ich unterscheide zwei Grundmodelle: die technikorientierte und die taktikorientierte Vermittlung.`
2. `Beide verfolgen das Ziel der Spielfähigkeit, unterscheiden sich jedoch im Ausgangspunkt: …`
3. `Ein Vorteil des taktikorientierten Modells ist …, ein Nachteil ist …`
4. `Für die beschriebene Lerngruppe beurteile ich das …-Modell als geeigneter, weil …`

### 5.3 Musterlösung

**Aufgabe 1**（AFB I → II）
1. 定义战术优先模型：**从简化比赛出发，按比赛需要补技术** ✓ 得分点
2. 说明其核心主张：先建立比赛理解与决策，再精练技术 ✓ 得分点
3. 对照技术优先模型：**从分解技术出发，最后进入比赛** ✓ 得分点
4. 点明二者**共同目标**（Spielfähigkeit），差异在起点与顺序 ✓ 得分点（关键：须给共同点）
5. 语言：用 `Ausgangspunkt / Reihenfolge / Spielfähigkeit` 术语 ✓ 加分点

**Aufgabe 2**（AFB II）
1. **Ausgangspunkt**：Übungsreihe（技术）vs. Spielreihe（战术）✓ 得分点
2. **Zielsetzung**：动作定型 vs. 比赛决策 ✓ 得分点
3. **Methoden**：重复练习/纠错 vs. 简化比赛/问题导向提问 ✓ 得分点
4. **共同点**：都以 Spielfähigkeit 为目标，都需逐步增加复杂度 ✓ 得分点（关键：`vergleichen` 要求共同点）
5. 结论：两模型互补，非互斥 ✓ 加分点
6. 语言：用 `im Gegensatz dazu / während … , …` 对照句式 ✓ 加分点

**Aufgabe 3**（AFB II）
1. **判定**：属**战术优先**模型 ✓ 得分点
2. 依据 1：以简化比赛（3v3）**开场** ✓ 得分点
3. 依据 2：教师用**问题导向提问**引出战术问题 ✓ 得分点（关键：须引用题干细节）
4. 依据 3：技术在**需求出现后**才练（Passen）✓ 得分点
5. 依据 4：练完技术**回到比赛**（循环结构）✓ 得分点
6. 补充：该序列与 TGfU 的六步逻辑一致 ✓ 加分点
7. 语言：`Die Sequenz folgt dem Muster Spiel – Problem – Übung – Spiel` ✓ 加分点

**Aufgabe 4**（AFB III）
1. 说明对象特征（异质班级：动机与水平差异大）✓ 得分点
2. **选模型**：战术优先（保动机、保参与）✓ 得分点
3. 设计起点：低门槛简化比赛（小场地/少人数/宽松规则）✓ 得分点
4. 设计进阶：逐步加规则与人数，难度梯度清晰 ✓ 得分点（关键：须体现 `entwickeln`）
5. 设计差异化：同课内不同规则版本（强者加限制）✓ 得分点
6. **依判据论证**：用 Lernziel / Lernvoraussetzungen / Zielgruppe 三判据逐一说明 ✓ 得分点（关键：`kriteriengeleitet`）
7. 反思：承认技术精度可能不足，需长期补技术环节 ✓ 加分点
8. 语言：全程术语正确、结构分段清晰 ✓ 加分点

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把「技术优先」说成「不教比赛」，把「战术优先」说成「不教技术」 | 记：两者都教，只是**顺序与起点**不同 |
| 知识错 | 只背模型名称，说不出 TGfU 的阶段或选择判据 | 背 TGfU 六步 + 三判据（Lernziel/Lernvoraussetzungen/Zielgruppe） |
| 表达错 | 比较题只写差异，不写共同点 | `vergleichen` 必须同时给 Gemeinsamkeiten 与 Unterschiede |
