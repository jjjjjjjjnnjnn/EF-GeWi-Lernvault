# Improvisation und Variation von Bewegung (动作的即兴与变奏)

> **中文理解**：编排（Bewegungsgestaltung）有两个「来源」——一个是**即兴（Improvisation）**：在给定框架内当场创造、不预先定死；另一个是**变奏（Variation）**：拿一个已存在的动作母题，只改一个准则（空间/时间/动态/形式结构）而保留其余。二者是 IF b 的第二重点，也是**从即兴到成品编排（Komposition）** 的标准生产链：即兴产生素材 → 变奏探索可能 → 筛选固定 → 编成作品。考试形态：实践部分的**展示/演示题**（Demonstration/Präsentation）最直接；口试 Teil 1 常要求「当场用某准则变奏一个动素并说明」；笔试（LK）则考**分析一段变奏用了哪个准则**或**设计一套变奏任务**。
>
> **Klausur-Relevanz**：IF b 原为完全空白，第一重点《Gestaltungskriterien-und-Indikatoren》给骨架，本笔记给**操作法**——口试考官最爱问「你能把刚才那个动作变出三种花样吗？你改的是哪个准则？」

## 1. 核心概念 (Kernbegriffe)

| 术语 (DE) | 中文 | English | 定义 | 备注 |
|---|---|---|---|---|
| Improvisation | 即兴 | improvisation | 在**给定框架**内**当场、未预先固定**地创造动作 | 结果是「素材」 |
| Variation | 变奏 | variation | 对**已知动作母题**做**有意的、定向的**改动 | 结果仍是「母题的家族成员」 |
| Bewegungsmotiv | 动作母题 | movement motif | 被反复使用/变奏的基本动作单元 | 变奏的靶子 |
| Variationskriterium | 变奏准则 | variation criterion | 被改动的那一个准则（Raum/Zeit/Dynamik/formaler Aufbau） | 一次只改一个 |
| Komposition | 组合编排 | composition | 把选定的素材组织成固定成品 | 即兴/变奏的下游 |
| Choreographie | 编舞 | choreography | 固定下来的成套动作 | 与即兴对立 |
| Verfremdung | 陌生化 | alienation | 把熟悉动作改到「认不出原样」的手法 | 变奏的极端形式 |
| Übertreibung | 夸张 | exaggeration | 把某参数放到极端（超大/超快/超慢） | 常用变奏手法 |
| Umkehrung | 反转 | reversal | 方向/左右/前后/顺序倒置 | 常用变奏手法 |
| Zeitlupe / Zeitraffer | 慢动作／快放 | slow motion / time lapse | 只改时间准则的变奏 | Zeit 准则 |
| Spiegeln | 镜像 | mirroring | 左右对调或两人互照 | Raum 准则 |
| Improvisationsregel | 即兴规则 | improvisation rule | 保证即兴不中断的约定 | 如「接受—扩展」原则 |
| «Ja, und …»-Prinzip | 「是，并且…」原则 | "yes, and" principle | 不否定同伴的提议，而是接住并扩展 | 即兴的合作规则 [据推断] |
| Bewegungsaufgabe | 动作任务 | movement task | 教师给定的框架（要表达什么、限什么） | 即兴的边界 |

## 2. 知识结构 (Struktur)

### 2.1 即兴 vs 变奏：一张对照表

中文理解：两者不是「随便动」与「认真做」的区别，而是**创作机制**不同——即兴是「无稿生成」，变奏是「有稿改稿」。

> *Klausur-Satz*: `Improvisation erzeugt Bewegung spontan innerhalb eines Rahmens, Variation verändert dagegen ein bereits bekanntes Bewegungsmotiv gezielt nach einem Kriterium.`

| 维度 | Improvisation（即兴） | Variation（变奏） |
|---|---|---|
| 起点 | 一个框架/任务/刺激（Musik、词、图像） | 一个**已知的**动作母题 |
| 结果 | 不可预知，可能有「废料」 | 母题的**受控**变体 |
| 控制度 | 低（开放） | 高（定向） |
| 用途 | **生成素材**、培养表现力与决断 | **深化素材**、训练准则意识 |
| 风险 | 卡住、重复、失控 | 变化过小（看不出）或过大（失母题） |
| 评判方式 | 看**过程**（流畅、接受、冒险） | 看**结果**（是否只改一个准则、母题是否可辨） |

### 2.2 变奏四准则（与第一重点对接）

中文理解：变奏的「靶子」就是四大编排准则。**铁律：一次只改一个准则**，否则无法归因、也无法评判。

> *Klausur-Satz*: `Bei einer Variation wird jeweils nur ein Gestaltungskriterium verändert, damit die Veränderung eindeutig zuordenbar bleibt.`

| 准则 | 变奏手法举例 |
|---|---|
| **Raum** | 换队形（Reihe→Kreis）、改路径（直→曲）、换层面（低→高）、镜像 |
| **Zeit** | 加速/减速、Zeitlupe、改变重音位置、插入停顿 |
| **Dynamik** | 加强/减弱张力、由流畅改顿挫、放大/缩小幅度 |
| **formaler Aufbau** | 倒置顺序、加重复段、把「高潮」移到最后、删段 |

> ⚠️ **「四准则一起改」是口试最常见失分**：变化越多≠越好，无法归因即无法评判（违反 kriteriengeleitet）。[据推断]

### 2.3 从即兴到成品：生产链

中文理解：这不是「二选一」，而是一条流水线——即兴出素材，变奏探边界，筛选固定，编成作品。

> *Klausur-Satz*: `Improvisation und Variation sind Vorstufen der Komposition: Erst werden Ideen erzeugt, dann systematisch variiert und schließlich ausgewählt und festgeschrieben.`

`Improvisation（生成）→ Variation（探索）→ Auswahl（筛选）→ Festlegung（固定）→ Komposition（成品）`

### 2.4 即兴的三个层次（口试可背）

1. **Gelenkte Improvisation（有引导的即兴）**：教师给明确框架（主题+准则限制）——最易考、最好评。
2. **Teilgelenkte Improvisation（半引导）**：只给主题，准则自选。
3. **Freie Improvisation（自由即兴）**：只给音乐/空间——难度最高，口试少考。

## 3. 解题方法 (Methoden)

### 3.1 Variationsanalyse（变奏分析：看结果 → 反推准则）

**编号步骤**：
1. **描述母题**：先说清「原动作是什么」—— *KLP 工具：Bewegungsbeschreibung*
2. **逐准则比对**：Raum / Zeit / Dynamik / formaler Aufbau 哪一项变了 —— *KLP 工具：Gestaltungskriterien*
3. **锁定唯一变化**：指出**被改的那一个**准则 + 具体指标 —— *KLP 工具：Indikatoren*
4. **判可辨性**：母题是否仍可辨认（变化是否过大/过小）—— *KLP 工具：in Beziehung setzen*
5. **依准则评判**：该变奏是否达到意图 —— *KLP 工具：kriteriengeleitet beurteilen*

> **判据 / 决策点**：若你数出「两个以上准则都变了」→ 先判定这是**重新编排（Neugestaltung）** 而非变奏，或指出该变奏「归因不清」是缺陷。

### 3.2 Variationsreihe entwickeln（变奏链设计：一个母题 × N 个准则）

**编号步骤**：
1. **选定一个母题**（越简单越好，如「一次跨步跳」）—— *KLP 工具：Bewegungsmotiv*
2. **Raum 变奏**：只改队形/路径/方向，其余不动 —— *KLP 工具：Raum*
3. **Zeit 变奏**：回到母题，只改速度/节奏 —— *KLP 工具：Zeit*
4. **Dynamik 变奏**：回到母题，只改张力/幅度 —— *KLP 工具：Dynamik*
5. **formaler Aufbau 变奏**：回到母题，只改顺序/重复 —— *KLP 工具：formaler Aufbau*
6. **合成与筛选**：从四组变体中选出 2–3 个，串成一段 —— *KLP 工具：Komposition*
7. **逐条 begründen**：说明每个变体改了什么、为什么 —— *KLP 工具：theoriegeleitet begründen*

> **判据 / 决策点**：口试里被要求「即兴变出三种」时，**口头先声明你要改哪个准则**（`Ich variiere nun den Raum, indem ich …`），考官才能给你分。

### 3.3 Improvisationsaufgabe entwerfen（即兴任务设计，AFB III）

1. **定目标**：练表现力？练准则意识？练合作？—— *KLP 工具：Zielsetzung*
2. **给框架**：主题 + 时间 + 空间 + 人数 —— *KLP 工具：Bewegungsaufgabe*
3. **给限制**：只许改哪一个准则（保证可归因）—— *KLP 工具：Variationskriterium*
4. **给规则**：如「接受—扩展」防中断 —— *KLP 工具：Improvisationsregel*
5. **定观察点**：明确考官/观察者看什么指标 —— *KLP 工具：Beobachtungsschwerpunkte*
6. **反思**：说明该任务对不同水平的难度适配 —— *KLP 工具：kriteriengeleitet*

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | **Demonstration / Präsentation**（实践展示类，KLP §3 题型）· **Analyseaufgabe**（分析变奏）· **Gestaltungsaufgabe**（设计即兴/变奏任务） |

| AFB | I 描述母题 → II 分析用了哪个准则 → III 设计变奏链并评判 |
| 建议分值 / 时长 | 属 LK 300 min 笔试 IF b 大题；口试 3–5 min 现场变奏 + 追问 |

> **三条轨道如何考它**：
> - **笔试（仅 LK）**：给一段变奏的文字描述或示意图，要求指出被改动的准则与指标，并评判变奏是否清晰可辨。
> - **口试（mündliche Prüfung）**：Teil 1 现场或预先准备一段变奏并解释；Teil 2 追问「如果只许改时间准则，你会怎么做」。
> - **实践部分（Praktische Prüfung）**：BF/SB6 的 Demonstration/Präsentation 直接展示即兴与变奏能力——考官可要求**当场变奏**，看你的流畅度与准则意识。

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> Erläutern Sie den Unterschied zwischen Improvisation und Variation und ordnen Sie beide Begriffe in den Prozess der Komposition ein.

**Aufgabe 2** `[原创]`
> Analysieren Sie folgende Variation eines Sprungmotivs hinsichtlich des veränderten Gestaltungskriteriums:
> *„Aus dem gleichen einbeinigen Absprung wird zunächst ein Sprung in die Weite, dann ein Sprung auf der Stelle, schließlich ein Sprung mit halber Drehung."*

**Aufgabe 3** `[原创]`
> Entwickeln Sie zu einem einfachen Bewegungsmotiv Ihrer Wahl eine Variationsreihe, bei der nacheinander die Kriterien Raum, Zeit und Dynamik verändert werden, und begründen Sie jede Veränderung.

**Aufgabe 4** `[原创]`
> Entwerfen Sie eine Improvisationsaufgabe für einen Kurs (BF/SB6) und legen Sie fest, welche Indikatoren beobachtet werden, um die Qualität der Improvisation zu beurteilen.

### 5.3 Musterlösung

**Aufgabe 1**（AFB I → II）
1. Improvisation = 框架内**当场、未固定**创造（素材生成）✓ 得分点
2. Variation = 对**已知母题**按**一个准则**定向改动 ✓ 得分点（关键：须点出「定向/一个准则」）
3. 定位到生产链：Improvisation → Variation → Auswahl → Festlegung → Komposition ✓ 得分点
4. 补一句「变奏需保证母题仍可辨认」✓ 加分点

**Aufgabe 2**（AFB II）
1. 先说母题：同一个单腿起跳（Absprung）✓ 得分点
2. 逐准则排除：Raum 未变（无队形/路径/方向变化）；Dynamik 未变（张力/幅度未述）；formaler Aufbau 未变 ✓ 得分点
3. 锁定 **Zeit**：由「远跳」→「原地」→「带半转」实际改的是节奏/时长与旋转时机 ✓ 得分点（关键）
4. 挂指标：Tempo / Zeitveränderung（含停顿与旋转时长）✓ 得分点
5. 判可辨性：母题（单腿起跳）仍可辨认 → 变奏成立 ✓ 加分点

**Aufgabe 3**（AFB III）
1. 选一个**简单**母题（如「一步跳」）✓ 得分点
2. **Raum 变奏**：只改方向/队形，母题不动 ✓ 得分点
3. **Zeit 变奏**：回母题，只改快慢/停顿 ✓ 得分点
4. **Dynamik 变奏**：回母题，只改张力/幅度 ✓ 得分点
5. 每次**只改一个准则**并显式说明 ✓ 得分点（关键：可归因）
6. 逐条 begründen（如「慢速变奏使动作的张力变化可被观察」）✓ 得分点（AFB III 要求 kriteriengeleitet）
7. 反思：指出对协调能力（节奏、空间定向）的要求 ✓ 加分点

**Aufgabe 4**（AFB III）
1. 定目标（如「训练准则意识」）✓ 得分点
2. 给框架：主题 + 时间（如 30 s）+ 空间 + 人数 ✓ 得分点
3. 给限制：只许改一个准则 ✓ 得分点（关键）
4. 给规则：「接受—扩展」原则防中断 ✓ 得分点
5. 定观察指标：Bewegungsfluss（是否中断）、Formenvielfalt（变化数量）、Kriterienklarheit（变化是否可归因）✓ 得分点
6. 反思：说明对初学者需缩小框架 ✓ 加分点

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把 Improvisation（即兴）当「随便动」，把 Variation 当「重新编一套」 | 记：即兴=无稿生成；变奏=有稿改一处 |
| 知识错 | 一次同时改空间+时间+动态，还说「这样更丰富」 | 铁律「一次只改一个准则」；丰富靠**串联多次**变奏实现 |
| 表达错 | 只说「我换了个动作」不说改的是哪个准则+哪个指标 | 每句变奏都写成「准则：指标：从…变为…，weil …」 |
