# Deutsch Lehrplan (EF, NRW, KLP 2023 kalibriert)

> 中文一句话：EF考"语言+文本+沟通+媒体"四块，文本含整本戏剧；考试看ZKE Vorgaben 2027 + 新Operatoren表（2023起）。

## 1. Inhaltsfelder EF (KLP 2023, Kap 2.2)

1. **Sprache** — Sprachebenen (Phonologie/Morphologie/Syntax/Semantik/Pragmatik), Sprachvarietäten (Distinktion/Identität), Gegenwartssprache (Mündlichkeit vs Schriftlichkeit).
2. **Texte** — **Drama als Ganzschrift** im historischen Kontext (Figur/Handlung/Dialog;很可能就是你的Lektüre!) + Erzähltexte + lyrische Texte + pragmatische Texte (Textsorte/Argumentationsgang/Leserlenkung/Intention) + literarische/pragmatische Texte im thematischen Zusammenhang.
3. **Kommunikation** — Alltag vs literarisch gestaltete Kommunikation, Kommunikationsmodelle, monologisch/dialogisch.
4. **Medien** — Information (Geltungsansprüche prüfen!), Partizipation (Generieren/Teilen/Kommentieren + Verantwortung), Multimodalität (Bild/Ton/Text).

## 2. Klausurformat (ZKE + KLP Kap 4)

- Zentrale Klausur Ende EF + schulinterne Klausuren；Aufgabenarten I–IV (KLP Kap 4)，三段 AFB 全覆盖、**AFB II 是重点**。
- Operatoren ab 2023（判分动词，见 `_Downloads/Deutsch/d_operatoren_ab2023.pdf`）：analysieren / deuten / interpretieren / erörtern / Stellung nehmen / untersuchen / verfassen 等——**只用表里的动词理解题**。
- 标准流程：Einleitung (Autor/Jahr/Titel/Textsorte/These, 3句) → Analyse (Inhalt+Form+Sprache, Beleg+Zeile) → Erörterung/Stellungnahme → Schluss。
