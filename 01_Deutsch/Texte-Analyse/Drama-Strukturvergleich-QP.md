# Drama — Strukturvergleich（戏剧结构对照 · Aufgabenart Ib）

> **中文理解**：本笔记覆盖 IF2 在 Q 阶段的新增要求——**比较结构上互不相同、来自不同历史语境的两部戏剧**（KLP §2.3.1/§2.3.2 IF2 明文 `strukturell unterschiedliche Dramen aus unterschiedlichen historischen Kontexten`）[已验证]。LK 还要多一层 `poetologische Konzepte`（诗学构想对照）[已验证]。
>
> **Klausur-Relevanz**：对应 **Aufgabenart Ib**（vergleichende Interpretation）[据推断，源：`Deutsch-Oberstufe.md` §5.2]，AFB II–III。它和 `Gedichtvergleich-Ib.md` 是同一个方法论家族（比较题），**先判「比戏剧还是比诗」再动笔**——这就是本项目的交错练习重点。
>
> ⏳ **待确认：本学期 Ganzschrift 书名 + 作者未定**（老师未答复）。本笔记采用**「候选短名单 + 通用工具箱」策略**：结构维度表先建，书名公布后只需补「本书专属人物表 + 场次梗概」，**不改方法论骨架**。

## 1. 核心概念 (Kernbegriffe)

| 术语 (DE) | 中文 | English | 定义 / 识别信号 | 备注 |
|---|---|---|---|---|
| strukturell unterschiedlich | 结构上互不相同 | structurally different | 两剧在**开放/封闭形式、幕场结构、时间空间处理**上不属同一构造类型 | KLP 明文要求 [已验证] |
| geschlossene Form | 封闭形式 | closed form | 五幕、地点时间统一（Ort/Zeit/Einheit）、因果链完整 | 与 offene Form 对照 |
| offene Form | 开放形式 | open form | 多场次、时空跳跃、插曲式（Stationendrama） | 与封闭形式对照 |
| Figurenkonstellation | 人物配置 | constellation of characters | 人物之间的关系网络（对立/对称/三角） | 比较维度之一 |
| Handlungsaufbau | 情节结构 | plot structure | 幕场划分、冲突升级、Wendepunkt | KLP 四要素之一 [已验证] |
| Dialoggestaltung | 对话设计 | dialogue design | 对白/独白比例、谈话策略、语体 | KLP 四要素之一 [已验证] |
| sprachliche Gestaltung | 语言设计 | linguistic design | 语体层次、修辞、语域（Register） | KLP 四要素之一 [已验证] |
| Konfliktverlauf | 冲突走向 | course of conflict | 冲突的起点、激化、解决或僵局 | 比较的常见焦点 |
| Vergleichsmaßstab | 比较维度 | tertium comparationis | 两剧共有的可比较「尺子」 | ⚠️ 比较题的命门 |
| historischer Kontext | 历史语境 | historical context | 创作/首演时代的时代背景 | KLP 明文要求 [已验证] |
| poetologisches Konzept | 诗学构想 | poetological concept | 作者/流派对「戏剧应当如何」的主张（LK） | LK 专属 [已验证] |
| diachron / synchron | 历时 / 共时 | diachronic / synchronous | 跨时代比 vs 同时代比 | KLP QP 双轴 [已验证] |

## 2. 知识结构 (Struktur)

### 2.1 ⏳ Ganzschrift 候选短名单（书名待确认）

| 候选剧目 | 作者 | 结构类型 | 时代 | 标注 |
|---|---|---|---|---|
| Nathan der Weise | Lessing | 封闭形式（五幕·抑扬格诗体） | Aufklärung | [据推断] |
| Die Räuber | Schiller | 开放形式（多线·狂飙突进） | Sturm und Drang | [据推断] |
| Faust I | Goethe | 开放形式（场次式） | Klassik | [据推断] |
| Woyzeck | Büchner | 开放形式（碎片场次） | Vormärz | [据推断] |
| Der zerbrochne Krug | Kleist | 封闭形式（单日·三一律式） | Klassik/Romantik | [据推断] |
| Der gute Mensch von Sezuan | Brecht | 开放形式（插曲·史诗剧） | Moderne | [据推断] |
| Die Physiker | Dürrenmatt | 封闭形式（三幕·悖论收束） | Nachkrieg | [据推断] |

> ⚠️ **上表全部为 [据推断]**——不是官方指定书单，只是「两端构造」的常见代表。书名确认后，本表可整段替换为「本书专属人物表 + 场次梗概」。
>
> *Klausur-Satz*: `Die beiden Dramen gehören unterschiedlichen strukturellen Traditionen an: Während das eine der geschlossenen Form folgt, ist das andere als offene, szenisch gereihte Form angelegt.`

### 2.2 结构对照的四个维度（通用工具箱）

中文：KLP 给出的戏剧四要素——`Figurengestaltung` / `Handlungsaufbau` / `Dialoggestaltung` / `sprachliche Gestaltung`——在比较题里**直接升级为四个比较维度** [已验证]。写比较题必须**沿维度交替对照**，不许「A 剧一段、B 剧一段」并列。

| 维度 | 追问 | 典型发现 |
|---|---|---|
| Figurengestaltung 人物塑造 | 人物是单一型还是矛盾型？配置是对立还是三角？ | 一个「封闭型」人物 vs 一个「发展型」人物 |
| Handlungsaufbau 情节结构 | 幕场划分、冲突升级、有无 Wendepunkt？ | 因果链 vs 插曲式并置 |
| Dialoggestaltung 对话设计 | 对白/独白比例、谈话策略、权力关系？ | 对称对话 vs 独白式自白 |
| sprachliche Gestaltung 语言设计 | 诗体/散文、语体层次、修辞密度？ | 抑扬格诗体 vs 日常口语 |

> *Klausur-Satz*: `Im Zentrum des Vergleichs steht der Handlungsaufbau: Das erste Drama entwickelt den Konflikt in einer geschlossenen Kausalkette, während das zweite ihn in locker gereihten Szenen entfaltet.`

### 2.3 Ib 比较阐释的任务结构与两轴定位

中文：Ib 的题干通常**先给比较维度**（„Vergleichen Sie … unter dem Aspekt …“），若不给则须**自主推出维度**并明写 [据推断，源：KLP §3 Vergleichsaufgaben「比较项或给定、或须自主推出」]。QP 还要求**共时（同时代）+ 历时（跨时代）双轴** [已验证]。

> *Klausur-Satz*: `Als Vergleichsmaßstab dient die Darstellung des Konflikts; dabei ist sowohl synchron (zeitgenössische Dramen) als auch diachron (Dramen aus verschiedenen Epochen) zu vergleichen.`

### 2.4 LK 加深：poetologische Konzepte

中文：LK 在四要素之外**再加诗学构想** [已验证]——即该剧/该流派对「戏剧是什么、应当怎么演」的理论主张（如 Brecht 的 `episches Theater` 与 `Verfremdung`、Dürrenmatt 的 `Tragikomödie`、Lessings `bürgerliches Trauerspiel` 构想）。这层是 **GK 与 LK 的显性分野点**。

> *Klausur-Satz*: `Die strukturellen Unterschiede lassen sich auf unterschiedliche poetologische Konzepte zurückführen: Das eine Drama folgt der Poetik des epischen Theaters, das andere der geschlossenen Tragödienform.`

## 3. 解题方法 (Methoden)

### 3.1 Strukturvergleich 五步法

**编号步骤**：
1. **定维度（Vergleichsmaßstab）**：动笔前写一句「比的是结构（Aufbau/Dialog/Figuren）而非纯内容」—— *KLP 工具：vergleichen（II–III）*
2. **逐维度交替对照**：沿 2.2 的四个维度，**A 与 B 交替说**，每条都写「同中见异」—— *KLP 工具：in Beziehung setzen（II–III）*
3. **结构取证**：每个判断配一处 Beleg（场次号 + 一句对白/舞台指示）—— *KLP 工具：Belegpflicht（Zitat + Zeile/Szene）*
4. **历史语境归位**：把差异放回两剧各自的创作时代解释（`einordnen`）—— *KLP 工具：einordnen（I–II）*
5. **诗学收束**（LK）：把差异归结到两剧的诗学构想差异—— *KLP 工具：deuten（III）/ sich auseinandersetzen mit（II–III）*

> **判据 / 决策点**：写完自查——「有没有明确维度？有没有交替对照？有没有 Szene-Beleg？有没有历史语境？」。**只有内容并列、无结构维度 = 违反 KLP „strukturell unterschiedlich" 要求，直接掉层**。

### 3.2 比较题与诗歌比较的辨别（防混淆）

中文：`Strukturvergleich`（戏剧）与 `Gedichtvergleich`（抒情）方法同源但维度不同——戏剧看**幕场与对话**，诗歌看**格律与意象**。

> **判据 / 决策点**：题干出现 `Drama` / `Szene` / `Dialog` → 用本笔记四维度；出现 `Gedicht` / `Strophe` / `Versmaß` → 转 `Gedichtvergleich-Ib.md`。**先花 10 秒判题，再动笔**（交错练习机制）。

### 3.3 时间与分值（GK 255 / LK 315 min 中单题）

| 段落 | 占比 | 内容 |
|---|---|---|
| Einleitung | 10% | 两剧定位（作者/时代/结构类型）+ 比较维度 |
| Strukturanalyse | 45% | 四维度交替对照 + Beleg |
| Historisch-poetologische Deutung | 35% | 语境归位 + 诗学收束（LK） |
| Schluss | 10% | 整体判断 |

> **判据 / 决策点**：Abitur 含选题时间且不得中断 [已验证]；先花 10–15 min 决策选哪题。

## 4. 🇨🇳 CN-Methode

不适用（该科无中国对照技法）。理由：中国语文的戏剧教学偏**主题思想与人物性格分析**，德国 `Strukturvergleich` 的核心是**构造类型（geschlossene/offene Form）与比较维度（Vergleichsmaßstab）的显性化**。⚠️ 危险迁移：把比较写成「两剧都很深刻」或逐剧分段的读后感 = 无维度、无 Beleg，跌到 AFB I。

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | **Ib**（vergleichende Interpretation，文学文本比较阐释） |
| Operator | `vergleichen`(II–III) · `interpretieren`(I–III) · `in Beziehung setzen`(II–III) · `deuten`(III) · `einordnen`(I–II) |
| AFB | II–III（重心 II；诗学收束落 III） |
| 建议分值 / 时长 | GK 255 / LK 315 min 四选一之一；单题约 90–120 min [据推断] |

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> `Vergleichen Sie den Handlungsaufbau der beiden Dramen. Bestimmen Sie zu Beginn Ihren Vergleichsmaßstab und belegen Sie Ihre Beobachtungen an je einer Szene.`
> （设问结构参照 NRW Ib 比较题；所比剧目自拟，非官方指定书目）

**Aufgabe 2** `[原创]`
> `Vergleichen Sie die Dialoggestaltung in den beiden Dramen und erläutern Sie, inwiefern die Unterschiede mit den jeweiligen historischen Kontexten zusammenhängen.`

**Aufgabe 3** `[原创]`
> `Vergleichen Sie die Figurenkonstellation der beiden Dramen unter dem Aspekt des Konflikts. Berücksichtigen Sie dabei mindestens einen synchronen und einen diachronen Vergleichspunkt.`

**Aufgabe 4（LK，III）** `[原创]`
> `Vergleichen Sie die beiden Dramen und erläutern Sie, inwiefern ihre strukturellen Unterschiede auf unterschiedliche poetologische Konzepte zurückzuführen sind.`

### 5.3 Musterlösung

**Aufgabe 1**
1. Vergleichsmaßstab：`Als Maßstab dient der Handlungsaufbau.` ✓ 得分点（维度先行）
2. 交替对照：`Während Drama A den Konflikt in einer geschlossenen Kausalkette entwickelt, reiht Drama B die Handlung in locker verbundenen Szenen.` ✓ 得分点（交替，不逐剧分段）
3. Beleg A：`Dies zeigt sich etwa in der geradlinigen Zuspitzung der dritten Szene von Drama A.` ✓ 得分点（Szene-Beleg）
4. Beleg B：`In Drama B dagegen folgen die Szenen ohne durchgehende Steigerung aufeinander.` ✓ 得分点（第二剧 Beleg）
5. 收束：`Damit stehen sich eine geschlossene und eine offene Dramenform gegenüber.` ✓（AFB II 判断）
- Operator 对应：`vergleichen`(II–III) + `in Beziehung setzen`(II–III)。

**Aufgabe 2**
1. 维度声明：`Verglichen wird die Dialoggestaltung.` ✓
2. 对照：`Drama A gestaltet den Konflikt überwiegend in symmetrischen Dialogen, Drama B in langen Monologen und Selbstgesprächen.` ✓ 得分点（术语 + 对照）
3. 语境归位：`Die monologische Anlage von Drama B verweist auf die Krise des Subjekts in seinem historischen Kontext.` ✓ 得分点（einordnen）
- Operator 对应：`vergleichen`(II–III) + `erläutern`(II–III)。

**Aufgabe 3**
1. 维度：`Verglichen wird die Figurenkonstellation.` ✓
2. 共时点：`Beide Dramen stellen eine Figurengruppe um eine zentrale Konfliktfigur.` ✓ 得分点（synchron）
3. 历时点：`Im älteren Drama ist die Konstellation ständisch geordnet, im jüngeren sind die sozialen Positionen verschwommen.` ✓ 得分点（diachron）
4. 权衡：`Der Vergleich zeigt, dass sich die Konfliktstruktur von einer ständischen zu einer individuellen verschiebt.` ✓（AFB III）
- Operator 对应：`vergleichen`(II–III) + `in Beziehung setzen`(II–III)。

**Aufgabe 4（LK）**
1. 结构差异陈述：`Drama B verzichtet auf die geschlossene Handlungsführung von Drama A.` ✓
2. 诗学归因：`Diese Differenz folgt aus unterschiedlichen poetologischen Konzepten: A folgt der geschlossenen Tragödienpoetik, B der Poetik des epischen Theaters.` ✓ 得分点（LK 专属，poetologische Konzepte）
3. 效果说明：`Die offene Form soll beim Publikum Distanz und Reflexion erzeugen.` ✓（AFB III）
- Operator 对应：`deuten`(III) + `sich auseinandersetzen mit`(II–III)。

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把「比较」写成两剧各自独立的分析（A 一段、B 一段）；把 Strukturvergleich 与 Gedichtvergleich 的维度互串 | 强制「先写 Vergleichsmaßstab 一句」；判题先辨文本类型 |
| 知识错 | 只比内容不比结构（违反 KLP „strukturell unterschiedlich"）；历史语境写错时代顺序 | 背 2.2 四维度表；时代年表三轮默写 |
| 表达错 | 用「很精彩/很深刻」替代 `geschlossene/offene Form` / `Figurenkonstellation`；Beleg 无 Szene 号 | 用 §2.2 术语；每处 Beleg 带场次号 |
