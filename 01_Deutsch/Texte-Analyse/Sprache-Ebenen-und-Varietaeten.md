# Sprache: Ebenen und Varietäten (语言：层面与变体)

> **中文理解**：IF1 Sprache 是**工具层 IF**——它本身很少单独成题，但 IIa 的 `sprachliche Gestaltung` 分析、Ia 的语言设计分析全部靠它供货。EF 层有三个必考重点：① 语言的**功能与结构特征**（Phonologie / Morphologie-Syntax / Semantik-Pragmatik 五层）；② **语言变体及其社会意义**（Dialekt / Soziolekt / Regiolekt / Distinktion / Identität）；③ **当代语言的变化**（Mündlichkeit vs. Schriftlichkeit）。Q 阶段在此之上加 `Sprache-Denken-Wirklichkeit`、`Sprachgeschichtlicher Wandel（gesteuert/ungesteuert）`，LK 再加 `Sprachskepsis` 与 `Spracherwerbstheorien`。
>
> **Klausur-Relevanz**：本笔记覆盖的每个术语，都是 IIa 语言分析段的**弹药**。术语叫错（如 `Hypotaxe` 写成 „lange Sätze“）= 命中九项评价标准第 8 项 Fachsprache；术语对了但不说 Wirkung = 卡在 AFB I。本 IF 在 EF 与 QP 全周期复用 [已验证]。

## 1. 核心概念 (Kernbegriffe)

| 术语 (DE) | 中文 | English | 定义 / 识别信号 | 备注 |
|---|---|---|---|---|
| Phonologie | 语音学层面 | phonology | 重音、停顿、头韵、拟声、元音重复等**声音**手段 | EF 五层之一 [已验证] |
| Morphologie | 词法 | morphology | 词形变化、构词（Kompositum / Derivation） | 与 Syntax 常合并分析 |
| Syntax | 句法 | syntax | 句子构造：长短句、Hypotaxe/Parataxe、被动、句序 | IIa 核心砖块 |
| Semantik | 语义 | semantics | 词义选择：Denotation（本义）/ Konnotation（附义） | 与 Pragmatik 交接 |
| Pragmatik | 语用 | pragmatics | 言外之意、语境功能、Anspielung（暗示） | AFB II→III 过渡点 |
| Sprachvarietät | 语言变体 | language variety | 同一语言的社会/地域/功能分化形式 | 上位概念 |
| Dialekt | 方言 | dialect | **地域**变体（如 Bayrisch, Kölsch） | 与 Soziolekt 最易混 |
| Soziolekt | 社会方言 | sociolect | **阶层/群体**变体（如 Jugendsprache, Kiezdeutsch） | 与 Dialekt 最易混 |
| Regiolekt | 区域变体 | regiolect | 介于标准语与方言之间的地区性说法 | 三档：Standard – Regiolekt – Dialekt |
| Distinktion | 区分功能 | distinction | 变体**标记群体边界**与social距离 | 变体的社会功能之一 |
| Identifikation über Sprache | 语言身份认同 | identification | 变体**表达归属与自我认同** | KLP 原文用词 [已验证] |
| Mündlichkeit | 口语性 | orality | 省略、重复、修正、插入语、即兴互动 | 与 Schriftlichkeit 对照 |
| Schriftlichkeit | 书面性 | literacy | 长句、衔接、名词化、规范、面向受众 | 与 Mündlichkeit 对照 |
| gesteuert / ungesteuert | 有控 / 无控 | controlled / uncontrolled | 语言变迁是否被**有意识干预**（如 Sprachpurismus） | QP 新重点 [已验证] |
| Sprachskepsis | 语言怀疑论 | language skepticism | 「语言能否如实表达世界」的怀疑立场 | **LK 专属** [已验证] |

## 2. 知识结构 (Struktur)

### 2.1 Sprachebenen und Funktionen（五层结构）

中文：语言分析不能只「贴标签」，要沿**五层**逐层取证。每层的识别信号不同，但答题句式一致：`Mittel（手段）→ Beleg（引用+行号）→ Wirkung（作用）`。

> *Klausur-Satz*: `Auf der Ebene der Syntax fällt die Häufung von Hypotaxen auf (Z. 3–5), die den Gedankengang verdichtet und den Leser zum langsamen Mitdenken zwingt.`

- **Phonologie** `[EF]`：头韵（Alliteration）、元音重复（Assonanz）、拟声（Lautmalerei）、重音与节奏（Rhythmisierung）。识别信号 = **听到的**重复。
- **Morphologie-Syntax** `[EF]`：`Parataxe`（短句并列）vs. `Hypotaxe`（长句嵌套）、`Ellipse`（省略）、`Anapher`（首语重复）、`Passiv`、`Inversion`。识别信号 = **句长与句式**。
- **Semantik-Pragmatik** `[EF]`：`Denotation` vs. `Konnotation`、`Metapher`、`Ironie`、`Euphemismus`。识别信号 = **词义是否超出字面**。

> *Klausur-Satz*: `Das Euphemismus „[Wort]“ (Z. [..]) verharmlost [Sachverhalt] und verschleiert damit die eigentliche Intention des Autors.`

### 2.2 Sprachvarietäten und ihre gesellschaftliche Bedeutung

中文：变体题的核心不是「他说得不一样」，而是「这种不一样**承担什么社会功能**」。两大功能：`Distinktion`（划界）与 `Identifikation`（认同）。

> *Klausur-Satz*: `Der Gebrauch des Soziolekts dient hier der Distinktion: Die Figur grenzt sich durch ihre Jugendsprache bewusst von der Erwachsenenwelt ab (vgl. Z. [..]).`

- **Distinktion** `[EF]`：变体标记**群体边界**。常用于戏剧人物分析（谁说什么话 = 谁在什么位置）。
- **Identität** `[EF]`：变体表达**归属与自我认同**（`sprachliche Zuschreibungen`）。
- **Varietätenvergleich** `[EF]`：比较两变体的用词/句式/场合。⚠️ 必须给 `Vergleichsmaßstab`（比较维度），否则缺 AFB III。
- **Dialekt-Soziolekt** `[Q1-Q2]`：判定地域变体 vs. 阶层变体。判别卡：**地域可定位** → Dialekt；**群体可定位** → Soziolekt。

> *Klausur-Satz*: `Während die erste Äußerung eindeutig dialektal gefärbt ist (regionale Lautung), verweist die zweite auf einen Soziolekt, der an die soziale Gruppe der Jugendlichen gebunden ist.`

### 2.3 Mündlichkeit vs. Schriftlichkeit

中文：这不是「好/坏」判断，而是**媒介条件**决定的特征差异。口语特征出现在文学对白里 ≠ 作者水平差，而是 Gattung 需要。

> *Klausur-Satz*: `Die Ellipsen und Wiederholungen (Z. [..]) sind keine sprachlichen Fehler, sondern Merkmale der Mündlichkeit, die die Spontaneität des Gesprächs abbilden.`

| 维度 | Mündlichkeit | Schriftlichkeit |
|---|---|---|
| 句法 | 短句、省略、插入语 | 长句、Hypotaxe、衔接 |
| 词汇 | 口语词、语气词 | 名词化、Fachwortschatz |
| 结构 | 即兴、修正、重复 | 规划、连贯、面向受众 |
| 场景 | 面对面、互动 | 距离、异步 |

### 2.4 Gegenwartssprache-Wandel `[Q1-Q2]`

中文：当代语言变迁题要区分**有控**与**无控**两种形式。`ungesteuert` = 自然演变（如 Anglizismen、Jugendsprache）；`gesteuert` = 有意识干预（Sprachpolitik、Rechtschreibreform、Vereinfachung）。

> *Klausur-Satz*: `Die Übernahme englischer Begriffe ist ein weitgehend ungesteuerter Wandel, während die Rechtschreibreform ein Beispiel für gesteuerte Sprachveränderung darstellt.`

### 2.5 Sprache-Denken-Wirklichkeit（QP 加深，简述）

中文：EF 只做「结构描写」；GK 加「符号—表象—对象」关系；LK 再加 `Sprachskepsis` 与 `Spracherwerbstheorien`。⚠️ `Sprachskepsis` 常被误读成「主题悲观」——它是**认识论立场**，不是情绪。

> *Klausur-Satz*: `Sprachskepsis meint nicht Weltuntergangsstimmung, sondern die erkenntnistheoretische Frage, ob Sprache Wirklichkeit überhaupt adäquat abbilden kann.`

## 3. 解题方法 (Methoden)

### 3.1 五层扫描法（Sprachliche Analyse）

**编号步骤**：
1. **定功能**：先问「这段语言要干什么」——informieren / appellieren / charakterisieren？—— *KLP 工具：Funktionen und Strukturmerkmale der Sprache*
2. **逐层扫**：Phonologie → Morphologie-Syntax → Semantik-Pragmatik，每层只记**最突出的一个**信号 —— *KLP 工具：五层 aspekte*
3. **三步链成句**：`Mittel + Beleg(Zitat, Z.) + Wirkung` —— *KLP 工具：sprachliche Gestaltung 分析要求*
4. **回扣意图**：把语言观察接到 `Intention`（作者想达到什么）—— *KLP 工具：Leserlenkung / Intention*
5. **AFB 定位**：只描写 = I；接功能 = II；判价值 = III —— *KLP 工具：AFB 三级定义*

> **判据 / 决策点**：题干是 `beschreiben`（只要客观呈现）还是 `analysieren`（要功能关联）？前者停在步骤 2，后者必须走完 3–4。

### 3.2 变体判别法（Dialekt vs. Soziolekt）

**编号步骤**：
1. **看可定位性**：能指到**地图上的地区** → Dialekt；能指到**社会群体** → Soziolekt —— *KLP 工具：Sprachvarietäten*
2. **看功能**：划界（Distinktion）还是认同（Identifikation）—— *KLP 工具：gesellschaftliche Bedeutung*
3. **给 Beleg**：引用具体语言信号（词/音/句式）+ 行号 —— *KLP 工具：Belegpflicht*
4. **写功能句**：`Der Varietätgebrauch fungiert als …` —— *KLP 工具：Funktion 描述*

> **判据 / 决策点**：如果两者都沾（如 Kiezdeutsch = 群体 + 地域），要**说明主导维度**，不能只贴一个标签。

## 4. 🇨🇳 CN-Methode

不适用（该科无中国对照技法）。理由：德语语言层面分析（Phonologie/Morphologie/Syntax 三分）对应的是德语语法的**本土描写传统**，中文的「字词句篇」层级与之不可直接映射；变体分析（Dialekt/Soziolekt）也没有中文可迁移的对应工具。**唯一可迁移的是「先找手段、再说作用」的分析习惯**，但那已是德国 KLP 本身的方法论，非中国特有。

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | **IIa**（主）/ Ia / IIIa（次） |
| Operator | `untersuchen`(II) · `analysieren`(I–III) · `beschreiben`(I–II) · `deuten`(III) · `erläutern`(II–III) |
| AFB | I–III，重心 II |
| 建议分值 / 时长 | ZKE 100 min 中语言段约占 25–30 min；GK 255 min 中占 40–50 min [据推断] |

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> `Beschreiben Sie die sprachlichen Mittel in den ersten beiden Sätzen und ordnen Sie sie in ihrer Wirkung ein. Belegen Sie mit Zeilenangabe.`
（题干结构参照 NRW IIa 的 `sprachliche Gestaltung` 设问；例文自写）

**Aufgabe 2** `[原创]`
> `Analysieren Sie, wie die Sprechweise der Hauptfigur ihre soziale Position markiert. Bestimmen Sie die Varietät (Dialekt oder Soziolekt) und begründen Sie Ihre Entscheidung.`

**Aufgabe 3** `[NRW-改编]`
> `Erläutern Sie an zwei Beispielen, ob es sich bei den beschriebenen Sprachveränderungen um gesteuerte oder ungesteuerte Formen handelt.`

**Aufgabe 4（LK 加深）** `[原创]`
> `Erörtern Sie, ob Sprachkritik an Anglizismen als berechtigte Sorge oder als sprachpuristische Übersteigerung zu bewerten ist.`

### 5.3 Musterlösung

**Aufgabe 1**
1. 定位第一句为 `Hypotaxe`（嵌套长句），第二句为 `Parataxe`（短句并列）。✓ 得分点（Mittel 命名准确）
2. 给出 Beleg：`„…“ (Z. 1)` 与 `„…“ (Z. 2)`。✓ 得分点（Zitat + Zeile）
3. 写 Wirkung：长句 = 论证密度；短句 = 强调、加速。✓ 得分点（Wirkung，AFB II）
4. 回扣：两句的反差制造 `Spannungsbogen`，为论点铺垫。✓ 得分点（回扣 Intention）
- Operator 对应：`beschreiben`（I–II）+ `einordnen`（I–II）→ 达标即 AFB II。

**Aufgabe 2**
1. 引用人物语言信号：`„Ey, is‘ doch egal“ (Z. [..])` —— 短引示例，标行号。✓
2. 判定：属 `Soziolekt`（Jugendsprache），非 Dialekt——理由：信号绑定**社会群体**而非**地域**。✓ 得分点（判别正确）
3. 功能句：`Die Sprechweise fungiert als Distinktion gegenüber der Erwachsenenwelt.` ✓ 得分点（Funktion）
4. 回扣人物：语言 = 权力关系标记。✓
- Operator 对应：`analysieren`（I–III）+ `begründen`（III）。

**Aufgabe 3**
1. 例一 `ungesteuert`：英语借词自然渗入日常语。✓
2. 例二 `gesteuert`：官方正字法改革/语言政策干预。✓
3. 判据句：`Gesteuert ist Wandel dann, wenn er auf bewusster Intervention beruht.` ✓
- Operator 对应：`erläutern`（II–III）。

**Aufgabe 4（LK）**
1. 一面：借词确实带来理解负担（Angst vor Verlust der Präzision）。✓
2. 另一面：语言变迁本就 ungesteuert，纯化诉求常忽略语言的生命力。✓
3. 权衡 + 自己的判断：`Wägt man ab, so wiegt die funktionale Toleranz schwerer als die puristische Sorge.` ✓（AFB III）
- Operator 对应：`erörtern`（I–III）。

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | Dialekt 与 Soziolekt 混用；`Denotation` 与 `Konnotation` 混用；`Hypotaxe` 与 `Parataxe` 写反 | 建判别卡：地域→Dialekt / 群体→Soziolekt |
| 知识错 | 把 `Sprachskepsis` 当「主题悲观」；`gesteuert`/`ungesteuert` 判定反 | 先背 KLP 定义再举例 |
| 表达错 | 用 „klingt stark“ / „lange Sätze“ 替代 `Rhythmisierung` / `Hypotaxe`；只 `nennen` 术语不给 Wirkung | 强制三步链 `Mittel + Beleg + Wirkung` |
