# Kommunikationsmodelle（交际模型 · Sender-Empfänger / Störung / Alltagsgespräch）

> **中文理解**：IF3 的**本体层笔记**。KLP EF 明确列出三条内容重点：`Alltagskommunikation / literarisch gestaltete Kommunikation`、`monologische und dialogische Kommunikation`、`Kommunikationsmodelle` [已验证，源：`Deutsch-Oberstufe.md` §2 IF3]。IF3 **不直接充当考试对象**，但 **IIa / IIIa / IIIb 的「读者引导 / 论辩 / 操纵」分析全部依赖它** [据推断，依 §5.3 结论 2]。本笔记覆盖：**Sender-Empfänger 模型**、**Störung 与 Missverstehen**、**日常谈话特征**。
>
> **Klausur-Relevanz**：模型是**分析工具**而非装饰——用模型「贴标签」而不产出分析结论 = 失分。典型错误：① 只用模型贴标签；② `Sender/Empfänger` 与 `Autor/Leser` 混用；③ 把「误解」一律归因于「表达不清」，忽略 `asymmetrische Kommunikation` 与意图性操纵。

## 2. 知识结构 (Struktur)

### 2.1 Sender-Empfänger 模型

中文：最基础的**线性模型**——Sender 把讯息**编码**，经**渠道**传给 Empfänger，后者**解码**。它帮你快速定位交际要素（谁、对谁、说什么、经什么渠道、有何干扰）。

> *Klausur-Satz*: `Das Modell beschreibt Kommunikation als Übertragung einer Botschaft vom Sender zum Empfänger, wobei die Nachricht kodiert und vom Empfänger dekodiert wird.`

⚠️ **铁律**：`Sender/Empfänger` 是**交际模型**中的角色，`Autor/Leser` 是**文本交际**中的角色——二者**不能混用**。

> *Klausur-Satz*: `Der Sender ist nicht mit dem Autor gleichzusetzen: Das Modell beschreibt eine Kommunikationssituation, nicht die Beziehung zwischen Verfasser und Publikum.`

**模型的局限**（体现 Differenziertheit）：
| 优点 | 局限 |
|---|---|
| 快速定位交际要素 | 过于线性，忽视反馈 |
| 便于发现干扰 | 不反映关系层 |
| 适用技术性交际 | 难解释误解的深层原因 |

### 2.2 Störung 与 Missverstehen

中文：**Störung** 是妨碍讯息传递的因素（技术性 / 语义性 / 心理性）；**Missverstehen** 是解码结果偏离编码意图。**误解 ≠ 操纵**——前者多为无意的偏差，后者是有意图的引导 [据推断]。

> *Klausur-Satz*: `Die Störung führt dazu, dass die Botschaft beim Empfänger anders dekodiert wird, als der Sender sie gemeint hat.`

⚠️ **最易混**：把一切误解归因于「表达不清」，忽略**非对称交际**（`asymmetrische Kommunikation`：一方掌握更多话语权）与**意图性操纵**。

> *Klausur-Satz*: `Nicht jede Störung beruht auf unklarer Formulierung; in asymmetrischer Kommunikation kann die Deutung gezielt gesteuert werden.`

### 2.3 Alltagsgespräch vs literarischer Dialog

中文：**日常谈话**是即兴、合作、目的多元的；**文学对话**是**人工设计（Gestaltung）**的，服务主题与人物 [据推断]。

| 特征 | Alltagsgespräch | Literarischer Dialog |
|---|---|---|
| 产生方式 | 即兴 | 人工设计 |
| 目的 | 多元、实用 | 服务主题/人物 |
| 结构 | 松散、可中断 | 有功能、有推进 |
| 受众 | 谈话参与者 | 读者 |

> *Klausur-Satz*: `Anders als das Alltagsgespräch ist der literarische Dialog künstlich gestaltet und dient der Figurenzeichnung und Themenentfaltung.`

⚠️ **文类错位**：用日常交际的规则去评价文学对话 = 知识错。

### 2.4 Monolog vs Dialog（交际形式）

中文：KLP EF 明列 `monologische und dialogische Kommunikation` [已验证]。**独白** = 单向（内心独白、演讲）；**对话** = 双向（轮流发言、回应）。

> *Klausur-Satz*: `Der Monolog ist durch Einseitigkeit gekennzeichnet, der Dialog durch wechselseitigen Bezug der Beiträge.`

## 3. 解题方法 (Methoden)

### 3.1 交际情境分析五步法

**编号步骤**：
1. **定位要素**：Sender / Empfänger / Botschaft / Kanal —— *KLP 工具：darstellen（I–II）*
2. **判定形式**：monologisch 还是 dialogisch —— *KLP 工具：einordnen（I–II）*
3. **找干扰**：技术性 / 语义性 / 心理性 Störung —— *KLP 工具：untersuchen（II）*
4. **判误解**：解码结果是否偏离意图 —— *KLP 工具：erläutern（II–III）*
5. **下结论**：交际是否成功，为什么 —— *KLP 工具：deuten（III）*

> **判据 / 决策点**：模型只作**定位工具**——每步之后必须**产出分析结论**，否则模型成了装饰。

### 3.2 误解 vs 操纵 判别法

**编号步骤**：
1. 问「偏离是**无意**还是**有意**」—— *KLP 工具：untersuchen（II）*
2. 问「是否存在**话语权不对等**」—— *KLP 工具：erläutern（II–III）*
3. 问「有无**引导手段**（修辞、省略、暗示）」—— *KLP 工具：analysieren（I–III）*
4. 下判：Missverstehen（无意的偏差）/ Manipulation（有意的引导）—— *KLP 工具：deuten（III）*

> **判据 / 决策点**：⚠️ 判定 Manipulation 必须**有文本证据**，不能仅凭「对方是权威」。

### 3.3 日常 vs 文学对话对照法

**编号步骤**：
1. 列日常谈话特征（即兴 / 合作 / 可中断）—— *KLP 工具：beschreiben（I–II）*
2. 列文学对话特征（设计 / 功能 / 推进）—— *KLP 工具：beschreiben（I–II）*
3. 逐条对照，指出文类差异的功能 —— *KLP 工具：in Beziehung setzen（II–III）*

> **判据 / 决策点**：若题干问「为何此处对话显得不自然」→ 正是 `Künstlichkeit`（人工性）在起作用。

## 4. 🇨🇳 CN-Methode

不适用（该科无中国对照技法）。理由：德语 `Kommunikationsmodelle`（Sender-Empfänger / Störung / 关系层）是**交际学**的分析框架，其判据是「要素定位 + 干扰归因 + 意图判定」；中文语文教学中的「口语交际」偏重**得体性与情境应对**，不提供可迁移的模型化分析工具。⚠️ 危险迁移：把「情商 / 说话得体」的评价标准套进德语交际分析 = 缺 Fachbegriff、缺判据。

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | **IIa / IIIa** 的交际分析视角（IF3 为次 IF，不单独成题）[据推断] |

| 建议分值 / 时长 | 作为分析段的一部分，非独立大题 [据推断] |

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> `Beschreiben Sie die Kommunikationssituation des vorliegenden Gesprächsauszugs. Bestimmen Sie Sender, Empfänger und die Form der Kommunikation.`
> （设问结构参照 NRW IF3 分析问；对话自写）

**Aufgabe 2** `[原创]`
> `Untersuchen Sie, an welcher Stelle es zu einer Störung kommt und wie diese das Verständnis beeinflusst.`

**Aufgabe 3** `[NRW-改编]`
> `Erläutern Sie den Unterschied zwischen einem Missverstehen und einer gezielten Manipulation. Belegen Sie Ihre Unterscheidung am Text.`

**Aufgabe 4** `[原创]`
> `Vergleichen Sie das vorliegende Alltagsgespräch mit einem literarisch gestalteten Dialog hinsichtlich ihrer Funktion.`

### 5.3 Musterlösung

**Aufgabe 1**
1. 要素定位：`Sender ist Figur A, Empfänger Figur B; die Botschaft betrifft eine Verabredung.` ✓ 得分点（要素完整）
2. 形式：`Es handelt sich um dialogische Kommunikation mit wechselseitigen Beiträgen.` ✓ 得分点（形式判定）
3. 补充：`Der Kanal ist mündlich-direkt.` ✓
- Operator 对应：`beschreiben`(I–II) + `einordnen`(I–II)。

**Aufgabe 2**
1. 干扰定位：`Die Störung entsteht, als A einen Vorwurf nur andeutet (vgl. Z. [..]).` ✓ 得分点（定位 + Beleg）
2. 类型：`Es handelt sich um eine semantische Störung, da die Andeutung mehrdeutig bleibt.` ✓
3. 影响：`B deutet die Andeutung als Angriff, obwohl A sie neutral meint.` ✓ 得分点（影响分析）
- Operator 对应：`untersuchen`(II) + `erläutern`(II–III)。

**Aufgabe 3**
1. 定义 Missverstehen：`Ein Missverstehen ist eine unbeabsichtigte Abweichung der Deutung.` ✓ 得分点
2. 定义 Manipulation：`Eine Manipulation ist eine gezielte Steuerung der Deutung.` ✓
3. 文本证据：`Im Text fehlen Hinweise auf Absicht, daher liegt ein Missverstehen vor.` ✓ 得分点（判据 + 证据）
- Operator 对应：`erläutern`(II–III) + `deuten`(III)。

**Aufgabe 4**
1. 日常特征：`Das Alltagsgespräch ist spontan und dient der Verständigung.` ✓
2. 文学特征：`Der literarische Dialog ist gestaltet und dient der Figurenzeichnung.` ✓ 得分点（对照）
3. 判断：`Die Künstlichkeit des literarischen Dialogs ist kein Mangel, sondern eine Funktion.` ✓（AFB III）
- Operator 对应：`vergleichen`(II–III) + `in Beziehung setzen`(II–III)。

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | `Sender/Empfänger` 与 `Autor/Leser` 混用；用日常规则评价文学对话（文类错位） | 明确区分「交际模型角色」与「文本交际角色」 |
| 知识错 | 把误解一律归因于「表达不清」，忽略非对称交际与意图性操纵 | 用 §3.2 判别法，先问「无意还是有意」 |
| 表达错 | 只用模型贴标签不产出结论；用日常口语替代 Fachbegriff | 每步模型分析后必写结论句；术语化表达 |
