# Aufgabenart III — Erörterung（论辩题型 · IIIa / IIIb）

> **中文理解**：Aufgabenart III 是 Abitur 四类题型中**结构最特殊**的一类。**IIIa** = 实用文本论辩（就文本的命题展开正反权衡）；**IIIb** = 文学文本论辩，但 KLP 原文限定为 `auf der Grundlage eines pragmatischen Textes`——**基础仍是一篇实用文本**，考生必须在「实用文本命题」与「文学文本」之间架桥 [已验证，源：`Deutsch-Oberstufe.md` §5.2]。因此 IIIb 是**双素材题型**，是本项目**唯一零覆盖**的高风险缺口 [据推断]。
>
> **Klausur-Relevanz**：四选一必含一题；AFB II–III 为主，收束于**自己的有据判断**。三大典型失分：① 只给正反两面**不给自己的判断**（官方定义要求 `letztlich zu einem Urteil gelangen`）；② IIIb 漏答那篇实用文本（半个题没答）；③ `prüfen`（III）与 `überprüfen`（II–III）混用——**官方表中两词不同级**。

## 2. 知识结构 (Struktur)

### 2.1 IIIa 与 IIIb 的分野

中文：**IIIa 只有一个对象**（实用文本的命题）；**IIIb 有两个对象**——论辩议题来自文学文本，但**论证的地基是一篇实用文本**。这意味着 IIIb 的答卷里必须**先出现实用文本的立场与论证**，再把它与文学文本挂钩。

> *Klausur-Satz*: `Die Aufgabe verlangt eine Erörterung auf der Grundlage des vorliegenden pragmatischen Textes; dessen Position und Argumentationsgang bilden das Fundament der eigenen Stellungnahme.`

⚠️ **铁律**：IIIb 中若只谈文学文本、完全不提那篇实用文本，等于**漏答半个题** [据推断，依 KLP §4 原文限定]。

> *Klausur-Satz*: `Der pragmatische Text liefert die These, der literarische Text das Anschauungsmaterial — beide müssen aufeinander bezogen werden.`

### 2.2 Erörterung 的三层结构

中文：官方定义要求三步——**① 呈现争议命题 → ② 正反权衡 → ③ 形成自己的有据判断**。第二步不是「A 面一段、B 面一段」的并列，而是**带权衡的对话**。

> *Klausur-Satz*: `Zunächst wird die im Text vertretene These herausgearbeitet, anschließend werden Pro- und Contra-Argumente abgewogen, um schließlich ein begründetes eigenes Urteil zu formulieren.`

**权衡的三个动作**（缺一即掉 AFB III）：
| 动作 | 德语信号 |
|---|---|
| 让步（承认对方部分合理） | `Zwar … , jedoch …` / `Einerseits …` |
| 反驳（给出更强理由） | `Allerdings greift dieses Argument zu kurz, weil …` |
| 收束判断 | `Wägt man beide Seiten ab, überwiegt … , sodass …` |

### 2.3 官方 Operator 的层级陷阱

中文：⚠️ **Deutsch 特有**——官方 Operatoren 表中 `prüfen` = **III**（纯反思层），而 `überprüfen` = **II–III**（含复核层）[已验证]。两者**不能互换**。同时 `erörtern` 跨 I–III，**必须读题干限定语**判层级。

> *Klausur-Satz*: `Während „prüfen“ eine eigene begründete Bewertung verlangt, meint „überprüfen“ das kritische Nachfragen anhand vorgegebener Kriterien.`

| 题干措辞 | 实际 AFB | 答法 |
|---|---|---|
| `stellen Sie die Position des Textes dar` | I | 只复述立场 |
| `erörtern Sie die Argumente des Textes` | II | 拆正反 + 权衡 |
| `erörtern Sie, ob … ; nehmen Sie Stellung` | III | 权衡 + 有据判断 |

## 3. 解题方法 (Methoden)

### 3.1 Erörterung 五步法（IIIa / IIIb 通用）

**编号步骤**：
1. **议题提取**：用一句话写出待论辩命题（These）—— *KLP 工具：darstellen / zusammenfassen*
2. **地基复原**：IIIb 必做——复原实用文本的 `Argumentationsgang` —— *KLP 工具：untersuchen（II）*
3. **正反成对**：至少 2 Pro + 2 Contra，每条带理由或例子 —— *KLP 工具：erörtern（I–III）*
4. **权衡与让步**：用 `Zwar … jedoch …` 结构逐对权衡 —— *KLP 工具：sich auseinandersetzen mit（II–III）*
5. **判断收束**：给出**自己的、有理由的**判断（不是「两面都有道理」）—— *KLP 工具：begründen（III）/ (kritisch) Stellung nehmen（III）*

> **判据 / 决策点**：动笔前 10 秒把题干译成中文动作——「复述立场」→ 停在 I 层；「权衡」→ II 层；「表态/判断」→ III 层。

### 3.2 IIIb 架桥法

**编号步骤**：
1. 先定位实用文本的**命题**（它主张什么）—— *KLP 工具：untersuchen*
2. 再定位文学文本的**对应呈现**（它如何演示/反证该命题）—— *KLP 工具：interpretieren（I–III）*
3. 建立**关联句**：实用文本的抽象命题 ↔ 文学文本的具体形象 —— *KLP 工具：in Beziehung setzen（II–III）*
4. 在权衡中**交替使用两个文本的证据** —— *KLP 工具：erörtern*
5. 判断句须**同时回扣两文本** —— *KLP 工具：begründen*

> **判据 / 决策点**：自查答卷——「有没有一句话同时提到实用文本与文学文本？」没有 → IIIb 未答完。

### 3.3 时间与结构配比（GK 255 / LK 315 min 中单题）

| 段落 | 占比 | 内容 |
|---|---|---|
| Einleitung | 10% | 议题引入 + 文本定位 |
| Textgrundlage | 20% | 实用文本立场与论证复原（IIIb 必写） |
| Abwägung | 45% | 正反成对权衡（主体） |
| Schluss | 25% | 自己的有据判断 |

> **判据 / 决策点**：Abitur Arbeitszeit **含选题时间且不得中断** [已验证]；先花 10–15 min 做选题决策。

## 4. 🇨🇳 CN-Methode

不适用（该科无中国对照技法）。理由：德语 `Erörterung` 的判据是**官方定义的「形成判断」义务**与**论证透明**（每个结论有 weil/da 支撑），其评价维度（九项标准第 6 项 `argumentative Begründung`）与中文议论文「论点—论据—论证」表面相似，但**德语要求权衡过程可见、让步显式化**，且**禁止无文本依据的表态**。⚠️ 危险迁移：把中文议论文的「排比气势 + 空泛升华」搬进答卷 = `sachliche Richtigkeit` 与 `Fachsprache` 双失分。

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | **III**（IIIa 实用文本论辩 / IIIb 文学文本论辩，基础为实用文本） |
| Operator | `erörtern`(I–III) · `begründen`(III) · `prüfen`(III) · `überprüfen`(II–III) · `(kritisch) Stellung nehmen`(III) |
| AFB | II–III（重心 III） |
| 建议分值 / 时长 | GK 255 min / LK 315 min 四选一之一；单题约 90–120 min [据推断] |

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> `Erörtern Sie, ob die im Text vertretene Forderung nach mehr Selbstverantwortung im Umgang mit digitalen Medien tragfähig ist. Nehmen Sie abschließend begründet Stellung.`
> （设问结构参照 NRW IIIa；材料自写）

**Aufgabe 2** `[原创]`
> `Analysieren Sie zunächst den Argumentationsgang des pragmatischen Textes. Erörtern Sie anschließend, inwiefern der literarische Text die dort vertretene These bestätigt oder infrage stellt.`
> （IIIb 混合题型训练：先复原实用文本，再挂钩文学文本）

**Aufgabe 3** `[NRW-改编]`
> `Prüfen Sie die These des Textes auf ihre Stichhaltigkeit. Berücksichtigen Sie dabei mindestens ein Gegenargument und wägen Sie beide Seiten ab.`

**Aufgabe 4（LK 加深）** `[原创]`
> `Erörtern Sie, inwiefern das im pragmatischen Text entworfene Menschenbild mit dem des literarischen Textes vereinbar ist. Beziehen Sie Ihre Position auf beide Textgrundlagen.`

### 5.3 Musterlösung

**Aufgabe 1**
1. 议题提取：`Der Text fordert mehr Eigenverantwortung im Umgang mit digitalen Medien.` ✓ 得分点（命题清晰）
2. Pro：`Für die These spricht, dass Eigenverantwortung die Medienkompetenz stärkt.` ✓
3. Contra：`Dagegen lässt sich einwenden, dass Nutzer ohne strukturelle Regulierung überfordert werden.` ✓ 得分点（正反成对）
4. 权衡：`Zwar ist Eigenverantwortung wichtig, jedoch greift sie zu kurz, solange Algorithmen Aufmerksamkeit gezielt binden.` ✓ 得分点（让步 + 反驳）
5. 判断：`Wägt man beide Seiten ab, überwiegt eine Kombination aus Eigenverantwortung und verbindlichen Regeln.` ✓ 得分点（AFB III，自己的有据判断）
- Operator 对应：`erörtern`(I–III) + `(kritisch) Stellung nehmen`(III)。

**Aufgabe 2（IIIb）**
1. 实用文本论证复原：`Der pragmatische Text argumentiert in drei Schritten: These, Begründung, Folgerung.` ✓ 得分点（Textgrundlage）
2. 文学文本定位：`Der literarische Text zeigt eine Figur, die an genau dieser Selbststeuerung scheitert.` ✓
3. 关联句：`Damit konkretisiert der literarische Text, was der pragmatische Text abstrakt fordert.` ✓ 得分点（架桥，IIIb 关键）
4. 权衡与判断：`Die literarische Anschauung relativiert die These, ohne sie ganz zu verwerfen.` ✓（AFB III）
- Operator 对应：`untersuchen`(II) + `erörtern`(I–III) + `in Beziehung setzen`(II–III)。

**Aufgabe 3**
1. 命题复核：`Die These stützt sich auf zwei Argumente, von denen eines empirisch schwach belegt ist.` ✓ 得分点（`prüfen` 需标准）
2. 反论引入：`Ein Gegenargument betrifft die soziale Ungleichheit des Zugangs.` ✓
3. 权衡：`Dieses Gegenargument wiegt schwerer, weil es die Voraussetzungen der These betrifft.` ✓ 得分点（权衡）
4. 结论：`Die These ist in ihrer absoluten Form nicht haltbar.` ✓（AFB III）
- Operator 对应：`prüfen`(III)（⚠️ 非 `überprüfen`）。

**Aufgabe 4（LK）**
1. 实用文本人观：`Der pragmatische Text entwirft den Menschen als rationalen, selbstbestimmten Akteur.` ✓
2. 文学文本人观：`Der literarische Text zeichnet den Menschen als fremdbestimmt und ambivalent.` ✓
3. 权衡：`Beide Entwürfe stehen in Spannung zueinander.` ✓ 得分点
4. 判断：`Eine Vermittlung gelingt nur, wenn man Selbstbestimmung als regulative Idee, nicht als Faktum versteht.` ✓（AFB III）
- Operator 对应：`erörtern`(I–III) + `begründen`(III)。

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | `prüfen` 与 `überprüfen` 混用（官方两词不同级）；IIIb 当成纯文学题 | 记牢 `prüfen`=III / `überprüfen`=II–III；IIIb 先写实用文本 |
| 知识错 | 只给正反两面**不给自己的判断**（违反官方 `Urteil` 要求）；IIIb 漏掉那篇实用文本 | 强制写收束判断句；答卷自查「两文本都提到了吗」 |
| 表达错 | 用 `Der Text ist überzeugend` 等口语代替 `stringente Argumentationsführung`；权衡写成并列 | 用 §2.2 权衡信号词（`Zwar … jedoch …`）+ Fachbegriff |
