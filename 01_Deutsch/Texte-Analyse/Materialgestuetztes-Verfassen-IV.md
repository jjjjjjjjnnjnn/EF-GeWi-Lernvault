# Materialgestütztes Verfassen von Texten (材料支撑写作 · Aufgabenart IV)

> **中文理解**：**IVa** = 材料支撑的**说明性**文本撰写（informierend）· **IVb** = 材料支撑的**论证性**文本撰写（argumentierend）。KLP §4 原文为 `Materialgestütztes Verfassen von Texten` [已验证]。核心情境永远是**三合一**：给定 Materialdossier（多份小材料）sichten + 课堂知识 einbauen + 自己经验 ergänzen，写给**真实读者**（Adressat），**起标题**，**标出处**。
>
> **Klausur-Relevanz**：**IV 类零训练**是本项目最危险缺口之一。三大失分点 ② 在 IV 类最致命——**材料未标出处 / 论点无材料支撑 → 直接跌到 AFB I**。另需严防把 IVa 写成 IVb（说明性 vs. 论证性跑偏）。

## 2. 知识结构 (Struktur)

### 2.1 IVa vs. IVb 的分野

中文：判断标准是**产出文本的 Ziel**，不是材料内容。IVa 的终点是「让读者**理解**一个事实关联」；IVb 的终点是「让读者**接受**一个立场」。

> *Klausur-Satz*: `Während ein informierender Text (IVa) einen Sachverhalt verständlich darstellt, zielt ein argumentierender Text (IVb) darauf, den Adressaten von einer Position zu überzeugen.`

**判别表**：
| 项 | IVa 说明性 | IVb 论证性 |
|---|---|---|
| Ziel | informieren / erklären | überzeugen / Position beziehen |
| 结构 | 分类、定义、举例 | These–Argument–Beleg–Gegenargument–Urteil |
| 语气 | sachlich, neutral | wertend, begründend |
| 结尾 | 小结/展望 | 明确立场 |

### 2.2 Materialmatrix（材料矩阵）

中文：动笔前先做矩阵，把每份材料映射到「可用于哪个论点/哪一段」，并记下出处。这一步是 IV 类的**结构性防失分**。

> *Klausur-Satz*: `Für die These, dass …, stützt sich der Beitrag auf Material 2 (Autor X), während Material 5 ein Gegenargument liefert.`

| 材料 | Kernaussage | 可用于 | 出处（Autor/Titel） |
|---|---|---|---|
| M1 | 现象描述 | Einleitung | Autor A |
| M2 | 支持论据 | Pro-Argument | Autor B |
| M3 | 反面数据 | Contra-Argument | Autor C |

### 2.3 出处标注三步链

中文：⚠️ IV 类铁律——**每个论点必须有材料支撑**，且**标明出处**。无出处 = AFB I。三步：引用 → 出处 → 功能。

> *Klausur-Satz*: `Wie Autor B betont, steigt die Zahl der Nutzer seit 2020 deutlich (Material 2) — dieses Faktenargument stützt die Forderung nach klaren Regeln.`

⚠️ 材料不足时：**2–3 个强 Verweise mit Autorname 胜过 6 个无功能的材料名**。

### 2.4 Adressatenbezug（读者意识）

中文：每个段落都要想着读者。IV 类不是「无读者的独白」——`verfassen` 官方定义明确要求「针对受众与目标进行呈示」[已验证]。

> *Klausur-Satz*: `Da sich der Beitrag an Schülerinnen und Schüler richtet, verzichte ich auf Fachjargon und wähle ein anschauliches Beispiel.`

### 2.5 Schreibsituation 三合一

中文：固定框架 = Material sichten + Unterrichtswissen einbauen + eigene Erfahrung ergänzen。⚠️ 只搬材料 = 无 Eigenständigkeit（九项标准第 5 项）失分；只写感想 = 无材料支撑。

> *Klausur-Satz*: `Neben den Materialien fließt auch das im Unterricht erworbene Wissen über [Begriff] ein, ergänzt durch eine eigene Beobachtung aus dem Alltag.`

## 3. 解题方法 (Methoden)

### 3.1 IV 类写作五步法

**编号步骤**：
1. **读 Schreibsituation**：确认 Textsorte / Adressat / Wortziel / Titelpflicht —— *KLP 工具：verfassen（面向受众与目标）*
2. **sichten + 矩阵**：通览材料，填 Materialmatrix（材料→论点→出处）—— *KLP 工具：entnehmen Materialdossiers*
3. **定 Position/Gliederung**：IVa 分说明板块；IVb 定 These + 正反结构 —— *KLP 工具：darstellen / erörtern*
4. **写作时逐段验**：每段有 1 个 Verweis + 1 个材料出处 —— *KLP 工具：Belegpflicht*
5. **收尾自查**：Titel？Adressat 一致？每个论点有出处？—— *KLP 工具：entwerfen（说明决策）*

> **判据 / 决策点**：题干动词是 `verfassen`（I–III）还是 `entwerfen`（III）？后者要求**说明自己的决策与工作步骤**，需另加一段方法说明。

### 3.2 IVa / IVb 判别程序

**编号步骤**：
1. 看题干动词：`informieren / darstellen` → IVa；`erörtern / Position beziehen / überzeugen` → IVb。
2. 看 Zieltext：Vortrag/Artikel（说明）vs. Kommentar/Heftbeitrag（论证）。
3. 看结尾要求：无立场要求 → IVa；要求 Stellungnahme → IVb。

> **判据 / 决策点**：⚠️ 若题干说「informieren Sie über die Debatte」，仍属 **IVa**——描述一场争论 ≠ 自己表态。

---

## 4. 🇨🇳 CN-Methode

不适用（该科无中国对照技法）。理由：德国 IV 类的核心是**以材料为依据、面向具体读者的产出**，其评价维度（Eigenständigkeit / Adressatenbezug / Verweispflicht）是德语写作教学特有框架；中文议论文写作强调「论点论据论证」三要素，但**不强制出处标注**，直接套用会导致 Verweis 缺失而跌到 AFB I。**唯一可迁移的是「先列提纲再动笔」的习惯**。

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | **IVa**（informierend）/ **IVb**（argumentierend） |
| Operator | `verfassen`(I–III) · `entwerfen`(III) · `darstellen`(I–II) · `erörtern`(I–III) |
| AFB | II–III，重心 II–III |
| 建议分值 / 时长 | GK 255 min 中 IV 约占整卷 1/2–2/3 时长 [据推断] |

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> `Verfassen Sie auf der Grundlage der Materialien 1–4 einen informierenden Beitrag für die Schülerzeitung zum Thema „Lernen mit digitalen Medien“. Geben Sie Ihrem Text einen Titel und weisen Sie Ihre Quellen nach.`
（设问结构参照 NRW IVa 情境框架；材料自写）

**Aufgabe 2** `[原创]`
> `Verfassen Sie einen argumentierenden Heftbeitrag zu der Frage, ob Handys im Unterricht verboten werden sollten. Beziehen Sie mindestens drei der Materialien ein und markieren Sie Ihre Position.`

**Aufgabe 3** `[NRW-改编]`
> `Entwerfen Sie einen Schreibplan für einen materialgestützten Text: Ordnen Sie jeder der fünf Materialien ein Argument und eine Quelle zu (Materialmatrix). Begründen Sie Ihre Auswahl.`

**Aufgabe 4** `[原创]`
> `Prüfen Sie die Belastbarkeit der Materialien 2 und 4 hinsichtlich Herausgeber, Datum und Beleg. Erläutern Sie, welches Material Sie für Ihre Argumentation bevorzugen würden.`

### 5.3 Musterlösung

**Aufgabe 1（IVa）**
1. Titel自拟：`„Lernen im Wandel — Chancen und Grenzen digitaler Medien“`。✓ 得分点（Titel 明文要求）
2. Einleitung：界定现象 + 点明读者（Schülerzeitung）。✓
3. 说明板块：按材料分块（Chancen / Risiken / Nutzungstipps），每块带 1 Verweis。✓ 得分点（材料+出处）
4. Adressatenbezug：避免术语、举例贴近学生。✓
5. 结尾：小结 + 展望（**不表态**，保持 IVa）。✓ 得分点（不越界成 IVb）
- Operator 对应：`verfassen`(I–III) + `darstellen`(I–II)。

**Aufgabe 2（IVb）**
1. These：`Handys sollten im Unterricht nicht verboten, sondern geregelt werden.` ✓
2. Pro-Argument + Material 出处（Autor B）。✓ 得分点
3. Contra-Argument + Material 出处（Autor C）。✓ 得分点
4. 权衡 + 明确 Position。✓ 得分点（IVb 核心）
5. 结尾呼吁 + 面向 Adressat。✓
- Operator 对应：`verfassen`(I–III) + `erörtern`(I–III)。

**Aufgabe 3**
1. 矩阵表：M1–M5 各配 Argument + 出处。✓ 得分点（结构化）
2. 选材理由：优先可查证、时效新的材料。✓ 得分点（begründen）
3. 说明取舍：为何舍某材料。✓（entwerfen 要求说明决策）
- Operator 对应：`entwerfen`(III)。

**Aufgabe 4**
1. M2 核查：Herausgeber 权威？Datum 新？Beleg 可追溯？✓
2. M4 核查：同上，指出弱点（如匿名、无数据）。✓
3. 优选理由句：`Ich bevorzuge Material 2, weil es einen nachprüfbaren Beleg und ein aktuelles Datum aufweist.` ✓
- Operator 对应：`prüfen`(III) + `erläutern`(II–III)。

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把 IVa 写成 IVb（说明性 vs. 论证性跑偏）；把「描述争论」当「自己表态」 | 看 Ziel 不看材料内容 |
| 知识错 | 材料未标出处 / 论点无材料支撑（**最致命**）；只搬材料无自己的整合 | 强制 Materialmatrix + 每段 1 Verweis |
| 表达错 | 无 Titel；Adressat 不一致（一会儿对学生、一会儿对专家）；`verfassen` 写成无读者独白 | 收尾自查三项 |
