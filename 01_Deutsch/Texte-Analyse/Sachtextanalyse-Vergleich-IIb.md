# Sachtextanalyse im Vergleich（实用文本比较分析 · Aufgabenart IIb）

> **中文理解**：**IIb = Vergleichende Analyse pragmatischer Texte**——比较**两篇实用文本**（评论、社论、演讲、散文等）在**文本类型、论证思路、读者引导、语言设计与意图**上的异同并**相互权衡** [已验证，源：`Deutsch-Oberstufe.md` §5.2]。它是 EF（单篇 IIa）→ QP 比较能力的**第一道台阶**。LK 另加一层：材料可能是 **komplexe pragmatische Texte**（多层论证、反论、隐含立场）[已验证]。
>
> **Klausur-Relevanz**：**中高优先级**。典型失分：① **写成两篇独立分析**（A 篇一段、B 篇一段）而无比较维度 → 违反 `vergleichen` 的「相互权衡」要求；② 忽视**文类差异**（用同一把尺子量 Kommentar 与 Rede）；③ LK 层级漏掉文本中的 `Konzession` / `Gegenargument`，导致 `Argumentationsgang` 复原不全。

## 2. 知识结构 (Struktur)

### 2.1 IIb 与 IIa 的区别

中文：**IIa 只分析一篇**；**IIb 要比较两篇**，因此多出一整套「比较维度」的操作。IIb 的答卷里**必须出现对照句**（`Während A … , betont B …`），而不是两段独立分析拼在一起。

> *Klausur-Satz*: `Die Aufgabe verlangt einen Vergleich zweier pragmatischer Texte; beide Positionen sind aufeinander zu beziehen und gegeneinander abzuwägen.`

⚠️ **结构原则**：不是「先分析 A 再分析 B」，而是**沿维度交替对照**（Dimension für Dimension）。

> *Klausur-Satz*: `Beide Texte behandeln dasselbe Thema, unterscheiden sich jedoch in Argumentationsstrategie und Adressatenbezug.`

### 2.2 五个标准比较维度

中文：IIb 的比较通常沿以下五维展开——**文类 / 论证 / 读者引导 / 语言 / 意图**。

| 维度 | 德语 | 比较问句 |
|---|---|---|
| 文本类型 | Textsorte | 两文本属同一文类吗？文类差异如何影响说服策略？ |
| 论证 | Argumentationsgang | 论证链条结构相同吗？谁更依赖例子、谁更依赖数据？ |
| 读者引导 | Leserlenkung | 称呼、设问、评价手段有何异同？ |
| 语言 | sprachliche Gestaltung | 句式（Parataxe/Hypotaxe）、修辞、语域有何差异？ |
| 意图 | Intention | 目标读者与写作目的有何不同？ |

> *Klausur-Satz*: `Als Vergleichsmaßstab dient die Argumentationsstrategie: Während Text A auf statistische Belege setzt, arbeitet Text B mit emotionalen Appellen.`

### 2.3 LK 加深：复杂实用文本 `[LK]`

中文：**LK 专属**——材料含 `Konzession`（让步）、`Gegenargument`（反论）与**隐含立场** [已验证]。复原论证时**必须把这些层次挖出来**，否则 `Argumentationsgang` 不完整。

> *Klausur-Satz*: `Der Text ist komplex strukturiert: Er räumt zunächst ein Gegenargument ein (Konzession), um es anschließend zu entkräften.`

⚠️ **LK 常见失分**：漏掉文本中的 `Konzession` / `Gegenargument` → `Argumentationsgang` 复原不全 → 直接掉层。

> *Klausur-Satz*: `Die scheinbare Ausgewogenheit des Textes entpuppt sich als rhetorische Strategie: Die Konzession dient nur der Vorbereitung der eigenen These.`

## 3. 解题方法 (Methoden)

### 3.1 IIb 五步法

**编号步骤**：
1. **单篇最小分析**：两文本各写一句 Kernaussage + Textsorte —— *KLP 工具：einordnen（I–II）/ darstellen（I–II）*
2. **定维度**：写出 `Vergleichsmaßstab` 一句话 —— *KLP 工具：vergleichen（要求相互权衡）*
3. **交替对照**：沿维度逐条比（不是逐篇比）—— *KLP 工具：in Beziehung setzen（II–III）*
4. **取证**：每维度带 Beleg（`„…“ (Z. x)`）—— *KLP 工具：analysieren（I–III）*
5. **权衡收束**：一句判断，说明哪篇说服力更强及理由 —— *KLP 工具：erörtern（I–III）/ beurteilen（II–III）*

> **判据 / 决策点**：题干是否给定比较维度？给定 → 严格照办；未给定 → 自选一个**能覆盖两文本**的维度并明写。

### 3.2 LK 复杂文本复原法 `[LK]`

**编号步骤**：
1. 画出论证链条：These → Argumente → Konzession → Entkräftung → Schluss —— *KLP 工具：untersuchen（II）*
2. 标出 `Konzession` 与 `Gegenargument` 的位置 —— *KLP 工具：analysieren（I–III）*
3. 判断「让步是真让步还是修辞策略」—— *KLP 工具：überprüfen（II–III）*
4. 把这一层次带入与 B 文本的比较 —— *KLP 工具：in Beziehung setzen*

> **判据 / 决策点**：⚠️ `überprüfen`(II–III) ≠ `prüfen`(III)——前者是「按标准复核」，后者是「独立检验并下判断」[已验证]。

### 3.3 时间配比（GK 255 / LK 315 min 中单题）

| 段落 | 占比 | 内容 |
|---|---|---|
| Einleitung | 10% | 两文本定位 + 议题 |
| 单篇要点 | 20% | 各文本 Kernaussage |
| Vergleich（主体） | 50% | 沿维度交替对照 |
| Abwägung / Schluss | 20% | 权衡判断 |

> **判据 / 决策点**：Abitur Arbeitszeit **含选题时间且不得中断** [已验证]；先花 10–15 min 做选题决策。

## 4. 🇨🇳 CN-Methode

不适用（该科无中国对照技法）。理由：德语 IIb 的比较要求**先立 `Vergleichsmaßstab`（比较维度）再交替对照**，且评价维度含「视角多样性」与「区分度」；中文语文的「对比阅读」常以「求同存异」概括，缺**显式的比较尺度声明**与**逐维权衡**。⚠️ 危险迁移：把两篇分析各写一段当「比较」，或只写「都谈到了 X」而无权衡 → 违反 `vergleichen` 官方定义。

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | **IIb**（Vergleichende Analyse pragmatischer Texte） |
| Operator | `vergleichen`(II–III) · `analysieren`(I–III) · `untersuchen`(II) · `in Beziehung setzen`(II–III) · `überprüfen`(II–III) |
| AFB | II–III（重心 II，权衡属 III） |
| 建议分值 / 时长 | GK 255 min / LK 315 min 四选一之一；比较题约整卷 1/2 时长 [据推断] |

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> `Analysieren Sie die beiden vorliegenden Kommentare im Hinblick auf ihren Argumentationsgang. Benennen Sie zu Beginn Ihren Vergleichsmaßstab.`
> （设问结构参照 NRW IIb；两篇例文自写）

**Aufgabe 2** `[原创]`
> `Vergleichen Sie die Mittel der Leserlenkung in beiden Texten. Arbeiten Sie dabei die unterschiedlichen Adressatenbezüge heraus.`

**Aufgabe 3** `[NRW-改编]`
> `Vergleichen Sie die sprachliche Gestaltung beider Texte und beurteilen Sie abschließend, welcher Text seine Intention wirksamer verfolgt.`

**Aufgabe 4（LK 复杂文本）** `[原创]`
> `Untersuchen Sie den Argumentationsgang des komplexeren Textes, indem Sie Konzession und Gegenargument herausarbeiten. Vergleichen Sie anschließend, wie beide Texte mit Gegenpositionen umgehen.`

### 5.3 Musterlösung

**Aufgabe 1**
1. Vergleichsmaßstab：`Als Maßstab dient der Argumentationsgang: These, Begründung und Schlussfolgerung.` ✓ 得分点（维度先行）
2. 单篇要点：`Text A argumentiert deduktiv (These zuerst), Text B induktiv (Beispiele zuerst).` ✓
3. 交替对照：`Während A auf Autorität setzt, stützt B sich auf Beispiele.` ✓ 得分点（对照而非并列）
4. 权衡：`A wirkt sachlicher, B anschaulicher — beide erreichen ihr Ziel auf verschiedene Weise.` ✓（AFB III）
- Operator 对应：`analysieren`(I–III) + `vergleichen`(II–III)。

**Aufgabe 2**
1. 手段定位：`Text A verwendet rhetorische Fragen (vgl. Z. [..])，Text B direkte Anrede.` ✓
2. 受话人：`A richtet sich an ein Fachpublikum, B an ein breites Publikum.` ✓ 得分点（Adressat）
3. 对照与权衡：`Der persönliche Ton in B steigert die Nähe, während A auf Distanz und Sachlichkeit setzt.` ✓（AFB III）
- Operator 对应：`vergleichen`(II–III) + `in Beziehung setzen`(II–III)。

**Aufgabe 3**
1. 语言维度：`A verwendet Hypotaxe und Nominalstil, B kurze Parataxen.` ✓
2. 作用：`Die komplexe Syntax in A wirkt sachlich, die kurzen Sätze in B erhöhen die Eindringlichkeit.` ✓
3. 判断：`Für ein breites Publikum ist B wirksamer, für ein Fachpublikum A.` ✓ 得分点（AFB III 判断）
- Operator 对应：`vergleichen`(II–III) + `beurteilen`(II–III)。

**Aufgabe 4（LK）**
1. Konzession 定位：`Der Text räumt ein: „Zwar mag …“ (Z. [..]).` ✓ 得分点（LK 必备）
2. Gegenargument 定位：`Anschließend entkräftet er das Gegenargument (Z. [..]).` ✓ 得分点
3. 对照：`Während A Gegenpositionen offen einbezieht, ignoriert B sie.` ✓
4. 判断：`Die Konzession in A dient der Absicherung der eigenen These.` ✓（AFB III）
- Operator 对应：`untersuchen`(II) + `überprüfen`(II–III) + `vergleichen`(II–III)。

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把 IIb 当两篇 IIa（无比较维度）；`überprüfen` 与 `prüfen` 混用 | 强制写 Vergleichsmaßstab；记 `prüfen`=III / `überprüfen`=II–III |
| 知识错 | 忽视文类差异；LK 漏 `Konzession` / `Gegenargument` | 比较前先判 Textsorte；LK 强制画论证链条图 |
| 表达错 | 逐篇分段无对照句；只比内容不比语言 | 用 `Während A … , B …` 对照句；每维度带 Beleg |
