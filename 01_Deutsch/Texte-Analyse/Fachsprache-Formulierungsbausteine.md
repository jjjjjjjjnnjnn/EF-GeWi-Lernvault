# Fachsprache und Formulierungsbausteine (学科语言与句式库)

> **中文理解**：这是**跨 IF 元层**笔记——不是知识点，而是**一块可直接搬进考场的砖**。它对应本项目三大失分点中的**第 ② 项（材料引用不足/复述代替分析）**与**第 ③ 项（Fachsprache 不足 + 语言正确性）**，同时为第 ① 项（AFB 层级误判）提供**同一 Operator 的三档答法对照**。核心三件套：① **Beleg-Baustein 句式库**（可整段照抄的骨架句）；② **Zitat/Zeile 三步链**（引用 → 出处 → 功能）；③ **Fachbegriff 替换表**（日常口语 → 学科术语）。
>
> **Klausur-Relevanz**：⚠️ 三大失分点里有**两个**直接落在本文件射程内。第 ③ 项命中九项评价标准第 8 项 `Fachsprache`；叠加 §13 Abs. 2：**Q 阶段大量语言错误最多扣 2 Notenpunkte，EF 降一个 Notenstufe** [已验证]。

## 2. 知识结构 (Struktur)

### 2.1 Zitat/Zeile 三步链（对应失分点 ②）

中文：**这是 Deutsch 分析段的原子单位**。任何分析句必须走完三步，缺一步即掉层。

> **三步链**：`Zitat（短引）` → `Zeilenangabe（行号）` → `Funktion（手段 + 作用）`

❌ 反面（复述，AFB I）：
> `Der Autor sagt, dass das Handy ablenkt und man Pausen braucht.`
（只转述内容，无引用、无手段、无作用）

✅ 正面（分析，AFB II）：
> *Klausur-Satz*: `Die Metapher „Ablenker“ (Z. 8) verdeutlicht die negative Wirkung des Geräts und lenkt den Leser in Richtung der Forderung nach Selbststeuerung.`

> **判据 / 决策点**：写完一句，自查「有 `„…“` 吗？有 `(Z. x)` 吗？有 Wirkung 吗？」三者缺一即重写。

**引用格式规范**：
| 情形 | 写法 |
|---|---|
| 单行 | `„Wort“ (Z. 5)` |
| 跨行 | `„…“ (Z. 5–7)` |
| 间接引用 | `vgl. Z. 5` |
| 强调原词 | `„Wort“ (Z. 5; Hervorhebung im Original)` |

### 2.2 Fachbegriff 替换表（对应失分点 ③）

中文：日常口语进答卷 = 直接扣 Fachsprache 分。下面左列是**必须替换**的口语表达。

> *Klausur-Satz*: `Statt „der Text ist überzeugend“ schreibe ich: „Der Text überzeugt durch eine stringente Argumentationsführung mit klarer These-Begründung-Folgerung-Struktur.“`

| ❌ 日常口语 | ✅ Fachbegriff |
|---|---|
| der Text ist überzeugend | `stringente Argumentationsführung` |
| er wiederholt sich | `Anapher / Wiederholung als Stilmittel` |
| lange Sätze | `Hypotaxe` |
| kurze Sätze | `Parataxe` |
| er will sagen, dass … | `Der Autor vertritt die These, dass …` |
| das Bild bedeutet … | `Die Metapher konnotiert … / verdeutlicht …` |
| das ist gut geschrieben | `präzise Wortwahl / treffende Metaphorik` |
| er redet überall davon | `Der Text thematisiert wiederholt …` |
| der Text ist emotional | `Der Text appelliert affektiv an …` |
| viele Leute denken | `In der öffentlichen Debatte wird … vertreten` |

### 2.3 同一 Operator 的三档答法（对应失分点 ①）

中文：⚠️ **头号陷阱**——`analysieren` / `interpretieren` / `erörtern` / `verfassen` 这 4 个动词**跨全部三个 AFB** [已验证]。不能凭动词判层级，必须读题干限定语。

> *Klausur-Satz*: `Ob eine Aufgabe auf AFB II oder III zielt, entscheidet nicht das Verb allein, sondern der Zusatz („inwiefern“, „nehmen Sie Stellung“, „beurteilen Sie“).`

**示例：`analysieren` 的三档**
| AFB | 题干特征 | 答法 |
|---|---|---|
| I | `nennen Sie die sprachlichen Mittel` | 只列手段名 + 行号 |
| II | `analysieren Sie die sprachliche Gestaltung` | 手段 + Beleg + Wirkung |
| III | `analysieren Sie, inwiefern … die Wirkung verstärkt` | 加判断 + 权衡 |

**示例：`erörtern` 的三档**
| AFB | 题干特征 | 答法 |
|---|---|---|
| I | `stellen Sie die Position des Autors dar` | 只复述立场 |
| II | `erörtern Sie die Argumente des Textes` | 拆正反 + 权衡 |
| III | `erörtern Sie, ob … ; nehmen Sie Stellung` | 权衡 + 自己的有据判断 |

> **判据 / 决策点**：动笔前 10 秒把题干译成中文动作（「分析」还是「评价」），再分配段落权重。

## 3. 解题方法 (Methoden)

### 3.1 Beleg-Baustein 句式库（可直接搬进考场）

**编号步骤**（每段分析强制走）：
1. **引入手段**：`Auffällig ist … / Besonders wirkt …` —— *KLP 工具：analysieren*
2. **给 Beleg**：`(vgl. Z. [..])` —— *KLP 工具：Belegpflicht*
3. **写作用**：`… verdeutlicht / unterstreicht / relativiert …` —— *KLP 工具：Wirkung*
4. **回扣主题**：`… und stützt damit die These, dass …` —— *KLP 工具：deuten*

**骨架句分类库**（全部自写，可整句照抄）：

*命名手段类*：
- `Der Text bedient sich des Mittels der [Metapher/Anapher/…], um …`
- `Auffällig ist der Wechsel von [Parataxe] zu [Hypotaxe] (Z. [..]).`

*说明作用类*：
- `Das [Mittel] (Z. [..]) verdeutlicht [Sachverhalt] und lenkt den Leser in Richtung [Intention].`
- `Die [Reihung] (Z. [..]) suggeriert [Wirkung] und untermauert damit die These, dass …`
- `Der [Kontrast] zwischen [A] und [B] (Z. [..]) spitzt die Argumentation zu.`

*收束判断类*：
- `Insgesamt lässt sich festhalten, dass der Text [Intention] verfolgt und dabei auf [Mittel] setzt.`
- `Wägt man beide Seiten ab, so relativiert sich [A], während [B] schwerer wiegt — deshalb [eigenes Urteil].`

> **判据 / 决策点**：每个分析段至少 1 组「命名 + 作用」句；整篇至少 1 句「收束判断」句（AFB III）。

### 3.2 语言正确性自查（对应失分点 ③）

**编号步骤**：
1. **术语自查**：把口语词逐个换成 Fachbegriff（用 §2.2 表）。
2. **时态自查**：分析文本用 `Präsens`（历史现在时）；引用作者观点用 `Konjunktiv I`。
3. **Beleg 自查**：每个 `„…“` 后是否有 `(Z. x)`。
4. **结构自查**：段落是否有主题句 + Beleg + 作用句。

> **判据 / 决策点**：⚠️ §13 Abs. 2——大量语言错误 Q 阶段扣至 2 分。写完留 5 min 专查语法/正字法/标点。

## 4. 🇨🇳 CN-Methode

不适用（该科无中国对照技法）。理由：本文件的 `Formulierungsbaustein`（句式模块）本质是德语**学术写作语域**（Wissenschaftssprache）的规约，与中文写作的「好词好句」不同——它要求**术语准确 + 引用规范 + 论证透明**，而非辞藻华丽。⚠️ 危险迁移：把中文作文的排比/抒情句式搬进德语答卷 = Fachsprache 与 Sachlichkeit 双失分。

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | **全部 I–IV**（元层通用） |
| Operator | `formulieren`（官方标为「generalisierende Aufforderung」，**未给数字 AFB**）[已验证] + 各题型核心动词 |
| AFB | I–III（句式库本身跨层） |
| 建议分值 / 时长 | Darstellungsleistung 单列计分，贯穿全卷 [已验证] |

### 5.2 训练题

**Aufgabe 1** `[原创]`
> `Formulieren Sie die folgende Alltagsaussage in eine fachsprachliche Klausurformulierung um: „Der Text wiederholt am Anfang immer dasselbe Wort, das wirkt stark.“`

**Aufgabe 2** `[NRW-改编]`
> `Ergänzen Sie den folgenden Analysesatz um Beleg und Zeilenangabe: „Die Metapher verdeutlicht die Gefahr des Konsums.“ Nutzen Sie den Verweis auf Z. 12.`

**Aufgabe 3** `[原创]`
> `Bestimmen Sie für die drei folgenden Aufgabenstellungen jeweils den Anforderungsbereich: (a) „Nennen Sie die sprachlichen Mittel.“ (b) „Analysieren Sie die sprachliche Gestaltung.“ (c) „Beurteilen Sie, inwiefern die Gestaltung die These stützt.“`

**Aufgabe 4（综合）** `[NRW-改编]`
> `Schreiben Sie einen vollständigen Analysabsatz (4–5 Sätze) zu einer Ihnen bekannten Textstelle: Ein Satz zur Einordnung, zwei Sätze mit Beleg und Wirkung, ein Satz als Fazit.`

### 5.3 Musterlösung

**Aufgabe 1**
1. 识别口语词：„immer dasselbe Wort“ = Wiederholung / Anapher。✓ 得分点（术语）
2. 识别口语评价：„wirkt stark“ = 需转成 Wirkung。✓
3. 规范句：`Die Anapher (Z. 1) verdichtet den Appell und verstärkt die Eindringlichkeit der Forderung.` ✓ 得分点（三步链完整）
- Operator 对应：`formulieren`（泛化指令）。

**Aufgabe 2**
1. 补引用：`„Konsumrausch“`。✓
2. 补行号：`(Z. 12)`。✓ 得分点（格式规范）
3. 完整句：`Die Metapher „Konsumrausch“ (Z. 12) verdeutlicht die Gefahr des Konsums und suggeriert einen Kontrollverlust.` ✓
- Operator 对应：`formulieren`。

**Aufgabe 3**
1. (a) = **AFB I**（`nennen` 官方为 I）。✓ 得分点
2. (b) = **AFB II**（`analysieren` 此处限「分析」，重分析段）。✓
3. (c) = **AFB III**（`beurteilen` 官方为 II–III，加 „inwiefern“ 提升到判断层）。✓ 得分点（层级判定）
- Operator 对应：AFB 层级识别（对应失分点 ①）。

**Aufgabe 4**
1. 首句 Einordnung：`Der Absatz steht im Kontext der Forderung nach Selbststeuerung.` ✓
2. 两句 Beleg + Wirkung：每句含 `„…“ (Z. x)` + Wirkungsverb。✓ 得分点（三步链 ×2）
3. 末句 Fazit：`Damit stützt die Passage die These, dass …` ✓ 得分点（回扣）
- Operator 对应：`analysieren`(I–III) + `deuten`(III)。

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 凭动词判 AFB（`analysieren` 一律当 II）；把 `erörtern` 当纯复述 | 用 §2.3 三档对照表；读题干限定语 |
| 知识错 | 口语词未替换成 Fachbegriff；时态错（用过去时分析文本） | §2.2 替换表 + 分析用 Präsens |
| 表达错 | `„…“` 后缺 `(Z. x)`；无 Wirkungssatz；结构无主题句 | 三步链自查 + 段落四件套 |
