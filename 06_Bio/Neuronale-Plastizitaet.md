## 2. 知识结构 (Struktur)

### 2.1 整合（Verrechnung）：神经元是「加法器」

中文：一个神经元同时接收成百上千个突触输入。**兴奋性输入（EPSP）去极化、抑制性输入（IPSP）超极化**，两者在轴突起始段**代数相加**。只有总和达到 `Schwellenwert`，才触发动作电位（全或无）。**两种总和**：`räumliche Summation` = 不同位置同时到达的输入相加；`zeitliche Summation` = 同一位置高频连续到达的输入相加。

> *Klausur-Satz*: Ein Neuron **verrechnet** die einlaufenden Signale: Exzitatorische und inhibitorische postsynaptische Potenziale werden am Axonhügel **summiert**; erst wenn die Summe den **Schwellenwert** erreicht, wird ein Aktionspotenzial ausgelöst. [据推断]

### 2.2 抑制性突触——「刹车」而非「反向信号」

中文：抑制性突触释放抑制性递质（如 **GABA**），使后膜**超极化（IPSP）**。它不产生「反向动作电位」，而是**让总和更难达到阈值**。意义：抑制是**信息处理**的一部分——没有抑制，神经元无法区分信号，也无法选择性发放。

> *Klausur-Satz*: Die **hemmende Synapse** erzeugt ein **IPSP** (Hyperpolarisation) und erschwert dadurch das Erreichen des Schwellenwerts; Inhibition dient damit der **Informationsverarbeitung**, nicht der Signalumkehr. [据推断]

### 2.3 学习的细胞机制：LTP 与 LTD

中文：**LTP（长时程增强）** 是「记忆的物质基础」：高频刺激 → 谷氨酸大量释放 → **NMDA 受体**（需去极化解除 Mg²⁺ 阻塞）开放 → Ca²⁺ 内流 → **AMPA 受体数量增多**、突触后膜更敏感 → 突触传递**持久增强**。**LTD（长时程抑制）** 则相反：低频刺激 → 突触传递持久减弱。**LTP 与 LTD 共同构成「用进废退」的分子版本**——反复练习增强相关突触，长期不用则削弱。

> *Klausur-Satz*: Bei der **LTP** führt hochfrequente Erregung über eine verstärkte Ca²⁺-Aufnahme durch **NMDA-Rezeptoren** zu einer dauerhaften Verstärkung der synaptischen Übertragung; die **LTD** schwächt sie bei niederfrequenter Erregung ab. [据推断]

### 2.4 神经系统障碍——从突触层面理解

中文：LK 要求从**突触层面**理解障碍。**成瘾**：药物长期作用 → 奖赏通路突触可塑性改变 → 耐受与依赖；**神经退行性疾病**（如 Alzheimer、Parkinson）：特定神经元/递质系统进行性退化；**脱髓鞘疾病**（如多发性硬化）：髓鞘受损 → 传导变慢或中断。**共同点**：都是**神经元/突触层面的功能改变**，而非单纯的「心理问题」。

> *Klausur-Satz*: Störungen des neuronalen Systems lassen sich auf der Ebene der **Synapsen und Neuronennetze** erklären — etwa als veränderte synaptische Plastizität (Sucht) oder als fortschreitender Verlust bestimmter Neurone (Neurodegeneration). [据推断]

### 2.5 与 EF 的接口——为什么「不需要新知识作桥」

中文：LTP 的全部元件在 EF 都已教：**突触传递**（递质-受体）、**信号转导**（受体 → 胞内级联 → 响应）、**膜电位**（去极化/超极化）。LK 的新增只有两点：**「突触强度可长期改变」**与**「NMDA 受体的巧合检测」**。其余都是 EF 知识的重组。

> *Klausur-Satz*: Die neuronale Plastizität baut vollständig auf EF-Konzepten auf — **Synapse, Signaltransduktion und Membranpotenzial**; neu ist im Wesentlichen die **dauerhafte Veränderbarkeit** der synaptischen Stärke. [据推断]

### ⛔ 分层差异（GK vs LK）

- **GK**：只有 `Ruhepotenzial` / `Aktionspotenzial` / `Erregungsleitung` / `Synapse` / `Stoffeinwirkung` / `neuromuskuläre Synapse`；**无 `Verrechnung`、无 `Plastizität`、无 `Störungen`** [已验证，Bio-Oberstufe.md IF2 共同条目]。
- **LK**：+ **整个 `Neuronale Plastizität` 块**（`Verrechnung` / `hemmende Synapse` / `Summation` / `Zelluläre Prozesse des Lernens` / `Störungen`）+ `Neurophysiologische Verfahren` [已验证，Bio-Oberstufe.md IF2 LK 增量]。
- ⚠️ **答题纪律**：GK 卷面出现「LTP / NMDA / Summation」= 超纲；LK 卷面只写「突触传递」而**不写可塑性改变** = 未答到 LK 深度。

## 3. 解题方法 (Methoden)

### 3.1 「总和判定三步法」——处理记录图 / 电位叠加题

**编号步骤**：
1. **定类型**：输入来自**不同位置**（→ 空间总和）还是**同一位置连续**（→ 时间总和）。—— *KLP 工具：`Verrechnung`*
2. **代数相加**：把各 EPSP（+）与 IPSP（−）**求和**，得到膜电位变化量。—— *KLP 工具：`ermitteln`*
3. **判发放**：总和是否达到 `Schwellenwert`？达 → 动作电位；不达 → 不发放（全或无）。—— *KLP 工具：`erklaeren` 的归因要求*

> **判据 / 决策点**：**必须区分两种总和**；只写「信号叠加」不判发放 → 未完成因果链。

### 3.2 「LTP 机制四步法」——解释学习/记忆题

**编号步骤**：
1. **高频刺激**：写刺激条件（高频/强刺激）。—— *KLP 工具：`beschreiben`*
2. **受体接力**：谷氨酸 → AMPA（快速去极化）→ **NMDA**（去极化后解除阻塞、Ca²⁺ 内流）。—— *KLP 工具：`Signaltransduktion`（EF 前置）*
3. **突触改变**：Ca²⁺ 触发 AMPA 受体增多 / 敏感性升高 → 传递**持久增强**。—— *KLP 工具：`synaptische Plastizität`*
4. **回扣学习**：把机制连到「反复练习为何能记住」。—— *KLP 工具：`begruenden`*

> **判据 / 决策点**：**NMDA 受体的「需去极化才开放」是关键判分点**；只说「Ca²⁺ 内流」不说其前置条件 → 丢分。

### 3.3 「障碍评价多视角法」——处理 AFB III 题

**编号步骤**：
1. **机制层**：先用突触/神经元层面解释障碍（Sachurteil 依据）。—— *KLP 工具：`analysieren`*
2. **个体层**：对患者生活质量、自主性的影响。
3. **社会层**：医疗成本、污名化、劳动能力。
4. **伦理层**：治疗干预（如神经调控药物）的边界。—— *KLP 工具：`beurteilen` + `bewerten` 分开写*

> **判据 / 决策点**：**只写机制不得分**；必须落到个体/社会/伦理，且 `Sachurteil` 与 `Werturteil` **分开**。

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> Ein Neuron erhält gleichzeitig Signale von drei exzitatorischen Synapsen. Jede erzeugt einzeln nur ein kleines EPSP, das den Schwellenwert nicht erreicht; treten die drei Signale gleichzeitig auf, wird ein Aktionspotenzial ausgelöst.
> a) Erklären Sie diesen Befund mit dem Prinzip der Summation.
> b) Unterscheiden Sie räumliche und zeitliche Summation.

**Aufgabe 2** `[NRW-改编]`
> In einem Versuch an Hippocampus-Schnitten wird ein präsynaptisches Neuron kurz hochfrequent gereizt. Danach ist die postsynaptische Antwort über Stunden deutlich verstärkt. Wird derselbe Weg mit niedriger Frequenz gereizt, ist die Antwort dagegen abgeschwächt.
> a) Benennen Sie die beiden beschriebenen Phänomene.
> b) Erklären Sie die Verstärkung auf zellulärer Ebene.

**Aufgabe 3** `[原创]`
> Eine Person zeigt nach jahrelangem Konsum einer Substanz eine immer höhere Dosisabhängigkeit und deutliche Verhaltensänderungen. In Fachkreisen wird von einer „Sucht als Störung des neuronalen Systems" gesprochen.
> a) Analysieren Sie die Sucht aus Sicht der synaptischen Plastizität.
> b) Beurteilen Sie die individuellen und gesellschaftlichen Folgen.

### 5.3 Musterlösung

**Aufgabe 1**
1. **a) 现象归因**：Jede Synapse erzeugt allein ein **subschwelliges** EPSP; erst die **Summe** der drei Eingänge erreicht den **Schwellenwert**. ✓ 得分点
2. **a) 机制**：Die EPSPs werden am Axonhügel **algebraisch addiert**; überschreitet die Summe den Schwellenwert, wird ein Aktionspotenzial ausgelöst (Alles-oder-Nichts). ✓ 得分点（发放判定）
3. **b) 空间总和**：Räumliche Summation = gleichzeitige Eingänge von **verschiedenen** Synapsen an unterschiedlichen Orten. ✓ 得分点
4. **b) 时间总和**：Zeitliche Summation = schnelle Folge von Eingängen an **derselben** Synapse. ✓ 得分点（两种区分）

**Aufgabe 2**
1. **a) 命名**：Hochfrequente Reizung → **LTP** (Langzeitpotenzierung); niederfrequente Reizung → **LTD** (Langzeitdepression). ✓ 得分点
2. **b) 机制—递质**：Hochfrequente Reizung setzt viel **Glutamat** frei → starke Aktivierung der **AMPA-Rezeptoren** und **Depolarisation**. ✓
3. **b) 机制—NMDA**：Die Depolarisation hebt die Mg²⁺-Blockade des **NMDA-Rezeptors** auf → **Ca²⁺-Einstrom**. ✓ 得分点（关键前置条件）
4. **b) 结果**：Ca²⁺ löst eine dauerhafte **Vermehrung/Erhöhung der Empfindlichkeit der AMPA-Rezeptoren** aus → die synaptische Übertragung bleibt **verstärkt**. ✓ 得分点（持久改变）

**Aufgabe 3**
1. **a) 机制层**：Wiederholter Konsum verändert über **synaptische Plastizität** die Stärke der Synapsen im **Belohnungssystem**; es kommt zu **Toleranz** (Rezeptor-Desensibilisierung) und zu **Abhängigkeit**. ✓ 得分点（Sachurteil 依据）
2. **a) 连接**：Ähnlich wie bei LTP/LTD wird die synaptische Übertragung dauerhaft verändert — hier jedoch krankhaft. ✓
3. **b) 个体层**：Für Betroffene: Verlust der Kontrolle, gesundheitliche Schäden, soziale Isolation. ✓ 得分点
4. **b) 社会层**：Für die Gesellschaft: Kosten im Gesundheitswesen, Kriminalität, Stigmatisierung — was die Hilfsbereitschaft der Betroffenen senken kann. ✓ 得分点
5. **b) 权衡与立场**：Unter der Bedingung, dass Therapieangebote verfügbar sind, überwiegen die Gründe für einen **stärker medizinisch-therapeutischen** statt rein strafenden Umgang. ✓ 得分点（AFB III 有条件立场）

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 混淆 `räumliche` 与 `zeitliche` Summation | 空间 = 多处同时；时间 = 同处连续 |
| 辨别错 | 把 IPSP 当成「反向动作电位」 | IPSP 是分级电位，只**加大达阈难度** |
| 知识错 | 说 LTP 只需 Ca²⁺ 内流 | 必写 **NMDA 受体需先去极化**解除阻塞 |
| 知识错 | 把 LTP 说成「神经元变多」 | 是**突触强度**改变，非神经元数量 |
| 表达错 | 评价题只写机制 | 必须落到个体/社会/伦理 + `Sachurteil`/`Werturteil` 分开 |
| 表达错 | GK 卷面写 LTP / Summation | 属 **LK** ⛔ |
