# CN-Methode: Experimentdesign Vier-Fragen (实验设计四问法)

> **中文理解**：这是**中国技法专项**笔记（Lernbaum §4 #34，★★★）。它把「设计或评价一个实验」固化为四问：**变量 → 对照 → 预测 → 局限性**。它直击德国 **Aufgabenart II `Fachpraktische Aufgabe`** 主战场 [已验证，KLP Kap. 4]。
>
> **Klausur-Relevanz**：德国把实验设计归入 `Erkenntnisgewinnungskompetenz`（四大 Kompetenzbereich 之一），并明文要求**自行设计与论证**（`E1–E17`），而**不是**「按指导执行」[已验证]。中国学生的典型短板正是「不缺操作、缺论证设计」[据推断，Bio-DE-CN-Mapping X-15]。本技法补的正是这一层**写法**。

---

## 1. 核心概念 (Kernbegriffe)

| 术语 (DE) | 中文 | English | 定义 / 要点 | 备注 |
|---|---|---|---|---|
| `Fragestellung` | 问题 | research question | 实验要回答什么 | 第一步 |
| `Hypothese` | 假设 | hypothesis | 可检验的猜想（若…则…） | hypothetisch-deduktiv |
| `unabhängige Variable` | 自变量 | independent variable | 实验中**只改这一个** | 变量控制核心 |
| `abhängige Variable` | 因变量 | dependent variable | 被测量、被观察的量 | 须说明如何测量 |
| `Kontrollvariable` / `Störvariable` | 控制变量 | controlled variable | 除自变量外须全部相同 | 对照的基础 |
| `Kontrollansatz` / `Kontrolle` | 对照组 | control | 与实验组仅差自变量的那一组 | ⚠️ ≠「什么都不做」 |
| `Nullprobe` / `Blindprobe` | 空白对照 | blank | 不加处理/不加酶的一组 | 判「是否自发」 |
| `Wiederholung` | 重复 | replication | 多次实验减小偶然误差 | 局限性第一项 |
| `Stichprobenumfang` | 样本量 | sample size | 样本数；小样本 → 结论弱 | 局限性第二项 |
| `Geltungsbereich` | 适用范围 | scope | 结论只覆盖所操控的变量范围 | 局限性第三项 |
| `Erkenntnisgewinnungskompetenz` | 科学探究能力 | inquiry competence | 德国四大能力维度之一 | DE-Anschluss |
| `hypothetisch-deduktiv` | 假说-演绎 | hypothetico-deductive | Fragestellung→Hypothese→Planung→Auswertung | 德国官方框架 |

## 2. 知识结构 (Struktur)

### 2.1 四问法总表

| 问 | 内容 | 检查项 | 德国归属 |
|---|---|---|---|
| **① 变量** | 自变量是什么（**只改一个**）？因变量如何测量？无关变量如何恒定？ | 三变量齐全 | `E1–E17` |
| **② 对照** | 对照组是「除自变量外**全部相同**」的那一组；需要时设**双对照** | 差异唯一 | `E1–E17` |
| **③ 预测** | 先写「若假设成立，则预期 X 组 > Y 组」，**再**看数据 | 预测先于数据 | `Hypothesen aufstellen` |
| **④ 局限性** | 重复 + 样本量 + 结论适用范围（不得超出所操控的变量） | 三项齐全 | `E15–E17` |

### 2.2 「对照组」的两种最常见误解

| 误解 | 为什么错 | 正确理解 |
|---|---|---|
| 「对照组就是什么都不做」 | 若两组环境不同，无法归因 | 对照组 = **除自变量外全部相同** |
| 「只要有一个对照就够」 | 若存在两个变量，一个对照无法区分 | 需要时设**双对照**（如「酶有无」+「温度」各一对照） |

> *Klausur-Satz*: Eine geeignete Kontrolle unterscheidet sich vom Versuchsansatz **nur** in der unabhängigen Variable; alle übrigen Bedingungen müssen identisch sein. [据推断]

### 2.3 假说-演绎的标准流程（德国官方框架）

中文：德国 KLP 把生物学工作方式统一置于 **hypothetisch-deduktiv** 框架下：`Fragestellung` → `Hypothese` → `Planung/Durchführung` → `Auswertung / Interpretation / methodische Reflexion` [已验证，Bio-Oberstufe.md §3]。

> *Klausur-Satz*: Nach dem hypothetisch-deduktiven Vorgehen wird zuerst eine Fragestellung formuliert, daraus eine überprüfbare Hypothese abgeleitet und anschließend ein geeigneter Versuchsansatz geplant. [已验证]

### 2.4 局限性的三段式写法

中文：**重复**（Wiederholung）→ 减小偶然误差；**样本量**（Stichprobenumfang）→ 小样本结论弱；**适用范围**（Geltungsbereich）→ 结论不得超出所操控的变量范围。这三项是 `E15–E17`（方法边界与证据基础）的直接落点。

> *Klausur-Satz*: Die Aussagekraft ist eingeschränkt, da keine Wiederholungen durchgeführt wurden und der Stichprobenumfang klein ist; zudem gilt die Aussage nur für den untersuchten Bereich des Faktors. [据推断]

## 3. 解题方法 (Methoden)

### 3.1 四问法标准操作

**编号步骤**：
1. **变量**：写下 **1 个自变量** + **1 个因变量（含测量方法）** + **列出所有需恒定的无关变量**。—— *KLP 工具：`planen`*
2. **对照**：写明对照组「只差自变量」；若有两个变量，设双对照。—— *KLP 工具：`entwickeln`*
3. **预测**：用「若…则…」句式先给预期，再核对数据。—— *KLP 工具：`Hypothesen aufstellen`*
4. **局限性**：重复 + 样本量 + 适用范围，三项逐一写。—— *KLP 工具：`prüfen` / `beurteilen`*

> **判据 / 决策点**：题目说 `planen` → 你要**自己设计**；说 `beurteilen` → 你要**评价给定方案**（找它缺了四问中的哪一问）。

### 3.2 评价给定实验方案

**编号步骤**：
1. 逐条对照四问，**指出缺项**（最常见：无对照、无重复、样本量小）。—— *KLP 工具：`prüfen`*
2. 说明缺项**如何影响结论**（不能排除什么、不能归因什么）。—— *KLP 工具：`begruenden`*
3. 给出**改进方案**（补对照 / 加重复 / 扩大样本）。—— *KLP 工具：`entwickeln`*

> **判据 / 决策点**：只说「不严谨」不得分；必须写出「**因为缺 X，所以不能排除 Y**」。

## 4. 🇨🇳 CN-Methode

### CN-Methode: 实验设计四问法（变量 / 对照 / 预测 / 局限性）

- **技法内容**：见 §2.1 与 §3.1。面对任何「设计或评价实验」的任务，按固定四问作答：① **变量**（自变量只改一个、因变量如何测、无关变量如何恒定）；② **对照**（除自变量外全相同，需要时双对照）；③ **预测**（先写「若…则…」再对数据）；④ **局限性**（重复 + 样本量 + 适用范围）。[CN-课标] 学业质量水平二→四的实验能力递进（依令执行 → 制订 → 基于给定条件设计 → 查阅资料并设计实施）。[据推断]
- **DE-Anschluss**：`Erkenntnisgewinnungskompetenz` `E1–E17`（**四大能力维度之一，德国的显式强项** [已验证]）· KLP 明示的四种工作方式 `Beobachten / Vergleichen / Experimentieren / Modellieren`，统一置于 **hypothetisch-deduktiv** 框架 · EF 的 `Untersuchung von osmotischen Vorgängen` 与 `Untersuchung von Enzymaktivitäten`（EF 明文方法 [已验证]）· QP 新增 `E15–E17`（方法边界与证据基础）。
- **合规性**：✅ 完全合规 —— 「变量/对照/重复」是**科学方法通用语**，德国 KLP 不但已教，而且**要求得比中国更显式**（德国把它做成独立能力维度；中国课标全文**未出现**「变量控制」「对照实验」两个术语，只有隐式的水平分级 [已验证，Bio-DE-CN-Mapping §7]）。**本技法是补德国「写法」、借中国「训练密度」，方向双向互补。**
- **⚠️ 分层差异**：中国的**定量**实验方法（显微计数、稀释涂布平板法、种群数量定量调查等）对 **GK 不合规**——GK 的生态学方法**仅要求定性**物种记录；**定量仅 LK** [已验证，Bio-DE-CN-Mapping OEK-07]。GK 用四问法时**不得引入定量方法**。
- **Abitur 应用**：**Aufgabenart II `Fachpraktische Aufgabe` 的主战场**，以及 Aufgabenart I 中「评价给定实验方案」的标准动作。⚠️ 关键：**实验设计归 `Erkenntnisgewinnung`，不是 `Sachkompetenz`**。
- **来源**：`[CN-课标]` + `[CN-教材]`

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | **Aufgabenart II** `Fachpraktische Aufgabe`（实验设计/评价）；含此部分时 Abitur 时长可延长且**须在题目中载明** [已验证] |
| Operator | `planen` · `entwickeln` · `prüfen` · `beurteilen` · `Hypothesen aufstellen` |
| AFB | I（识别变量）→ **II（设计与解释，重心）** → III（评价与改进） |
| 建议分值 / 时长 | 3 题约 20–25 BE，约 25–30 min [已验证，GK 255 min] |

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> Sie sollen untersuchen, ob das Enzym Katalase die Zersetzung von Wasserstoffperoxid (H₂O₂) beschleunigt. Zur Verfügung stehen: Kartoffelstücke (enthalten Katalase), abgekochte Kartoffelstücke, H₂O₂-Lösung, Messzylinder, Stoppuhr.
> a) Formulieren Sie eine Fragestellung und eine überprüfbare Hypothese.
> b) Planen Sie einen Versuchsansatz mit Kontrolle und benennen Sie unabhängige und abhängige Variable.

**Aufgabe 2** `[原创]`
> Ein Schüler führt den Versuch aus Aufgabe 1 **einmal** mit **einem** Kartoffelstück und **ohne** Kontrolle durch; er schließt aus dem Ergebnis, dass Katalase H₂O₂ zersetzt.
> Beurteilen Sie die Aussagekraft dieses Vorgehens und schlagen Sie zwei Verbesserungen vor.

**Aufgabe 3** `[NRW-改编]`
> Ein Versuch soll zeigen, dass die Aktivität eines Enzyms mit steigender Temperatur bis zum Optimum zunimmt. Es werden fünf Ansätze bei 10 °C, 20 °C, 30 °C, 40 °C und 50 °C durchgeführt; alle übrigen Bedingungen sind identisch.
> Prüfen Sie, ob dieser Ansatz der Vier-Fragen-Methode genügt, und ergänzen Sie fehlende Punkte.

### 5.3 Musterlösung

**Aufgabe 1**
1. **a) Fragestellung**：`Beschleunigt Katalase aus Kartoffeln die Zersetzung von Wasserstoffperoxid?` ✓
2. **Hypothese**：`Wenn Katalase die Zersetzung katalysiert, dann verläuft die Gasbildung mit frischer Kartoffel schneller als mit abgekochter Kartoffel.` ✓ 得分点（若…则…句式）
3. **b) 变量**：Unabhängige Variable = **Anwesenheit des Enzyms** (frisch vs. abgekocht); abhängige Variable = **Volumen des gebildeten Gases pro Zeiteinheit** (Messzylinder + Stoppuhr). ✓ 得分点（因变量 + 测量方法）
4. **Kontrolle**：Der **abgekochte** Kartoffelansatz dient als Kontrolle (Enzym denaturiert); alle übrigen Bedingungen (H₂O₂-Konzentration, Temperatur, Volumen) müssen **identisch** sein. ✓ 得分点（只差自变量）

**Aufgabe 2**
1. **缺陷 1**：Es fehlt eine **Kontrolle**; ohne abgekochten Ansatz kann nicht ausgeschlossen werden, dass H₂O₂ **auch ohne Enzym** (spontan) zerfällt. ✓ 得分点（缺对照 → 不能排除什么）
2. **缺陷 2**：Es gibt **keine Wiederholung** und nur **eine** Probe; ein Einzelwert ist nicht reproduzierbar. ✓ 得分点（重复 + 样本量）
3. **改进 1**：Zusätzlichen **Kontrollansatz** mit abgekochter Kartoffel durchführen. ✓
4. **改进 2**：Jeden Ansatz **mehrfach wiederholen** und den **Mittelwert** bilden. ✓
5. **标准句**：Erst mit Kontrolle und Wiederholungen lässt sich der Effekt eindeutig auf das Enzym zurückführen. ✓

**Aufgabe 3**
1. **① 变量**：✅ 自变量 = Temperatur (5 Stufen); abhängige Variable muss noch **explizit** benannt werden (z. B. Gasbildung pro Zeiteinheit). ✓ 得分点（指出因变量未写明）
2. **② 对照**：✅ Die 5 Temperaturstufen sind **gegenseitig** Kontrollen (nur die Temperatur variiert). ✓
3. **③ 预测**：❌ Es fehlt eine **Hypothese / Erwartung** („Wenn die Temperatur steigt, dann steigt die Aktivität bis zum Optimum."). ✓ 得分点（补预测）
4. **④ 局限性**：❌ Es fehlen Angaben zu **Wiederholungen** und **Stichprobenumfang**; auch ist der **Geltungsbereich** (nur 10–50 °C) anzugeben. ✓ 得分点（补局限）
5. **标准句**：Der Ansatz genügt den Punkten ① und ②, jedoch fehlen eine Hypothese sowie Angaben zu Wiederholungen und Geltungsbereich. ✓

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把 `Kontrollansatz` 理解成「什么都不做」 | 对照组 = **除自变量外全相同** |
| 辨别错 | 把实验设计当成 `Sachkompetenz` | 归 **`Erkenntnisgewinnung`**（德国硬区分） |
| 知识错 | 只改一个自变量却改了温度/浓度等多个 | 变量表逐项核对 |
| 知识错 | 先看数据再写预测（顺序倒置） | 预测**先于**数据（假说-演绎） |
| 表达错 | 只说「不严谨」不给理由 | 必须写「**因为缺 X，所以不能排除 Y**」 |
| 表达错 | 结论超出所操控的变量范围 | 补 `Geltungsbereich` 一句 |
| 表达错 | 引入 GK 不合规的**定量**方法 | GK 只用**定性**方法（定量仅 LK） |
