# Zellbiologie-Grundlagen（显微镜 + 尺度 + 植物/动物/细菌）

> 中文一句话：先建立"多大—用什么看—长什么样—为什么长这样"的链条，考试永远是 看图认结构 → 说出结构 → 用结构解释功能 → 给判断。

## 1. 中文讲一遍：Größen-Skala（数量级，用自己的话）

- 尺度从小到大，大致：原子约 0,1 nm → 水分子约 0,3 nm → DNA 双螺旋宽约 2 nm → 抗体约 10 nm → 病毒约 100 nm（一百纳米上下）→ 细菌 1–3 µm → 染色体约 1–10 µm → 红细胞约 7–8 µm → 一般真核细胞 10–100 µm → 草履虫可达约 50–300 µm → 蛙卵超过 1 mm。
- 记住三个分界：**1 nm**（分子世界）、**1 µm**（细菌/细胞器可见起点）、**1 mm**（肉眼起点）。
- 光学显微镜（Lichtmikroskop）能看到细菌和细胞，但看不到病毒：它的分辨极限约 0,2 µm（= 200 nm），病毒（约 100 nm）在线以下。想看病毒和分子细节要电子显微镜。
- 口诀：细菌 yes（微米级），病毒 no（纳米级，光镜不够）。

## 2. 中文讲一遍：Mikroskopieren（三步 + 放大倍数）

- 三步：① 制片/放片（Präparat auf den Objekttisch）→ ② 调清晰（先粗调后细调，scharf stellen）→ ③ 用专业术语标注（mit Fachbegriffen beschriften）。
- 总放大倍数 = 目镜 × 物镜（Vergrößerung = Okular × Objektiv），比如 10× 目镜配 40× 物镜就是 400×。
- 图看不清先别换高倍镜：先调焦、调光、检查切片位置，再逐级换物镜——这是实验题"如果模糊怎么办"的标准思路。
- 画图要求：线条干净、标注线用直尺引出、只写真名（Zellkern、Zellwand、Chloroplast……），不写"小圆圈"这种口语。

## 3. 中文讲一遍：Pflanze vs Tier vs Bakterium（对照 + 结构→功能一句）

| Merkmal | Pflanzenzelle | Tierzelle | Bakterium |
|---|---|---|---|
| Zellwand | 有（纤维素，撑住+定形） | 无（只有膜，所以形状灵活） | 有（肽聚糖，不同成分，保护） |
| Chloroplasten | 有（光合作用产糖） | 无（靠吃现成有机物） | 无（个别光合细菌靠膜色素，不叫叶绿体） |
| Vakuole | 一个中央大液泡（储水+撑起膨压） | 小而多（暂存+运输） | 无 |
| Zellkern | 有（DNA 被膜包着，好调控） | 有 | 无（环状 DNA 裸露在细胞质，叫拟核区） |
| Organellen (Mitochondrien/ER/Golgi) | 有 | 有 | 无（核糖体有，复杂内膜系统无） |
| Größe | 约几十 µm | 约 10–30 µm | 约 1–3 µm |

- 结构→功能各一句：叶绿体有色素+膜系统，所以能把光能转成化学能；大液泡存水产生膨压，所以草本植物能挺立；细菌没有细胞核和内膜系统，所以体积小、繁殖快、结构简单。

## 4. 中文讲一遍：Organisationsebenen（一句话链）

- Zelle（细胞）→ Gewebe（组织）→ Organ（器官）→ Organismus（个体）；往下还有 Organell → Molekül，往小走是"零件"，往大走是"分工合作"。
- 考试要会双向：给一个例子（比如皮肤、人、叶子、草履虫）能说出它处在哪一级；给"整体大于部分之和"这种论述题，能用"分工+相互作用产生新功能"来表态。

## 5. 中文讲一遍：Bio-Operatoren ab 2025（三档区别）

- **beschreiben**：只"说什么样"，结构化+术语，不解释原因（AFB I，看图说话）。
- **erklären**：回答"为什么"，必须把现象还原到规则/机制上（结构→功能、因果链）。
- **beurteilen**：下事实判断（Sachurteil），用专业标准论证对错/好坏。
- **bewerten**：下价值判断（Werturteil），要引入社会价值和规范来论证（比如伦理、生态代价）。
- 记忆钩：beschreiben = 照片，erklären = 说明书，beurteilen = 专家鉴定，bewerten = 陪审团量刑。
