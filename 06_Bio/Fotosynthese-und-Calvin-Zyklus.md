# Fotosynthese und Calvin-Zyklus (光合作用与卡尔文循环)

> **中文理解**：这是 Q 阶段 IF3「Stoffwechselphysiologie」的 `Aufbauender Stoffwechsel`（同化代谢）核心，KLP 明文含 `Calvin-Zyklus`（`Fixierung` / `Reduktion` / `Regeneration`）、`Zusammenhang von Primär- und Sekundärreaktionen`、`Abhängigkeit der Fotosyntheserate von abiotischen Faktoren` 与 `Funktionale Angepasstheiten`（叶结构 / 叶绿体精细构造 / 吸收光谱与作用光谱）[已验证，Bio-Oberstufe.md §2 IF3]。一句话：**光反应把光能转成 ATP 与 NADPH 并放出 O₂，卡尔文循环用这些能量把 CO₂ 变成糖**。
>
> **Klausur-Relevanz**：它是 Q 代谢的「同化侧」主干，且 `Abhängigkeit der Fotosyntheserate` 是 **GK 明文要求 + 中国最可直接迁移的一块**（曲线三看法 + 限制因子切换），命中率极高 [据推断，Bio-DE-CN-Mapping STW-04]。它也是化学渗透机制（`Chemiosmotische ATP-Bildung.md`）在叶绿体一侧的落点。

## 2. 知识结构 (Struktur)

### 2.1 叶绿体的结构-功能对应（Basiskonzept: Struktur und Funktion）

中文：叶绿体有**外膜、内膜、类囊体（Thylakoid）堆叠成的基粒（Granum）**与**基质（Stroma）**。**光反应发生在类囊体膜上**（膜上嵌着色素与电子传递链），**卡尔文循环发生在基质中**。类囊体堆叠**增大膜面积** → 容纳更多光合色素 → 提高捕光效率。这就是区室化服务于能量转化的典型。

> *Klausur-Satz*: Im Chloroplasten laufen die Primärreaktionen an der **Thylakoidmembran** ab, der Calvin-Zyklus im **Stroma**; die Stapelung der Thylakoide vergrößert die Membranfläche und erhöht so die Lichtausbeute. [据推断]

### 2.2 光反应（Primärreaktion）——把光能转成 ATP 与 NADPH

中文：光能被叶绿素吸收 → 激发电子进入**电子传递链** → 沿链传递时**泵出质子形成梯度** → 经 ATP 合酶生成 **ATP**；同时电子最终传给 **NADP⁺** 生成 **NADPH**。水的光解补足电子并放出 **O₂**（光合放氧的来源）。产物 ATP 与 NADPH 送进基质供暗反应。

> *Klausur-Satz*: In der Primärreaktion wird Lichtenergie über die Elektronentransportkette in **ATP** und **NADPH** umgewandelt; bei der **Photolyse des Wassers** entsteht **O₂** als Nebenprodukt. [据推断]

### 2.3 卡尔文循环（Sekundärreaktion）——三相循环

中文：① **Fixierung**：CO₂ 与 RuBP 结合（Rubisco 催化），立即裂解为 **2 分子 3-PGA**；② **Reduktion**：3-PGA 在 **ATP 与 NADPH** 供能下被还原为 **G3P**（三碳糖）；③ **Regeneration**：部分 G3P 经耗 ATP 的步骤**再生 RuBP**，使循环持续。净产出：每固定 CO₂ 得到可用于合成葡萄糖的碳骨架。

> *Klausur-Satz*: Der Calvin-Zyklus verläuft in drei Phasen: **Fixierung** von CO₂ an RuBP, **Reduktion** zu G3P unter Verbrauch von ATP und NADPH sowie **Regeneration** von RuBP. [已验证，Bio-Oberstufe.md IF3]

### 2.4 光反应与暗反应的耦合（Zusammenhang Primär/Sekundär）

中文：两阶段**互相依赖、方向相反**：光反应向暗反应**提供 ATP 与 NADPH**；暗反应把用过的 **ADP + Pi 与 NADP⁺ 归还**光反应。物质成环、能量单向流入。**去掉任何一侧，另一侧即停**——这是耦合题的标准答案骨架。

> *Klausur-Satz*: Die Primärreaktion liefert der Sekundärreaktion **ATP und NADPH**; die Sekundärreaktion gibt **ADP + Pi und NADP⁺** zurück — beide sind wechselseitig aufeinander angewiesen. [据推断]

### 2.5 光合速率与限制因子（Abhängigkeit von abiotischen Faktoren）

中文：光强、CO₂ 浓度、温度通过**限制因子交替**控制光合速率。典型曲线：光强升段 → 速率随光强上升（**光强是限制因子**）；到**平台期** → 光强不再限制，**换 CO₂ 或温度成为限制因子**（**不是反应停止**）。温度过高时酶变性，速率下降（不可逆）。

> *Klausur-Satz*: Erreicht die Fotosyntheserate trotz steigender Lichtintensität ein Plateau, so ist das Licht nicht mehr der **limitierende Faktor**; ein anderer Faktor (z. B. CO₂-Konzentration oder Temperatur) begrenzt nun die Rate. [据推断]

### ⛔ 分层差异（GK vs LK）

- **GK 要求**：光反应与暗反应全流程 + Calvin 三相 + 光合速率曲线 + 叶/叶绿体适应结构（**定性**）[已验证，Bio-Oberstufe.md §2 IF3]。
- **LK 增量（GK 不得引入）**：`Energetisches Modell der Lichtreaktionen`、`Lichtsammelkomplex`、**`C4-Pflanzen`（须比较 C3/C4 的暗反应）**、`Tracer-Methode` [已验证，Bio-Oberstufe.md IF3 LK 增量 / Lernbaum-Bio §4 ⛔]。
- ⚠️ **C4 边界**：C4 植物（空间分离的两步固碳、规避光呼吸）属 **LK 独立 Schwerpunkt**，**GK 完全不含**。GK 答题**不得**出现 C4 机制；LK 才需比较 C3/C4 的 Sekundärvorgänge。

## 3. 解题方法 (Methoden)

### 3.1 「两阶段对照法」——处理任何光合机制题

**编号步骤**：
1. **定场所**：光反应 → **类囊体膜**；暗反应 → **基质**。—— *KLP 工具：`Kompartimentierung` / `Struktur und Funktion`*
2. **列输入/输出**：光反应入光能 + H₂O，出 ATP + NADPH + O₂；暗反应入 CO₂ + ATP + NADPH，出 G3P + ADP/Pi + NADP⁺。—— *KLP 工具：`Stoff- und Energiebilanz`*
3. **说耦合**：写清 ATP/NADPH 的**双向往来**，证明互相依赖。—— *KLP 工具：`Zusammenhang von Primär- und Sekundärreaktionen`*

> **判据 / 决策点**：题目问「如果光照中断，暗反应会怎样」→ 答案核心是**ATP/NADPH 断供 → 循环停摆**，而非「暗反应不需要光所以继续」。

### 3.2 「曲线三看法」——限制因子题的标准动作

**编号步骤**：
1. **看走向**：分段描述（陡升 / 平台 / 下降），**引用区间数值**。—— *KLP 工具：`auswerten`*
2. **看极值/转折点**：峰值 = 最适；平台 = 饱和。—— *KLP 工具：`ermitteln`*
3. **看因果**：升段 → 该因子为限制因子；**平台 → 限制因子切换，而非反应停止**；温度过高下降 → 酶变性（不可逆）。—— *KLP 工具：`erklaeren`*

> **判据 / 决策点**：多条曲线并列时，**先找「哪条更低/先到平台」**——最低的那条当前受其对应因子限制。

### 3.3 「收支表法」——耦合与净产出核算

**编号步骤**：
1. 列**输入项**（光能、CO₂、H₂O、ATP、NADPH）与**输出项**（糖、O₂、ADP、NADP⁺）。
2. 用**总方程** `6 CO₂ + 6 H₂O → C₆H₁₂O₆ + 6 O₂` 做量的换算。
3. 由**净变化**判断过程方向。—— *KLP 工具：`Stoff- und Energiebilanz`*

## 4. 🇨🇳 CN-Methode

### CN-Methode: 曲线三看法（走向 / 极值 / 因果）—— 限制因子切换

- **技法内容**：任何 `y-x` 曲线固定三步 —— ① **看走向**：分段描述（陡升 / 缓升 / 平台 / 下降），引用具体区间数值；② **看极值/转折点**：峰值即最适点，平台即饱和；③ **看因果**：**转折点必对应机制切换**——升段 = 该因子为限制因子；平台 = **限制因子切换或饱和，而不是反应停止**；降段（酶）= 变性（不可逆）。[据推断，Bio-DE-CN-Mapping CN-Methode 6]
- **DE-Anschluss**：GK Stoffwechsel 的 `Abhängigkeit der Fotosyntheserate von abiotischen Faktoren`（**明文要求**）· EF 的 `Enzyme: Kinetik` 与 `Untersuchung von Enzymaktivitäten`（EF 已教）· `Darstellungsaufgaben`（法定考查形式，明列「图表解释」）[已验证]。**曲线读法是德国的官方训练项。**
- **合规性**：✅ —— 两边都要求读曲线，本技法只是把顺序固化。中国的增量是「**平台 = 因子切换，非停止**」这一句纠偏（德国学生与中国学生犯同样的错）[据推断]。
- **Abitur 应用**：**本课命中率最高的一块**（GK 明文考点）+ EF 酶动力学 + 生态耐受曲线。**AFB I（描述）+ AFB II（解释）** 组合，正对「AFB II 为重心」的要求。
- **来源**：`[CN-课标]` 必修1 2.2.1 + 实验「探究不同环境因素对光合作用的影响」；`[CN-教材]` 曲线分析法

> **与本课主线的接口**：本技法在光合题里只做**限制因子判断**；定量核算（净光合速率）按 `Stoff- und Energiebilanz` 处理，**GK 只要求定性方向** [据推断，CN-Methode 7 边界]。

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> Die Abbildung zeigt einen Chloroplasten mit Thylakoidmembranen und Stroma sowie die beiden Phasen der Fotosynthese.
> a) Beschreiben Sie mithilfe der Abbildung die Vorgänge in der Primär- und der Sekundärreaktion.
> b) Erklären Sie den Zusammenhang zwischen beiden Reaktionen.

**Aufgabe 2** `[NRW-改编]`
> Ein Diagramm zeigt die Fotosyntheserate in Abhängigkeit von der Lichtintensität bei zwei unterschiedlichen CO₂-Konzentrationen (Kurve A: niedrig, Kurve B: hoch). Beide Kurven steigen zunächst und erreichen ein Plateau; das Plateau von Kurve B liegt höher.
> a) Beschreiben Sie den Verlauf beider Kurven.
> b) Erklären Sie, warum die Kurven ab einem bestimmten Punkt ein Plateau erreichen.

**Aufgabe 3** `[原创]`
> Ein Schüler behauptet: „Die Dunkelreaktion heißt so, weil sie nur im Dunkeln abläuft."
> Beurteilen Sie diese Aussage fachlich und formulieren Sie eine korrigierte Version.

### 5.3 Musterlösung

**Aufgabe 1**
1. **a) 光反应**：An der Thylakoidmembran wird Lichtenergie aufgenommen; über die Elektronentransportkette entstehen **ATP und NADPH**, bei der Photolyse des Wassers wird **O₂** freigesetzt. ✓ 得分点（场所 + ATP/NADPH + O₂）
2. **a) 暗反应**：Im Stroma fixiert **Rubisco** CO₂ an **RuBP** (Fixierung), das Produkt wird mit ATP und NADPH zu **G3P reduziert** (Reduktion), RuBP wird regeneriert (Regeneration). ✓ 得分点（三相名）
3. **b) 耦合**：Die Primärreaktion liefert **ATP und NADPH**, die Sekundärreaktion gibt **ADP + Pi und NADP⁺** zurück. ✓ 得分点（双向往来）
4. **b) 收尾**：Dadurch sind beide Phasen **wechselseitig voneinander abhängig**. ✓

**Aufgabe 2**
1. **a) 描述**：Beide Kurven steigen zunächst **proportional zur Lichtintensität** und erreichen dann ein **Plateau**; das Plateau von Kurve B (hohe CO₂-Konzentration) liegt **höher**. ✓ 得分点（升段 + 平台 + 高度差）
2. **b) 解释升段**：Im steigenden Bereich ist das **Licht der limitierende Faktor**; mehr Licht → mehr ATP/NADPH → höhere Rate. ✓ 得分点（限制因子）
3. **b) 解释平台**：Im Plateau ist das Licht nicht mehr limitierend; nun begrenzt ein **anderer Faktor** (CO₂ oder Temperatur) die Rate — die Reaktion **stoppt nicht**. ✓ 得分点（因子切换 ≠ 停止）
4. **b) 收尾**：Die höhere CO₂-Konzentration verschiebt die Begrenzung, daher liegt das Plateau von B höher. ✓

**Aufgabe 3**
1. **定性**：Die Aussage ist **fachlich falsch**. ✓
2. **纠错 1**：Die Dunkelreaktion benötigt **kein Licht als Energiequelle**, läuft aber auch **im Licht** ab — Licht hemmt sie nicht. ✓ 得分点（不需光 ≠ 只在暗处）
3. **纠错 2**：Sie ist auf die **Produkte der Primärreaktion** (ATP, NADPH) angewiesen und läuft tagsüber parallel ab. ✓
4. **修正版**：„Die Sekundärreaktion (Calvin-Zyklus) benötigt kein Licht direkt, läuft aber im Licht ab, weil sie auf ATP und NADPH aus der Primärreaktion angewiesen ist." ✓

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把 `Absorptionsspektrum`（吸收）与 `Wirkungsspektrum`（作用）混用 | 吸收 = 吸什么光；作用 = 什么光**真驱动光合** |
| 辨别错 | 把 O₂ 来源说成 CO₂ | O₂ 来自**水的光解** |
| 知识错 | 说平台期「反应停止」 | 平台 = **限制因子切换/饱和**，非停止 |
| 知识错 | 漏掉 Calvin 的**第三相 Regeneration** | 三相齐全：Fixierung / Reduktion / Regeneration |
| 知识错 | GK 卷面写 C4 机制 | C4 属 **LK** ⛔，GK 不得出现 |
| 表达错 | 只说「能量传过去」，不写 ATP/NADPH 载体 | 明确写 **ATP / NADPH** 的生成与归还 |
