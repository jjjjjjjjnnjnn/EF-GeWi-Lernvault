# LK-Energiemodell, C4-Pflanzen und Gärung (能量模型·C4植物·发酵) · `[LK]`

> **中文理解**：这是 Q 阶段 **IF3 Stoffwechselphysiologie** 的 **LK 增量块**，KLP 明文列出四块：`Energetisches Modell der Lichtreaktionen` + `Lichtsammelkomplex`、`Energetisches Modell der Atmungskette`、`C4-Pflanzen`、`Alkoholische Gärung und Milchsäuregärung`，外加方法 `Tracer-Methode` [已验证，Bio-Oberstufe.md §2 IF3 LK 增量 / bi.txt L1684-1708]。一句话：**用「能量水平模型」统一描述两条膜基电子传递链，并补齐 C4 与无氧代谢两条支路**。考试形态是**比较 + 模型 + 收支 + 评价**（`vergleichen` / `erklaeren` / `berechnen` / `beurteilen`），AFB II 为主、评价段到 AFB III。
>
> **Klausur-Relevanz**：本块是**中国学生的最大缺口之一**——中国不讲化学渗透的**能量模型化**，也不讲 C4 的两步空间分离机制，发酵工程（工程侧）与德国 LK 的 `Gärung`（代谢侧）**不在同一层** [据推断，Bio-DE-CN-Mapping STW-08/09/10]。LK 还须**比较线粒体与叶绿体的膜基能量转化机制** [已验证，bi.txt L1712-1733]。
>
> ⛔ **分层禁止（本篇为 LK 专属）**：`Energetisches Modell`、`Lichtsammelkomplex`、`C4-Pflanzen`、`Alkoholische/Milchsäuregärung`、`Tracer-Methode` **全部为 LK 增量**；GK 的 IF3 只到光合全流程 + 呼吸四阶段 + `Chemiosmotische ATP-Bildung`（机制，**不含能量模型**）[已验证，Bio-Oberstufe.md IF3]。**GK 考生不得复习本篇任何内容**。

## 2. 知识结构 (Struktur)

### 2.1 能量模型（光反应）——把「电子传递」画成能量阶梯

中文：`Energetisches Modell` 用**纵轴 = 氧化还原电位（能量水平）**、横轴 = 反应步骤，画出电子从**水**（低能量）经**光激发**跃升到**高能量**、再沿传递链**逐级下降**回到 **NADPH** 的过程。**关键读法**：每一次「下降」都释放能量，被用于**泵质子**；两次光激发（PSII 与 PSI）是电子**两次被「抬升」**的点。

> *Klausur-Satz*: Im energetischen Modell der Lichtreaktionen werden die Elektronen durch **zwei Lichtanregungen** auf ein hohes Energieniveau gehoben und geben beim **schrittweisen Absinken** entlang der Transportkette Energie ab, die zum Protonenpumpen genutzt wird. [据推断]

### 2.2 能量模型（呼吸链）——同一张图的镜像

中文：呼吸链的能量模型画的是电子从 **NADH/FADH₂**（高能量）沿复合体**逐级下降**到 **O₂**（最低能量）的过程。**每一次下降**释放的能量用于泵质子。**与光反应的对照**：光反应是「光把电子抬上去」，呼吸链是「电子自己往下掉」——**方向相反，机制同构**。

> *Klausur-Satz*: Im energetischen Modell der Atmungskette „fallen" die Elektronen von NADH/FADH₂ **stufenweise** auf das niedrige Niveau von O₂ ab; die frei werdende Energie wird ebenfalls zum Aufbau eines Protonengradienten genutzt. [据推断]

### 2.3 两链比较——LK 的核心要求

| 维度 | 光反应（类囊体膜） | 呼吸链（线粒体内膜） |
|---|---|---|
| 电子来源 | **水**（光解）+ 光激发 | **NADH / FADH₂**（有机物氧化） |
| 电子「走向」 | 光**抬升**电子 → 逐级下降 | 电子**自行**逐级下降 |
| 末端受体 | **NADP⁺ → NADPH** | **O₂ → H₂O** |
| 能量中间态 | **质子梯度** | **质子梯度** |
| ATP 装置 | **ATP 合酶** | **ATP 合酶** |
| 能量模型形态 | 有**两次跃升**的阶梯 | **单调下降**的阶梯 |

中文：**共同点优先**（质子梯度 + ATP 合酶 + 逐级能量释放），再列差异（电子源/走向/末端受体）。**「同构」是 LK 的核心判分点**——若只列差异，等于没答到 LK 要求。

> *Klausur-Satz*: Beide Ketten beruhen auf demselben **energetischen Grundprinzip** (stufenweiser Elektronentransport → Protonengradient → ATP-Synthase); sie unterscheiden sich in **Elektronenquelle, Richtung der Anregung und terminalem Akzeptor**. [据推断]

### 2.4 C4 植物——两步空间分离，规避光呼吸

中文：**问题**：高温干旱时气孔关闭 → 叶内 CO₂ 低、O₂ 高 → RuBisCO 误固定 O₂ → **光呼吸**（浪费能量）。**C4 方案**：① **叶肉细胞**用 **PEP 羧化酶**（对 CO₂ 亲和力远高于 RuBisCO）先把 CO₂ 固定为四碳化合物（苹果酸）；② 四碳化合物运到**维管束鞘细胞**释放 CO₂，使局部 CO₂ 浓度极高 → RuBisCO 只做固碳，**不启动光呼吸**。**代价**：多耗 2 个 ATP/CO₂，故 C4 只在高温强光下**净收益更高**。

> *Klausur-Satz*: C4-Pflanzen fixieren CO₂ zunächst im Mesophyll über die **PEP-Carboxylase** und setzen es in den **Bündelzellscheiden** wieder frei; die dadurch erhöhte CO₂-Konzentration unterdrückt die **Photorespiration**. [据推断]

### 2.5 发酵——意义是「再生 NAD⁺」而非「多产 ATP」

中文：缺氧时呼吸链停摆，NADH 无法被氧化 → 糖酵解因**缺 NAD⁺** 而停滞。发酵的作用是**把 NADH 重新氧化成 NAD⁺**，让糖酵解继续（净得 2 ATP）。**两种发酵**：酒精发酵（丙酮酸 → 乙醇 + CO₂，酵母）与乳酸发酵（丙酮酸 → 乳酸，肌肉/乳酸菌）。**关键**：发酵**不增加 ATP 产量**，它只让糖酵解**不中断**。

> *Klausur-Satz*: Die Gärung dient vor allem der **Regeneration von NAD⁺** aus NADH, damit die Glykolyse auch ohne Sauerstoff weiterläuft; sie erhöht die ATP-Ausbeute **nicht**, sondern sichert nur den Fortgang der Glykolyse. [据推断]

### 2.6 Tracer 法——代谢通路是怎么被搞清楚的

中文：`Tracer-Methode` 用**放射性/稳定同位素标记**特定原子（如 ¹⁴C），追踪它在代谢物中的**去向**，从而确定反应顺序。Calvin 循环的三步就是靠 ¹⁴CO₂ 标记**逐时段取样**被阐明的。**方法边界**：只能追踪**标记原子**，不能直接测通量；标记物可能被旁路分流，需谨慎归因。

> *Klausur-Satz*: Mit der **Tracer-Methode** lassen sich Stoffwechselwege aufklären, indem markierte Atome (z. B. ¹⁴C) im Verlauf der Reaktionen verfolgt werden; sie zeigt den **Weg**, aber nicht direkt die **Flussrate**. [据推断]

### ⛔ 分层差异（GK vs LK）

- **GK**：光合全流程（含 Calvin）+ 呼吸四阶段 + `Chemiosmotische ATP-Bildung`（**机制**）；**无能量模型、无 C4、无发酵、无 Tracer** [已验证，Bio-Oberstufe.md IF3 共同条目]。
- **LK**：+ `Energetisches Modell`（光反应/呼吸链）+ `Lichtsammelkomplex` + `C4-Pflanzen` + `Gärung`（酒精/乳酸）+ `Tracer-Methode`；且须**比较两细胞器的膜基能量转化** [已验证，Bio-Oberstufe.md IF3 LK 增量]。
- ⚠️ **答题纪律**：GK 卷面出现「能量模型图 / C4 / 发酵 / Tracer」= 超纲；LK 卷面**只做定性流程描述而不画/不读能量模型** = 未答到 LK 深度。

## 3. 解题方法 (Methoden)

### 3.1 「能量模型读图法」——处理任何电子传递能量图

**编号步骤**：
1. **定轴**：纵轴是**能量水平/氧化还原电位**，横轴是反应步骤。—— *KLP 工具：`Energetisches Modell`*
2. **找跃升**：哪些点是电子被**抬升**（光反应 = 两次光激发）。—— *KLP 工具：`erklaeren`*
3. **数下降**：每段下降 = 能量释放 = 泵质子。—— *KLP 工具：`chemiosmotische ATP-Bildung`（EF→Q 接口）*
4. **定终点**：电子最终落到哪个受体（O₂ / NADP⁺）。—— *KLP 工具：`erklaeren`*

> **判据 / 决策点**：**「下降段 = 泵质子」是核心判分点**；只说「电子传下去」不说能量去向 → 丢分。

### 3.2 「C3/C4 比较法」

**编号步骤**：
1. 写**共同点**（都是光合、都有 Calvin、都固 CO₂）。—— *KLP 工具：`vergleichen`*
2. 写**机制差异**：C3 一步固碳（有光呼吸）；C4 **两步空间分离**（PEP 羧化酶 + 维管束鞘）。—— *KLP 工具：`C4-Pflanzen`*
3. 落到**适应意义**：高温干旱下的净收益优势 + ATP 代价。—— *KLP 工具：`begruenden`*

> **判据 / 决策点**：只说「C4 更高效」不说**两步空间分离机制** → 未得分。

### 3.3 「发酵收支核算法」

**编号步骤**：
1. 列**输入**（葡萄糖、ADP、Pi、NAD⁺）与**输出**（ATP、乙醇/乳酸、CO₂）。—— *KLP 工具：`berechnen`*
2. 标**净 ATP**（有氧 vs 无氧对比）。—— *KLP 工具：`Stoff- und Energiebilanz`*
3. 点明发酵的**真正意义 = 再生 NAD⁺**。—— *KLP 工具：`begruenden`*

> **判据 / 决策点**：把发酵说成「为了多产 ATP」→ 概念性失分；必须写「为让糖酵解继续」。

## 4. 🇨🇳 CN-Methode

### CN-Methode: 物质与能量收支表法（Bilanz）—— 含 ⚠️ 定量边界

- **技法内容**：把 C4 与发酵统一处理为**收支表** —— ① 列**输入/输出项**（C4：ATP 代价 vs 净碳收益；发酵：葡萄糖 → ATP + 乙醇/乳酸）；② 用**总方程**做量的换算；③ 由**净变化**判断优劣（C4 在高温强光下净收益高、发酵只为维持糖酵解）。中国对细胞代谢的**定量核算**训练成体系 [据推断，Bio-DE-CN-Mapping CN-Methode 7]。
- **DE-Anschluss**：`Stoff- und Energiebilanz`（**GK+LK 明文**）· `Energetisches Modell`（LK）· `Gärung` 的能量平衡（LK）· EF 的 `Anabolismus/Katabolismus` + `ATP-ADP`（**EF 已教**）。
- **合规性**：⚠️ **仅 LK 合规** —— 技法本身是**收支方法**（合规），但其**载体内容**（能量模型/C4/发酵）属 **LK 独有**。⚠️ **双重边界**：① 中国「10%–20% 传递效率」类定量推算属超出项；② 中国的**发酵工程**（灭菌/培养基/划线/涂布）是**工程侧**，与德国 LK 的 `Gärung`（**代谢侧**）**不在同一层**，**禁止**把工程流程写进答案 [据推断，Bio-DE-CN-Mapping CN-Methode 9 反例 (a)]。
- **Abitur 应用**：STW-08/09/10（能量模型 / C4 / 发酵，**仅 LK**）。AFB II（比较与收支）→ AFB III（生物技术优化光合作用的多视角评价）。
- **来源**：`[CN-课标]` 必修1 2.2.3–2.2.4 + 选必3 概念3（发酵工程，**仅作对比，不引入**）

### 5.3 Musterlösung

**Aufgabe 1**
1. **a) 光反应曲线**：Zu Beginn niedriges Niveau (Wasser); durch **zwei Lichtanregungen** wird das Elektron auf ein hohes Niveau gehoben, danach sinkt es **stufenweise** ab. ✓ 得分点（两次跃升）
2. **a) 呼吸链曲线**：Das Elektron startet bei **NADH/FADH₂** auf hohem Niveau und sinkt **monoton** bis zum niedrigen Niveau von **O₂** ab. ✓ 得分点（单调下降）
3. **b) 共同点**：Beide Ketten: **stufenweiser Elektronentransport → Protonengradient → ATP-Synthase**. ✓ 得分点（同构）
4. **b) 差异**：Elektronenquelle: **Wasser/Licht** vs. **NADH/FADH₂**; terminaler Akzeptor: **NADP⁺** vs. **O₂**. ✓ 得分点（差异）

**Aufgabe 2**
1. **a) 机制—固碳**：Die C4-Pflanze fixiert CO₂ im Mesophyll über die **PEP-Carboxylase**, die eine **höhere Affinität** zu CO₂ hat als RuBisCO. ✓ 得分点
2. **a) 机制—放碳**：In den **Bündelzellscheiden** wird CO₂ wieder freigesetzt → hohe CO₂-Konzentration → RuBisCO betreibt **keine Photorespiration**. ✓ 得分点（规避光呼吸）
3. **b) 代价**：Der C4-Weg kostet **zusätzliche ATP** (2 ATP pro CO₂). ✓ 得分点
4. **b) 归因**：Bei kühlem, feuchtem Klima sind die Stomata weit geöffnet, die Photorespiration ist gering → der **Nutzen** des C4-Wegs wiegt die **Zusatzkosten** nicht auf. ✓ 得分点（条件权衡）

**Aufgabe 3**
1. **a) 机制**：Unter Luftabschluss steht die **Atmungskette** nicht zur Verfügung; nur die **Glykolyse** liefert ATP (netto **2 ATP** pro Glucose). ✓ 得分点
2. **a) 无进一步氧化**：Die oxidative Decarboxylierung, der Zitronensäurezyklus und die Atmungskette entfallen, daher keine weiteren ATP-Quellen. ✓
3. **b) 必要性**：Ohne Sauerstoff kann NADH nicht über die Atmungskette reoxidiert werden; die Gärung **regeneriert NAD⁺**. ✓ 得分点（核心判分点）
4. **b) 结果**：Nur so kann die **Glykolyse weiterlaufen** und ATP bereitstellen — die Gärung ist also **kein** ATP-Gewinn, sondern eine **Aufrechterhaltung** des Stoffwechsels. ✓ 得分点（意义纠正）
