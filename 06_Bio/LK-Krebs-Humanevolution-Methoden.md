## 2. 知识结构 (Struktur)

### 2.1 Krebs —— 双重失守模型（LK）

中文：细胞周期受**原癌基因**（踩油门）与**抑癌基因**（踩刹车）共同调控。当**原癌基因被激活**（功能增强）**且抑癌基因失活**（功能丧失）时，检查点失效 → 细胞无限增殖 → 肿瘤。这是 EF `Zellzyklus-Regulation` 的直接后果。

> *Klausur-Satz*: **(LK)** Eine Krebszelle entsteht typischerweise durch **Aktivierung von Onkogenen** und **Inaktivierung von Anti-Onkogenen**; dadurch versagt die Kontrolle des Zellzyklus und die Zelle teilt sich unkontrolliert. [据推断]

**个性化医疗**：基于肿瘤的**具体突变谱**选择靶向药物——把「突变 → 蛋白质 → 药物靶点」的因果链用于治疗决策。

> *Klausur-Satz*: **(LK)** Die **personalisierte Medizin** nutzt das individuelle Mutationsprofil eines Tumors, um gezielt wirksame Therapien auszuwählen. [据推断]

### 2.2 Evolution des Menschen und kulturelle Evolution（LK）

中文：人类演化不是「线性进步」，而是**树状分叉**。证据链包括：**化石记录**（Fossilgeschichte）、**系统树**（`Stammbäume`，用原始/衍生特征判断亲缘）、**工具使用**（Werkzeuggebrauch）与**语言发展**（Sprachentwicklung）。基因与文化的**协同演化**是人类演化的特征之一。

> *Klausur-Satz*: **(LK)** Die Evolution des Menschen ist **keine lineare Entwicklung**, sondern ein **verzweigter Stammbaum**; Belege liefern Fossilien, Werkzeugfunde und die Sprachentwicklung. [据推断]

### 2.3 Molekulare Methoden —— PCR / 电泳 / 基因工程（LK）

- **PCR**：高温变性（解链）→ 退火（`Primer` 结合）→ 延伸（聚合酶合成），循环放大目标片段。
- **Gelelektrophorese**：DNA 带负电，在电场中向正极迁移；**片段越小迁移越快**，据此分离与判读。
- **Gentechnik**：用 `Restriktionsenzym` 切割、连接酶连接、载体导入宿主，实现 DNA 的**改造与导入**；`Gentherapie` 是其医学应用。

> *Klausur-Satz*: **(LK)** Die **PCR** vervielfältigt einen DNA-Abschnitt in Zyklen aus **Denaturierung, Primer-Anlagerung und Extension**; in der **Gelelektrophorese** wandern **kleinere Fragmente weiter** als größere. [据推断]

## 3. 解题方法 (Methoden)

### 3.1 「突变—通路—后果」三步法（肿瘤题）

**编号步骤**：
1. **定位基因类型**：是 `Onkogen` 还是 `Anti-Onkogen`？—— *KLP 工具：Krebs-Modell*
2. **判断突变方向**：功能**增强**（原癌）还是功能**丧失**（抑癌）？—— *KLP 工具：`Genmutationen`*
3. **连到检查点**：说明该基因如何影响 `Zellzyklus` 控制 → 失控增殖。—— *KLP 工具：EF `Zellzyklus-Regulation`*

> **判据 / 决策点**：题目出现两类基因时，必须**分别**说明作用方向（不可只说「突变致癌」）。

### 3.2 「条带读图法」（PCR + 电泳题）

**编号步骤**：
1. **定方向**：DNA 向**正极**迁移。—— *KLP 工具：`Gelelektrophorese`*
2. **读位置**：比较条带与标准（Ladder）的位置 → 得片段大小。—— *KLP 工具：`ermitteln`*
3. **下结论**：条带有无/位置差 → 判断是否含目标片段 / 是否有突变。—— *KLP 工具：`auswerten`*
4. **写局限**：说明该方法**只能判断大小与有无**，不能直接读出序列。—— *KLP 工具：E15–E17 方法边界*

> **判据 / 决策点**：题目若问「能否证明某碱基替换」，答**不能**（替换不改变片段长度）——这是典型的 AFB III 反思点。

### 3.3 「证据链法」（人类演化题）

**编号步骤**：
1. 列出证据类型（化石 / 工具 / 语言 / 分子）。
2. 每条证据写**它支持什么推论**。
3. 用「原始 vs 衍生特征」判断亲缘方向。—— *KLP 工具：`ursprüngliche und abgeleitete Merkmale`*
4. 收尾强调**树状分叉**而非线性进步。

> **判据 / 决策点**：不得用「更进步」这类**目的论**表述——KLP 明文警告避免 `final` 论证 [已验证]。

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]` `[LK]`
> In einer Tumorzelle ist ein **Onkogen** durch eine Mutation dauerhaft aktiv; zugleich ist ein **Anti-Onkogen** durch eine Deletion funktionslos geworden.
> a) Erklären Sie, warum diese beiden Veränderungen zusammen zum unkontrollierten Zellwachstum führen.
> b) Beurteilen Sie, warum sich dieselbe Therapie nicht bei allen Patienten gleich gut eignet.

**Aufgabe 2** `[NRW-改编]` `[LK]`
> Ein DNA-Abschnitt wird per **PCR** vervielfältigt und anschließend per **Gelelektrophorese** untersucht. Probe A zeigt eine Bande auf Höhe von 300 bp, Probe B zwei Banden (200 bp und 300 bp); der Standard ist als Leiter aufgetragen.
> a) Beschreiben Sie das Prinzip der PCR in drei Schritten.
> b) Ermitteln Sie, welche Probe auf eine **Deletion** hindeutet, und begründen Sie Ihre Entscheidung.
> c) Prüfen Sie, ob sich mit dieser Methode eine **Basensubstitution** nachweisen lässt.

**Aufgabe 3** `[原创]` `[LK]`
> Ein Stammbaum der Homininen wird anhand von Fossilien, Werkzeugfunden und molekularen Daten rekonstruiert.
> a) Erklären Sie, warum die Evolution des Menschen als **verzweigter Stammbaum** und nicht als lineare Entwicklung dargestellt wird.
> b) Diskutieren Sie die Aussagekraft von Werkzeugfunden für die Rekonstruktion der **kulturellen Evolution**.

**Aufgabe 4** `[CN-改编]` `[LK]`
> Zur Herstellung eines gentechnisch veränderten Organismus sollen ein Zielgen und ein Vektor verwendet werden.
> Beschreiben Sie die vier Arbeitsschritte der Gentechnik und erläutern Sie, welche Rolle **Restriktionsenzyme** dabei spielen.

### 5.3 Musterlösung

**Aufgabe 1**
1. **原癌基因（a）**：Das mutierte **Onkogen** ist dauerhaft aktiv → es fördert die Zellteilung **ohne** Regulation. ✓ 得分点（作用方向：增强）
2. **抑癌基因**：Das funktionslose **Anti-Onkogen** kann die Teilung **nicht mehr hemmen**. ✓ 得分点（作用方向：丧失）
3. **协同后果**：Beide Veränderungen zusammen heben die **Kontrollpunkte des Zellzyklus** auf → unkontrollierte Proliferation. ✓ 得分点（回扣 EF `Zellzyklus-Regulation`）
4. **个性化（b）**：Tumoren unterscheiden sich in ihrem **Mutationsprofil**; eine Therapie wirkt nur, wenn sie den konkreten Treiber trifft → **personalisierte Medizin** nötig. ✓ 得分点（提出 Mutationsprofil）

**Aufgabe 2**
1. **PCR 三步（a）**：① **Denaturierung** (Hitze trennt die Doppelstränge); ② **Primer-Anlagerung** (Annealing); ③ **Extension** (Polymerase verlängert). ✓ 得分点（三词齐全）
2. **读图（b）**：Probe B zeigt **zwei** Banden (200 bp und 300 bp) → ein **kürzeres** Fragment deutet auf eine **Deletion** hin. ✓ 得分点（用「更短片段」作判据）
3. **对照 A**：Probe A zeigt nur eine Bande bei 300 bp → kein Hinweis auf Deletion. ✓
4. **方法边界（c）**：Eine **Basensubstitution** verändert die Fragmentlänge **nicht** → sie ist mit der Gelelektrophorese **allein nicht** nachweisbar; dazu wäre z. B. eine Sequenzierung nötig. ✓ 得分点（点明方法边界 E15–E17）

**Aufgabe 3**
1. **树状（a）**：Fossilien zeigen **mehrere gleichzeitig existierende** Linien mit gemeinsamen und unterschiedlichen Merkmalen → ein **verzweigter** Stammbaum statt einer Linie. ✓ 得分点（多点共存）
2. **收尾**：Die Darstellung als «lineare Entwicklung» wäre eine unzulässige **finale** (zielgerichtete) Deutung. ✓ 得分点（反目的论）
3. **工具证据（b）**：Werkzeugfunde belegen **technische Fähigkeiten** und deren Weitergabe; sie stützen die Annahme einer **kulturellen Evolution**. ✓
4. **局限**：Funde sind **unvollständig** und ihre Deutung ist von der Fundsituation abhängig → Aussagekraft begrenzt. ✓ 得分点（给局限）

**Aufgabe 4**
1. **获取**：Das Zielgen wird z. B. mit **Restriktionsenzymen** oder per PCR gewonnen. ✓
2. **构建**：Zielgen und Vektor werden über komplementäre Schnittstellen **verbunden** (Ligase). ✓
3. **导入**：Das **rekombinante DNA-Molekül** wird in eine Wirtszelle eingebracht. ✓
4. **检测**：Erfolgreiche Aufnahme wird über Markergene oder Gelelektrophorese **überprüft**. ✓ 得分点（四步齐全）
5. **限制酶作用**：Restriktionsenzyme schneiden DNA an **spezifischen Sequenzen** und erzeugen **passende Enden**, die das gezielte Verknüpfen ermöglichen. ✓ 得分点（专一性 + 匹配末端）

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 混淆 `Onkogen`（增强致病）与 `Anti-Onkogen`（丧失致病） | 记「油门 vs 刹车」：油门卡住 / 刹车失灵 |

| 表达错 | 把人类演化写成「线性进步」 | 一律写 **verzweigter Stammbaum**；忌目的论表述 |
