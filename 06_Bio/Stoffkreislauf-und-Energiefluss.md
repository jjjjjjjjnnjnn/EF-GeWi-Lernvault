# Stoffkreislauf und Energiefluss (物质循环与能量流动)

> **中文理解**：本篇是 EF→Q **真断层**上的第二块砖（#22）。核心是一句必须背死的对立：**物质循环（Stoffkreislauf）可循环，能量流动（Energiefluss）单向且逐级递减** [已验证，Bio-Oberstufe IF4]。考试形态是**描述碳循环 + 解释能流 + 建收支表**（`beschreiben` / `darstellen` / `erklaeren`），AFB I→II 为主。
>
> **Klausur-Relevanz**：KLP 在 `Stoffkreislauf und Energiefluss` 下点名 `Kohlenstoffkreislauf` 与 `Nahrungsnetz` 两条，属 **GK 与 LK 共同必学** [已验证，Bio-Oberstufe IF4]。这是整个 IF4 里「中国素材最可直接迁移」的一块（中国选必2 有单向递减 + 生态金字塔 + 生物富集）[据推断，Bio-DE-CN-Mapping OEK-03]。
>
> ⚠️ **LK 边界（必须显式标注）**：**能量传递效率的定量计算（如 10%–20% 定律）对 GK 属超出项** —— GK 只要求**定性**的「单向递减」，定量与能量核算集中在 **LK** [据推断，Bio-DE-CN-Mapping OEK-03 / CN-Methode 7 边界]。**GK 考生不得做传递效率的数值推算**，只写「逐级递减」即可。

## 2. 知识结构 (Struktur)

### 2.1 断层定位：从「细胞内 ATP 收支」到「生态系统收支」

中文：EF 已教 `ATP-ADP-System` 与 `Anabolismus/Katabolismus`（**细胞内的物质与能量转化**）——这是 EF 留给 Q 的**弱接口之一**（虽主要指向 Stoffwechsel，但「收支」这一思维可平移）[据推断，Bio-DE-CN-Mapping EF-09]。本篇把「收支」从细胞放大到生态系统：**同一个「投入—产出」框架，换一个尺度**。

> *Klausur-Satz*: Das im EF gelernte **ATP-ADP-System** beschreibt Energieumwandlung auf **Zellebene**; im Ökosystem wird derselbe Bilanzgedanke auf **Nahrungsnetze** übertragen. [据推断]

### 2.2 物质循环：碳循环的四个环节

中文：`Photosynthese`（固定 CO₂ → 有机物）→ 沿食物链传递 → `Zellatmung`（释放 CO₂）→ `Destruenten` 矿化（归还无机碳）→ 火山/燃烧补足。**闭环**是关键词：碳原子被反复利用。答题须**闭合**到「回到大气 CO₂」[据推断]。

> *Klausur-Satz*: Im **Kohlenstoffkreislauf** wird CO₂ durch die Photosynthese fixiert, über die Nahrungskette weitergegeben und durch Zellatmung und Destruenten wieder freigesetzt; der Kreislauf ist **geschlossen**. [据推断]

### 2.3 能量流动：单向 + 递减

中文：能量**从太阳进入**，经生产者 → 消费者逐级传递，每一级都有大量能量以**热**散失（`Energieentwertung`），因此**不可能循环**。所以「金字塔」越往上越窄。**这是与物质循环的根本区别**：物质是「环」，能量是「流」[已验证，OEK-03]。

> *Klausur-Satz*: Energie wird im Ökosystem **nur einmal durchlaufen** und bei jeder Trophieebene teilweise als Wärme entwertet; sie ist daher **nicht recycelbar**, während Stoffe im Kreislauf geführt werden. [已验证方向，句子原创]

### 2.4 收支表（Bilanz）—— 本篇的解题骨架

中文：把「输入 / 输出 / 净变化」列成表。生态层三行即可：① 输入 = 太阳能（+ 外来有机质）；② 传递 = 各级同化；③ 输出 = 呼吸散热 + 未利用残体（由分解者归还物质）。**判断标准**：物质行**闭合**（总和守恒），能量行**递减**（逐级变少）。见 §3.1。

> *Klausur-Satz*: In der Bilanz sind die **Stoffflüsse geschlossen**, während die **Energieflüsse** mit jeder Trophieebene abnehmen. [据推断]

## 3. 解题方法 (Methoden)

### 3.1 物质与能量收支表法（Bilanz）

**编号步骤**：
1. **列输入项**：太阳能 / CO₂ / 水 / 矿质盐（+ 人为输入如肥料）。—— *KLP 工具：`darstellen`*
2. **列传递项**：按营养级逐行写（生产者 → K1 → K2 → Destruenten）。—— *KLP 工具：`darstellen`*
3. **列输出项**：呼吸释放 CO₂ + 热、残体被分解、被人类收获。 —— *KLP 工具：`erklaeren`*
4. **判性质**：**物质行必须闭合**（守恒），**能量行必须递减**（不可逆）。—— *KLP 工具：`begruenden`*
5. **回扣材料**：把结论写回给定的食物网/碳循环图。 —— *KLP 工具：德国「Deutung 回扣材料」硬要求* [据推断]

> **判据 / 决策点**：只要题目问「能量能否循环」，答「**否**，单向递减，因能量以热贬值」；问「物质能否循环」，答「**是**，经分解者闭合」。两句不可说反。
> ⚠️ **GK 边界**：若题目给具体能量数值要求算传递效率 → 属 **LK**；GK 只做**定性**判断 [据推断]。

### 3.2 食物网分析法（Nahrungsnetz auswerten）

**编号步骤**：
1. 标出 `Produzent` 起点与各 `Konsument` 级。—— *KLP 工具：`ordnen`*
2. 数出层级数 = 能量传递的「级数」（越多 → 顶端可利用能量越少）。—— *KLP 工具：`ermitteln`*
3. 找出 `Destruent` 的指向（通常指向所有层的残体）。—— *KLP 工具：`beschreiben`*

> **判据 / 决策点**：食物网题的高分句永远是「**层级越多，顶端能量越少**」——必须回扣能量递减。

## 4. 🇨🇳 CN-Methode

### CN-Methode: 物质与能量收支表法（Bilanz）—— 含 ⚠️ 定量边界

- **技法内容**：把光合/呼吸/生态三类问题统一处理为**收支表** —— ① 列输入/输出项；② 用总方程做量的换算（光合与呼吸方向相反）；③ 由**净变化**判断哪个过程占优；④ 生态层：物质**循环**、能量**单向递减**，两个方向不可说反。中国侧的增量是「**单向递减 + 生态金字塔 + 生物富集**」这套系统化表述 [据推断]。
- **DE-Anschluss**：EF 的 `Anabolismus und Katabolismus` + `ATP-ADP-System`（**EF 已教**）· GK/LK 的 `Stoff- und Energiebilanz`（明文，但主要在 Stoffwechsel-IF）· Q-IF4 的 `Stoffkreislauf und Energiefluss` / `Nahrungsnetz`（GK 点名）[已验证]。
- **合规性**：✅（主技法）—— 「收支」正是德国 `Bilanz` 一词的字面要求。
- **⚠️ 分层边界**：**10%–20% 能量传递效率的定量推算对 GK 属超出项**（GK 只要求定性的「单向递减」），**可理解、不复习** [据推断，Bio-DE-CN-Mapping CN-Methode 7]。**LK** 才做能量核算。
- **Abitur 应用**：OEK-03（碳循环 + 能流，AFB I+II）；LK 加能量核算后可到 AFB III。
- **来源**：`[CN-课标]` 选必2 2.2.2–2.2.6（食物链网 / 物质循环与能量单向递减 / 生态金字塔 / 生物富集）[据推断]

| 项 | 内容 |

| 建议分值 / 时长 | 3 题约 20 BE，约 20–25 min（GK 255 min）[已验证，Abitur 时长] |

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> Ein Wald-Ökosystem: Buchen → Raupen → Meisen → Habicht; Blätter und Kot werden von Pilzen und Bakterien zersetzt.
> a) Beschreiben Sie das Nahrungsnetz mit den Fachbegriffen der Trophieebenen.
> b) Erklären Sie, warum die Biomasse zur Spitze hin abnimmt.

**Aufgabe 2** `[原创]`
> Ein Schüler behauptet: „Die Energie aus der Sonne wird im Ökosystem wie das Wasser im Kreislauf immer wieder benutzt."
> Beurteilen Sie diese Aussage und korrigieren Sie sie.

**Aufgabe 3** `[CN-改编]`
> Stellen Sie für das obige Wald-Ökosystem eine Bilanz auf: Nennen Sie je zwei Stoff- und zwei Energie-Einträge sowie -Austritte, und begründen Sie den Unterschied zwischen Stoff- und Energiefluss.

### 5.3 Musterlösung

**Aufgabe 1**
1. **a) 层级**：Buche = **Produzent**; Raupe = **Konsument 1. Ordnung**; Meise = **Konsument 2. Ordnung**; Habicht = **Konsument 3. Ordnung**; Pilze/Bakterien = **Destruenten**. ✓ 得分点（逐层点名）
2. **a) 补充**：Die Destruenten sind mit **allen** Ebenen über Blätter und Kot verbunden. ✓
3. **b) 归因**：Bei jeder Trophieebene wird ein Teil der Energie durch **Zellatmung als Wärme** entwertet (**Energieentwertung**). ✓ 得分点（点名机制）
4. **b) 结论**：Deshalb steht der nächsten Ebene **weniger** Energie zur Verfügung → die Biomasse nimmt nach oben ab. ✓ 得分点
5. **标准句**：Die Abnahme beruht auf der **Energieentwertung** bei jeder Übertragung, nicht auf einer Verringerung der Stoffmenge. ✓

**Aufgabe 2**
1. **定性**：Die Aussage ist **fachlich falsch**. ✓
2. **纠错（能量）**：Energie wird **nicht** im Kreislauf geführt, sondern **einmalig** durchlaufen und bei jeder Ebene als Wärme entwertet. ✓ 得分点（单向）
3. **纠错（物质）**：Nur **Stoffe** werden über Destruenten im Kreis geführt. ✓ 得分点（物质 vs 能量）
4. **标准句**：Energie **fließt**, Stoffe **kreisen**. ✓（本库标志句）

**Aufgabe 3**
1. **物质收支**：Eintritt: CO₂, Wasser/Mineralstoffe; Austritt: CO₂ aus Zellatmung, gelöste Mineralstoffe im Sickerwasser. ✓ 得分点
2. **能量收支**：Eintritt: **Sonnenlicht**; Austritt: **Wärme** (Zellatmung) + nicht genutzte Restenergie. ✓ 得分点
3. **差异归因**：Stoffe sind **geschlossen** (Destruenten mineralisieren und geben sie zurück), Energie ist **offen und abnehmend** (Entwertung, kein Recycling). ✓ 得分点（核心区分）
4. **标准句**：Die Bilanz zeigt **geschlossene Stoffflüsse** und **offene, abnehmende Energieflüsse**. ✓

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 说「能量循环利用」 | 能量**单向**；只有物质循环 |
| 辨别错 | 把 `Destruent` 当成消费者 | 分解者归还**无机物**，不属营养级消费 |
| 知识错 | 忘记碳循环须**闭合**到大气 CO₂ | 结尾必写「归还大气」 |
| 知识错 | GK 考生做 10% 传递效率计算 | ⚠️ 定量属 **LK**；GK 只写「递减」 |
| 表达错 | 只说「能量变少」，不说**为什么**（热散失） | 必须点名 `Energieentwertung` |
| 表达错 | 食物网题不写「层级越多顶端越少」 | 这是该题型的高分句 |
