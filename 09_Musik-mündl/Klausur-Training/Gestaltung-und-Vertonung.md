# Gestaltung und Vertonung: Aufgabenart III (创作与配乐：题型三流程)

> **中文理解**：这是 **QP 专属的 PRODUKTION（制作）** 条目。KLP 规定笔试只有三种 Aufgabenart，其中 **Aufgabenart III = Gestaltung mit schriftlicher Erläuterung（创作 + 书面说明）**：在已知语境中**创作**音乐结构，通常先制定 **Gestaltungskonzept（塑造构想）**、完成 **Komposition（作曲）**，并**论证**自己的构想与作曲决策。题干**必须标明形态**：`Vertonung`（配乐）/ `Bearbeitung`（改编）/ `Stilkopie`（风格摹写）/ `Neukomposition`（新作）。IF1 QP 的 `Vertonen von Texten`（为文本谱曲）与 IF3 QP 的「数字工具 + 图解式/传统记谱」都属于这一能力族。[已验证：KLP §4.1 Aufgabenart III + IF1/IF3 QP PRODUKTION 条目]
>
> **Klausur-Relevanz**：🔴 **QP 专属硬要求，此前项目完全空白**。⚠️ **若在 Abitur 选择 Gestaltungsaufgabe（Aufgabenart III），考试时长 +60 分钟**（LK 300→360 / GK 240→300）[已验证]。核心失分点是「只创作、不论证」——Aufgabenart III **明确要求 Begründung**。
>
> ⏳ 待确认：Halbjahr-Thema 与具体创作任务未定；**口试中 Aufgabenart III 的实操形态**（是否现场作曲、如何呈现）KLP 未规定 [未获取到]。本篇按笔试逻辑写，口试部分按「以笔试题型为取向」处理。

## 2. 知识结构 (Struktur)

### 2.1 Aufgabenart III 的四形态（题目标明，须对齐）

中文：KLP 要求题目标明形态，**你的创作与说明必须与该形态一致**——写 Stilkopie 却自由发挥即失分。

| 形态 | 任务实质 | 关键约束 | 说明重点 |
|---|---|---|---|
| `Vertonung` | 为文本/场景配乐 | 忠于文本的情绪/结构 | 文本—参数映射的理由 |
| `Bearbeitung` | 改编既有材料 | 保留可识别核心 | 改了什么、为何改 |
| `Stilkopie` | 摹写某风格 | 遵守该风格规范 | 用了哪些风格标志 |
| `Neukomposition` | 自由创作 | 遵循给定语境/构想 | 构想的内在一致性 |

> *Klausur-Satz*: `Ich richte meine Gestaltung konsequent an der vorgegebenen Form aus; das wirkt nachvollziehbar, weil die Aufgabe III die Form ausdrücklich benennt und ihre Umsetzung bewertet.`

### 2.2 Gestaltungskonzept：目标—手段映射（本主题核心工具）

中文：创作的**第一步永远是构想**：先说清「要造成什么效果」，再决定「用哪些参数实现」。这张映射表是书面说明的骨架。

| 目标（Wirkung） | 可用参数（Parameter） | 具体手段（Mittel） |
|---|---|---|
| 不安 / 紧张 | Harmonik / Rhythmik | 半音、不协和、切分、加速 |
| 悲伤 / 内省 | Melodik / Klangfarbe | 下行旋律、小调、低沉音区 |
| 庄严 / 宏大 | Dynamik / Instrumentation | 强奏、全奏、宽广节奏 |
| 轻盈 / 活泼 | Rhythmik / Artikulation | 快速、断奏、高音区 |
| 神秘 / 悬疑 | Klangfarbe / Harmonik | 弱奏、颤音、模糊调性 |

> *Klausur-Satz*: `Ich lege zuerst das Gestaltungskonzept fest und ordne jedem Ziel ein musikalisches Mittel zu; das wirkt systematisch, weil die kompositorischen Entscheidungen dadurch begründbar werden.`

### 2.3 创作流程五阶段（Konzept → Komposition → Erläuterung）

```
① Konzept   —— 目标效果 + 形态（Vertonung/Bearbeitung/Stilkopie/Neukomposition）
② Planung   —— 参数映射表（目标 → 参数 → 手段）
③ Komposition —— 用图解式或传统记谱写出片段
④ Präsentation —— 按要求的记谱形式呈现（必要时用数字工具）
⑤ Erläuterung —— 逐条论证作曲决策 + 自我评判
```

> **判据 / 决策点**：⚠️ **不得跳过 ⑤**。Aufgabenart III 的评分核心正是「构想与决策的论证性」——只交作品不写说明 = 直接失分。

> *Klausur-Satz*: `Ich dokumentiere den Weg von Konzept über Komposition bis zur Erläuterung; das wirkt vollständig, weil Aufgabe III neben der Gestaltung ausdrücklich die Begründung verlangt.`

### 2.4 EF→QP 升级：同一 IF 的层级上移（**3 个 IF 在 EF/QP 共用的处理逻辑**）

中文：EF 阶段**不要求专门创作**；创作（PRODUKTION）是 QP 才出现的独立要求。IF1（`Vertonen von Texten`）与 IF3（数字工具 + 记谱）在 QP 各有一条 PRODUKTION 条目。

| 维度 | EF 层 | QP 层（本笔记） | 判据 |
|---|---|---|---|
| ① Schwerpunkte | 无专门创作条目 | `Vertonen von Texten`（IF1）+ 数字工具/记谱（IF3） | EF 不创作，QP 要创作 [已验证] |
| ② 动词 | `beschreiben / benennen` | `entwerfen / entwickeln / komponieren / begründen` | 从描述转向制作 |
| ③ 标准 | 用给定标准 | **自主选择判据**评判自己的创作 | QP 自主立标准 [已验证] |
| ④ 时长 | 无 | **Gestaltungsaufgabe +60 min** | Abitur 规定 [已验证] |

> *Klausur-Satz*: `Während auf EF-Ebene nur beschrieben und analysiert wird, verlangt die QP-Ebene eine eigene Gestaltung samt Begründung; das wirkt stufengerecht, weil die Produktion erst in der Qualifikationsphase eigenständig gefordert wird.`

> ⚠️ **Abitur 时长提醒** [已验证]：LK 300 min / GK 240 min；**选 Gestaltungsaufgabe（Aufgabenart III）时 +60 min**（即 LK 360 / GK 300）。

## 3. 解题方法 (Methoden)

### 3.1 Aufgabenart III 五步法（Kernmethode）

**编号步骤**：
1. **读形态**：题干标了 `Vertonung/Bearbeitung/Stilkopie/Neukomposition` 中的哪一个 —— *KLP 工具：`benennen`（AFB I）*
2. **写构想**：目标效果 + 参数映射表（≥3 组）—— *KLP 工具：`entwerfen`（AFB II）*
3. **作片段**：按映射写出约 8–16 小节，选合适记谱 —— *KLP 工具：`komponieren`（AFB II）*
4. **呈现**：图解式或传统记谱；必要时说明数字工具用法 —— *KLP 工具：`entwickeln`（AFB II）*
5. **论证 + 自评**：每条决策给 `weil` 理由；指出可改进处 —— *KLP 工具：`begründen / beurteilen`（AFB III）*

> **判据 / 决策点**：若题干含「entwerfen/komponieren」→ 必是 III 型，**必须**有 Konzept + Komposition + Erläuterung 三件套。

### 3.2 文本—参数映射法（`Vertonung` 专用）

中文：为文本配乐时，先做**逐句情绪标注**，再映射到参数，最后才落笔。

| 文本特征 | 映射参数 | 示例手段 |
|---|---|---|
| 疑问句 | Melodik | 句尾上行 |
| 叹息/失落 | Melodik + Harmonik | 下行小二度、小调 |
| 急促/紧迫 | Rhythmik + Tempo | 密集音型、加速 |
| 停顿/静默 | Pause + Dynamik | 休止、极弱 |

> *Klausur-Satz*: `Ich übertrage die Struktur des Textes systematisch in musikalische Parameter; das wirkt begründet, weil jede kompositorische Entscheidung so auf eine Textstelle zurückführbar ist.`

### 3.3 记谱呈现法（图解式 vs 传统）

中文：记谱选择本身要说明理由。图解式适合音响形态/音色/噪音；传统记谱适合音高节奏明确的结构。

> *Klausur-Satz*: `Ich wähle die Notation passend zum Gestaltungsziel und begründe die Wahl; das wirkt souverän, weil die QP ausdrücklich sowohl grafische als auch traditionelle Notation vorsieht.`

### 3.4 自我检验法（`überprüfen`，AFB III）

中文：交卷前用三问自检：① 每个目标是否都有对应手段？② 记谱是否清楚可实现？③ 说明是否逐条给了理由？

> *Klausur-Satz*: `Ich überprüfe meine Gestaltung daraufhin, ob jede Entscheidung im Konzept verankert und begründet ist; das wirkt methodisch sauber, weil die Bewertung genau diese Begründung verlangt.`

### 5.2 训练题

**Aufgabe 1 — Vertonung** `[NRW-官方公开题型结构]`
> Entwerfen Sie eine kurze Vertonung (ca. 8–16 Takte, grafische oder traditionelle Notation) zu der vorgegebenen Textstelle. Legen Sie ein Gestaltungskonzept vor und erläutern Sie Ihre kompositorischen Entscheidungen. (Operator: entwerfen, komponieren, begründen) `[题干结构参照 KLP §4 Aufgabenart III（含 Vertonung 形态标注）；解析原创]`

**Aufgabe 2 — Stilkopie** `[NRW-改编]`
> Erstellen Sie eine kurze Stilkopie im Stil einer vorgegebenen Epoche (ca. 8 Takte) und begründen Sie, welche stilistischen Merkmale Sie übernommen haben und warum. (Operator: entwerfen, komponieren, begründen)

**Aufgabe 3 — Bearbeitung** `[原创]`
> Bearbeiten Sie das vorliegende Motiv zu einer kurzen Gestaltung mit verändertem Ausdruck. Dokumentieren Sie Ihr Gestaltungskonzept und erläutern Sie, was Sie beibehalten und was Sie verändert haben. (Operator: entwickeln, komponieren, erläutern)

**Aufgabe 4 — 口试 Teil 2 追问** `[原创]`
> Prüfungsgespräch: „Sie haben für die Vertonung ein absteigendes Motiv gewählt. Welche Wirkung hätte ein aufsteigendes Motiv an derselben Stelle, und nach welchem Kriterium beurteilen Sie, welche Lösung die bessere ist?" (Operator: überprüfen, beurteilen)

### 5.3 Musterlösung（分步，标得分点）

**Aufgabe 1（Vertonung）**
1. 形态声明: 明确 `Vertonung`。 ✓ 得分点：形态标注（KLP 硬要求）
2. Gestaltungskonzept: 目标效果（如「忧伤内省」）+ 参数映射 ≥3 组。 ✓ 得分点：构想清晰（AFB II）
3. Komposition: 约 8–16 小节，记谱清楚。 ✓ 得分点：可实现性
4. 逐条论证: 每条决策 `weil`（如「句尾下行小二度，因为文本是叹息」）。 ✓ 得分点：`weil` 论证（AFB III 核心）
5. 记谱选择说明 + 自我评判: 图解式/传统记谱的理由 + 可改进处。 ✓ 加分点（differenziert）

**Aufgabe 2（Stilkopie）**
1. 形态声明 + 目标风格。 ✓ 得分点：形态明确
2. 列出该风格标志特征（≥3 条，如织体/和声/节奏型）。 ✓ 得分点：风格知识（AFB I–II）
3. 片段实现：特征可识别。 ✓ 得分点：摹写一致性
4. 论证: 说明保留了哪些标志、为何。 ✓ 得分点：`weil` 论证
5. 自评: 与风格规范的贴合度。 ✓ 加分点

**Aufgabe 3（Bearbeitung）**
1. 形态声明 + 原始材料分析（先分析再改）。 ✓ 得分点：材料分析
2. 保留/改变决策清单: 明确「改了什么」。 ✓ 得分点：differenziert
3. 实现 + 记谱。 ✓
4. 论证: 每个改动对应一个表达目标。 ✓ 得分点：决策—目标链（AFB III）
5. 自评: 表达转变是否达到。 ✓ 加分点

**Aufgabe 4（Teil 2）**
1. 复述问题（争取时间）。 ✓
2. 给出替代方案的效果假设（上行 → 希望/上扬）。 ✓ 得分点：参数—效果意识
3. 明示自选判据: `Auf der Grundlage des Kriteriums der Textangemessenheit … urteile ich …`。 ✓ 得分点：自主标准（AFB III）
4. 关联: `Ich vergleiche zwei Lösungen anhand selbst gewählter Kriterien; das wirkt begründet, weil die Bewertung einer Gestaltung eigene Maßstäbe verlangt.` ✓ 得分点：主动关联

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 流程错 | 只交作品，不写 Gestaltungskonzept / Erläuterung | III 型三件套缺一不可；先写构想再落笔 |
| 形态错 | 题干要 Stilkopie，却自由发挥 | 先读形态，再对齐创作 |
| 知识错 | 混淆 Aufgabenart III 的四种形态 | Vertonung≠Bearbeitung≠Stilkopie≠Neukomposition |
| 表达错 | 说明只写「我觉得好听」 | 强制 `weil` 论证：每条决策接一个理由 |
| 记谱错 | 记谱潦草不可实现，或未说明记谱选择 | 按目标选图解式/传统记谱并说明理由 |
| 时间错 | 忽略 Gestaltung 需 +60 min | 备考时按 LK 360 / GK 300 计时练习 |
