# Mündliche Prüfung: Teil 1 als zusammenhängender Vortrag (口试第一部分：连贯演讲训练)

> **中文理解**：本项目为**口试（mündliche Prüfung）方向**。KLP 规定：口试分两段——**Teil 1 是考生「独立、连贯的演讲」（zusammenhängender Vortrag）**，Teil 2 是 **Prüfungsgespräch（考试对话）**，涉及更大的学科与跨学科关联；总时长 **20–30 分钟**；**考生无选择权**；题目**不得只限单一 Kurshalbjahr 的内容**，且须覆盖全部三个 AFB。[已验证：KLP §4 Mündliche Abiturprüfung]
>
> **Musik 专属规定**：**口试第一部分的题目，以笔试的 Aufgabenart 为取向**（`Im Fach Musik orientieren sich die Aufgaben für den ersten Prüfungsteil an den Aufgabenarten für die schriftliche Abiturprüfung.`）[已验证]。→ 只要按笔试 **Aufgabenart I / II / III** 三型各练一套，即可覆盖口试 Teil 1。
>
> **Klausur-Relevanz**：🔴 **口试方向必补**。Teil 1 要求「不用提问就能讲 5–8 分钟」，这是与笔试最不同的能力，必须专门训练。
>
> ⏳ 待确认：口试时长、Prüfungstermin、Hörbeispiele-Liste 未定；口试中 Aufgabenart III 的**实操形态**（是否现场作曲、如何呈现）KLP 未规定 [未获取到]。本篇按三型通用结构写。

## 2. 知识结构 (Struktur)

### 2.0 口试结构总图（Teil 1 + Teil 2）

中文：口试不是「问答串烧」（KLP 明文禁止 `zusammenhanglose Einzelfragen aneinanderzureihen`）。Teil 1 必须**自成一体**；Teil 2 是围绕同一题目的**对话式深化**。

| 段 | 时长（估） | 任务 | 考生动作 |
|---|---|---|---|
| 准备 | 考前（书面题目提前给） | 阅读任务 + 听例 | 记关键词、定主线 |
| **Teil 1** | 约 5–8 min | 连贯演讲 | 按 Aufgabenart 结构讲完，不被打断 |
| **Teil 2** | 约 10–20 min | Prüfungsgespräch | 接追问、跨 IF/跨学科 |

> *Klausur-Satz*: `Im ersten Teil trage ich meine Ergebnisse zusammenhängend vor, im zweiten Teil vertiefe ich sie im Prüfungsgespräch; das entspricht der Vorgabe, weil keine unzusammenhängenden Einzelfragen gestellt werden dürfen.`

### 2.1 Teil 1 的通用骨架（六段，可直接背）

中文：无论哪种 Aufgabenart，Teil 1 都可用这套骨架组织，保证「连贯」：

```
1. Einleitung      —— 任务复述 + 主线预告（„Ich werde … darlegen."）
2. Beschreibung    —— 客观听感/参数（听到什么）
3. Analyse         —— 结构 + 术语（怎么组织的）
4. Deutung         —— 结构 → 效果 → 意义（意味着什么）
5. Einordnung      —— 归类（时代/体裁/语境）
6. Fazit + Urteil  —— 自己的判断 + 明示标准
```

> *Klausur-Satz*: `Ich strukturiere meinen Vortrag in Einleitung, Beschreibung, Analyse, Deutung, Einordnung und Fazit; das wirkt klar, weil eine feste Gliederung den roten Faden sichert.`

### 2.2 Aufgabenart I 的 Teil 1 结构（Analyse und Interpretation）

中文：主线 = 「描述 → 分析 → 诠释」。**分析结果必须导向诠释**（KLP：分析结果是诠释与评判的基础）。

- 结构：任务复述 → 参数描述 → 结构/曲式分析 → 表达意图诠释 → 惯例声明 → 判断
- 高频追问（Teil 2）：`Woran erkennen Sie das?` / `Welche Konvention steht dahinter?`

> *Klausur-Satz*: `Ich analysiere die Struktur und leite daraus die Deutung ab; das wirkt schlüssig, weil das Analyseergebnis die Grundlage der Interpretation bildet.`

### 2.3 Aufgabenart II 的 Teil 1 结构（Erörterung fachspezifischer Aspekte）

中文：主线 = 「立场 → 正反论证 → 结论」。常以**文本/引言**为出发点，音乐取课堂已知材料。

- 结构：复述命题 → 提出立场 → 正论点（+证据）→ 反论点（+证据）→ 权衡 → 结论（明示标准）
- 高频追问：`Welche Gegenposition gibt es?` / `Auf welcher Grundlage urteilen Sie?`

> *Klausur-Satz*: `Ich erörtere die These, indem ich Argumente und Gegenargumente abwäge und zu einem begründeten Urteil komme; das wirkt überzeugend, weil die Abwägung mehrere Positionen einbezieht.`

### 2.4 Aufgabenart III 的 Teil 1 结构（Gestaltung + Erläuterung）

中文：主线 = 「构想 → 实现 → 论证」。先给 **Gestaltungskonzept**（塑造构想），再说明作曲决策，并**按要求呈现**（图解式或传统记谱）。⚠️ 口试中该型的实操形态 KLP 未规定 [未获取到]，按笔试逻辑准备。

- 结构：任务与形态（Vertonung/Bearbeitung/Stilkopie/Neukomposition）→ 构想 → 参数决策（为什么这样写）→ 呈现说明 → 自我评判
- 高频追问：`Warum diese Entscheidung?` / `Wie würde es klingen, wenn Sie … änderten?`

> *Klausur-Satz*: `Ich erläutere mein Gestaltungskonzept und begründe jede kompositorische Entscheidung; das wirkt nachvollziehbar, weil Aufgabe III neben der Gestaltung ausdrücklich die Begründung verlangt.`

### 2.5 EF→QP 升级在口试中的体现（**3 个 IF 在 EF/QP 共用的处理逻辑**）

中文：口试题目不得只限单一学期内容，因此可能同时触及 EF 层与 QP 层。答同一 IF 时，**按学段要求调整深度**：

| 维度 | 若题目落 EF 层 | 若题目落 QP 层 | 判据 |
|---|---|---|---|
| 描述深度 | 说出「听到什么」 | 分析「为什么/如何起作用」 | 强度上移 |
| 评判 | 用**给定**标准 | 用**自主选择**标准并明示 | QP 自主立标准 [已验证] |
| 跨 IF | 单 IF 内 | 常要求跨 IF / 跨学科关联 | Teil 2 特征 [已验证] |
| 创作 | 一般不要求 | 可能要求 Gestaltung | QP 独有 [已验证] |

> *Klausur-Satz*: `Ich passe die Tiefe meiner Antwort an die Stufe an: auf EF-Ebene beschreibe ich, auf QP-Ebene analysiere ich mit selbst gewählten Kriterien; das wirkt stufengerecht, weil derselbe Inhaltsfeld-Begriff je nach Anforderung anders zu bearbeiten ist.`

> ⚠️ 口试备考结论：**三个 IF（意义/发展/用途）× 三个 Aufgabenart × EF/QP 两层**都可能出现 → 必须**全面覆盖**，不能押题。参见《Wirkungsabsichten-und-Stereotype.md》（IF3 空白风险）与《Paradigmenwechsel.md》（IF2 QP）。

## 3. 解题方法 (Methoden)

### 3.1 Teil 1 演讲五步准备法（考前 15–20 min）

**编号步骤**：
1. **圈出 Operatoren**，判定 Aufgabenart（I/II/III）—— *KLP 工具：Aufgabenart 定位*
2. **听例 ≥2 遍**，第一遍写参数（听到什么），第二遍写结构 —— *KLP 工具：`beschreiben`（AFB I）*
3. **定主线**（Roter Faden）：一句话说「我要证明/展示什么」 —— *KLP 工具：`herausarbeiten`（AFB II）*
4. **填六段骨架**（§2.1），每段写 3–5 个关键词，**不写完整句** —— *KLP 工具：结构组织*
5. **准备 2 个「备用论点」** 应对 Teil 2 追问 —— *KLP 工具：`beurteilen`（AFB III）*

> **判据 / 决策点**：若题干含「analysieren/interpretieren」→ Aufgabenart I 结构；含「erörtern/beurteilen」→ II；含「entwerfen/komponieren」→ III。

### 3.2 「听到→效果→因为」句式法（口试得分句）

中文：所有描述句都用同一模板，保证专业语言与论证性。

> *Klausur-Satz*: `Ich höre … (Parameter); das wirkt …, weil … (Fachbegriff/Konvention).`

### 3.3 时间控制法

中文：Teil 1 约 5–8 min。练习法：每段限 1–1.5 min，用手机计时；若超时，砍「描述」段细节，保「分析+诠释+判断」段。

> *Klausur-Satz*: `Ich verteile meine Zeit auf die sechs Abschnitte und halte den roten Faden ein; das wirkt souverän, weil ein klarer Zeitrahmen den Vortrag strukturiert.`

### 3.4 Teil 2 接话法（Prüfungsgespräch）

中文：被追问时三步走：① **复述问题**（争取时间）② **给立场/答案** ③ **给理由 + 主动关联**（连到另一 IF 或跨学科）。

> *Klausur-Satz*: `Ich greife die Frage auf, formuliere meine Position und begründe sie mit einem Bezug zu einem anderen Inhaltsfeld; das wirkt sicher, weil ich aktiv Zusammenhänge herstelle.`

| 笔试对照 | GK 240 / LK 300 min（+60 Gestaltung）[已验证] |
| 材料 | 题目连同材料**口试前书面交给考生** [已验证] |

### 5.2 训练题（三型各一套，附口试呈现要求）

**Aufgabe 1 — Aufgabenart I（Analyse und Interpretation）** `[NRW-改编]`
> Sie erhalten einen Hörausschnitt. Analysieren Sie die musikalischen Strukturen und interpretieren Sie die Ausdrucksabsicht. Tragen Sie Ihre Ergebnisse in einem zusammenhängenden Vortrag vor (ca. 6 min). (Operator: analysieren, interpretieren)

**Aufgabe 2 — Aufgabenart II（Erörterung fachspezifischer Aspekte）** `[原创]`
> „Filmmusik manipuliert den Zuschauer." Erörtern Sie diese These anhand von Beispielen und nehmen Sie begründet Stellung. Präsentieren Sie Ihre Argumentation in einem zusammenhängenden Vortrag (ca. 6 min). (Operator: erörtern, Stellung nehmen)

**Aufgabe 3 — Aufgabenart III（Gestaltung mit Erläuterung）** `[NRW-官方公开题型结构]`
> Entwerfen Sie eine kurze Vertonung (ca. 8 Takte, grafische oder traditionelle Notation) zu einer vorgegebenen Szene und begründen Sie Ihr Gestaltungskonzept im Vortrag (ca. 6 min). (Operator: entwerfen, komponieren, begründen) `[题干结构参照 KLP §4 Aufgabenart III（含 Vertonung 形态标注）；解析原创]`

**Aufgabe 4 — Teil 2 追问训练（跨 IF）** `[原创]`
> Prüfungsgespräch: „Sie haben die Struktur analysiert — wie würden Sie dasselbe Beispiel aus der Perspektive der Verwendung (IF3) beurteilen?" (Operator: einordnen, beurteilen)

### 5.3 Musterlösung（分步，标得分点）

**Aufgabe 1（Aufgabenart I）**
1. Einleitung: 任务复述 + 主线（„Ich zeige, wie Struktur und Ausdruck zusammenhängen."）。 ✓ 得分点：主线明确
2. Beschreibung: 参数逐项（Melodik/Rhythmik/Harmonik/Dynamik/Klangfarbe）。 ✓ 得分点：≥3 参数 + 术语
3. Analyse: 结构/曲式 + 术语。 ✓ 得分点：结构判断有据
4. Deutung: `Ich höre …; das wirkt …, weil …`。 ✓ 得分点：分析→诠释链条完整
5. Konvention: 惯例声明（非固有）。 ✓ 加分点
6. Fazit: 判断 + 明示标准。 ✓ 得分点（AFB III）

**Aufgabe 2（Aufgabenart II）**
1. 复述命题 + 明确立场（部分成立/不成立）。 ✓ 得分点：立场明确
2. Pro-Argument: 音乐确实引导感知（Wahrnehmungssteuerung，举例）。 ✓
3. Contra-Argument: 观众有自主解读空间；效果依赖惯例与语境。 ✓ 得分点：≥2 立场
4. 权衡: `Einerseits … andererseits …`。 ✓ 得分点：权衡句式
5. 结论 + 明示标准: `Auf der Grundlage des Kriteriums … urteile ich …`。 ✓ 得分点：自主标准（AFB III）

**Aufgabe 3（Aufgabenart III）**
1. 任务与形态: 明确 `Vertonung`（KLP 要求题目标明形态）。 ✓ 得分点：形态标注
2. Gestaltungskonzept: 目标效果 + 参数映射（如「不安→半音/低音区」）。 ✓ 得分点：构想清晰
3. 作曲决策论证: 每条决策给理由。 ✓ 得分点：`weil` 论证（Aufgabenart III 硬要求）
4. 呈现说明: 图解式/传统记谱的选择理由。 ✓ 得分点：记谱说明
5. 自我评判: 效果是否达到 + 改进方向。 ✓ 加分点

**Aufgabe 4（Teil 2）**
1. 复述问题（争取时间）。 ✓
2. 立场: 同一例可从 IF3 视角重判为「功能/效果」对象。 ✓ 得分点：跨 IF 关联
3. 理由 + 主动关联: `Ich ordne dasselbe Beispiel nun unter dem Aspekt der Verwendung ein; das wirkt schlüssig, weil Struktur und Funktion zwei Perspektiven auf dasselbe Objekt sind.` ✓ 得分点：跨 IF 主动关联

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 结构错 | Teil 1 变成「想到哪说到哪」，无主线 | 考前填六段骨架，每段 3–5 关键词 |
| 知识错 | 只描述不诠释（Aufgabenart I 半途而废） | 强制「分析→诠释」链条，收尾必给判断 |
| 表达错 | 用日常语（「很好听」）代替术语 | 全用 `Ich höre …; das wirkt …; weil …` 句式 |
| 时间错 | 描述段过长，没时间给判断 | 计时练习；超时先砍描述细节 |
| 对话错 | Teil 2 只答一个字，不主动关联 | 三步接话法：复述→立场→理由+跨 IF 关联 |
| 覆盖错 | 只练一种 Aufgabenart | 三型各练一套（本篇 §5.2） |
