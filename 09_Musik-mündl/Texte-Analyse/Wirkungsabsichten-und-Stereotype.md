# Wirkungsabsichten und Stereotype (效果意图与刻板印象)

> **中文理解**：IF3「音乐的用途」的 EF 层问的不是「音乐美不美」，而是「**谁在什么场合用这段音乐、想达到什么效果、用了什么手段**」。核心概念是 **Wirkungsabsicht（效果意图）**——电影配乐、广告曲、仪式音乐、政治宣传曲都不是「自由艺术」，而是**带着任务**写的；实现任务的工具仍然是老一套参数（Melodik/Rhythmik/Harmonik/Dynamik/Klangfarbe）。第二层概念是 **Stereotyp / Klischee（刻板印象 / 陈词滥调）**：某些音乐套路之所以「一响就懂」，是因为听众**共享**一套惯例联想，而不是音乐本身固有悲喜。[已验证：KLP IF3 EF 两条 inhaltliche Schwerpunkte 即此两项]
>
> **Klausur-Relevanz**：🔴 **本 IF 在本项目内曾完全空白**。而 KLP 明文规定**口试题目不得只限于单一 Kurshalbjahr 的课堂内容** → 3 个 IF 均可能被考。IF3 空白 = **直接考试风险**。本笔记为 IF3 的首篇，与《Film-und-Werbemusik.md》配套。
>
> ⏳ 待确认：Halbjahr-Thema 与具体听力例曲清单未定。本篇**按 IF 全覆盖写，不押单一主题**；具体作品处标 `⏳`。

## 1. 核心概念 (Kernbegriffe)

| 术语 (DE) | 中文 | English | 定义 / 判据 | 备注 |
|---|---|---|---|---|
| `Wirkungsabsicht` | 效果意图 | intended effect | 使用者（作曲者/导演/广告主/机构）希望音乐在听者身上**引发**的反应 | IF3 EF 核心词 [已验证] |
| `Wirkung` | 效果 / 实际作用 | (actual) effect | 音乐在**具体听者**身上真正产生的反应 | 与 Absicht **不是一回事**，考试常考区分 |
| `musikalische Struktur` | 音乐结构 | musical structure | 参数秩序 + 形式原则的组织 | 效果的**手段**（共享基础层） |
| `Stereotyp` | 刻板印象 | stereotype | 被反复使用、被听众**共享**的固定音乐套路（如「恐怖片音效」） | 中性词，重在「共享」 [据推断] |
| `Klischee` | 陈词滥调 | cliché | 因过度使用而**失去新意**的套路 | 常与 Stereotyp 并列出现 [已验证：KLP 原文用「Stereotype und Klischees」] |
| `Wahrnehmungsbedingung` | 感知条件 | condition of perception | 使套路生效的前提：听众**先验**共享的惯例知识 | QP 层升级为 `Wahrnehmungssteuerung` |
| `Funktionskontext` | 功能语境 | functional context | 音乐被使用的场合（电影/广告/仪式/政治/游戏） | IF3 的**视角**本身 |
| `Parodie` / `Verfremdung` | 戏仿 / 陌生化 | parody / defamiliarization | 故意搬用套路却反其道而行，使套路「失效」 | AFB III 的讨论素材 |
| `Leitmotiv` | 主导动机 | leitmotif | 固定角色/情境的专属动机（Wagner 传统） | IF3 与 IF1 交叉点 |

> 三语提示：口试只需说德语，但**术语的英文等价**有助于把概念想清楚（例如 effect vs. intended effect 的差别，德语 `Wirkung` vs. `Wirkungsabsicht` 同构）。

## 2. 知识结构 (Struktur)

### 2.1 Wirkungsabsicht ≠ Wirkung（意图与效果之别）—— 本 IF 的第一道分水岭

中文：**意图**是「作者/使用者想要什么」，**效果**是「听者实际感到什么」。考试里最容易失分的就是把两者当成一回事。分析时永远先问：**是谁的意图？面向谁？在什么语境？**

> *Klausur-Satz*: `Ich unterscheide zwischen der Wirkungsabsicht des Produzenten und der tatsächlichen Wirkung beim Hörer; das ist entscheidend, weil dieselbe Struktur in verschiedenen Kontexten unterschiedlich wirken kann.`

### 2.2 套路清单：Stereotype-Katalog（按使用语境分类）

中文：IF3 要求「识别套路」。下面是**按语境**整理的常见套路，注意：套路的价值在于**可辨识**，不在于「高级」。⚠️ 全部为通用音乐学常识归纳，非教材原文。

| 语境 Kontext | 典型套路 Stereotyp | 常配手段 Struktur | 意图 Wirkungsabsicht |
|---|---|---|---|
| 恐怖片 Horrorfilm | 不协和音簇、高音弦乐颤音、突然的静默+爆响 | Harmonik（Cluster/Tritonus）、Klangfarbe（sul ponticello） | 制造不安、警觉 |
| 英雄/史诗 Epos | 大调铜管号角、切分附点、宽广旋律 | Melodik（号角音型）、Dynamik（ff） | 唤起崇高、集体感 |
| 广告 Werbung | 明快大调、短动机、记忆点（Ohrwurm）、渐强收尾 | Melodik（易记动机）、Formtyp（短循环） | 记忆度 + 好感迁移 |
| 悲剧/哀悼 Tragik | 小调、下行半音「叹息动机」、弦乐连奏 | Harmonik（小调/半音）、Melodik（Lamento） | 共情、肃穆 |
| 政治宣传 Propaganda | 进行曲节拍、统一齐奏、简单重复口号式旋律 | Rhythmik（Marsch）、Melodik（重复） | 凝聚、服从、动员 |
| 仪式 Ritual | 固定曲式、无变奏的重复、钟声/管风琴音色 | Formtyp（Strophenform）、Klangfarbe（Orgel） | 庄严、秩序感 |
| 电子游戏 Videospiel | 循环（Loop）、强度分层（Layer）、无明确终止 | Formtyp（循环）、Dynamik（Schichten） | 持续沉浸 + 反馈 |

> *Klausur-Satz*: `Ich benenne das Stereotyp und ordne es dem Funktionskontext zu; das wirkt nachvollziehbar, weil das Klischee erst durch den gemeinsamen Kontext der Hörer verständlich wird.`

### 2.3 套路为何有效：共享惯例（→ 连接 IF1）

中文：套路不是「音乐固有属性」，而是**听众共享的惯例联想**。恐怖片的不协和音之所以「吓人」，是因为听众**被训练过**在这种语境里把不协和读作危险。这一点直接连到 IF1 的「Ausdrucksgesten vor dem Hintergrund musikalischer Konventionen」——**没有惯例，就没有效果**。

> *Klausur-Satz*: `Ich erläutere die Wirkung nicht als Eigenschaft der Musik, sondern als Folge gemeinsamer Hörkonventionen; das wirkt differenziert, weil damit erklärt wird, warum dasselbe Klischee je nach Hörerbiografie unterschiedlich anschlägt.`

### 2.4 EF→QP 升级：同一 IF 的层级上移（**3 个 IF 在 EF/QP 共用的处理逻辑**）

中文：Musik 的 3 个 IF **名称在 EF 与 QP 完全相同**，升级不换 IF，而是**同一 IF 内四维上移**。IF3 的具体路径：

| 维度 | EF 层（本笔记） | QP 层（见后续笔记） | 判据 |
|---|---|---|---|
| ① inhaltliche Schwerpunkte | `Wirkungsabsichten / Stereotype und Klischees` | `Wahrnehmungssteuerung / außermusikalische Kontexte` | 从「识别套路」→「分析操控机制」 |
| ② 动词强度 | `beschreiben / benennen` | `analysieren / beurteilen / erörtern` | 从「说出是什么」→「论证怎么起作用」 |
| ③ 评判标准 | 用**给定**标准评判套路效果 | 用**自主选择**的标准评判（`selbstständig ausgewählte Kriterien`） | QP 要求自己立标准 [已验证] |
| ④ PRODUKTION | 无专门创作条目 | 出现「数字工具 + 图解/传统记谱」制作条目 | QP 独有 [已验证] |

> *Klausur-Satz*: `Ich unterscheide die EF-Ebene des Benennens von der QP-Ebene des Analysierens der Wahrnehmungssteuerung; das wirkt präzise, weil derselbe Inhaltsfeld-Begriff je nach Anforderungsbereich anders zu bearbeiten ist.`

> ⚠️ 口试含义：题目**不得只限单一学期**，因此**EF 与 QP 两层都可能被问到**。本笔记 EF 层打底，QP 层由《Wahrnehmungssteuerung.md》《Musik-in-Kontexten.md》（§4 #11/#12，已建）承接。

## 3. 解题方法 (Methoden)

### 3.1 逆向分析法（Wirkung → Struktur，IF3 首选）

**编号步骤**：
1. 先定**语境与使用者**：这段音乐出现在哪？谁放的？面向谁？—— *KLP 工具：`Funktionskontext` 归类（`einordnen`，AFB II）*
2. 写下**推测的效果意图**（一句话）：`Man will …, dass der Hörer …` —— *KLP 工具：`Wirkungsabsicht` 假设（`formulieren`，AFB I）*
3. 回到**参数**找证据：Melodik / Rhythmik / Harmonik / Dynamik / Klangfarbe / Form 逐项，只写「听到什么」 —— *KLP 工具：共享基础层参数系统（`beschreiben`，AFB I）*
4. 把参数**连到意图**：`Ich höre X; das wirkt Y, weil Z.` —— *KLP 工具：`erlaeutern`（AFB II）*
5. 最后加一句**惯例声明**：这套效果依赖共享套路 —— *KLP 工具：`herausarbeiten`（AFB II）*

> **判据 / 决策点**：当题干问「这段音乐**想干什么**」（而非「这是什么风格」）时，用逆向法；若问「这是什么时代的音乐」→ 转 IF2。

### 3.2 参数—效果对照法（用于快速建句式）

中文：把「听到的参数」与「套路效果」做成对照表，口试时现场配对，避免只说「很紧张」而说不出手段。

| 参数 Parameter | 听感线索 | 常见套路效果 |
|---|---|---|
| Harmonik | 不协和 / 半音下行 / 属持续音 | 不安 / 哀伤 / 悬置 |
| Rhythmik | 进行曲 / 切分 / 突然停顿 | 动员 / 悬念 / 惊愕 |
| Klangfarbe | 铜管齐奏 / 弦乐颤音 / 电子 Pad | 崇高 / 紧张 / 现代感 |
| Dynamik | 突强突弱 / 长渐强 | 惊吓 / 期待 |
| Melodik | 号角音型 / 叹息动机 / 易记短句 | 英雄 / 悲伤 / 记忆度 |

> **判据 / 决策点**：口试中**每说一个效果，必须配一个参数**；无参数支撑的效果句 = 不得分（见 §6 表达错）。

### 3.3 套路「失效」检测法（AFB III 用）

中文：若作品**故意搬用套路却反着用**（如把英雄号角用在小丑出场），这就是 Parodie/Verfremdung，是高级论点。步骤：① 认出套路 → ② 指出语境错位 → ③ 论证意图（讽刺/批判）。

> *Klausur-Satz*: `Ich erkenne ein bekanntes Klischee, das hier jedoch verfremdet eingesetzt wird; das wirkt ironisch, weil die Erwartung des Hörers bewusst enttäuscht wird.`

**不适用**（本项目设计上 Musik 无中德对照技法；CN-Methode 仅用于理科）。理由：音乐分析高度依赖德语术语体系与西方音乐惯例，中国高中音乐课程无对应的「音乐学分析技法」可迁移。

| 口试适配 | Teil 1：连贯演讲「语境→意图→参数→效果→惯例」；Teil 2：追问「若换一段音乐，效果会怎样变」 |

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> Ein kurzer Orchesterausschnitt aus einem Spielfilm wird eingespielt: tiefe Streicher tremolo, Cluster, plötzliche Stille, dann ein lauter Schlag. Benennen Sie das vermutete Klischee, ordnen Sie den Funktionskontext ein und beschreiben Sie die eingesetzten musikalischen Mittel. (Operator: benennen, beschreiben, einordnen)

**Aufgabe 2** `[原创]`
> Ein Werbespot unterlegt ein Produkt mit einem kurzen, eingängigen Dur-Motiv, das am Ende in einer Steigerung wiederholt wird. Analysieren Sie die Wirkungsabsicht und erläutern Sie den Zusammenhang zwischen Struktur und angestrebter Wirkung. (Operator: analysieren, erläutern)

**Aufgabe 3** `[NRW-官方公开题型结构]`
> „Die Wirkung von Filmmusik liegt in der Musik selbst." Erörtern Sie diese These am Beispiel eines Ihnen bekannten Klischees und nehmen Sie begründet Stellung. (Operator: erörtern, Stellung nehmen) `[题干结构参照 KLP §4 Aufgabenart II，解析为原创]`

### 5.3 Musterlösung（分步，标得分点）

**Aufgabe 1**
1. Klischee benennen: `Tremolo-Cluster + abrupte Stille + Schlag` = typisches **Horrorfilm-Stereotyp**。 ✓ 得分点：术语正确（Stereotyp/Klischee）
2. Funktionskontext: `Spielfilm (Thriller/Horror)`, Adressat = Kinopublikum。 ✓ 得分点：语境归类明确
3. Mittel: `Harmonik`（Cluster/Tritonus → 不协和）；`Klangfarbe`（sul ponticello/tremolo → 神经质）；`Dynamik`（pp→Stille→ff 突爆）。 ✓ 得分点：≥3 参数，每个带术语
4. Satz: `Ich höre Cluster und Tremolo, die in eine plötzliche Stille münden; das wirkt bedrohlich, weil die Unterbrechung die Erwartung eines Schrecks aufbaut.` ✓ 得分点：效果句含「因为」
5. 惯例声明: 效果依赖共享的恐怖片惯例。 ✓ 得分点（加分项）

**Aufgabe 2**
1. Struktur: `Dur-Motiv`（Melodik：易记）、`Steigerung`（Dynamik/Instrumentation 叠加）。 ✓
2. Wirkungsabsicht: 建立**好感 + 记忆度**，让产品与正面情绪绑定。 ✓
3. 关联句: `Ich höre eine Steigerung im Wiederholungsprinzip; das wirkt einprägsam und positiv, weil Wiederholung die Erinnerung stützt und Dur mit Offenheit verknüpft wird.` ✓
4. 惯例声明: 正面迁移是广告音乐的惯例，非音乐固有。 ✓（加分项）

**Aufgabe 3**
1. 立场明确：**该说法不成立**（Wirkung 依赖语境与惯例，非音乐固有）。 ✓ 得分点：明确立场
2. 反例：同一不协和音在恐怖片=威胁，在先锋音乐=中性/审美对象。 ✓
3. 论证链：`weil` 语境 → `deshalb` 效果差异。 ✓ 得分点：论证性
4. 结论：`Die Wirkung entsteht erst im Zusammenspiel von Struktur und Kontext; deshalb ist die These in dieser absoluten Form zu verwerfen.` ✓

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把 `Wirkungsabsicht`（意图）与 `Wirkung`（效果）混为一谈 | 分析前先写一行「谁的意图 / 面向谁」 |
| 知识错 | 把套路效果说成「音乐固有属性」（「不协和音本来就吓人」） | 一律加「惯例性」限定：`aufgrund gemeinsamer Hörkonventionen` |
| 表达错 | 只说「很紧张/很震撼」而不给参数 | 强制句式 `Ich höre X; das wirkt Y, weil Z.`（每句必带参数） |
| 视角错 | 只描述音乐，不谈语境/使用者 | IF3 必须先答「谁在什么场合用」再谈音乐 |
