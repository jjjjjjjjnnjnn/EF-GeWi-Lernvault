# Klausur Teil B Doppelpack: Hörverstehen + Mediation (offizielle Formate,待老师定考哪轨)

> 中文：英语 Klausur 固定结构= Teil A（写作+阅读综合，已有 Role-Models 笔记）+ Teil B（二选一：听力 或 转述/调解）。两轨都按 NRW 官方施工标准准备，考哪轨都不慌；官方 EF 评分表是公开的，照着练就是照着评分标准练。

## 1. Track 1: Hörverstehen（听力，EF 典型量）

- 中文：EF 一般 2 个听力文本、共约 6 分钟、每篇听两遍、全程约 20 分钟。题型只在四种里出：选择（multiple choice）、配对（matching）、简答（short answer）、补全（completion/table）。一题只考一种听法：抓大意（global）、捞细节（selective）、理关系（detailed）。
- 官方铁律（直接当检查表用）：题目按听力顺序排、题与题独立（不连环）、不抄原文措辞当正确选项、不只靠常识蒙对、题干短、少用否定。
- 只评内容对错，不评语言（听力部分写错单词不扣分）——所以先抓对，再写整齐。
- 流程句：`First listen for the gist, second listen for the details; I note keywords, not full sentences.`
- Quelle: MSB NRW Konstruktionshinweise Klausuren moderne Fremdsprachen (Okt 2025) + Handreichung Hoerverstehen/Mediation (standardsicherung.schulministerium.nrw.de) — 只转述规则，链接见 Ressourcen.md。

## 2. Track 2: Mediation / Sprachmittlung（德→英转述）

- 中文：给一篇德语原文（EF 较短，Abitur 级 450–600 词），任务是写成英文目标文本（email、article、summary 等，题里会点名格式）。只转述题目要的那几个方面，不是全文翻译——选题（selection）本身就是考点。
- 三段式动笔：Situation saisir（谁写给谁、干什么）→ relevante Aspekte auswaehlen（只捡题要的点）→ Zieltextformat einhalten（格式分开算分）。
- 评分两块：内容（要点全、切题）+ 语言（脱离原文自己组织句子、用主题词汇、语法拼写）。背出来的"万能句"必须改写贴合原文，照抄德语句式是扣分项。
- 流程句：`I select only the relevant aspects and reshape them into the required target format.`
- Quelle: 同上官方文件 + Bezirksregierung Duesseldorf EF-Bewertungsraster (A/B/C, oeffentlich) — 只转述规则。

## 3. Doppelpack-Checkliste（考前一夜对照表）

- [ ] 两轨题型名能英德对译（multiple choice = Auswahlaufgabe 等）。
- [ ] 听力：第一遍只写关键词，第二遍才补细节；不确定就按文本顺序猜位置。
- [ ] 转述：先划题要的 Aspekte，再动笔；格式（称呼/标题/段落）先搭架子。
- [ ] 时间：听力跟录音走不回头；转述留 5 分钟检查格式+拼写。
