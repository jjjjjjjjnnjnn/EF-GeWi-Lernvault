# Fehlerschwerpunkte, Selbstevaluation und Mehrsprachigkeit (错误重点、自我评估与多语档案)

> **中文理解**：这是 **KB4 `Sprachlernkompetenz`（语言学习能力）** 的合篇，对应 KLP §3.4 策略清单的第 8、9 条（`nachhaltiger Umgang mit Fehlerschwerpunkten`、`Selbstevaluationsinstrumente`）与 EF 明文的 `Mehrsprachigkeitsprofil` [已验证，`Englisch-Oberstufe.md` §3.4]。KB4 是 KLP 明文称有「特殊教育价值」的**元层**，**不单独成 Abitur 题**，但它决定前三个能力领域的**增长速率**，且 `Erfüllung fremdsprachlicher Normen` 与 `Sicherheit im Umgang mit der Fremdsprache` 两项评分标准直接由它兑现 [已验证，KLP §4.3]。
>
> **Klausur-Relevanz**：这是 Lernbaum **失分点 ②「语言规范与语域失控」** 的**上游治理**——考试里丢的语言分，本质是平时没建错误清单、没做产出侧自检。本篇交付三样可直接执行的东西：① 四类错因的**可持续管理流程**；② receptive + productive **双向自检表**；③ 中/德/英**三语对照档案**（对中文母语者价值最高）。

## 2. 知识结构 (Struktur)

### 2.1 错误重点的四类错因（本项目 `Fehlerlog.md` 已列 + 本篇扩展）

**中文**：错误**不能按「拼写错 / 语法错」分**，而要按**认知环节**分——因为**错因决定对策**。英语 Lernbaum §0③ 与本项目 `Fehlerlog.md` 已锁定四类 [已验证]。

| 类型 | 表现（本项目已列） | 真正要练的能力 |
|---|---|---|
| **辨别错** (discrimination) | 分不清 `summarize` 与 `comment`；Summary 里加了评论 | 读题 → 任务边界判断 |
| **知识错** (knowledge) | Analysis 只点名 device 不给 effect；时态用错（Summary 用 past） | 概念 / 术语 / 规则本身 |
| **表达错** (expression) | 中式英语、德式英语；句子能懂但不地道 | 语块（collocation）与句法 |
| **语域错** (register) | 正式信里出现 `gonna`；一篇内跳档 | 语用适切性（`pragmatische Angemessenheit`）|

> *Klausur-Satz*: `I classify every error by its cause — discrimination, knowledge, expression or register — because each cause needs a different remedy.`

### 2.2 反馈三层（把「对答案」升级成「改机制」）

**中文**：Brummer et al. 2024（g≈0.41；KR g≈0.64）[据推断，Lernbaum §0②]。**一整套做完再统一对答案**，然后三层收口 [据推断]。

1. **KR（Knowledge of Results）**：先判对错，不改写。
2. **延迟展开**：隔一段时间再回看，解释**为什么**错。
3. **过程反馈**：归类错因 + 写一句「下一步改什么」+ **换一道新题验证**（迁移保障）。

> *Klausur-Satz*: `Feedback only counts once I have written down the next concrete step and tested it on a new task.`

### 2.3 双向自检表（receptive + productive）—— EF 每半学期一次

**中文**：现有自检偏**接受性**，导致**高估水平** [据推断，Lernbaum KB4 L2.3]。自检必须**两侧对称**，结果直接回写 `Fehlerlog.md` 排优先级。

| 维度 | 接受性（receptive）| 产出性（productive）|
|---|---|---|
| 词汇 | 能读懂 B2 文本的生词率 < 5%？ | 合书能默写出主题词 + 搭配？ |
| 语法 | 能识别复杂从句结构？ | 能主动写出三种从句且不错？ |
| 语域 | 能判断段落正式度？ | 能按目标读者切换 register？ |
| 题型 | 能认出题干 Operator？ | 能在限时内按 Operator 产出？ |

> *Klausur-Satz*: `My self-check covers both receptive and productive skills, because reading well does not mean writing well.`

### 2.4 多语档案（中 / 德 / 英三语对照）

**中文**：KLP EF 明文要求 `Mehrsprachigkeitsprofil` [已验证]。对中文母语者，核心价值在**显性标注迁移**：哪些结构中文/德语**正迁移**（帮），哪些**负迁移**（坑）。

| 现象 | 来源语 | 对英语的影响 | 对策 |
|---|---|---|---|
| 无冠词/量词习惯 | 中文 | 漏 `a/the`、`information` 加 `s` | 名词可数性清单 |
| 主谓一致弱标记 | 中文 | `he go`、`the list show` | 写作后专项扫一遍 |
| 语序/从句框架 | 德语 | 动词位置负迁移、句子过长 | 拆句训练 |
| 复合名词/搭配 | 德语 | 直译造词（`handy` 类） | 查搭配词典 |
| 时态体貌 | 中文 | Summary 误用过去时 | Summary 固定 simple present |

> *Klausur-Satz*: `My Chinese and German both shape my English; I keep a profile of where they help and where they mislead me.`

## 3. 解题方法 (Methoden)

### 3.1 错误清单的可持续管理四步（每周 15 min）

**编号步骤**：
1. **收集**：整套卷子做完后一次性登记错题，标**原句 + 我的写法 + 正确写法** —— *KLP 工具：`nachhaltiger Umgang mit Fehlerschwerpunkten`* [已验证]。
2. **归类**：按 §2.1 四类打标（辨别 / 知识 / 表达 / 语域）—— *KLP 工具：`Fehlerschwerpunkte`*。
3. **转卡**：只把**知识错 + 表达错**做成 Anki 卡（错误句 → 正确句），走 FSRS 到期制 —— *KLP 工具：间隔重复* [据推断]。
4. **迁移验证**：下套卷子前先默写高频错项，再在新题里检验是否复发 —— *KLP 工具：`Transfersicherung`*。

> **判据 / 决策点**：**辨别错不进 Anki**（要练判断，不是背）；**拼写错与语域错不得混类**（对策完全不同）。

### 3.2 双向自检执行流程（每半学期一次）

**编号步骤**：
1. **先测产出侧**（写作 + 口头各 1 题，限时）—— *KLP 工具：`Selbstevaluation`* [已验证]。
2. **再测接受侧**（阅读 + 听力各 1 题）—— *KLP 工具：`rezeptive C1-Anteile`* [据推断]。
3. **填 §2.3 表**，标出**两侧落差**（产出常低于接受）—— *KLP 工具：`评估并记录自身语言水平`* [已验证]。
4. **回写 `Fehlerlog.md` 排优先级**，落差最大维度排最前 —— *KLP 工具：过程反馈*。

> **判据 / 决策点**：自检**必须含产出侧**，否则会把「读得懂」误当「写得出」（recognition ≠ recall）。

### 3.3 多语迁移三步

**编号步骤**：
1. **锁定现象**（这次错是哪种迁移？）—— *KLP 工具：`Mehrsprachigkeitsprofil`* [已验证]。
2. **查 §2.4 表**判定正 / 负迁移 —— *KLP 工具：对比辨别* [据推断]。
3. **写成判别卡**（「中文里 X → 英语里要 Y」）—— *KLP 工具：`Sprachbewusstheit`*。

> **判据 / 决策点**：三语**不是三套独立系统**；凡反复错的点，先问「是不是母语/德语在拖后腿」。

## 4. 🇨🇳 CN-Methode

**完全适用且高价值**。中国英语教学有成熟的**错题本（错题整理）**与**限时作文互评**传统，与本篇 §3.1 直接同构 [据推断]。⚠️ 但差异有二：① 中国错题本多以**语法/词汇点**为单位，**不区分「辨别错」**（中国不考 `summarize` vs `comment` 的任务边界）；② 中国少做**语域错**归类（不考 `Zieltextformat` 单独计分）。来源：`[CN-课标]` / `[CN-高考]`。**迁移建议**：保留「错题本 + 周期重做」骨架，补上 §2.1 的辨别/语域两栏。

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | 不单独成题（元层）；**间接兑现**于语言分与过程分 |
| Operator | `state` · `describe` · `explain` · `assess` · `outline` · `list, name` |
| AFB | I–III（元层横跨，按任务情境定）|
| 建议分值 / 时长 | 影响 `Erfüllung fremdsprachlicher Normen` · `Sicherheit im Umgang mit der Fremdsprache`；自检每周 15 min、每半学期一次完整自检 |

### 5.2 训练题

**Aufgabe 1** `[原创]`（错因归类）
> *Below are five errors taken from student summaries. Classify each as a discrimination, knowledge, expression or register error, and state the remedy you would apply.*
> （材料：5 句自撰典型错句，覆盖四类）

**Aufgabe 2** `[NRW-改编]`（双向自检设计）
> *Design a self-assessment task that tests one productive and one receptive skill at B2 level. Explain what each part measures and how you would record the result.*
> （题干结构取自 KLP EF `评估并记录自身语言水平` 形态）

**Aufgabe 3** `[原创]`（多语迁移）
> *Describe one structure in which your first language (Chinese) or German interferes with your English writing, and explain how you would build a discrimination card for it.*

### 5.3 Musterlösung

**Aufgabe 1**
1. **`The summary tells us that the author is wrong.`** ✓ → **discrimination error**：Summary 不得含评价（得分点：判定 + 说出「summary 不加评论」规则）。
2. **`The author uses a metaphor.`（无 effect）** ✓ → **knowledge error**：Analysis 需 `device + effect`（得分点：判定 + 指出缺 effect）。
3. **`This makes the text very very interesting.`** ✓ → **expression error**：空洞、非术语化（得分点：判定 + 给出 `device + effect` 改法）。
4. **`Hey guys, the author argues…`（在正式信里）** ✓ → **register error**：语域跳档（得分点：判定 + 指出 `Zieltextformat`）。
5. **每条配对策一句** ✓（得分点：四类**分别**给出对应处理，非笼统「多练」）。

**Aufgabe 2**
1. **产出侧任务** ✓：限时 150 词 summary（得分点：明确产出 + 限时）。
2. **接受侧任务** ✓：同主题阅读并答 3 题（得分点：明确接受）。
3. **说明各自测量点** ✓：产出测 `Erfüllung fremdsprachlicher Normen`，接受测 `Leseverstehen`（得分点：指标对应）。
4. **记录方式** ✓：结果写入 `Fehlerlog.md` 并按 §2.1 归类（得分点：闭环回写）。
5. **指出预期落差** ✓：产出分通常低于接受分（得分点：体现双向自检的意义）。

**Aufgabe 3**
1. **锁定现象** ✓：如「中文无冠词 → 英语漏 `the`」（得分点：具体到结构）。
2. **判定迁移方向** ✓：`negative transfer`（得分点：正/负迁移命名）。
3. **判别卡内容** ✓：正面「中文 X」，反面「英语须 Y + 一个例句」（得分点：卡片可执行）。
4. **验证方式** ✓：新作文里专项检查该结构（得分点：迁移保障）。

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 错因归类时把拼写错写成「表达错」，导致练错方向 | 用 §2.1 四类表逐条对照打标 |
| 知识错 | 只登记错误不写「正确写法」，无从重练 | §3.1 第 1 步强制三栏：原句/我写/正确 |
| 表达错 | 自检只做阅读听力（receptive），高估水平 | §3.2 强制含产出侧，填 §2.3 双向表 |
| 语域错 | 把三语当独立系统，反复犯同一负迁移 | §3.3 建中德英迁移判别卡 |
