# Textsortenmerkmale und Belegtechniken (文本类型特征与举证技法)

> **中文理解**：这是 KB3 `Text- und Medienkompetenz` 的**方法论层**——把「文本是什么」（Textsorten）与「怎么拆它」（Belegtechnik）合在一起，并把认识**用回自身文本生产**（KLP 明文要求 `produktiver Rückbezug`）[已验证]。KLP EF 就把 `Textsortenmerkmale`（判定文类并分析其内容-语言-形式关系）与 `Belegtechniken`（以文本为据）列入能力期望 [已验证]。
>
> **Klausur-Relevanz**：**文类判定是 Teil 3 的开篇砖块**——文类判错会导致后续方向全偏（把 Kommentar 当 Bericht 去找「客观性」）。而 P.E.E. 是 Analysis 段的执行标准：只 Point + Evidence 不给 Explain，直接掉回 AFB I。

## 2. 知识结构 (Struktur)

### 2.1 Textsorten 清单（KLP 原文）

**中文**：KLP 按学段列出输入文本清单 [已验证]。**EF 没有 Rede 与 Sachbuch，这是 GK 的难度分野点。**

| 类别 | EF 输入文本 | Q GK/LK 新增 |
|---|---|---|
| Sach-/Gebrauchstexte | 信息/论证/评论型报刊文本、书评、图片、Cartoon、统计图表、PR 材料、招聘广告、社交网络形式、访谈、Podcast、报道、纪录片 | **Rede（演讲）**、**Sachbuch（专业书）** |
| Literarische Texte | **一部较短的当代小说**、诗歌、歌曲、graphic novel 选段、电影/电视剧选段 | 同谱，难度升级 |
| 形态 | 连续 / 非连续 / 多模态 + 视听 | `komplexere` / `komplexe` |

> *Klausur-Satz*: `The text is a speech, a text type that only appears from the Qualifikationsphase onwards, so I expect direct audience address and rhetorical structuring.`

### 2.2 文类 → 特征 → 读者期待 → 分析动作（四栏对照，本笔记交付核心）

**中文**：判文类的目的不是贴标签，而是**预测分析动作**。文类判对，分析就有的放矢。

| 文类 | 典型特征 | 读者期待 | 分析动作 |
|---|---|---|---|
| News report | 客观、inverted pyramid、第三人称 | 事实 | 找事实层级 + 中立性 |
| Opinion piece / Kommentar | 第一人称、带色彩的词、明确立场 | 观点 | 找立场 + 举证 + 带引号的词 |
| Review（书评） | 评价性形容词、优缺点并陈 | 判断 | 找评价标准 |
| Speech | 呼语 `you`、重复、排比、行动号召 | 被说服 | 找受众 + 修辞目的 |
| Sachbuch | 论证层次（让步→转折）、术语 | 系统认知 | 区分作者立场 vs 转述立场 |
| Advertisement / PR | 祈使句、夸张、口号 | 被推动消费 | 找诉求（pathos/ethos/logos） |
| Blog | 第一人称、互动问句、小标题 | 陪伴感 | 找亲密策略 |
| Novel extract | 叙事视角、人物、场景 | 沉浸 | 找视角 + 人物 + 主题 |

> *Klausur-Satz*: `Because this is an opinion piece, the author's real attitude is most likely to surface in the final paragraph and in the quotation marks around key terms.`

### 2.3 Sach-/Gebrauchstext vs 文学文本：两条分析路径

**中文**：两类文本的**分析提问方式不同**——判错路径 = 方向性失分。

| 维度 | Sach-/Gebrauchstext | Literarischer Text |
|---|---|---|
| 核心问题 | 作者**说服/告知**什么，怎么做到？ | 文本**呈现**了什么经验，怎么呈现？ |
| 证据 | 数据、引语、论证结构 | 视角、意象、人物、对话 |
| 结论 | 立场 + 效果 | 主题 + 阐释 |
| 常见陷阱 | 只 `describe` 不进 `analyse` | 当实用文找「事实与数据」 |

> *Klausur-Satz*: `As a literary text, it does not argue a thesis; it stages a conflict, so my analysis focuses on narrative perspective and imagery rather than on data.`

### 2.4 Rede 与 Sachbuch：Q 阶段两个新增文类

**中文**：Rede 有**现场受众与口语节奏**，不能当文章分析；Sachbuch 的**论证是多层嵌套的**，不能读成单线。

| 文类 | 结构抓手 | 分析动作 |
|---|---|---|
| Rede | exordium（开场）→ argumentatio（论证）→ peroratio（收束/呼吁）[据推断] | 找受众在场感 + 重复/排比 + 行动号召 |
| Sachbuch | 让步 → 转折 → 主张；区分「作者立场」与「转述他人立场」 | 复原论证层次 + 分立场 |

> *Klausur-Satz*: `In this speech the peroratio turns the argument into an appeal, which is why the final paragraph uses imperatives and the inclusive "we".`

### 2.5 非连续文本（图表 / Cartoon）

**中文**：非连续文本要**读数据/画面 → 转成论点**，不能只 `describe`。

| 材料 | 分析动作 |
|---|---|
| Statistik / 图表 | 读趋势 → 说明它支撑/削弱哪个论点 |
| Cartoon | 描述画面 → 判 Relation（互证/反差/补充）→ 说效果 |
| 图片 | 同上；注意 Bild-Text-Relation |

> *Klausur-Satz*: `The chart does not speak for itself: I have to turn its trend into a claim and connect it to the author's argument.`

### 2.6 P.E.E. 与生产性回用（Belegtechnik 两步）

**中文**：P.E.E. 是分析段的**执行标准**；生产性回用是**三段之间的桥接**——KLP 明文要求把分析认识用回自身文本生产 [已验证]。

**P.E.E. 三步**：
- **Point**：点名手段（术语精确）
- **Evidence**：精确行号（`l. 12` / `cf. l. 12`）
- **Explain**：对读者的效果（连接论证目的）

**生产性回用桥接句（背 3 条）**：
- `As the analysis has shown, … — which is why, in my view, … .`
- `The way the author frames … supports my position that … .`
- `Building on the device identified above, I would argue that … .`

> *Klausur-Satz*: `My comment refers back to what I found in the analysis, so that the three tasks form one argument instead of three separate texts.`

## 3. 解题方法 (Methoden)

### 3.1 文类判定四步（读题后 60 秒）

**编号步骤**：
1. **看标题 / 首段 / 出处**（`The Guardian` 评论页？某公司官网？）—— *KLP 工具：`Textsortenmerkmale`* [已验证]。
2. **看人称与立场标记**（第一人称 + 评价词 → opinion piece）—— *KLP 工具：`describe`*。
3. **看结构**（inverted pyramid → report；让步-转折 → Sachbuch/Rede）—— *KLP 工具：`analyse`*。
4. **下判断并写一句**（`This is …, as can be seen from …`）—— *KLP 工具：`characterize`*。

> **判据 / 决策点**：若两类特征混杂（如「评论型报道」），**取主导特征并说明混合性**——这本身是加分点。

### 3.2 P.E.E. 执行标准（每段都跑）

**编号步骤**：
1. **Point**：精确术语点名 device —— *KLP 工具：`Fachsprache`* [已验证]。
2. **Evidence**：给行号（不给行号 = 无举证）—— *KLP 工具：`Belegtechnik`* [已验证]。
3. **Explain**：effect 句（第 2–4 层，见 `Englisch-Funktions-und-Interpretationswortschatz.md`）—— *KLP 工具：`Differenziertheit`* [已验证]。

> **判据 / 决策点**：三条走透 2 条 > 五条各写一半。宁可少而深。

### 3.3 生产性回用桥接三步

**编号步骤**：
1. **回顾第 2 小题的发现**（一句话）—— *KLP 工具：`produktiver Rückbezug`* [已验证]。
2. **用桥接句引入第 3 小题**（`As the analysis has shown, …`）—— *KLP 工具：`comment`*。
3. **让立场建立在该发现上**（不是凭空表态）—— *KLP 工具：`evaluate`*。

> **判据 / 决策点**：若第 3 段完全不提第 2 段，等于「三段各写各的」——Teil 3 最典型的结构性失分。

## 4. 🇨🇳 CN-Methode

**不适用（该科无中国对照技法）**。理由：中国语文/英语的阅读教学以「概括段意、分析中心思想」为主，**不要求判文类并预测读者期待、不要求行号举证、不要求区分作者立场与转述立场**；中国高考英语阅读是选择题，不产出分析段。⚠️ 唯一可迁移的是「先判文体再答题」的直觉，但须补上 NRW 的 Textsortenmerkmal 四栏与分析动作。来源：`[CN-课标]`。

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | Teil 3（Schreiben/Leseverstehen integriert）的**开篇砖块 + 分析底座** |
| Operator | `outline` · `describe` · `analyse` · `point out` · `interpret` · `compare` |
| AFB | I（判定/定位）→ II（特征-功能关系）→ III（回用/判断）|
| 建议分值 / 时长 | 不单独计分；决定 Teil 3 第 2、3 小题的方向正确性 |

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`（文类判定 + 特征）
> *Outline the text type of the article below and describe two typical features. Explain what these features suggest about the author's intention.*
> （材料：一段评论型报刊文本；题干结构取自 NRW 公开题的 `outline` + `describe` 形态，材料为自撰同类文本）

**Aufgabe 2** `[NRW-改编]`（P.E.E. 执行）
> *Analyse how the author uses language to persuade the reader. Refer to the text by line.*

**Aufgabe 3** `[原创]` `[Q1]` `[GK]`（Rede · 生产性回用）
> *Analyse the speech below, focusing on how its structure and its direct address work together. Then comment on whether the speaker's appeal is convincing, building on your analysis.*

### 5.3 Musterlösung

**Aufgabe 1**
1. **文类判定** ✓：`The text is an opinion piece, as can be seen from the first-person stance and the evaluative vocabulary.`（得分点：判定 + 依据）
2. **特征 1** ✓：`It opens with a personal anecdote to build sympathy.`（得分点：特征 + 功能）
3. **特征 2** ✓：`It ends with an appeal, not a neutral conclusion.`（得分点：特征 + 功能）
4. **意图** ✓：`Together these features suggest that the author wants to persuade, not merely to inform.`（得分点：特征-意图关系，非罗列）

**Aufgabe 2**
1. **Point** ✓：`The author employs a negatively connotated word field (cf. ll. 6–9).`（得分点：术语 + 行号）
2. **Explain** ✓：`This creates a critical tone and frames the policy as a threat.`（得分点：effect）
3. **第二处** ✓：`The rhetorical question "…" (l. 14) forces the reader to take a side.`（得分点：不同 device）
4. **收束** ✓：`Overall, the language works to leave the reader with no neutral option.`（得分点：整体判断）

**Aufgabe 3**（Q1 GK）
1. **结构分析** ✓：`The speech moves from a shared memory (exordium) to the argument and closes with a call to action.`（得分点：Rede 结构）
2. **直接呼语** ✓：`The repeated "you" (ll. 8, 12, 19) makes each listener feel personally responsible.`（得分点：口语受众在场）
3. **回用桥接** ✓：`As the analysis has shown, the appeal rests on emotion rather than evidence — which is why I find it persuasive but not fully convincing.`（得分点：`produktiver Rückbezug`）
4. **立场有据** ✓：立场建立在前段发现上，而非凭空表态（得分点：三段一体化）

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 文类判错（Kommentar 当 Bericht）导致全篇方向偏 | 用 §3.1 四步，先看人称与立场标记 |
| 知识错 | 只列特征不说「这些特征对读者起什么作用」 | 每条特征必配一个功能 |
| 表达错 | P.E.E. 缺 Explain（只 Point + Evidence） | 强制写 effect 句 |
| 语域错 | 用日常词代替文类术语 | 用 `opinion piece / inverted pyramid / appeal` |
