# Darstellungsaufgaben: Diagramm ⇄ Tabelle ⇄ Gleichung (表征三轨互转训练)

> **中文理解**：德国化学 KLP 有一类**法定考查形式**叫 `Darstellungsaufgaben`（呈示类任务），原文明确要求「**表格、图表、图像的描述与阐释**」以及「**表征形式互相转换**」[已验证，KLP 第 4 章 Überprüfungsformen]。翻译成人话：**同一份化学事实，必须能在「图 / 表 / 方程式」三条轨道之间来回搬**。这不是三个独立知识点，而是一套**互转程序**——EF-1 的 `Strukturformeln zeichnen`（CH-EF1-C-02）与 EF-2 的 `Energieprofil`（CH-EF2-A-03）正是这套程序的两个入口。
>
> **Klausur-Relevanz**：化学 Abitur **禁止纯论文式题目**，每题必须绑定材料或实验 [已验证]；而材料题的第一步几乎总是「读图/读表」，最后一步几乎总是「写方程式」。**三轨互转是材料题的通用起手式与收尾式**，属 AFB I（书写规范）到 AFB II（迁移重建）。

## 2. 知识结构 (Struktur)

### 2.1 三条轨道（本笔记的骨架）

**中文理解**：任何化学事实都能被三种语言表达——**图（几何/符号）**、**表（数值/结构）**、**方程式（化学语言）**。三条轨道共享同一份「物质的量账本」，所以可以互转。

- **① 图轨道 `Diagramm / Skizze`**：Energieprofil、c–t 曲线、滴定曲线、结构式/键线式、装置草图。
- **② 表轨道 `Tabelle`**：Messreihe（时间—浓度、体积—时间）、Eₐ/ΔH 对照表、官能团—现象对照表。
- **③ 方程式轨道 `Reaktionsgleichung`**：配平反应式、半反应式、酯化式、燃烧式。

> *Klausur-Satz*: *Dieselbe chemische Information lässt sich in einem Diagramm, in einer Tabelle oder in einer Reaktionsgleichung darstellen; die Darstellungsaufgabe verlangt die begründete Umwandlung zwischen diesen Formen.*

### 2.2 为什么三轨能互转：共享「接口量」

| 互转方向 | 桥接的「接口量」 | 典型操作 |
|---|---|---|
| 图 → 表 | 坐标点 (t, c) / (Verlauf, E) | 逐点读值填入表 |
| 表 → 图 | 同上一对量 | 描点连线 + 标坐标轴与单位 |
| 图/表 → 方程式 | 物质的种类与系数比 | 由变化量反推反应物/产物并配平 |
| 方程式 → 图 | ΔH（始终态差）与 Eₐ（峰高差） | 按能量账画 Energieprofil |

> ⚠️ **三条轨道的接口量是「量」不是「结论」**：互转时必须先把原始量（时间、浓度、能量、体积）搬过去，**再**做解释。跳过量的搬运直接写结论 = 脱离材料 [已验证：化学禁止无材料依托]。

### 2.3 法定地位：这不是「技巧」而是「考点」

- `Darstellungsaufgaben` 与 `Experimentelle/fachpraktische Aufgaben`、`Präsentationsaufgaben`、`Bewertungsaufgaben` 并列为**四类法定 Überprüfungsformen** [已验证]。
- 化学 Abitur 明文：**「eine Aufgabe ohne Material- oder Experimentbezug ist nicht zulässig」** [已验证] → 三轨互转是「绑定材料」这条硬约束的操作化。
- ⚠️ 数学的双轨是「工具许可（免工具/带工具）」；**化学的双轨是「表征类型」**——`qualitativ-modellhaft erklären`（S11–S15，模型语言）与 `quantitativ-mathematisch beschreiben`（S16–S17，数学语言）[已验证]。三轨互转同时服务这两条线。

> *Klausur-Satz*: *Die Darstellungsaufgabe verlangt, dass Beobachtungen und Daten zunächst strukturiert dargestellt und anschließend in eine andere Darstellungsform übertragen und gedeutet werden.*

## 3. 解题方法 (Methoden)

### 3.1 三轨互转四步法（`darstellen` / `auswerten` 标准程序）

1. **定轨道**：判断题目给的是图、表还是方程式，要求交的是哪一种。—— *KLP 工具：Darstellungsaufgabe 的「表征形式互相转换」*
2. **提量**：从源轨道**只搬原始量**（坐标值、表头列、系数与物质），不改写、不解释。—— *KLP 工具：`beschreiben`（结构化且用专业术语）*
3. **守恒桥接**：用「同一物质的量在轨道间守恒」把源量接到目标量（质量守恒 / 电子守恒 / 能量守恒）。—— *KLP 工具：`Stöchiometrie` + `Basiskonzept Energie`*
4. **重建目标轨道**：按该轨道的**书写规范**落笔（见 §3.2），最后才补一句 Deutung。—— *KLP 工具：`Darstellungsleistung`*

> **判据 / 决策点**：若目标是**图** → 先画坐标轴并标单位，再描点；若目标是**表** → 先写表头与单位；若目标是**方程式** → 先配平，再补条件与状态符号。

### 3.2 逐轨书写规范（扣分点即规范点）

| 轨道 | 必做 | 常见扣分 |
|---|---|---|
| 图 (Diagramm) | 坐标轴标 `Energie / Reaktionsverlauf`、单位、曲线走向 | 不标坐标轴；催化剂曲线画成改 ΔH |
| 表 (Tabelle) | 表头含物理量与单位；有效数字一致 | 漏单位；数据错位 |
| 方程式 (Gleichung) | 配平、条件（`Kat.` / `Δ`）、状态符号 `(s)(l)(g)(aq)` | 漏配平；漏条件；酯化写成 `→` 而非 `⇌` |

### 3.3 两类高频互转模板

**A. Messreihe（表）⇄ c–t 图 ⇄ 速率/方程式**
1. 表 → 图：以 t 为横轴、c 为纵轴描点。—— *KLP 工具：`auswerten`*
2. 图 → 速率：取两点求平均速率 `v̄ = Δc/Δt`；初速率取 t→0 切线。—— *KLP 工具：`ermitteln`*
3. 速率 → 方程式：由浓度变化方向定反应物/产物，配平。—— *KLP 工具：`aufstellen`*

**B. 方程式 ⇄ Energieprofil（图）⇄ 对照表**
1. 由方程式读 ΔH 符号 → 定吸/放热。—— *KLP 工具：Basiskonzept Energie*
2. 画图：起点=反应物能量，峰=活化态，终点=产物能量；`Eₐ = 峰 − 起点`，`ΔH = 终点 − 起点`。—— *KLP 工具：Energieprofil（CH-EF2-A-03）*
3. 催化剂：**只降 Eₐ，不改 ΔH**（峰变矮，起终点不动）。—— *KLP 工具：Katalyse*

## 4. 🇨🇳 CN-Methode

### CN-Methode: 「三重表征」互转（宏观 ⇄ 微观 ⇄ 符号）+ 图表信息提取
- **技法内容**：中国化学教学把每个事实写成**三种表征**——**宏观**（现象/物性）、**微观**（粒子/模型）、**符号**（式/方程式），并要求**三向互译**；配套「图表信息提取」训练（先读坐标轴与单位，再取点，再算斜率/面积）。迁移到德国三轨：宏观≈表、微观≈图（粒子/能量模型）、符号≈方程式。
- **DE-Anschluss**：`qualitativ-modellhaft erklären`（S11–S15，正对微观/模型轨道）· `quantitativ-mathematisch beschreiben`（S16–S17，正对符号/数学轨道）· `Darstellungsaufgaben`（法定互转要求）· `Energieprofil`（CH-EF2-A-03）· `Strukturformel zeichnen`（CH-EF1-C-02）。**全部工具德国已教，零新增知识。**
- **合规性**：✅ 完全合规 —— 引入的只是**互转的组织顺序**（先宏观、再微观、再符号），不引入任何德国 KLP 之外的**知识块**。
- **Abitur 应用**：全 IF 通用。材料题第一步「读图读表」、末步「写方程式」；`Aufgabenart I` 与 `fachpraktische Aufgabe` 的数据处理。
- **来源**：`[CN-教材]`（三重表征为结构性方法名）+ `[CN-高考]`（图表题训练套路，**原创改写**）。

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | I `Materialgebundene Aufgabe`（含 Messreihe / Schaubild） |
| Operator | `darstellen` / `beschreiben` / `auswerten` / `skizzieren` / `ermitteln` |
| AFB | I（规范书写）→ II（跨轨道迁移重建）→ III（由互转结果推结论） |
| 建议分值 / 时长 | 单题 8–12 BE |

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> Bei der Zersetzung von Wasserstoffperoxid wurden folgende Messwerte aufgenommen:
>
> | t in s | 0 | 20 | 40 | 60 | 80 |
> |---|---|---|---|---|---|
> | c(H₂O₂) in mol/L | 1,00 | 0,72 | 0,52 | 0,38 | 0,27 |
>
> **a)** Stellen Sie die Messreihe in einem c–t-Diagramm dar (Achsen und Einheiten beschriften).
> **b)** Ermitteln Sie die mittlere Reaktionsgeschwindigkeit im Intervall 0–40 s.
> **c)** Geben Sie die Reaktionsgleichung der Zersetzung an (mit Zustandssymbolen).

**Aufgabe 2** `[NRW-改编]`
> Für eine Reaktion liegt ein Energieprofil mit zwei Kurven vor: eine unkatalysiert und eine katalysiert.
> **a)** Erstellen Sie eine Tabelle mit den Größen „Aktivierungsenergie" und „Reaktionsenthalpie" für beide Kurven.
> **b)** Begründen Sie, welche Größe sich durch den Katalysator ändert und welche nicht.

**Aufgabe 3** `[原创]`
> Gegeben ist die Strukturformel von Ethylethanoat (Essigsäureethylester).
> **a)** Übertragen Sie die Strukturformel in die Summenformel und benennen Sie den Stoff systematisch.
> **b)** Formulieren Sie die Synthesegleichung ausgehend von Ethanol und Ethansäure (mit Katalysator und Gleichgewichtspfeil).

**Aufgabe 4** `[CN-改编]`
> In einem Diagramm ist die Konzentration eines Produkts über die Zeit für zwei Temperaturen (T₁ < T₂) aufgetragen.
> **a)** Beschreiben Sie den Kurvenverlauf strukturiert.
> **b)** Übertragen Sie die Kernaussage in eine Tabelle („Temperatur | Anfangssteigung | Endwert").
> **c)** Deuten Sie den Unterschied mit einem Basiskonzept.

### 5.3 Musterlösung

**Aufgabe 1**
1. a) Achsen: x = `t in s`, y = `c(H₂O₂) in mol/L`；五点描出，平滑下降曲线 ✓ 得分点（**坐标轴与单位缺一扣分**）
2. b) `v̄ = Δc/Δt = (1,00 − 0,52) mol/L / 40 s = 0,48/40 = 0,012 mol·L⁻¹·s⁻¹` ✓ 得分点（**呈示 Ansatz**）
3. c) `2 H₂O₂(aq) → 2 H₂O(l) + O₂(g)`（MnO₂ 催化）✓ 得分点（**配平 + 状态符号 + 条件**）

**Aufgabe 2**
1. a) 表：未催化 → `Eₐ = 峰 − 起点`（较大）、`ΔH = 终点 − 起点`；催化 → `Eₐ` 较小、`ΔH` 不变 ✓
2. b) 催化剂**只降低 Eₐ**（提供较低能量路径），**不改变 ΔH**，因 ΔH 只由始终态决定 ✓ 得分点（**须点明「始终态不变」**）

**Aufgabe 3**
1. a) Summenformel `C₄H₈O₂`；系统命名 **Ethylethanoat** ✓
2. b) `CH₃COOH + C₂H₅OH ⇌ CH₃COOC₂H₅ + H₂O`，条件 **konz. H₂SO₄, Δ** ✓ 得分点（**`⇌` + 条件**）

**Aufgabe 4**
1. a) 两条曲线均先快后缓并趋于**同一 Endwert**（同一平衡/完全转化），T₂ 的 Anfangssteigung 更大 ✓
2. b) 表：T₁ | 小 | 同值；T₂ | 大 | 同值 ✓
3. c) 升温 → 分子平均动能增大 → 有效碰撞比例升高 → 速率更快；**终点相同**说明只影响速率不影响转化限度 ✓ 得分点（Basiskonzept `Chemische Reaktion` / `Energie`）

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把「图 → 表」做成「图 → 结论」，跳过量的搬运 | 四步法第 2 步只搬量、不解释 |
| 知识错 | 认为催化剂改变 ΔH；把 ΔH 与 Eₐ 混为一谈 | 记住：`ΔH = 始终态差`、`Eₐ = 峰高差` |
| 表达错 | 图不标坐标轴/单位；方程式漏配平、漏条件或状态符号 | 落笔前过 §3.2 规范表 |
