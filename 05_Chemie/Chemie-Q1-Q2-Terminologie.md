# Chemie Q1/Q2-Terminologie (Q1/Q2 术语词表 DE-CN-EN)

> **中文理解**：Q 阶段（Qualifikationsphase）四个 Inhaltsfeld 各有**成套术语**，且大量术语在德国用**不同符号**（`K_S`/`pK_S` 而非中国的 `K_a`/`pK_a`）。术语卡缺卡最严重的正是 Q-1 与 Q-2 [据推断，Lernbaum-Chemie §0]。本词表按 IF 分块，标 `[GK]`/`[LK]`，专为**检索练习 + 间隔重复 + 答题句嵌入**设计。
>
> **Klausur-Relevanz**：术语是 `benennen` / `angeben`（AFB I）的直接得分点，也是 `erläutern` / `vergleichen` 的表达基础。⚠️ 语言错误在 Q 阶段最多扣 **2 Notenpunkte** [已验证，APO-GOSt § 13 Abs. 2]——术语与符号写错是硬扣分。
>
> ⛔ **明确不做**：本词表**不含** `Salzhydrolyse`（盐类水解，KLP 全文无 `Hydrolyse`）、物质结构整册术语（杂化轨道 / 晶体四分类 / 电子排布式）、配合物系统术语——三项均超纲 [已验证 / 据推断]。

## 3. 解题方法 (Methoden)

### 3.1 术语卡三用法（间隔重复 + 检索）

1. **卡片格式**：正面 DE 术语，背面 CN + EN + 一句 Klausur-Satz。—— *KLP 工具：`benennen`（AFB I）*
2. **检索练习**：合书默写术语 + 符号（**写符号，不只写中文**）。—— *KLP 工具：Fachsprache*
3. **句嵌入**：每个术语必须能造一个完整德语 Aussagesatz。—— *KLP 工具：`erläutern` / `beschreiben`*

> **判据 / 决策点**：只会中文对译 ≠ 掌握；**能在无提示下写出德语术语 + 符号 + 一句答题句**才算过。

### 3.2 术语辨析（`vergleichen` 常考对）

| 对 | 判别 |
|---|---|
| K_S vs K_B | 酸常数 vs 碱常数 |
| K_S vs K_L | 酸碱电离 vs 溶解平衡 |
| Anode vs Kathode | ⚠️ 极性随原电池/电解池反转 |
| Oxidation vs Reduktion | 失电子 vs 得电子 |
| radikalische Substitution vs elektrophile Addition | 饱和烃 vs 不饱和烃 |
| Thermoplaste vs Duroplaste | 线型可熔 vs 交联不熔 |

## 4. 🇨🇳 CN-Methode

### CN-Methode: 术语桥（DE-CN-EN 三栏对齐 + 符号校准）
- **技法内容**：把中国已学的术语先按「概念」对齐到德国术语，再单独处理**符号差异**（`K_a → K_S`、`K_sp → K_L`、`ΔH_f → Standardbildungsenthalpie`）。中国侧的价值在于**已有概念储备**，可加速德语术语的挂载。
- **DE-Anschluss**：全部术语均为德国 KLP 原文术语（GK/LK Schwerpunkte）[已验证]；中国侧提供的是**已学概念的锚点**，不引入新知识。
- **合规性**：✅ —— 术语对齐不涉及知识块；⚠️ 但**不得**借对齐之名把中国的 `水解常数 K_h`、`杂化轨道`、`配位数` 等**超纲术语**带进来。
- **Abitur 应用**：全 IF；`benennen` / `angeben` / `vergleichen`。
- **来源**：`[CN-教材]`（概念锚点）+ `[CN-课标]`（用于符号差异说明）。

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |

| Operator | `benennen` / `angeben` / `beschreiben` / `vergleichen` |

| 建议分值 / 时长 | 嵌入各题首问，2–6 BE |

### 5.2 训练题

**Aufgabe 1** `[原创]`
> Benennen Sie die folgenden Größen mit dem in NRW üblichen Symbol: (i) die Säurekonstante, (ii) deren negativer dekadischer Logarithmus, (iii) das Löslichkeitsprodukt.

**Aufgabe 2** `[NRW-改编]`
> Erläutern Sie in je einem vollständigen Satz den Unterschied zwischen `Anode` und `Kathode` sowie zwischen `Oxidation` und `Reduktion`.

**Aufgabe 3** `[原创]`
> Vergleichen Sie `radikalische Substitution` und `elektrophile Addition` hinsichtlich Substrat und Mechanismusbegriff.

**Aufgabe 4** `[CN-改编]`
> Ordnen Sie die Begriffe `Puffersystem`, `Nernst-Gleichung`, `Chiralität`, `Nanochemie` dem jeweils richtigen Inhaltsfeld zu und markieren Sie, ob sie zum Grundkurs oder nur zum Leistungskurs gehören.

### 5.3 Musterlösung

**Aufgabe 1**
1. (i) **`K_S`**（nicht `K_a`）✓ 得分点
2. (ii) **`pK_S`** ✓
3. (iii) **`K_L`**（nicht `K_sp`）✓ 得分点（**符号校准**）

**Aufgabe 2**
1. Anode/Kathode: *An der Anode findet die Oxidation statt, an der Kathode die Reduktion; die Polarität kehrt sich zwischen galvanischer Zelle und Elektrolyse um.* ✓
2. Oxidation/Reduktion: *Oxidation bedeutet Elektronenabgabe, Reduktion bedeutet Elektronenaufnahme.* ✓ 得分点（**完整句 + 术语准确**）

**Aufgabe 3**
1. Substrat: radikalische Substitution → **gesättigte** Kohlenwasserstoffe；elektrophile Addition → **ungesättigte**（C=C）✓ 得分点
2. Mechanismusbegriff: 前者为**Radikal**（Homolyse），后者为**Elektrophil**（Heterolyse）✓

**Aufgabe 4**
1. `Puffersystem` → Q-1，**LK** ✓
2. `Nernst-Gleichung` → Q-2，**LK** ✓
3. `Chiralität` → Q-3，**LK** ✓
4. `Nanochemie` → Q-4，**LK** ✓ 得分点（**四项全 LK——GK/LK 分界线**）

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 用中国符号 `K_a`/`K_sp` 作答；Anode/Kathode 极性搞反 | 一律用德国符号；先判装置类型 |
