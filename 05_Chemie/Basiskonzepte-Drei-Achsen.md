# Basiskonzepte Drei-Achsen-Karte (三大基础概念三轴追踪卡)

> **中文理解**：德国化学 KLP 比数学**多一维**——`Basiskonzepte`（基础概念）三条横贯轴：**Aufbau und Eigenschaften der Stoffe**（物质的结构与性质）、**Chemische Reaktion**（化学反应）、**Energie**（能量）。KLP 明文「werden übergreifend auf alle Kompetenzbereiche bezogen」，并在每个 Inhaltsfeld 末尾以「Ausgewählte Beiträge zu den Basiskonzepten」**显式列出**该 IF 贡献什么 [已验证，KLP 第 2.1.3 章]。
>
> **Klausur-Relevanz**：这是德国化学作答的**官方得分语言**——答题时点明「这是结构-性质视角 / 这是能量视角」直接命中 `Herstellen geeigneter Zusammenhänge`。**中国课标以「主题 + 素养」组织，无等价的横贯型概念轴** [据推断] → 这是中国学生的**必补项**。

## 2. 知识结构 (Struktur)

### 2.1 三轴一句话定义

- **① Aufbau und Eigenschaften**：**由结构推性质**。官能团 → 物性；离子晶格 → 高熔点；金属键 → 导电延展；染料结构 → 显色。
- **② Chemische Reaktion**：**反应本身**。Donator-Akzeptor 原理、可逆性与动态平衡、质子传递、氧化还原、五条机理。
- **③ Energie**：**能量账**。催化剂降低活化能、热力学第一/第二定律、焓与熵、自由能、Hess。

> *Klausur-Satz*: *Die drei Basiskonzepte der Chemie sind der Aufbau und die Eigenschaften der Stoffe, die chemische Reaktion sowie die Energie. Sie werden übergreifend auf alle Kompetenzbereiche bezogen.*

### 2.2 每个 Inhaltsfeld 对三轴的贡献（KLP 显式清单）

⚠️ **各 IF 贡献分布不均**——有的 IF 未列某一轴 [已验证，KLP 各 IF 末尾]：

| Inhaltsfeld | ① Aufbau/Eigenschaften | ② Chemische Reaktion | ③ Energie |
|---|---|---|---|
| **EF-1** Organische Stoffklassen | ✅ 官能团系统化 + 分子间作用力 | ✅ 氧化还原扩展 + 酯化 | ❌ **未列** |
| **EF-2** 速率与平衡 | ❌ **未列** | ✅ 可逆性→动态平衡；循环视为反应序列 | ✅ 催化剂作用机制 |
| **Q-1** Säuren/Basen/Analytik | ✅ Brønsted 定义 + pH/常数定位 | ✅ 质子传递深化 MWG 量化 | ✅ 第一定律 + 焓 |
| **Q-2** Elektrochemie/Energetik | ✅ 金属键 + 水合离子迁移性 | ✅ 氧化还原深化 Donator-Akzeptor | ✅ 标准生成焓 + Hess + 自由能 + 多相催化 |
| **Q-3** Reaktionswege organisch | ✅ 染料结构-显色 | ✅ 五条机理 | ❌ **未列** |
| **Q-4** Moderne Werkstoffe | ✅ 塑料结构-性能 | ✅ 聚合 | ❌ **未列** |

> ⚠️ **答题陷阱**：若在某 IF 里硬套「未列」的那条轴（如 EF-1 谈 Energie），会显得跑题 [据推断]。**先查上表，再决定标哪条轴。**

### 2.3 三轴与「表征双轨」的关系

KLP 把 `Sachkompetenz` 切成两条平行线 [已验证]：
- `qualitativ-modellhaft erklären`（S11–S15，粒子层面模型解释）
- `quantitativ-mathematisch beschreiben`（S16–S17，数学语言）

→ **三轴给出「从哪个视角讲」，双轨给出「用哪种语言讲」。** 一道好答案 = 选对轴 + 两条轨都走到。

> *Klausur-Satz*: *Die qualitative-modellhafte und die quantitativ-mathematische Beschreibung sind zwei parallele Zugänge; das jeweilige Basiskonzept gibt dabei die fachliche Perspektive vor.*

### 2.4 三轴作为「得分语言」的用法

答题时在句首或段首**显式点名视角**，例如：
- 「Aus der Perspektive des **Aufbaus und der Eigenschaften** folgt …」
- 「Unter dem **Basiskonzept Chemische Reaktion** lässt sich … als Donator-Akzeptor-Vorgang deuten …」
- 「Aus **energetischer Sicht** ist die Reaktion exotherm, da …」

→ 这直接对应 KLP 的 `Herstellen geeigneter Zusammenhänge`（S6–S10 的「选择并联结化学概念」）。

## 3. 解题方法 (Methoden)

### 3.1 三轴定位四步法（`erlaeutern` / `darstellen` 标准程序）

**编号步骤**：
1. **读 IF 与题目**：判断题目属于哪个 Inhaltsfeld（EF-1 / EF-2 / Q-1…）。—— *KLP 工具：Inhaltsfeld 结构*
2. **查 2.2 表**：该 IF **列了哪几条轴**？（避开「未列」的轴）—— *KLP 工具：`Ausgewählte Beiträge zu den Basiskonzepten`*
3. **选主视角并写开场句**：用 §2.4 的句式点名视角。—— *KLP 工具：`Herstellen geeigneter Zusammenhänge`（S6–S10）*
4. **双轨展开**：先 `erklären`（模型/粒子），再 `berechnen`（数学）。—— *KLP 工具：`qualitativ-modellhaft` + `quantitativ-mathematisch`*

> **判据 / 决策点**：若题目问「为什么/如何解释」→ 轴 ①（结构）或 ②（反应）；若问「能量变化/是否自发」→ 轴 ③。**一题可涉及多轴，但须点明每条轴各自的结论。**

### 3.2 三轴速判表（30 秒决策）

| 题目信号词 | 主视角 | 典型落点 |
|---|---|---|
| 沸点/熔点/溶解性/官能团/晶格 | ① Aufbau/Eigenschaften | EF-1 · Q-1 离子晶格 |
| 平衡移动/质子传递/电子转移/机理 | ② Chemische Reaktion | EF-2 · Q-1 · Q-2 · Q-3 |
| 焓/熵/自发/催化剂/电动势 | ③ Energie | EF-2 催化 · Q-1 中和焓 · Q-2 Hess |

## 4. 🇨🇳 CN-Methode

### CN-Methode: 不适用（该科无中国对等技法）

- **说明**：中国《普通高中化学课程标准（2017 年版 2020 年修订）》用**5 项核心素养**（宏观辨识与微观探析 / 变化观念与平衡思想 / 证据推理与模型认知 / 科学探究与创新意识 / 科学态度与社会责任）组织课程。这是**能力侧**框架；德国把「结构 / 反应 / 能量」做成了**内容侧**骨架。**两者不可互换** [据推断]。
- **DE-Anschluss**：无（这是德国独有维度，中国侧无对应物）。
- **合规性**：⚠️ **不可嫁接**——中国无等价概念轴，只能**按德国原文重建**（本笔记即为此目的）。可借用的仅是中国的**做题习惯**（先定性后定量），但**框架本身必须来自德国 KLP**。
- **Abitur 应用**：全学段全 IF 通用；尤其 Bewertung 题与跨 IF 综合题（4 题选 3 的整卷结构天然要求跨 IF 联结）。

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> Ethanol (Siedepunkt 78 °C) und Dimethylether (Siedepunkt −24 °C) haben die gleiche Summenformel C₂H₆O.
> **a)** Erläutern Sie den Siedepunktunterschied mithilfe eines Basiskonzepts und benennen Sie dieses ausdrücklich.
> **b)** Begründen Sie, warum das Basiskonzept „Energie" hier nicht im Vordergrund steht.

**Aufgabe 2** `[原创]`
> Bei der Synthese von Ammoniak gilt: N₂(g) + 3 H₂(g) ⇌ 2 NH₃(g), ΔH < 0.
> **a)** Deuten Sie die Gleichgewichtslage sowohl unter dem Basiskonzept „Chemische Reaktion" als auch unter „Energie".
> **b)** Zeigen Sie, dass beide Perspektiven zu unterschiedlichen Aussagen über die optimale Temperatur führen können.

**Aufgabe 3** `[CN-改编]`
> In einer galvanischen Zelle wird die Reaktion Zn + Cu²⁺ → Zn²⁺ + Cu genutzt (ΔE = 1,10 V).
> **a)** Ordnen Sie den Vorgang den drei Basiskonzepten zu und begründen Sie jeweils Ihre Zuordnung.
> **b)** Formulieren Sie zu jedem Basiskonzept einen vollständigen deutschen Aussagesatz, der in einer Klausur als Bewertungsbaustein dienen könnte.

### 5.3 Musterlösung

**Aufgabe 1**
1. a) **Basiskonzept ausdrücklich nennen: Aufbau und Eigenschaften der Stoffe** ✓ 得分点（**不点名不给分**）
2. Ethanol 有 **Hydroxygruppe** → 可形成**氢键**；Dimethylether 无 O–H → 只有偶极作用 ✓
3. 氢键更强 → 分子间作用力更大 → 沸点更高 ✓ 得分点
4. b) 沸点差异由**结构与分子间作用力**解释，不涉及能量转化或反应；EF-1 的 Basiskonzept 清单**未列 Energie** ✓ 得分点（**对应 §2.2 表**）

**Aufgabe 2**
1. a) **Chemische Reaktion**：放热（`ΔH < 0`）→ 按 Le Chatelier，升温使平衡**左移**，产率下降 ✓ 得分点
2. **Energie**：放热反应提供能量；但过高温度虽加快速率，却降低平衡产率 → 速率与平衡的**矛盾** ✓ 得分点
3. b) 结论差异：从**平衡**看要**低温**（提高产率），从**速率/能量**看要**高温**（加快达平衡）→ 工业取折中温度 + 催化剂 ✓ 得分点（**须点明「两视角结论不同」**）

**Aufgabe 3**
1. a) **① Aufbau/Eigenschaften**：Zn/Cu 为金属，用**电子气模型**解释电子导体 ✓
2. **② Chemische Reaktion**：本质是**电子转移**（Donator-Akzeptor），Zn 失电子、Cu²⁺ 得电子 ✓
3. **③ Energie**：`ΔE = 1,10 V` 即化学能→电能的量度，`ΔE > 0` 表明自发 ✓ 得分点（三轴各一结论）
4. b) 示例句：① *Aus der Perspektive des Aufbaus und der Eigenschaften folgt, dass die metallische Bindung im Zink und Kupfer den Elektronentransport ermöglicht.* ② *Unter dem Basiskonzept Chemische Reaktion lässt sich der Vorgang als Elektronenübertragung deuten.* ③ *Aus energetischer Sicht ist die Reaktion spontan, da die Zellspannung positiv ist.* ✓ 得分点（**句式规范 + 术语准确**）

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 在某 IF 硬套该 IF「未列」的轴（如 EF-1 谈 Energie）；三轴混为一谈 | 先查 §2.2 表；每轴各写一条独立结论 |
| 知识错 | 把 Basiskonzept 当成「知识点」而非「视角」；以为是中国式「素养」 | 它是**作答视角**，作用是让答案可被归入官方评分维度 |
| 表达错 | 答题不点名视角（只写内容不写「从…角度看」）；德语句式不完整 | 段首用 §2.4 固定句式；每轴一个完整 Aussagesatz |
