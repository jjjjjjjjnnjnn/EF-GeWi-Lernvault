# EF-1 Auffüllung: Funktionsgruppen, Nachweisreaktionen, Oxidationsreihe und Veresterung (官能团检验·醇氧化序列·酯化)

> **中文理解**：EF 阶段化学的 Inhaltsfeld 是 `Organische Stoffklassen`（有机物质类别）。现有笔记只覆盖了「分子间作用力与物质性质」一侧，**缺三块核心**：
> ① **官能团检验**（Nachweisreaktionen）—— 用实验现象反推物质类别，是材料题的第一入口；
> ② **醇的氧化序列与氧化数**（Oxidationsreihe / Oxidationszahlen）—— 连接「结构」与「反应」的桥梁；
> ③ **酯化合成**（Veresterung）—— EF 唯一的合成反应，也是 Q-3 `Reaktionswege in der organischen Chemie` 的直接上游。
>
> **Klausur-Relevanz**：这三块是 EF 材料题的**必考骨架**——给现象判类别（①）、给结构推产物（②）、给原料写合成（③）。

## 1. 核心概念 (Kernbegriffe)

| 术语 (DE) | 中文 | English | 定义 / 公式 | 备注 |
|---|---|---|---|---|
| funktionelle Gruppe | 官能团 | functional group | 决定物质类别的原子团，如 -OH / -CHO / -COOH | 命名与性质的核心 |
| Nachweisreaktion | 检验反应 | detection reaction | 由特征现象判定官能团的实验 | 见 §3.1 |
| Fehling-Probe | 斐林检验 | Fehling's test | 醛 + Fehling 试剂 → **rot**（Cu₂O 沉淀） | 醛专属 |
| Tollens-Probe | 银镜检验 | Tollens' test | 醛 + Tollens 试剂 → **Silberspiegel** | 醛专属 |
| Oxidationszahl | 氧化数 | oxidation number | 形式电荷分配，C 的氧化数反映氧化程度 | 见 §3.2 |
| Oxidationsreihe | 氧化序列 | oxidation series | primär → Aldehyd → Carbonsäure；sekundär → Keton；tertiär → keine Reaktion | EF 必考 |
| Veresterung | 酯化 | esterification | Alkohol + Carbonsäure ⇌ Ester + Wasser | 酸催化、可逆 |

## 2. 知识结构 (Struktur)

### 2.1 官能团 ⇄ 物质类别 ⇄ 检验反应

| 官能团 | 物质类别 | 特征检验 | 现象 |
|---|---|---|---|
| C=C（Doppelbindung） | Alkene | Bromwasser / Baeyer-Probe | 溴水褪色 / KMnO₄ 褪色 |
| -OH | Alkohole | （Na：H₂；或氧化） | 气泡 / 见 §2.2 |
| -CHO | Aldehyde | **Fehling / Tollens** | 红色沉淀 / 银镜 |
| -COOH | Carbonsäuren | Indikator / Carbonat | 变红 / CO₂ 气泡 |
| -COO- | Ester | （水解后验酸与醇） | — |

> *Klausur-Satz*: Der Nachweis erfolgt über die charakteristische Farbänderung bzw. Gasentwicklung; daraus lässt sich die funktionelle Gruppe ableiten.

### 2.2 醇的氧化序列

| 醇类型 | 结构特征 | 氧化产物（Stufe 1 / Stufe 2） |
|---|---|---|
| primär | -CH₂OH | Aldehyd → Carbonsäure |
| sekundär | -CHOH- | Keton（**不再氧化**） |
| tertiär | -C(OH)- | **keine Reaktion**（无 α-H） |

> *Klausur-Satz*: Da am C-Atom der OH-Gruppe kein Wasserstoffatom gebunden ist, ist eine weitere Oxidation nicht möglich.

## 3. 解题方法 (Methoden)

### 3.1 检验反应判类别（材料题第一入口）

1. 读现象（颜色变化 / 沉淀 / 气泡 / 银镜）—— *KLP 工具：Nachweisreaktion*
2. 对照 §2.1 表定位官能团 —— *KLP 工具：funktionelle Gruppe*
3. 写反应方程式并配平（氧化还原需电子守恒）—— *KLP 工具：Redoxreaktion*
4. 若多个官能团共存，**用排除法**逐步收窄 —— *KLP 工具：Struktur-Eigenschafts-Beziehung*

### 3.2 氧化数计算（四步）

1. 定 H = +I，O = −II（通则）
2. 设目标 C 的氧化数为 x
3. 按分子电中性（或离子电荷）列方程求解
4. 比较反应前后 Δx 判氧化/还原 —— *KLP 工具：Oxidationszahl*

> **判据 / 决策点**：氧化数**升高** = 氧化；每个 C 的 Δ 值之和 × 原子数 = 转移电子数。

### 3.3 酯化反应写法

1. 写结构式：`R-COOH + HO-R' →` —— *KLP 工具：Carbonsäure / Alkohol*
2. 标出脱水位置（酸脱 -OH，醇脱 -H）—— *KLP 工具：Kondensation*
3. 产物 `R-COO-R' + H₂O`，条件：**H₂SO₄ 催化、加热、可逆** —— *KLP 工具：Katalyse / Gleichgewicht*
4. 命名：`<Alkansäure>-<Alkyl>ester`

### CN-Methode: 「碳骨架 × 官能团」双轴定位 + 氧化数法
- **技法内容**：判有机反应时先画「碳骨架轴」（C 数、支链、环）再画「官能团轴」（-OH/-CHO/-COOH/…），两轴交叉定位物质；配平氧化还原时一律用**氧化数升降法**代替试凑。

### 5.1 官方题型定位

| 项 | 内容 |

| 建议分值 / 时长 | 单题 8–12 BE |

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> Eine unbekannte organische Verbindung gibt bei der Fehling-Probe einen roten Niederschlag, bei der Bromwasser-Probe jedoch keine Entfärbung. Benennen Sie die nachgewiesene funktionelle Gruppe und begründen Sie, welche Stoffklasse ausgeschlossen werden kann.

**Aufgabe 2** `[原创]`
> Butan-2-ol wird mit einem Oxidationsmittel umgesetzt. Bestimmen Sie das Produkt, begründen Sie Ihre Wahl mit der Oxidationsreihe und berechnen Sie die Oxidationszahl des Reaktionszentrums vor und nach der Reaktion.

**Aufgabe 3** `[NRW-改编]`
> Beschreiben Sie die Synthese von Ethylethanoat ausgehend von Ethanol. Geben Sie die Reaktionsgleichung an, benennen Sie die Katalyse und erläutern Sie, warum es sich um eine Gleichgewichtsreaktion handelt.

### 5.3 Musterlösung

**Aufgabe 1**
1. Roter Niederschlag bei Fehling → **Aldehydgruppe (-CHO)** ✓
2. Keine Entfärbung von Bromwasser → **keine C=C-Doppelbindung** ✓
3. *Klausur-Satz*: Nachgewiesen wird die Aldehydgruppe; Alkene sind ausgeschlossen, da Bromwasser nicht entfärbt wird. ✓

**Aufgabe 2**
1. Butan-2-ol ist **sekundär** (OH am C-2, zwei C-Nachbarn) ✓
2. Oxidation → **Butan-2-on (Keton)**, keine weitere Oxidation ✓
3. Oxidationszahl: C-2 vorher = 0 → nachher = +II；Δ = +2 ✓
4. *Klausur-Satz*: Da am C-2 zwei Wasserstoffatome durch die Oxidation formal entfernt werden, steigt die Oxidationszahl um zwei. ✓

**Aufgabe 3**
1. `CH₃COOH + C₂H₅OH ⇌ CH₃COOC₂H₅ + H₂O` ✓
2. Katalysator: **konz. H₂SO₄**, Wärme ✓
3. Gleichgewicht: Esterbildung ist **reversibel**（Esterhydrolyse als Rückreaktion）✓
4. *Klausur-Satz*: Die Veresterung ist eine Kondensationsreaktion, die unter Säurekatalyse als Gleichgewichtsreaktion abläuft. ✓

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把 Tollens（银镜）与 Fehling（红色沉淀）混为同一现象 | 现象与试剂成对记 |
| 知识错 | 认为三级醇也能被氧化 | 记住「无 α-H 不氧化」 |
| 表达错 | 酯化写成单向箭头 `→` | 必须用 `⇌` 并标条件 |
