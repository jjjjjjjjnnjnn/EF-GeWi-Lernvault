# Bewertung: Sachurteil vs. Werturteil + Autorenintention (事实判断 vs 价值判断 + 立场与意图分析)

> **中文理解**：德国化学 KLP 的第四个能力领域是 `Bewertungskompetenz`（评价能力），分三小层：① **多视角评判**（multiperspektivisch beurteilen，B1–B4）② **有标准地形成意见与决策**（kriteriengeleitet，B5–B11）③ **反思决策过程与后果**（B12–B14）[已验证，KLP 第 2.1.1 章]。化学的官方 Operatoren 表把「判断」**劈成两半**：`beurteilen` = **Sachurteil（事实判断，用专业标准）**，`bewerten` = **Werturteil（价值判断，引入社会价值与规范）** [已验证，Operatoren ab Abitur 2025]。这是中国学生**最容易混为一谈**的一组动词。
>
> **Klausur-Relevanz**：EF-2 明文要求「分析不同来源对**人类干预自然物质循环后果**的**立场与叙述意图**」，Q-4 LK 明文要求「纳米材料的机遇与风险评价 **+ 作者意图分析**」[已验证]。两者是同一题型家族——**AFB III 的主力载体**，且化学明文**禁止无材料依托的议论文** [已验证]，必须「先读材料 → 再分离事实/价值/立场 → 再落判断」。

## 2. 知识结构 (Struktur)

### 2.1 `beurteilen` vs `bewerten`：官方二分

**中文理解**：两词都译「评价」，但**判据来源不同**——`beurteilen` 只准用**学科标准**（原子经济性、能效、产率、毒性、溶解度…）；`bewerten` 必须再叠一层**社会价值/规范**（环保责任、健康、可持续、经济）。

| 维度 | `beurteilen`（Sachurteil） | `bewerten`（Werturteil） |
|---|---|---|
| 判据来源 | 专业标准（化学事实） | 社会价值、规范、伦理 |
| 典型句式 | „Nach dem Kriterium der Atomökonomie ist … vorteilhafter." | „Aus Gründen der Nachhaltigkeit sollte man … ablehnen." |
| 是否含「应该」 | ❌ 不含 | ✅ 含（sollte / ist zu empfehlen） |
| AFB 落点 | II–III | III |

> *Klausur-Satz*: *Das Sachurteil stützt sich ausschließlich auf fachliche Kriterien, während das Werturteil zusätzlich gesellschaftliche Werte und Normen einbezieht.*

### 2.2 常用专业评价标准（`beurteilen` 的弹药库）

| 标准 | 德语 | 何时用 |
|---|---|---|
| 原子经济性 | Atomökonomie | 合成路线评价 |
| 能效 | Energieeffizienz | 工业 Verfahren |
| 产率 / 转化率 | Ausbeute / Umsatz | 平衡调控 |
| 毒性 / 危害 | Toxizität / Gefährdung | 溶剂、试剂、防腐剂 |
| 可持续性 | Nachhaltigkeit | 循环、材料、能源 |
| 经济性 | Wirtschaftlichkeit | 工业流程 |
| 溶解性 / 分离难度 | Löslichkeit / Trennbarkeit | 后处理 |

### 2.3 立场与意图分析：三层分离表（模板卡核心）

**中文理解**：材料题里的「作者观点」不能直接当事实用。先把材料拆成**三层**，再谈判断。

| 层 | 名称 | 问什么 | 产出 |
|---|---|---|---|
| **① Faktenebene** | 事实层 | 材料中哪些是**可检验**的化学事实/数据？ | 引材料原句或数据 |
| **② Wertebene** | 价值层 | 作者诉诸哪些**价值/规范**（环保、健康、经济、进步…）？ | 列出 1–2 个价值词 |
| **③ Intentionsebene** | 意图层 | 作者**为何**这样写？想推动读者做什么？（Wortwahl / 情感词 / 省略） | 一句话意图 + 语言策略 |

> ⚠️ **铁律**：立场 ≠ 事实。把作者的价值主张当成化学事实来「证明」，是化学评价题的头号失分点 [据推断，依 KLP「禁止无材料依托」推导]。

> *Klausur-Satz*: *Der Autor stützt seine Position auf das Argument …, verschweigt jedoch …; seine Intention besteht offenbar darin, den Leser zu …*

### 2.4 多视角 + 行为选项（B1–B11 的落点）

- **多视角**：同一事态至少从**两个**视角看（如「生态 vs 经济」「健康 vs 便利」），各给一条有据结论。
- **行为选项**：评价的**收尾必须是可执行选项**（`Handlungsoptionen`），不能止于「有好有坏」。

> *Klausur-Satz*: *Aus ökologischer Perspektive ist … zu empfehlen, während aus wirtschaftlicher Sicht …; als Handlungsoption ergibt sich daher …*

## 3. 解题方法 (Methoden)

### 3.1 评价题五步法（`bewerten` / `beurteilen` 通用）

1. **定判断类型**：题目用 `beurteilen` 还是 `bewerten`？—— *KLP 工具：Operatoren 二分（Sach- vs Werturteil）*
2. **列标准清单**：从 §2.2 选 2–3 条适用标准，写下来再落笔。—— *KLP 工具：`kriteriengeleitet`（B5–B11）*
3. **回扣材料**：每条结论前写「aus dem Material folgt …」，引数据/原句。—— *KLP 工具：化学禁止无材料依托 [已验证]*
4. **多视角各一条**：至少两个视角，各给一条有据结论。—— *KLP 工具：`multiperspektivisch`（B1–B4）*
5. **收尾给行为选项**：一句 `Als Handlungsoption …`。—— *KLP 工具：Handlungsoption（B11）*

> **判据 / 决策点**：题干出现 `beurteilen` → **只准用专业标准**，写「sollte」会越界；出现 `bewerten` → **必须叠价值层**，只列化学数据会判为「未达 Werturteil」。

### 3.2 立场与意图分析六步（`analysieren` 材料题专用）

1. **定位 These**：作者的核心主张是哪句？—— *KLP 工具：`analysieren`（提炼重要组成部分）*
2. **提 Argumente**：用了哪些论据？引了哪些数据？—— *KLP 工具：K1–K4（信息 erschließen）*
3. **分层**：填入 §2.3 三层分离表（Fakten / Werte / Intention）。—— *KLP 工具：Bewertungskompetenz*
4. **识别语言策略**：情感词、夸张、选择性省略。—— *KLP 工具：`analysieren`*
5. **对照第二来源**：与另一份材料/数据比较。—— *KLP 工具：`multiperspektivisch`*
6. **给出自己的判断**：先 Sachurteil，必要时再 Werturteil。—— *KLP 工具：`beurteilen` → `bewerten`*

## 4. 🇨🇳 CN-Methode

### CN-Methode: 不适用（该科无中国对等技法）；仅可借 STSE 多视角讨论
- **说明**：中国课标以 5 项核心素养中的「**科学态度与社会责任**」承载价值侧内容，属**能力素养**，**不做 Sach-/Werturteil 的显式二分**，也无「分析作者立场与叙述意图」的法定任务 [据推断]。德国把评价拆成 B1–B14 的**可评分条目**，中国侧无对应框架。
- **DE-Anschluss**：无对等框架。可**部分借用**的是中国 STSE（科学-技术-社会-环境）式的**多视角罗列习惯**（先摆各视角再下结论），它天然接近 `multiperspektivisch`，但**不提供** Sach/Wert 的分界与 `Handlungsoption` 的写法。
- **合规性**：⚠️ **不可嫁接框架本身** —— 只能借用「先列视角再判断」的**书写习惯**；Sach-/Wert 二分与意图分析**必须按德国原文重建**（本笔记即为此目的）。
- **Abitur 应用**：EF-1-E-02（溶剂/乙醇/可持续性）、EF-2-E-02（干预物质循环的立场与意图）、Q4-C-02（纳米机遇风险 + 作者意图）。
- **来源**：`[CN-课标]`（用于说明「无对等」这一结论）。

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|
| Aufgabenart | I `Materialgebundene Aufgabe`（**必须绑定材料**） |
| Operator | `beurteilen` / `bewerten` / `analysieren` / `diskutieren` |
| AFB | II（多视角、有标准）→ III（立场意图分析 + 决策反思） |
| 建议分值 / 时长 | 单题 10–15 BE |

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> Ein Hersteller wirbt: „Unser neues Reinigungsmittel ist umweltfreundlich, weil es vollständig biologisch abbaubar ist." Weitere Angaben fehlen.
> **a)** Beurteilen Sie die Aussage anhand fachlicher Kriterien (Sachurteil).
> **b)** Bewerten Sie, ob die Werbung als Grundlage einer Kaufentscheidung ausreicht (Werturteil).

**Aufgabe 2** `[NRW-改编]`
> Zwei Quellen zur Ammoniaksynthese: Quelle A betont den Nutzen für die Düngemittelversorgung, Quelle B die CO₂-Emissionen.
> **a)** Analysieren Sie die Position und die Intention beider Quellen (Dreischichttabelle: Fakten / Werte / Intention).
> **b)** Formulieren Sie eine multiperspektivische Beurteilung und nennen Sie eine Handlungsoption.

**Aufgabe 3** `[原创]`
> Ethanol kann als Kraftstoff („E10") oder als Lösungsmittel in Kosmetika eingesetzt werden.
> **a)** Erstellen Sie eine Kriterienliste für die Bewertung beider Verwendungen.
> **b)** Führen Sie je ein Sachurteil pro Verwendung durch.

**Aufgabe 4** `[CN-改编]`
> Ein Artikel behauptet, Nanopartikel in Sonnencreme seien „völlig ungefährlich", ohne Quellen zu nennen.
> **a)** Prüfen Sie die Behauptung, indem Sie Fakten- und Werteebene trennen.
> **b)** Bestimmen Sie die Intention des Autors und diskutieren Sie, welche Informationen zur Bewertung fehlen.

### 5.3 Musterlösung

**Aufgabe 1**
1. a) **Sachurteil**: „biologisch abbaubar" 只支持**可降解性**这一条；缺 **Toxizität**（中间产物）、**Ökotoxizität**、**Verpackung/Energie** 等标准 → 仅凭此**不能**支撑「umweltfreundlich」全称判断 ✓ 得分点（**点明标准清单**）
2. b) **Werturteil**: 引入**Nachhaltigkeit** 与 **Verbraucherschutz** 规范；信息不完整 → **作为 Kaufentscheidung 依据不充分**；`Handlungsoption`：要求完整 Sicherheitsdatenblatt / unabhängige Prüfung ✓ 得分点（**含 sollte/选项**）

**Aufgabe 2**
1. a) **Dreischichttabelle**：A — Fakten: Düngemittelversorgung；Werte: Ernährungssicherheit；Intention: 支持继续生产。B — Fakten: CO₂-Emissionen；Werte: Klimaschutz；Intention: 推动减排 ✓
2. b) **multiperspektivisch**: 生态视角（排放高）↔ 经济/社会视角（粮食安全）；`Handlungsoption`: 使用 grüner Wasserstoff + 提高能效 ✓ 得分点（**两视角 + 选项**）

**Aufgabe 3**
1. a) Kriterien: Energieeffizienz, CO₂-Bilanz, Rohstoffkonkurrenz (Nahrung vs. Treibstoff), Toxizität, Löslichkeit ✓
2. b) **Sachurteil Kraftstoff**: 由 CO₂-Bilanz 与 Rohstoffkonkurrenz 判「争议较大」；**Sachurteil Lösungsmittel**: 由 Löslichkeit 与 Toxizität 判「在替代溶剂下可优化」 ✓ 得分点（**两判断均只用专业标准，不出现「应该」**）

**Aufgabe 4**
1. a) Faktenebene: 无来源、无 Größenangabe、无 Langzeitstudie → 无法检验；Wertebene: „völlig ungefährlich" 是**价值化措辞**而非化学事实 ✓ 得分点（**指出立场≠事实**）
2. b) **Intention**: 安抚消费者 / 促销；**fehlende Informationen**: Partikelgröße, Konzentration, Aufnahme über Haut, Studienlage → 需补后方可 `bewerten` ✓

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把 `beurteilen` 写成 `bewerten`（或反之）；把作者立场当化学事实 | 落笔前先判动词；先过三层分离表 |
| 知识错 | 只列化学数据就收尾（未达 Werturteil）；只给单一视角 | 至少两视角 + 一条 `Handlungsoption` |
| 表达错 | 脱离材料自说自话（化学明文禁止）；缺标准清单直接下结论 | 每条结论前写 `aus dem Material folgt …`；先列标准 |
