# Sicherheit und Bewertung im Labor (实验室安全写成 Bewertung · B11)

> **中文理解**：德国化学 KLP 有一条容易被忽略的能力要求——`Bewertungskompetenz` 的 **B11「评价实验室与日常安全并导出行为选项」** [据推断，属 KLP 第 2.1.1 章 B5–B11「kriteriengeleitet Meinungen bilden und Entscheidungen treffen」组]。关键词是「**评价**」：安全不只是「背几条规则」，而是要**用专业标准把风险与收益摆开、给 Schutzmaßnahmen、最后给行为选项**——写成一段可评分的 `Bewertung`。这恰好是中国学生的**双向缺口**：中国有 18 个必做实验与安全规范（不缺「做过什么」），但**安全不进评价维度** [据推断，Mapping X-10]；德国正好反过来。
>
> **Klausur-Relevanz**：`fachpraktische Aufgabe`（Aufgabenart II）与所有涉及 Gefahrstoffe 的材料题都可能追问「安全地实施」。它属 AFB II（有标准地判断）到 AFB III（权衡 + 决策反思），且**必须绑定具体实验情境**（化学明文禁止无实验依托的题目 [已验证]）。

## 1. 核心概念 (Kernbegriffe)

| 术语 (DE) | 中文 | English | 定义 / 公式 | 备注 |
|---|---|---|---|---|
| Gefahrstoff | 危险物质 | hazardous substance | 有 H-/P-Satz 标识的物质 | CLP/GHS |
| Gefahrenpiktogramm | 危险符号 | hazard pictogram | GHS01–GHS09 菱形符号 | 见 §2.2 |
| H-Satz | 危险说明 | hazard statement | 描述危险的编码语句 | 旧称 R-Satz |
| P-Satz | 防范说明 | precautionary statement | 描述防护措施的编码语句 | 旧称 S-Satz |
| Sicherheitsdatenblatt (SDB) | 安全数据表 | safety data sheet | 物质安全信息的法定文件 | 材料题常给摘录 |
| Schutzmaßnahme | 防护措施 | protective measure | 技术/组织/个人三层 | 见 §2.3 |

| Nutzen-Risiko-Abwägung | 收益-风险权衡 | benefit-risk assessment | 有标准地权衡后决策 | Bewertung 核心 |

## 2. 知识结构 (Struktur)

### 2.1 为什么安全是「Bewertung」而不是「规则清单」

**中文理解**：背规则只能命中 AFB I。要命中 B11，必须走 `kriteriengeleitet` 的完整评价链：**识别危险 → 列 Schutzmaßnahmen → 权衡 → 给行为选项**。

> *Klausur-Satz*: *Die Sicherheit im Labor wird nicht nur durch Regeln gewährleistet, sondern muss kriteriengeleitet beurteilt werden, indem Gefahren, Schutzmaßnahmen und Nutzen gegeneinander abgewogen werden.*

### 2.2 GHS 危险符号（速认表）

| 符号 | 德语名 | 中文 | 典型场合 |
|---|---|---|---|
| GHS02 | Flamme | 易燃 | 乙醇、乙醚等有机溶剂 |
| GHS03 | Flamme über Kreis | 氧化性 | 过氧化氢、硝酸盐 |
| GHS05 | Korrosion | 腐蚀 | 浓硫酸、NaOH |
| GHS06 | Totenkopf | 剧毒 | 氰化物等 |
| GHS07 | Ausrufezeichen | 刺激性/有害 | 稀酸、部分盐 |
| GHS08 | Gesundheitsgefahr | 健康危害 | 致癌/致敏物 |
| GHS09 | Umwelt | 环境危害 | 重金属盐、杀虫剂 |

> ⚠️ **易错**：GHS05（腐蚀）≠ GHS07（刺激）；GHS02（易燃）≠ GHS03（氧化性，助燃）。材料题常靠这两个对比设陷阱。

### 2.3 三层 Schutzmaßnahmen（P-Satz 的归类逻辑）

| 层 | 德语 | 例子 |
|---|---|---|
| 技术层 | technische Maßnahmen | Abzug（通风橱）、Augendusche、Notdusche |
| 组织层 | organisatorische Maßnahmen | 只做允许的实验、教师在场、废物分类 |
| 个人层 | persönliche Maßnahmen | Schutzbrille、Laborkittel、Handschuhe |

**五条必背操作规则** [据推断，为德国学校实验室通行规则]：
1. **Schutzbrille** 全程佩戴。
2. 挥发性/有毒气体操作在 **Abzug** 内。
3. **绝不用嘴吸取**液体（用 Pipettierhilfe）。
4. 稀释浓酸：**酸入水**（„Erst das Wasser, dann die Säure, sonst geschieht das Ungeheure."）。
5. 可燃溶剂附近**无明火**；长发束起。

### 2.4 处置（Entsorgung）按类别

- **Organische Lösungsmittel** → 有机废液桶（**不得**倒入水槽）。
- **Schwermetallsalze**（如 Cu²⁺、Ag⁺）→ 重金属废液。
- **Säuren / Basen** → 中和后按规处置。
- ⚠️ **不得混桶**：氧化剂与有机废液混放可能自燃。

> *Klausur-Satz*: *Die anfallenden Reste werden nach Abfallgruppen getrennt entsorgt; Lösungsmittel dürfen nicht in den Abfluss gegeben werden.*

## 3. 解题方法 (Methoden)

### 3.1 安全评价五步法（把安全写成 `Bewertung`）

1. **定情境**：实验要做什么？用哪些 Gefahrstoffe？—— *KLP 工具：`beschreiben`（结构化）+ 材料*
2. **识危险**：查 Piktogramm 与 H-Satz，写出 1–3 条具体危险。—— *KLP 工具：GHS/H-Satz 系统*
3. **列措施**：技术 / 组织 / 个人三层各至少一条。—— *KLP 工具：P-Satz*
4. **权衡**：用标准（Nutzen、Risiko、Machbarkeit）作 `Nutzen-Risiko-Abwägung`。—— *KLP 工具：`kriteriengeleitet`（B5–B11）*
5. **给行为选项**：一句 `Als Handlungsoption …`。—— *KLP 工具：Handlungsoption（B11）*

> **判据 / 决策点**：题目若说 `bewerten` → 必须含价值权衡；若说 `planen` → 措施要具体到可执行（哪个 Abzug、什么手套）；只写规则清单 = 未达 AFB II。

### 3.2 `planen`（实验方案）中的安全嵌入

1. 写 **Fragestellung / Hypothese**。—— *KLP 工具：E1–E3*
2. 写 **Durchführung** 时**同步**标注安全措施（而非末尾补一段）。—— *KLP 工具：`planen`（开发并记录解决路径）*
3. 写 **Entsorgung**。—— *KLP 工具：Entsorgung*
4. 写 **Gefährdungsbeurteilung** 一句。—— *KLP 工具：Gefährdungsbeurteilung*

## 4. 🇨🇳 CN-Methode

### CN-Methode: 不适用（框架不对等）；仅可借实验操作熟练度
- **说明**：中国课标必修 1.4「科学态度与安全意识」+ 附录 3 的 **18 个必做实验硬性清单**（必修 9 + 选必 9）[据推断，Mapping X-10]。中国**不缺安全规范与实验经验**，但安全**不进入评价维度**——不要求「把安全写成 Bewertung」。
- **DE-Anschluss**：无对等评价框架。可**部分借用**的是中国训练出的**实验操作熟练度**（可直接迁移到 `fachpraktische Aufgabe`），但**清单机制本身无价值**（德国**无必做实验清单** [已验证]）。
- **合规性**：⚠️ **只借操作熟练度，不借清单机制** —— 不得以「中国做过某实验」替代「按德国要求评价安全」。
- **Abitur 应用**：`fachpraktische Aufgabe`（Aufgabenart II）；所有 Gefahrstoffe 材料题。
- **来源**：`[CN-课标]`（用于说明「无对等」这一结论）。

## 5. Klausur-Training

### 5.1 官方题型定位

| 项 | 内容 |
|---|---|

### 5.2 训练题

**Aufgabe 1** `[NRW-改编]`
> Für einen Versuch soll konzentrierte Schwefelsäure mit Wasser verdünnt werden. Ein Sicherheitsdatenblatt weist H314 (verursacht schwere Verätzungen) und P280 (Schutzhandschuhe/Augenschutz tragen) aus.
> **a)** Nennen Sie die Gefahrenpiktogramme, die für konzentrierte Schwefelsäure zutreffen.
> **b)** Bewerten Sie zwei Durchführungsvarianten: (i) Wasser in die Säure geben, (ii) Säure in das Wasser geben.

**Aufgabe 2** `[原创]`
> Ein Schülerexperiment nutzt Ethanol als Lösungsmittel, daneben steht eine offene Gasbrennerflamme.
> **a)** Beurteilen Sie die Gefährdung anhand von Piktogramm und H-Satz.
> **b)** Entwickeln Sie drei Schutzmaßnahmen (technisch/organisatorisch/persönlich) und eine Handlungsoption.

**Aufgabe 3** `[NRW-改编]`
> Nach einer Fällungsreaktion mit Kupfer(II)-sulfat-Lösung bleibt ein kupferhaltiger Rest.
> **a)** Beschreiben Sie die sachgerechte Entsorgung.
> **b)** Bewerten Sie die Alternative „in den Abfluss geben" mit fachlichen Kriterien.

**Aufgabe 4** `[CN-改编]`
> Für die Synthese von Essigsäureethylester (konz. H₂SO₄ als Katalysator, Erhitzen) soll ein Versuchsprotokoll erstellt werden.
> **a)** Planen Sie die Durchführung inklusive Sicherheitsmaßnahmen und Entsorgung.
> **b)** Formulieren Sie eine abschließende Gefährdungsbeurteilung.

### 5.3 Musterlösung

**Aufgabe 1**
1. a) **GHS05 (Korrosion)** 明确；若浓度高亦可涉 **GHS07** ✓ 得分点
2. b) Variante (i) **不可**：水入浓酸 → 局部剧烈放热 → **喷溅/暴沸** ✓；Variante (ii) **可行**：酸缓慢入水并搅拌、冷却 ✓ 得分点（**必须给出方向理由**）
3. 规则句：*„Erst das Wasser, dann die Säure."* ✓

**Aufgabe 2**
1. a) **GHS02 (Flamme)**：乙醇易燃；明火 → **Brand-/Explosionsgefahr** ✓ 得分点
2. b) technisch：**Abzug** 或移开明火；organisatorisch：改用 Heizplatte、小量操作；persönlich：Schutzbrille ✓
3. **Handlungsoption**：用 Heizplatte 替代明火，并在 Abzug 内操作 ✓ 得分点（**三层齐全 + 选项**）

**Aufgabe 3**
1. a) 铜盐属 **Schwermetallsalze** → 收集入**重金属废液桶**，不得倒入水槽 ✓ 得分点
2. b) `beurteilen`：从 **Gewässergefährdung (GHS09)** 与 **Recht** 两标准 → 「倒入水槽」**不可接受** ✓ 得分点（**只用专业标准**）

**Aufgabe 4**
1. a) Durchführung：乙醇 + 冰醋酸 + 少量 konz. H₂SO₄，**Rückflusskühler** 加热；Schutz：**Abzug + Schutzbrille + Handschuhe**；Entsorgung：有机废液 + 中和酸性残余 ✓
2. b) Gefährdungsbeurteilung：H₂SO₄ korrosiv、乙醇 entzündbar → 需 Abzug 与无明火；**Restrisiko** 由教师在场与量小控制 ✓ 得分点（**含权衡与措施对应**）

## 6. Fehlerquellen（典型错误）

| 类型 | 表现 | 对策 |
|---|---|---|
| 辨别错 | 把 GHS05（腐蚀）与 GHS07（刺激）混淆；把「水入酸」当成同样可行 | 记符号-危险配对；方向规则「酸入水」 |
| 知识错 | 认为「倒入水槽」只需用水冲淡即可；把有机废液与氧化剂混桶 | 按 Abfallgruppe 分类；氧化剂单放 |
| 表达错 | 只列规则清单，无权衡、无 Handlungsoption（未达 B11） | 走五步法；末尾必写 `Als Handlungsoption …` |
